Задача: **$1**

Запусти субагента `multica-orchestrator` и передай ему: проверить готовность задачи `$1` по
`docs/multica/operating-model.md` §4 и правило единственного writer по §5.

Оркестратор обязан вернуть по каждому из пяти условий §4 отдельную строку «выполнено / не
выполнено» со ссылкой на файл, а затем общий вердикт «задачу можно брать» либо «нельзя» с
причиной, и предложенную последовательность стадий из шапки задачи.

Ничего не реализуй в этом заходе. Если вердикт «нельзя» — на этом остановись и покажи причину.
Если задача имеет параллельность «нет: меняет продуктовый код», отдельно покажи результат
проверки активной кодовой цепочки: ветку, незакоммиченные изменения в `server/`, `web/`,
`packages/`.

Напомни: статус `готова` ставит только владелец. Ты его не ставишь ни при каких условиях.
