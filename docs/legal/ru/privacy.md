## 3. Перечень обрабатываемых персональных данных

Оператор обрабатывает следующие персональные данные:

| Данные | Цель | Срок хранения |
|---|---|---|
| Адрес электронной почты | Идентификация, уведомления | Весь срок действия аккаунта + период архива |
| Имя (отображаемое) и хэндл | Отображение профиля автора | Весь срок действия аккаунта + период архива |
| Аватар (загруженное изображение) | Отображение профиля | Весь срок действия аккаунта + период архива |
| IP-адрес и user-agent сессии | Безопасность, защита от злоупотреблений | Срок хранения журнала сессий |
| `visitorId` (идентификатор посетителя, см. раздел [#cookies](#cookies)) | Подсчёт аудитории | 2 года |
| Диагностический IP событий вовлечённости | Статистика чтения, защита от ботов | Срок хранения событий вовлечённости |
| Данные обращений в поддержку (текст обращения, email) | Ответ на обращение | Срок хранения обращений |
| Идентификаторы и суммы платежей (при включении платности) | Учёт платежей, возвраты | По законодательству о бухгалтерском учёте |

3.1. Платформа **не** использует трекеры третьих сторон, не осуществляет поведенческое
профилирование и не передаёт персональные данные рекламным сетям.

3.2. При передаче текста статьи AI-провайдеру для автоматической проверки допустимости
(Правила публикации) текст передаётся **без имени и адреса электронной почты** автора.

## 4. Цели обработки персональных данных

- предоставление доступа к функциям Платформы (регистрация, публикация);
- обеспечение безопасности и защиты от злоупотреблений;
- измерение аудитории без идентификации конкретных лиц;
- ответ на обращения Пользователей;
- соблюдение требований законодательства Российской Федерации.

---

## 5. Правовые основания обработки

- согласие субъекта персональных данных (ст. 6 ч. 1 п. 1 152-ФЗ) — для всех данных, собираемых
  при регистрации;
- исполнение договора (ст. 6 ч. 1 п. 5 152-ФЗ) — для обеспечения работы Платформы;
- законные интересы Оператора (ст. 6 ч. 1 п. 7 152-ФЗ) — для безопасности и статистики.

---

## 6. Передача персональных данных третьим лицам

6.1. Оператор передаёт персональные данные третьим лицам только в следующих случаях:

- **Почтовый провайдер**: адрес электронной почты Пользователя для отправки системных
  уведомлений и магических ссылок.
- **AI-провайдер**: текст статьи (без имени и email) для проверки допустимости содержания
  и AI-перевода.
- **Платёжный провайдер** (при включении платности): данные, необходимые для проведения
  платежей; данные банковских карт хранятся у платёжного провайдера.
- **По требованию законодательства**: при наличии законного основания (судебный запрос,
  требование уполномоченных органов).

6.2. Оператор не продаёт персональные данные Пользователей третьим лицам.

---

## 7. Хранение данных

7.1. Данные Пользователей хранятся на серверах на территории Российской Федерации в
соответствии с требованиями ст. 18 ч. 5 152-ФЗ.

7.2. Сервисы разработки (Neon PostgreSQL для разработки) не содержат персональных данных
реальных пользователей.

---

## 8. Cookie и идентификатор посетителя {#cookies}

8.1. Платформа устанавливает **`visitorId`** — случайный идентификатор посетителя в виде
файла cookie первой стороны (first-party cookie) сроком на два года.

8.2. Этот идентификатор используется исключительно для подсчёта аудитории Платформы: он
позволяет отличить повторный визит от нового, не устанавливая личность посетителя. Идентификатор
не передаётся третьим сторонам, не используется для отслеживания Пользователя на других сайтах и
не является инструментом таргетированной рекламы.

8.3. Помимо `visitorId`, Платформа использует технические файлы cookie, необходимые для
обеспечения сессий (например, для сохранения состояния входа). Эти cookie не содержат
персональных данных сверх необходимого минимума.

8.4. Форма уведомления о cookie и необходимость баннера согласия уточняются по итогам
юридической консультации `[ДОПУЩЕНИЕ — требует проверки юриста]`.

## 9. Права субъекта персональных данных

Пользователь вправе:

9.1. **Получить информацию** об обрабатываемых данных, обратившись через `/contact?topic=privacy`.

9.2. **Экспортировать свои данные** через `/me/export`. Экспорт доступен в любое время.

9.3. **Удалить аккаунт** через `/me/delete` (обратимое архивирование) или запросить
окончательное удаление через службу поддержки. При окончательном удалении финансовые записи
сохраняются в обезличенной форме («надгробие записи») в соответствии с требованиями
законодательства.

9.4. **Отозвать согласие** на обработку персональных данных. Отзыв согласия означает
невозможность использования аккаунта; Пользователь вправе удалить аккаунт в момент отзыва.

9.5. **Обратиться с жалобой** в Роскомнадзор (Федеральная служба по надзору в сфере связи,
информационных технологий и массовых коммуникаций).

## 10. Изменение Политики

10.1. Оператор вправе вносить изменения в настоящую Политику. Изменения, затрагивающие
существенные условия обработки, доводятся до сведения Пользователей при следующем входе.

10.2. Актуальная версия Политики публикуется на странице `/legal/privacy`. Предыдущие версии
доступны по запросу.
