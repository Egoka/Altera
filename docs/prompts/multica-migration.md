# Промпты корректировки Multica

- **Статус**: подготовлены для C0–C6; чтение/план не разрешает менять настройки.
- **План**: [корректировки](../plans/2026-09-13-multica-corrections.md).
- Каждый блок самодостаточен и копируется целиком. Он поручает подготовить точное изменение
  поля по актуальному snapshot, сохраняя уникальные правила; это не универсальная замена system prompt.
