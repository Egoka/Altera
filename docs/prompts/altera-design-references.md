# Altera — промты для Claude Design

Файл состоит из трёх частей:

- **Часть I — инструкция.** Как вести разговор с дизайнером и что приложить. Не копируется.
- **Часть II — промты.** Пронумерованные блоки в ограждениях. Каждый блок — одно сообщение
  Claude Design, копируется целиком и отправляется как есть. Перед блоком стоит серая строка
  «Источники» и «Приложить» — она **не копируется**, она для проекта.
- **Часть III — справочник.** Разборы референсов, правила пополнения реестра, источники истины.
  Вставляется по требованию, не по расписанию.

# Часть I — инструкция

## Порядок разговора

Все промты — сообщения **одного** разговора, по порядку. Контекст первого сообщения действует
дальше, поэтому блоки 2 и следующие не повторяют его целиком.

| Промт | Что получаем |
|---|---|
| 1 | Контекст, границы, дизайн-система, реестр референсов. В ответ — список механизмов, без макетов |
| 2 | Медийные паттерны `D1`–`D6` |
| 3 | Паттерны `D7`–`D12` |
| 4 | UI-кит `K1`–`K6` |
| 5 | Главная — `P1`, `P2` |
| 6 | Материал — `P3`, `P4`, `P5` |
| 7 | Лента рубрики — `P6` |
| 8 | Страница автора — `P7` |
| 9 | Списки рубрик, тегов, авторов — `P8` |
| 10 | Поиск — `P9` |
| 11 | Цены — `P10` |
| 12 | Вход — `P11` |
| 13 | Служебные страницы — `P12` |
| 14 | Тёмная тема — `P13` |
| 15 | Обзор системы — `P14` |
| 16 | Приёмка |

Порядок не переставляется: паттерны → кит → страницы. Кит, собранный до паттернов, повторит то,
что уже есть в проекте; страницы, собранные до кита, разойдутся между собой.

Промты 7–15 можно отложить: обязательный минимум — с 1 по 6, он покрывает главную и материал,
то есть две страницы, на которых держится журнал.

## Что приложить к первому сообщению

1. **Файлы гарнитур** — `web/app/assets/fonts/`: `Waterway Display Font`, `Garamond Libre Font
   Family`, `Cormorant SC`, `Bergamasco`. Без них макеты отрисуются системной засечкой, и
   проверять будет нечего.
2. **Логотип** — `web/app/assets/AlteraLogo.svg`, **с оговоркой** «вот что есть сейчас, можно
   предложить иное». Приложенный как константа, он молча закрепит айдентику, которую никто не
   утверждал.
3. **Демонстрационный контент** — фиксированный набор русских заголовков, деков, имён авторов и
   один длинный текст. Без него каждый артборд получит свой выдуманный контент, и сравнить макеты
   между собой будет нельзя. Отдельная задача, отдельный файл.
4. **Скриншоты двух-трёх референсов** — если дизайнер не может открыть сайты сам.

Изображений в проекте почти нет. Либо приложи свой набор с понятной лицензией, либо оставь в
промте требование ставить серые блоки с подписью соотношения сторон — оно там есть. Брать
изображения с сайтов-референсов нельзя.

## Правило, которое держит весь разговор

Границы разделены на три уровня, и они описаны в промте 1. Главное в них — **отклонение от
уровня 2 называется вслух**: дизайнер показывает оба варианта рядом и называет причину. Молча
воспроизвести унаследованное и молча его выбросить одинаково неверно, потому что выбор гарнитур,
палитры и мер — решение владельца, а для решения он должен увидеть выбор.

Если ответ дизайнера нарушает уровень 1 — не спорь в переписке, вставь блок 16 «Приёмка».

# Часть II — промты

## Промт 1 · Контекст, границы и дизайн-система

> **Источники**: `docs/vision/06-design-system.md` §2–§4, §10; `docs/spec/00-registries/routes.md`;
> продуктовые ограничения — рабочий журнал решений §20.5, §21.18, §21.30, ADR-0036, ADR-0021,
> ориентир ADR-0043. Уровень 2 обоснован тем, что ADR о типографике нет, а в журнале Г1–Г9 слов
> «гарнитура», «шрифт», «палитра», «акцентный» нет вовсе.
> **Приложить**: файлы гарнитур, логотип с оговоркой, демонстрационный контент.

````text
Ты проектируешь дизайн культурного онлайн-журнала Altera. Это первое сообщение: контекст,
границы и материал. Ничего не рисуй в ответ на него — задание будет следующим сообщением.

## Что такое Altera

Двуязычный (русский и английский) культурный и познавательный онлайн-журнал. Продукт держится
на материалах, их авторах, рубриках и тегах. Нужен дизайн полноценного редакционного издания:
выразительного, интеллектуального, современного и удобного для продолжительного чтения.

## Продуктовые правила — не обсуждаются

| Правило | Следствие для дизайна |
|---|---|
| Чтение бесплатное и полное; платит автор за возможность публиковаться | Ни замков, ни «осталось 2 статьи», ни обрезанного текста |
| Платная стена зарезервирована и не реализуется | Не рисовать заглушки платного доступа |
| Чисел рейтинга читатель не видит никогда | Никаких баллов, процентов, позиций в топе цифрами |
| Счётчик прочтений показывается только от ста, округлённо | «1,2K прочтений», но не «7 прочтений» |
| Число подписчиков автора — тоже только от ста, и позже | Нужны оба состояния: показано и скрыто |
| Комментариев в продукте нет | Не проектировать ветку обсуждения |
| Жалобы и рассылки отложены | Кнопок «пожаловаться» и «подписаться на письма» нет |
| Языки не смешиваются в одной ленте | Переключатель языка — только при опубликованной парной версии |
| Блок «Популярное» появится позже | Зона проектируется, но показывается и в состоянии «скрыта» |
| Личный кабинет и админка — на готовой библиотеке компонентов | Сейчас проектируем только публичный сайт |

## Границы: три уровня свободы

Задача — не применить готовую систему к страницам, а вывести систему из референсов.

Уровень 1 — зафиксировано, не обсуждается:
- продуктовые правила выше;
- состав зон и состояний каждой страницы, который я дам в задании на эту страницу;
- имена токенов (--color-paper, --color-ink, --color-ink-muted, --color-accent, --color-rule,
  --color-surface) и имена вариантов карточки (lede, large, small, rank) — это идентификаторы
  в коде, а не внешний вид;
- требования доступности и стоп-лист ниже.

Уровень 2 — пересматривается с аргументом. Это пришло из текущей сборки проекта, а не из
отдельного решения владельца:
- набор из четырёх гарнитур и распределение ролей между ними;
- акцентный тон — оранжево-красное семейство;
- ширина контейнера и мера текста.

Правило уровня 2: отклонение называется вслух. Если вывод паттернов требует другой роли
гарнитуры, другого акцента или другой меры — покажи оба варианта рядом и назови причину. Молча
воспроизвести унаследованное и молча его выбросить — одинаково неверно: решение принимает
владелец, и он должен увидеть выбор.

Уровень 3 — свободно: композиция, масштабы, вертикальный ритм, отношения текста и изображения,
характер издания. Это предмет работы, здесь наследовать нечего.

## Характер: что здесь значит «модный и профессиональный»

Современность даёт редакционная типографика и работа с изображением, а не эффекты.

- Крупный масштаб и сильный контраст кеглей. Ведущий заголовок на десктопе заметно крупнее
  всего остального; расстояние между уровнями иерархии читается мгновенно, без чтения текста.
- Капитель в служебных ролях. Кикер рубрики, байлайн, подпись к изображению — прописными с
  разрядкой. Это главный узнаваемый приём издания.
- Волосяные линейки вместо контейнеров. Материалы разделяются воздухом, типографикой и линиями.
  Карточек с тенями, рамками и заливками на публичном сайте нет.
- Асимметрия внутри строгой сетки. Ведущий материал занимает неравную долю, соседние блоки
  выравниваются по общим направляющим. Асимметрия — решение композиции, а не случайность.
- Скупой акцент. Цвет работает на функциональных элементах: активная рубрика, ссылка при
  наведении, бейдж автора. Не фон секции, не заголовок, не декоративное пятно.
- Изображение получает место. Обложка материала и «полная ширина» внутри текста — полноценные
  композиционные события, а не иллюстрации-миниатюры.
- Ноль лексики продуктовых лендингов: никаких трёх иконок с преимуществами, мягких скруглений,
  градиентных кнопок и плиток равной высоты.

Проверка характера: если убрать изображения, страница должна остаться выразительной за счёт
одной типографики. Если это не так — иерархия слабая.

## Цветовые токены

Одна семантическая палитра. Имена менять нельзя, значения — свободны.

| Токен | Назначение | Светлая | Тёмная |
|---|---|---|---|
| --color-paper | фон страницы | тёплый белый | почти чёрный |
| --color-ink | основной текст | почти чёрный | тёплый белый |
| --color-ink-muted | подписи, даты, служебное | серый | серый |
| --color-accent | активная рубрика, ссылка при наведении, бейдж автора | оранжево-красное семейство | приглушённое |
| --color-rule | линейки и разделители | светло-серый | тёмно-серый |
| --color-surface | поля форм, поверхности приложения | | |
| --color-success, --color-warning, --color-danger | состояния | | |

Следствие правила контраста: #ff5a1f даёт на белом примерно 3,1 : 1 — этого хватает крупному
тексту и элементам интерфейса, но не хватает ссылке в основном тексте. Для текстового акцента
нужна тёмная ступень того же семейства, около #d03801 — это примерно 4,9 : 1. Конкретные
ступени выбираешь ты.

Не вводи вторую палитру: в текущей сборке проекта две одинаковые палитры — это дефект, который
дизайн закрывает, а не воспроизводит. Не добавляй чужеродный зелёный в редакционные блоки.

## Типографика

Четыре гарнитуры приложены к этому сообщению. Отправная точка — раскрыть их, а не подбирать
новые: файлы уже в проекте и проверены на кириллице. Если вывод паттернов требует иного
распределения ролей или иной гарнитуры в одной из ролей — это допустимо по правилу уровня 2:
покажи оба варианта и назови причину.

| Роль | Гарнитура | Где |
|---|---|---|
| Заголовки страниц и названия секций | Waterway | шапки рубрик, авторов, подписи секций главной |
| Заголовки материалов и карточек, дек, основной текст | Garamond Libre | страница материала, все карточки |
| Кикеры, байлайны, подписи к изображениям, метки | Cormorant SC (капитель) | рубрика на карточке, автор, подпись к фото |
| Логотип | Bergamasco | только логотип, больше нигде |
| Интерфейс: навигация, кнопки, формы, пагинация | системный гротеск | шапка, футер, элементы управления |

Шкала и ритм:
- основной текст материала 1,125–1,25 rem, интерлиньяж 1,6–1,7, мера 65–75 знаков;
- заголовки по модульной шкале 1,25 от базового;
- вертикальный ритм кратно 4 px; расстояние до заголовка всегда больше расстояния после него;
- капитель — прописными с разрядкой примерно 0,06–0,10 em, кегль мелкий.

Проверяй на кириллице. Все демонстрационные заголовки русские, включая длинный — три строки в
ведущей карточке — и очень короткий, в одно слово. Гарнитуры имеют разную высоту строчных и
по-разному ведут себя на прописных; макет обязан выдержать оба случая без ручной подгонки.

## Сетка и точки перелома

Одна схема на весь сайт — это уровень 1. Конкретные значения — уровень 2.
- контейнер 1280, горизонтальные отступы 16 / 24 / 32 по мере роста экрана;
- мера текста материала — около 768;
- сетка карточек 1 / 2 / 3 колонки; точки перелома 640, 768, 1024, 1280.

## Медиа — вторая половина задачи

Журнал держится на тексте и на изображении. Проектируй оба.

- Три ширины изображения в материале: по мере текста, «широкая» — до контейнера, «полная» — во
  всю ширину окна. У каждой своя логика подписи.
- Подпись и атрибуция обязательны: подпись капителью, атрибуция мельче и приглушённым цветом.
  Это отдельный типографический элемент, а не серый текст под картинкой.
- Варианты файлов 480 / 960 / 1440 / 2000, выбор по ширине блока, размытая заглушка до загрузки.
- Кадрирование по смыслу. Портрет автора, живопись и архитектура не обрезаются под один
  горизонтальный формат. Заложи минимум три соотношения и покажи, как карточка живёт с каждым.
- Материал без обложки — штатный случай: зона обложки скрывается, заголовок не проваливается.
- Визуальные паузы. В длинном материале изображение «полной ширины» работает как смена дыхания.
  Но изображения не вытесняют названия материалов и навигацию: это журнал, а не портфолио.
- Если изображений нет — ставь серые блоки с подписью соотношения сторон. Не бери изображения
  с сайтов-референсов.

## Движение

Движения в редакционном журнале мало, и оно служебное.

| Что | Решение |
|---|---|
| Действие повторяется десятки раз в день (наведение, переход по ссылке) | не анимировать или свести к смене цвета |
| Появление и исчезновение (меню, раскрывашка фильтров) | ease-out, 150–250 мс |
| Перемещение на экране | ease-in-out |
| Нажатие кнопки | 100–160 мс, при нажатии масштаб 0,97 |
| Любая анимация интерфейса | строго меньше 300 мс |

- ease-in в интерфейсе не использовать никогда: он тормозит ровно тот момент, на который
  смотрит читатель. Встроенные кривые слабые, бери сильный ease-out вида
  cubic-bezier(0.23, 1, 0.32, 1).
- Появление карточек по прокрутке запрещено: в издании, где читают, всплывающий контент мешает.
- Каруселей нет. Ведущий материал узнаётся композицией, а не автопереключением.
- Режим уменьшенного движения отключает всё, кроме мгновенной смены состояния.

## Доступность — уровень 1

- контраст текста не ниже 4,5 : 1, крупного не ниже 3 : 1;
- фокус виден всегда и нарисован отдельным состоянием, а не системным контуром по умолчанию;
- вся навигация доступна с клавиатуры; основная навигация не строится на наведении курсора;
- у каждого изображения есть альтернативный текст; заголовки идут по порядку;
- у форм видимые подписи, а не только подсказка внутри поля;
- цель нажатия на мобильном не меньше 44 на 44.

## Стоп-лист — уровень 1

1. Шаблонный продуктовый лендинг, блок преимуществ, отзывы, логотипы партнёров.
2. Крупные скругления, тени, стеклянные поверхности, градиенты, декоративные эффекты.
3. Бесконечная прокрутка — пагинация постраничная.
4. Автокарусели, параллакс, анимированные счётчики.
5. «Популярное» без данных о популярности; редакторский выбор под видом пользовательского
   рейтинга.
6. Повтор одних и тех же материалов ради заполнения экрана: мало материалов — короче страница.
7. Копирование чужих логотипов, шрифтов-айдентик, иллюстраций и текстов из референсов.
8. Функции, которых нет в продукте: комментарии, платная стена, аудиоверсия, донаты, магазин,
   рассылка, «читать позже» вне закладок.
9. Семь разных стилей карточек, палитр или комплектов шрифтов — по одному на референс.

| The New Yorker | https://www.newyorker.com/ и https://www.newyorker.com/culture | журнальную иерархию и заметное авторство | логотип, фирменное начертание, сложность новостного сайта |
| Kinfolk | https://www.kinfolk.com/ и https://www.kinfolk.com/stories-categories/arts-culture/ | фотографию и визуальные паузы | магазин, печатную подписку, пустоты портфолио |

Референсы — сырьё, а не меню готовых решений и не справочник настроения. Смотри не только
главные страницы, но и рубрики, материалы, страницы авторов: механизм подачи виден на внутренних
страницах, а не на витрине.

## Формат работы

Один холст. Артборды в сетку, слева направо: сначала паттерны (D), затем кит (K), затем
страницы (P). Десктоп — ширина артборда 1440, мобильный — 390, высота по содержанию. Имя
артборда вида «D1 · Ведущий разворот» или «P1 · Главная — desktop»; номера не меняй. Тёмная
тема — отдельные артборды, а не слой поверх светлых.

Демонстрационный контент — русский, правдоподобный, узнаваемо вымышленный. Если набор не
приложен, бери рубрики «Идеи», «Искусство», «Города», «Наука», «Память»: это демонстрационные
названия для макета, а не утверждённый состав рубрик издания.

## Что сделать прямо сейчас

Изучи восемь референсов и верни текстом, без макетов: по каждому — два-три механизма подачи,
сформулированных так, чтобы их можно было воспроизвести и проверить. Механизм, а не
впечатление: не «у Noema строгая сетка», а «ведущий материал занимает неравную долю ширины, и
его нижняя граница выравнена по верхней границе второго ряда». Впечатление воспроизвести
нельзя, механизм — можно.

Если какой-то референс открыть не удалось — скажи об этом прямо, не додумывай.
````

## Промт 2 · Медийные паттерны D1–D6

> **Источники**: метод вывода — собственное решение промта; слоты выведены из зон страниц
> `docs/spec/20-public/article.md` §5, `home.md` §5 и из ADR-0008 (подпись и атрибуция).
> **Приложить**: ничего, если контент и шрифты приложены к промту 1.

````text
Теперь выводим паттерны. Границы из первого сообщения в силе: уровень 1 не трогаем, отклонение
уровня 2 называем вслух.

## Метод

Четыре шага на каждый паттерн.

1. Принцип как механизм, а не как впечатление — ты уже выделил такие механизмы в прошлом ответе.
2. Слот. Берётся одна задача подачи из перечня ниже.
3. Сборка. Паттерн собирается минимум из двух принципов разных источников плюс одного
   ограничения Altera — продуктового правила, состояния или свойства контента. Ограничение
   обязательно: именно оно делает паттерн своим, а не средним арифметическим чужих решений.
4. Проверка на разрушение. Паттерн проверяется на трёх наполнениях: длинный русский заголовок в
   три строки, отсутствие изображения, вертикальное изображение вместо горизонтального. Паттерн,
   выживающий только на удачном наполнении, — картинка, а не паттерн.

Правило оригинальности. Если готовый паттерн опознаётся как «это из Aeon» — он не выведен, а
скопирован, и переделывается. Проверка простая: назови два источника и ограничение. Не назвал —
копия.

Чего метод не разрешает:
- брать принцип и ограничение из одного и того же источника;
- собирать паттерн из двух источников, которые отвечают за одно и то же;
- объявлять ограничением собственное предпочтение, которого нет в продуктовых правилах.

## Артборд паттерна

Каждый паттерн — один артборд из четырёх частей:
- сам паттерн в рабочем размере, на демонстрационном контенте;
- строка происхождения: «принцип A (источник) + принцип B (источник) + ограничение Altera»;
- три проверки на разрушение рядом, в уменьшенном масштабе;
- одно предложение: что паттерн решает и когда его не применять.

## Слоты этого захода

Это медийные слоты — они несут основную нагрузку журнала.

| Артборд | Задача подачи |
|---|---|
| D1 | Ведущий разворот: отношение заголовка, дека и главного изображения |
| D2 | Ритм текста и изображения в длинном материале: переходы между мерой, «широким» и «полным» |
| D3 | Подпись и атрибуция как типографический элемент, а не серая строчка под картинкой |
| D4 | Визуальная пауза: чем полноширинное изображение отличается от разрыва вёрстки |
| D5 | Кадрирование по типу содержания: портрет, живопись, архитектура, предмет |
| D6 | Материал без изображения: чем держится карточка и шапка, когда медиа нет |

Если окажется, что слот Altera не нужен, — скажи об этом и не выводи паттерн ради счёта.
````

## Промт 4 · UI-кит K1–K6

> **Источники**: `docs/vision/06-design-system.md` §4 (состав компонентов и их состояния),
> §11 (что в текущей сборке подлежит замене: дубли карточек, шаблонный футер).
> **Приложить**: ничего.

````text
Собери UI-кит журнала. Кит ничего не изобретает заново: он применяет выведенные паттерны. Если
элемент кита не опирается ни на один паттерн — это сигнал, что пропущен слот, а не повод
придумать элемент на месте. Скажи об этом вместо того, чтобы закрыть дыру на ходу.

Каждый элемент показывается со своими состояниями, иначе кит не годится для вёрстки.

## K1 · Основа

Палитра светлая и тёмная с указанием имени токена и фактического контраста к фону.
Типографическая шкала на русском тексте: все роли с кеглем, интерлиньяжем и разрядкой. Линейки
трёх плотностей. Шаг вертикального ритма. Контейнер и колонки с направляющими. Точки перелома.

## K2 · Атомы метаданных и управления

Кикер рубрики. Байлайн с аватаром и без. Дата. Бейдж автора. Метка «перевод». Время чтения.
Теги: одиночный, ряд, перенос на вторую строку. Публичный счётчик прочтений в двух состояниях:
показан и скрыт. Кнопка закладки: пусто, в закладках, занято, без сессии. Кнопки трёх уровней —
основная, второстепенная, текстовая — с состояниями наведения, нажатия, фокуса и блокировки.
Поле ввода и поле поиска. Ссылка внутри текста. Пагинация: середина, первая страница, последняя.

## K3 · Карточка материала — четыре варианта

Ровно четыре, имена не переименовывать.

| Вариант | Роль | Обязательные состояния |
|---|---|---|
| lede | герой ведущего блока | длинный и короткий заголовок, без обложки, бейдж автора, «перевод» |
| large | текст с изображением | то же плюс вертикальное и квадратное изображение |
| small | строка с изображением сбоку | без изображения, длинный заголовок в три строки |
| rank | номер в топе | номера 1, 9, 10 — у цифр разная ширина |

Общие правила для всех вариантов: одинаковые правила метаданных, одинаковая типографика;
различие — только масштаб и композиция.

## K4 · Шапка и футер

Шапка: логотип, рубрики из данных, поиск, «Войти» или аккаунт, «Писать», переключатель языка.
Состояния: рубрик нет — только логотип и вход; рубрик много — покажи, что происходит с
переполнением; активная рубрика; пользователь авторизован; мобильное меню открыто и закрыто.

Футер: о проекте, правила публикации, оферта, политика персональных данных, возвраты, реквизиты,
контакты, RSS. Это реальные разделы издания, а не шаблонные колонки «Продукты / Поддержка /
Компания».

## K5 · Блоки чтения

Абзац. Заголовки второго и третьего уровня внутри материала. Цитата. Маркированный и нумерованный
список. Изображение с подписью в трёх ширинах. Разделитель. Ссылка внутри текста. Изображение не
загрузилось. Покажи блоки подряд, одним потоком текста, — так виден вертикальный ритм.

## K6 · Состояния лент и страниц

Подпись-принцип над подборкой, например «по дате публикации». Скелет загрузки для ведущего блока
и для списка. Пустое состояние в двух видах: «здесь пока пусто — станьте первым автором» со
ссылкой на страницу подписки и «ничего не найдено, сбросить фильтры». Состояние ошибки с
идентификатором запроса и ссылкой «написать в редакцию».
````

````text
## P1 · Главная, десктоп, адрес /

Три независимые подборки материалов из всех рубрик. Блоков «по рубрике» на главной нет: владелец

6. Футер.

ним; «Новое» — три колонки; «Популярное» — правой колонкой рядом с «Новым».

Главная не превращается ни в лендинг с описанием проекта, ни в равномерную сетку одинаковых
превью.

## P2 · Главная, мобильный, 390

Одна колонка, порядок зон 2, 3, 4, 6. Карточки large становятся small с изображением сбоку.
Шапка сворачивается в меню. Липких элементов нет, кроме шапки при прокрутке вверх.

Редакционная иерархия сохраняется: это не уменьшенный десктоп, ведущий материал остаётся
крупным событием.
````

# Часть III — справочник

Не копируется целиком. Разбор отдельного референса вставляется в разговор, если дизайнер
затрудняется вынуть из него механизм.

## Разборы референсов

**Noema — редакционная композиция.** Показывает, как устроен интеллектуальный журнал: главный
материал, тематическая навигация, заметное авторство, несколько уровней редакционного отбора
(Most Read, Editors' Picks, Best of the Archive). Для Altera: крупный выразительный заголовок и
сильное изображение ведущего материала; явный контраст между главным, второстепенным и
компактным; асимметрия внутри строгой сетки; разделение пространством и линейками, а не
одинаковыми контейнерами с тенями. Оговорка: у Altera ровно три подборки на главной, уровни
отбора Noema — источник композиционных ролей, а не блоков.

**Aeon — страница статьи.** Подача больших эссе: выразительное начало, заголовок, содержательный
подзаголовок, автор с биографией; тематические направления отделены от форматов; изображения с
подписями. Для Altera: текст — главное содержание страницы, интерфейс — поддерживающий слой;
после крупного вступления читатель переходит в спокойную колонку с устойчивым вертикальным
ритмом; чётко различаются заголовок, лид, основной текст, цитата, подпись к изображению и
служебная строка. Оговорка: аудиоверсию, сохранение и донаты не переносим.

**Works in Progress — типографика и системная вёрстка.** Дисциплина сетки, выразительная
типографика, оформление сложных длинных материалов; разные типографические роли для текста и
второстепенной информации. Для Altera: малое число гарнитур при отчётливой иерархии размеров и
начертаний; основной текст литературный, метаданные точные и ненавязчивые; все отступы, линии,
подписи и выравнивания принадлежат одной системе, даже когда блоки различаются композицией.
Оговорка: печатные выпуски, подписка и коммерческие гарнитуры не переносятся.

**Monocle — масштаб и навигация.** Организация большого редакционного сайта: тематические
направления, разные типы блоков, представление авторов. Для Altera: содержательная насыщенность
без визуального шума; заметные названия разделов, устойчивое выравнивание, разные масштабы
публикаций; читатель всегда понимает, где он и что доступно дальше. Навигация по рубрикам
отделена от служебных действий. Страницы рубрик — самостоятельные точки входа. Система
выдерживает рост архива без добавления каждого тега в шапку. Оговорка: воспроизводим
масштабируемость структуры, а не масштаб бизнеса.

**Psyche — темы и форматы.** Переход от хронологической ленты к тематическому исследованию:
тематические разделы, самостоятельные форматы, редакционные подборки, понятная маркировка,
разные шаблоны материалов. Для Altera: различать материалы умеренно — подписью формата,
пропорцией изображения, композицией превью, но не отдельной дизайн-системой на каждый вид. Чётко
разделять рубрику, тег и формат. Оговорка: специализацию издания и его социальные функции не
переносим.

**The New Yorker — иерархия и авторство.** Культурное издание с самостоятельными рубриками,
постоянными колонками и заметными подписями авторов. Для Altera: журнальный ритм — крупный
ведущий материал, несколько менее крупных, затем компактные текстовые анонсы; выразительность
через типографику, иллюстрации, линейки и пропорции, а не через эффекты. Автор заметен и на
странице материала, и в превью. Оговорка: логотип, фирменное начертание и сложность большого
новостного сайта не переносятся.

**Kinfolk — фотография и паузы.** Подача визуальных историй: фотографии, тематические подборки,
интервью. Для Altera: качественной фотографии дать место; крупные изображения там, где они
несут содержание; чередовать насыщенные текстовые участки с визуальными паузами; кадрировать
осмысленно. Оговорка: магазин и печатную подписку не переносим, главную не превращаем в
портфолио с пустотами.

## Как пополнять реестр

Ссылки собраны, чтобы список рос. Новый референс добавляется строкой в таблицу промта 1 и, если
даёт самостоятельный принцип, абзацем сюда по шаблону:

```
**Название — за чем взят.** Что показывает референс, по факту сайта, одно-два предложения.
Для Altera: какой конкретный принцип переносим. Оговорка: чего не переносим.
```

Правила:

- Один референс — один принцип. Если принцип уже закрыт другим сайтом, ссылка идёт в кандидаты,
  а не в реестр: два источника «про одно и то же» ломают правило оригинальности промта 2.
- Ссылка указывается на главную **и** на внутреннюю страницу — по одной витрине характер издания
  не читается.
- Если референс противоречит продуктовым правилам, побеждают правила; противоречие записывается
  в колонку «чего не берём».
