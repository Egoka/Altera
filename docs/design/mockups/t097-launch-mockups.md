# Макеты страниц запуска и состояний (T-097)

- **Задача**: T-097
- **Дата**: 2026-09-14
- **Источники**: `docs/vision/06-design-system.md`, `docs/spec/20-public/`, `docs/spec/30-account/`, `docs/spec/40-admin/`, ADR-0021
- **Компонентная библиотека**: FishtVue — приложение (кабинет, редактор, админка); собственные компоненты дизайн-системы — публичное чтение (ADR-0021)

---

## Дизайн-токены (из `06-design-system.md`)

```
--color-paper      фон страницы (тёплый белый / почти чёрный)
--color-ink        основной текст (почти чёрный / тёплый белый)
--color-ink-muted  подписи, даты (серый)
--color-accent     акцент #ff5a1f-семейство (приглушённое в тёмной)
--color-rule       разделители (светло-серый / тёмно-серый)
--color-surface    карточки, формы
--color-success / --color-warning / --color-danger
```

**Типографика** (публичные страницы):
- Display / H1 секций: Waterway
- Заголовки материалов и карточек, основной текст: Garamond Libre
- Подписи, кикеры, байлайны: Cormorant SC
- Логотип: Bergamasco
- Интерфейс (навигация, кабинет, админка): font-sans

**Три точки останова**:
- **mobile** (< 768) — одна колонка
- **tablet** (md, 768–1023) — 2 колонки карточек, адаптированные панели
- **desktop** (lg, ≥ 1024) — полная раскладка, контейнер `max-w-7xl`, `px-4 sm:px-6 lg:px-8`

**Общий каркас** (`AppShell`):
- `AppHeader`: логотип (Bergamasco), рубрики из данных (`SectionNav`), поиск, вход / аккаунт, «Писать» → `/pricing` или кабинет, переключатель языка; на mobile — гамбургер
- `AppFooter`: о проекте, правила, оферта, политика ПД, возвраты, реквизиты, контакты, RSS
- Тёмная тема: `@nuxtjs/color-mode`, класс на `html`

## Примечания для разработчика

1. **FishtVue vs. собственные компоненты** (ADR-0021): публичные страницы (1–4) — только собственные; кабинет (6), редактор (7), очередь (8), сводка (9) — FishtVue поверх токенов. Компоненты не смешивать.
2. **Тёмная тема**: `@nuxtjs/color-mode`, класс `dark` на `html`; все состояния проверять в обеих темах. FishtVue получает тот же селектор через свою тему.
3. **i18n**: все текстовые метки — из словаря локали (`ru` / `en`); строки плейсхолдеров и EmptyState — тоже.
4. **Состояния-redirect**: 302 / 303 на клиенте — через `navigateTo` Nuxt; на сервере — `sendRedirect`; страница-назначение маскирует истинный триггер (для безопасности), но UX назначения остаётся в объёме своих спецификаций.
5. **Конфликт версий** и **диалоги подтверждения** (очередь, редактор) — FishtVue Dialog, не нативный `window.confirm`.
6. **Офлайн** (редактор) — локальное хранение в `localStorage`; синхронизация — реализация в `offline.md`, здесь только индикатор в панели.
