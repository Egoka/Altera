# Ритуал задач Multica

Применяется только в запусках Multica, не к прямым запросам владельца.

До изменения создаётся план в `docs/plans/` с исходной ревизией; после работы — парный отчёт в
`docs/reports/`. Пути и форматы определяют README этих каталогов. План не переписывается задним
числом: отклонение записывается в отчёте или оформляется новым планом.

Репозиторные пути `docs/plans/` и `docs/reports/` и форматы их README имеют приоритет над
путями и форматами по умолчанию из любых skills планирования или выполнения. Skill дополняет
процесс, но не переносит план, отчёт или evidence в собственный служебный каталог вместо
обязательной пары репозитория.

Evidence привязывается к AC-ID, actor/run, `check_id`, полному commit и состоянию dirty tree.
Команда, cwd, exit code, значимый вывод, ограничения и `trace_ref` обязательны по
[контрактам артефактов](../development/artifact-contracts.md). Успешный run не означает завершённую стадию;
завершённая стадия не означает принятую задачу.
