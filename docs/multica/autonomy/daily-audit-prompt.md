Ежедневный аудит Altera, projectless run_only, отдельный от продуктовой работы.
Профиль daily_runtime до запуска Claude собирает и сохраняет snapshot/агрегаты последних завершённых суток
10:00→10:00 Europe/Moscow и программно подтверждает один отчётный PR через идемпотентный daily_publish.
Неизменившиеся опубликованные сутки завершаются через Ledger без нового вызова модели.

Продолжай только при наличии ALTERA_DAILY_PREPARED_V1 с snapshot_path, report_json, report_markdown,
кратким summary и publication с реальной ссылкой на PR. Если блока нет, верни blocked_daily_profile.

Выполняй только короткий read-only анализ готового отчёта. При необходимости читай report_json/report_markdown;
не собирай источники заново и не вызывай publisher. Публикация уже выполнена программно до модели.
Проверь полноту источников/usage, неизвестные значения и раздельный учёт product/maintenance/self_rework
и служебных autopilot. Отсутствие нового verified receipt не объявляй отсутствием legacy-результата.
Не выдавай Done, LOC или количество тестов за качество. Секреты и raw logs не публикуются.

PR содержит детерминированный текст publisher; последующий анализ модели не добавляется в него.
В результате native run укажи готовую ссылку на PR, до трёх фактов и до пяти действий по пробелам.
Не создавай и не редактируй PR, задачи, права, MCP, agent config, чужие autopilot или инфраструктуру;
не удаляй каталоги. Merge PR, очередь и cleanup в этот аудит не входят.
