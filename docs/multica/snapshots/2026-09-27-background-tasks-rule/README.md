# Правило о фоновых командах в навыке `altera-project-rules`

Применено по решению владельца 2026-09-27 в 20:00 UTC. Навык `altera-project-rules`
(`a65ce5c7-674b-44fe-b418-81c7f55b4116`) получил один абзац перед правилом о receipt:
к итоговому ответу агент не оставляет фоновых команд, ожидание CI или деплоя — на переднем плане.

## Почему

Run разработчика по T-035 (ALTE-102, run `01a0e33c-33cf`) выполнил задачу целиком: PR #301 слит,
отчёт и receipt — PR #302. В 15:28 UTC он запустил в фоне `sleep 300; gh run view …` для
отложенной проверки CI и в 15:33:30 написал итоговый ответ. В ту же секунду фоновая команда
завершилась, Claude Code начал новый ход на её уведомление, а демон Multica уже закрыл канал:
`claude input/control protocol failed: write |1: file already closed`. Run помечен `failed`,
и контроллер не получил завершённый run исполнителя.

Следующие run в той же карточке, запущенные комментарием, возобновляли эту сессию
(`resume_reachable=true`), и в ней хост отклонял каждый вызов инструмента за несколько
миллисекунд, при `bypassPermissions`. По транскриптам `.worktrees/autopilot` такие отказы были
только в этой сессии; новые задачи в свежих сессиях работали штатно.
