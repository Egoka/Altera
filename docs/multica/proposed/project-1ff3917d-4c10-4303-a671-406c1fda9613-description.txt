Altera — культурная publishing-платформа: журнал о живописи, музыке, фотографии, спорте и путешествиях. Монорепозиторий pnpm: web (Nuxt 4, Vue 3, Tailwind 4, FishtVue, i18n ru/en) и server (GraphQL Yoga поверх node:http, Prisma 6, PostgreSQL Neon, Redis) — не Express.

Проверенный baseline: pnpm test на 2e542a0, 2026-09-13 — server 19 и web 5, exit 0; это исторический результат, не обещание текущего числа или прохождения CI. Актуальные команды и результаты — docs/development/testing.md и docs/reports/2026-09-13-autonomy-execution-report.md.

Продуктовый контракт задаёт журнал владельца → docs/spec → ADR → vision. Код и выполненные проверки показывают фактическое состояние на конкретной ревизии; расхождение с контрактом является дефектом или открытым решением, а не новым продуктовым правилом.

Исторический перечень ограничений из среза 2026-09-09; в этом обновлении повторно не проверен целиком. Сверяй каждый пункт с текущим кодом и evidence до использования как актуального факта.
