## 2. Принципы

1. **Типографика важнее виджетов.** Публичный сайт — это чтение; компоненты чтения — свои
   (ADR-0021). Ориентир по плотности и ритму — The Atlantic: крупный заголовок, дек, автор,
   мера текста, изображения на всю ширину при необходимости.
2. **Один источник токенов** — `main.css` (`@theme`); FishtVue и письма берут те же значения.
3. **Каждый блок редактора имеет ровно один компонент рендера**; вид блока определяется
   здесь, а не автором (ADR-0017).
4. **Состояния — часть компонента**: загрузка, пусто, ошибка, ограничение плана описываются
   вместе с компонентом.
5. **Мобильный — чтение и письмо**, desktop — раскладка и редакция.
6. **Лента честная**: порядок задаёт рейтинг (ADR-0034), подписи секций — тексты, читатель
   получает словесное объяснение позиции; бесконечной прокрутки, «умных» лент, тем оформления
   для авторов и внешних CDN шрифтов нет `[ДОПУЩЕНИЕ: шрифты]`.

## 3. Токены

### Цвета

Одна семантическая палитра вместо двух одинаковых:

| Токен | Назначение | Светлая | Тёмная |
|---|---|---|---|
| `--color-paper` | фон страницы | тёплый белый | почти чёрный |
| `--color-ink` | основной текст | почти чёрный | тёплый белый |
| `--color-ink-muted` | подписи, даты | серый | серый |
| `--color-accent` | акцент (дата, ссылки при наведении, активные элементы, бейдж pro) — текущий оранжево-красный | `#ff5a1f`-семейство | приглушённое |
| `--color-rule` | линейки, разделители | светло-серый | тёмно-серый |
| `--color-surface` | карточки приложения, формы | | |
| `--color-success`, `--color-warning`, `--color-danger` | состояния приложения | | |

Значения выбираются при доводке; контраст текста к фону — не ниже 4,5:1 (AA), крупного —
3:1. Тёмная тема — только через `@nuxtjs/color-mode` (класс на `html`); `useTheme` и
`body.dark` удаляются; FishtVue получает тот же селектор.

### Типографика

| Роль | Гарнитура | Где |
|---|---|---|
| Display: заголовки страниц (H1), названия секций | Waterway | шапки рубрик, авторов, секций главной |
| Заголовки материалов и карточек, дек, основной текст материала | Garamond Libre | страница материала, карточки |
| Подписи, кикеры, байлайны | Cormorant SC (капитель) | автор, рубрика на карточке, подписи к изображениям |
| Логотип | Bergamasco | только логотип |
| Интерфейс: навигация, кнопки, формы, кабинет, админка | системный sans (`font-sans`) `[ДОПУЩЕНИЕ: без подключения Google-шрифтов]` | шапка, футер, кабинет, админка |

Шкала: базовый размер текста материала 1,125–1,25 rem, интерлиньяж 1,6–1,7, мера 65–75
знаков (`max-w-3xl`); заголовки по модульной шкале 1,25. Базовая типографика в `@layer base`
включается (сейчас закомментирована).

### Отступы, сетки, контейнер

Одна схема: контейнер `max-w-7xl`, горизонтальные отступы `px-4 sm:px-6 lg:px-8`; мера
текста `max-w-3xl`; сетка карточек 1 / 2 / 3 колонки по breakpoints Tailwind (`sm 640`,
`md 768`, `lg 1024`, `xl 1280`). Шесть существующих схем заменяются этой.

### Медиа

Варианты изображений: 480, 960, 1440, 2000 `[ДОПУЩЕНИЕ]`; `srcset` и `sizes` по размеру
блока (обычный — мера текста, широкий — контейнер, во всю ширину — viewport); LQIP из
`placeholder`.

## 7. Главная

Секции (состав и принцип — гейт Г4 при проектировании рейтинга, `docs/spec/60-ranking/
home-sections.md`), первое приближение: «Главное» — топ по рейтингу по всем рубрикам; по
секции на рубрику — топ рубрики; «Новое» — опубликованное за 48 часов по рейтингу; «Авторы»
— по рейтингу автора. У каждой секции — подпись словами, что в ней и почему. На этапе 1, до
рейтинга, все секции сортируются по дате с подписью «по дате публикации».

## 8. Каталог, поиск, ленты

- Рубрика = лента по рейтингу с фильтром по формату и тегу; переключатель «по рейтингу / по
  дате».
- Поиск — PostgreSQL FTS (ADR-0025): строка, сниппеты, фильтры рубрика/формат/тег/период;
  результаты — по релевантности, рейтинг как вторичный ключ `[ДОПУЩЕНИЕ]`; подсказки по
  заголовкам, авторам, тегам.
- Страница автора — материалы по рейтингу; бейдж pro; кнопка подписки на автора (3).

## 9. Соответствие блок → компонент

Таблица в `05-editor.md` §7: `paragraph → ProseParagraph`, `heading → ProseHeading`,
`blockquote → ProseQuote`, списки → `ProseList`, `figure → ProseFigure`, `horizontalRule →
ProseDivider`; этап 4: `gallery`, `video`, `audio`, `aside`, `embed`, `table`, `columns`.
Рендерер живёт в пакете `content` (ADR-0029) и выпускает только компоненты чтения. Каталог
блоков — отдельный проход (`docs/spec/95-blocks/`).

## 10. Доступность, производительность, SEO

**WCAG 2.2 AA** (гейт CI с этапа 3): контраст 4,5:1; фокус видим; вся навигация с клавиатуры;
`alt` у изображений (из медиа); заголовки по порядку; `lang` на `html` и на версии; формы с
подписями; `prefers-reduced-motion`. Инструменты: axe в Playwright — 0 critical/serious;
ручной чек-лист клавиатуры.

**Бюджеты** (Lighthouse CI с этапа 3, красный CI при превышении): LCP < 2,5 с на странице
материала на сиде; JS публичной страницы < 150 КБ; CLS < 0,1; шрифты — `font-display: swap`,
предзагрузка двух основных начертаний `[ДОПУЩЕНИЕ]`.

**SEO-инфраструктура** (canonical — этап 1, остальное — этап 3): `useSeoMeta` на каждой
странице; canonical у каждой версии; hreflang для опубликованных пар; `sitemap.xml` по
локалям; `rss.xml` по локалям; OG-изображение (обложка или дефолт); JSON-LD `Article`
(заголовок, автор как `Person`, даты, рубрика), `Person` на странице автора, `BreadcrumbList`;
`noindex` для `/me`, `/admin`, предпросмотра, поиска с параметрами, `/pricing` с промокодом.

## 11. FishtVue и наведение порядка

FishtVue — приложение: админка, кабинет, обвязка редактора, формы входа и оплаты
