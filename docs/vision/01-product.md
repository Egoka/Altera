# Продукт: что такое Altera и для кого

- **Ревизия**: 2 (2026-09-06), заменяет ревизию 1 (коммит `636538c`).
- **Статус**: принято владельцем 2026-09-06 (ADR-0043).
- **Основание**: продуктовые рамки ADR-0043, срез реальности `00-reality-check.md`, решения
  ADR-0034…0046.
- Этот документ владеет словарём терминов, описанием аудиторий, принципом монетизации и
  определением выдачи. Остальные документы ссылаются на него, а не пересказывают.

## 0. Что изменилось относительно ревизии 1

| Было (ревизия 1) | Стало (ревизия 2) | Решение |
|---|---|---|
| Два контура: открытая публикация и редакционная витрина | Одна лента, одна модель материала, витрины и заказов нет | ADR-0036 |
| Публикация бесплатна и неотчуждаема; правило-арбитр «никогда за право публиковаться» | Право публиковать даёт платный план standard или pro | ADR-0035 |
| «Без алгоритмов»: хронология и ручной отбор | Рейтинговая выдача с названными компонентами, без персонализации | ADR-0034 |
| Уровни доверия как ворота публикации | Каждая публикуемая ревизия проходит AI, затем человека | ADR-0037, ADR-0039, ADR-0045 |
| Первый платный продукт — поддержка автора; биллинг на этапе 4 | Планы free / standard / pro; биллинг на этапе 1; донатов нет | ADR-0035 |
| Шесть ролей, подписчик — состояние | Семь ролей с `analyst`; роль автора выводится из подписки | ADR-0042, ADR-0035 |
| Закладки не планируются | Закладки у любого аккаунта | ADR-0041 |
| Шесть культурных тем | Разные темы человеческой жизни; ориентир — The Atlantic | ADR-0043 |
| Перевод делает автор или редакция | AI-перевод для pro с правкой автором | ADR-0046 |

---

## 1. Одним абзацем

Altera — журнал на разные темы человеческой жизни, устроенный как The Atlantic: длинные
тексты, редакционное качество, одна лента. Читать может любой и бесплатно. Писать может
автор с платным планом: standard открывает публикацию, pro повышает грейд автора, даёт его
новым статьям буст в рейтинге на сутки и AI-перевод на второй язык. Каждая публикуемая
версия проходит проверку AI, затем человека. Выдача — по рейтингу статьи, который
складывается из названных компонентов и одинаков для всех читателей.

## 2. Словарь

| Термин | Значение |
|---|---|
| **Материал** | Текст с общими метаданными (автор, рубрика, формат, теги, обложка) и одной или несколькими языковыми версиями |
| **Языковая версия** | Русская или английская версия материала: свой заголовок, текст, адрес, статус, дата публикации (ADR-0002) |
| **Ревизия** | Снимок языковой версии; все изменения сохраняются (ADR-0007). Публикуемая ревизия проходит проверку |
| **Рубрика** | Тема материала (категория), задаёт адрес и навигацию; список ведёт редакция (ADR-0005). Владелец называет её «категория» |
| **Формат** | Жанр: эссе, обзор, фоторепортаж, интервью, колонка; атрибут, не адрес; необязателен |
| **Тег** | Свободное слово автора; редакция сливает и чистит |
| **План** | `free`, `standard`, `pro` — уровень подписки пользователя (ADR-0035). `free` выдаётся при регистрации |
| **Подписка** | Оплаченный период плана standard или pro; состояния `active`, `past_due`, `canceled`, `expired` |
| **Посетитель** | Нет аккаунта; читает всё |
| **Читатель** | Аккаунт с планом `free`: читает, сохраняет закладки, подписывается на авторов, жалуется |
| **Автор** | Аккаунт с активным планом standard или pro (или ручным грантом): создаёт и публикует материалы |
| **Грейд автора** | `basic` при standard, `pro` при pro; входит в рейтинг автора (ADR-0037) |
| **Проверка** | Две ступени перед публикацией ревизии: AI-вердикт по правилам публикации, затем решение ревьюера (ADR-0045) |
| **AI-оценка** | Балл и критерии качества материала от AI-агента редакции; виден автору; вход рейтинга; модератор может переопределить (ADR-0039) |
| **Рейтинг статьи** | Число, по которому сортируются ленты: соответствие теме, давность, рейтинг автора, просмотры, AI-оценка, буст (ADR-0034) |
| **Рейтинг автора** | Производная от грейда и истории его материалов; вход рейтинга статьи |
| **Буст** | Надбавка к рейтингу новой статьи pro-автора на 24 часа (ADR-0040) |
| **Просмотры** | Уникальные суточные прочтения без профилирования (ADR-0027, ADR-0038) |
| **Закладка** | Приватное сохранение материала аккаунтом (ADR-0041) |
| **Ревьюер** | Роль `moderator`: вторая ступень проверки, жалобы, снятие с публикации, блокировки |
| **Редактор** | Роль `editor`: таксономия, замечания, правка текста на проверке, переводы |
| **Аналитик** | Роль `analyst`: только чтение агрегированной статистики |
| **Администратор**, **Владелец** | `admin` — всё, кроме владения; `owner` (супер-админ) — ровно один (ADR-0042) |

## 3. Аудитория

**Посетители.** Приходят из поиска и соцсетей на минуту-две. Им нужно: текст читается сразу,
без баннеров и регистрации; понятно, что это за издание; есть куда пойти дальше (рубрика,
автор, топ). Сигнал успеха — вторая страница за визит.

**Читатели.** Завели бесплатный аккаунт ради закладок и подписки на авторов. Им нужно:
рубрики и авторы как навигация, честная лента без персонализации, письма о новых
материалах авторов, на которых подписались, — не чаще раза в день.

**Авторы.** Платят за право публиковать в месте, где текст выглядит как в журнале и где есть
читатели. Им нужно: редактор без требований к оформлению, понятная проверка с причинами и
обратной связью от AI, статистика прочтений, рейтинг, который объясним, экспорт своих
текстов в любой момент. Pro-авторы дополнительно покупают заметность (грейд, буст) и второй
язык.

**Администраторы.** На старте — владелец в нескольких ролях; затем ревьюеры, редакторы,
аналитик. Им нужно: очередь проверки с AI-вердиктом, инструменты таксономии, управление
подписками и администраторами, статистика, аудит.

Аудитория на старте нулевая; гипотезы проверяются на первых десятках авторов.

## 4. Что продаётся и что бесплатно

1. **Чтение бесплатно для всех и целиком.** Paywall не проектируется; поле доступа в модели
   зарезервировано и включается только отдельным ADR (ADR-0036).
2. **Подписка покупает возможности автора**: право создавать и публиковать (standard), грейд,
   буст, AI-перевод, статистика (pro). Деньги за размещение вне плана — реклама в ленте,
   разовое «продвижение» — не проектируются.
3. **Донатов и подписки на автора нет.** Вся экономика — планы пользователя (ADR-0035).
4. **Платежи с первого этапа**: ЮKassa или Т-Касса за адаптером, чеки 54-ФЗ у провайдера,
   152-ФЗ для персональных данных (ADR-0010, ADR-0011).
5. **MIT относится к коду.** Права на материалы у авторов; платформа получает неисключительную
   лицензию на публикацию и показ (ADR-0028); экспорт своих материалов доступен всегда, в том
   числе после истечения подписки (ADR-0044).

## 5. Выдача

- **Одна лента.** Главная, рубрики, теги, страница автора — списки опубликованных версий
  локали по убыванию рейтинга статьи. Персонализации нет: список одинаков для всех.
- **Рейтинг** складывается из названных компонентов (ADR-0034): соответствие теме, давность
  с затуханием, рейтинг автора, просмотры, AI-оценка, буст. Веса — параметры конфигурации,
  меняются редакцией с аудитом; формула — `docs/spec/60-ranking/`.
- **Главная состоит из секций** с разными выборками на общем рейтинге: топ по всем рубрикам,
  топ рубрики, новое за период; состав и принцип каждой секции — гейт владельца при
  проектировании рейтинга.
- **Объяснимость.** Автор видит разложение рейтинга своей статьи; читатель — словесное
  объяснение позиции без чисел; факт буста читателю не показывается, бейдж pro-автора —
  показывается.
- До появления рейтинга (этап 2) ленты сортируются по дате публикации — временно.

## 6. Проверка и качество

Каждая ревизия, отправленная к публикации, проходит две ступени (ADR-0045): AI выносит вердикт
по правилам публикации и ставит оценку (ADR-0039); ревьюер одобряет или возвращает с
причиной. Автор видит вердикт, балл, критерии и пояснения, может оспорить отказ AI. Правка
опубликованного текста — новая ревизия по тому же пути; читатель до одобрения видит прежнюю
версию. Уровней доверия нет (ADR-0037); реакции редакции на нарушения — возврат, снятие с
публикации с причиной, блокировка (ADR-0014).

| Граница | Решение |

| Персонализированной ленты и рекомендаций нет | ADR-0034 |
| Международного биллинга и второй валюты нет | ADR-0010, ADR-0043 |
| Донатов и выплат авторам нет | ADR-0035 |

## 8. Правила публикации: состав будущего публичного текста

Текст пишет владелец (ADR-0028, гейт этапа 1). Он должен содержать: что нельзя публиковать
(чужие тексты и изображения без прав, незаконный контент, спам, персональные данные третьих
лиц, скрытую рекламу); ответственность автора за права на текст и изображения, обязательность
лицензии и атрибуции изображений (ADR-0008); как работает проверка — AI-ступень, человеческая
ступень, срок ответа 48 часов, что значит «вернуть с причиной», как оспорить; что может
редакция (снять с публикации с причиной, вернуть на доработку) и чего не может (править
опубликованный текст без ревизии); как снимается материал по претензии правообладателя; что
происходит с материалами при истечении подписки (остаются, ADR-0044), блокировке и удалении
аккаунта (ADR-0014); лицензия: права у автора, платформе — неисключительная лицензия; экспорт
доступен всегда; какие данные и зачем отправляются AI-провайдеру (ADR-0039).

## 9. Публичные тексты и README

README и тексты сайта описывают открытую платформу с бесплатной публикацией и обещают то,
чего нет (MDC-редактор, Vercel, Render) [ФАКТ: `README.md`]. На этапе 1, до открытой
регистрации, они переписываются под этот документ: журнал, планы и что они дают, проверка,
рейтинг, права на контент, MIT для кода, честный статус проекта. Это пункт DoD этапа 1
(`docs/issues/02-first-author-pays-and-publishes.md`).

## 10. Продуктовые гипотезы по этапам

| Этап | Гипотеза |
|---|---|
| 1 | Автор готов платить за standard ради места, где текст выглядит как в журнале, и опубликует хотя бы один материал; конверсия регистраций в standard измерима на первых десятках |
| 2 | Рейтинговая выдача даёт читателю лучшие материалы наверху, и авторы понимают, почему их статья там, где она есть; pro покупают ради заметности |
| 3 | Читатель, нашедший материал через поиск или рубрику, заводит аккаунт ради закладок и подписки на автора и возвращается; AI-перевод даёт англоязычную аудиторию pro-авторам |
| 4 | Редакция из нескольких человек работает на одном движке без ручных обходов |
| 5 | Соавторство и профессиональные инструменты нужны хотя бы части активных авторов |

Проверяемые метрики — в файлах этапов `docs/issues/`.
