# Исключения прав владельца — дизайн

## Цель

Реализовать утверждённую политику `docs/spec/50-access/permission-exceptions.md`: только владелец
управляет индивидуальными `grant`/`deny` для служебных ролей, срок может быть бессрочным или конечным,
а выдача, отзыв и истечение фиксируются в append-only аудите.

## Хранение и инварианты

`PermissionException` хранит пользователя и его роль на момент выдачи, код права, вид, причину,
актора, начало, необязательный конец, отзыв и отметку обработанного истечения. Связь с ролью не даёт
исключению пережить смену роли. `reader`, `author` и право `owner` отклоняются как `VALIDATION_ERROR`.
Конечный срок обязан быть позже времени выдачи.

## Сервис и аудит

Доменный сервис принимает Prisma-подобный клиент и явный `now`, чтобы тесты не зависели от часов.
Grant и revoke выполняются транзакционно вместе с `permission.exception.grant` и
`permission.exception.revoke`. Expiry runner выбирает закончившиеся необработанные записи и для каждой
атомарно ставит `expiredAt`; аудит `permission.exception.expire` создаётся только победителем условного
update, поэтому повторный запуск и несколько процессов не дублируют событие.

## GraphQL и проверка доступа

Новый SDL предоставляет чтение списка для `admin`/`owner` и owner-only мутации `grantException` и
`revokeException`. Контекст аутентифицированного пользователя загружает его неотозванные исключения;
существующая синхронная `ensurePermission` учитывает их по умолчанию, сохраняя текущий API вызовов.
Право `owner` и обычные роли исключениями не расширяются.

## Планировщик

Сервер запускает небольшой interval runner после старта и делает первый проход сразу. Ошибки пишутся
структурированным logger и не останавливают HTTP-сервер. Таймер `unref()` не удерживает процесс.

## Проверка

Unit-тесты сначала фиксируют отказ не-владельцу, validation границ, атомарный audit grant/revoke и
идемпотентное истечение с подменой времени. Тест контекста подтверждает загрузку исключений, а общий SDL
contract и server build проверяют GraphQL/Prisma согласованность.
