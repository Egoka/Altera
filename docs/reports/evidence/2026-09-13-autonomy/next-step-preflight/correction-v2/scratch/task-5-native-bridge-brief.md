# Task 5 Native Bridge — design-only preparation

> Для следующего implementer: исполнять только после scoped review и отдельного dispatch root; один writer, без subagents. Этот brief не разрешает регистрацию, binding, native trigger или чтение credentials.

**Goal:** установить actual native MCP semantics минимальным metadata-only D1, затем подготовить trusted adapter, запускающий неизменённые роли/модели исключительно в Linux boundary.

**Architecture:** отдельный D1 читает только проверенный daemon temp JSON и заканчивает exit 78. После его приёмки adapter повторно валидирует live input при каждом invocation, создаёт ограниченную RO Linux policy и вызывает существующий launcher. Existing Multica остаётся scheduler; gate и acceptance выполняет внешний coordinator.

**Tech stack:** небольшой native diagnostic, bounded strict JSON parser, существующие Python launcher / Node protocol guard / pinned Docker image. Выбор parser dependency требует отдельного review; shell/interpreter/PATH lookup в D1 не нужны.

**Spec:** task-5-brief.md, task-5-metadata-discovery-design.md, task-5-checker-hook-design.md в родительском scratch; docs/plans/2026-09-13-autonomy-execution.md, docs/development/runtime-isolation.md. Это ограниченный дизайн, не готовый implementation plan с принятой неизвестной конфигурацией.

## Milestone A: D1 capability и входной контракт

Предпочтителен отдельный executable `scripts/agent-runtime/metadata-config-probe.c`, чтобы прежние D0 source/binary/proof оставались неизменными. Build helper и tests — рядом; точные filenames для них: `build_metadata_config_probe.py`, `test_metadata_config_probe.py`. Никаких model, child/spawn/exec/system, stdin reads, network, host writes, Keychain/auth API, config discovery, stdout completion. Единственные разрешённые выходы процесса — bounded stderr descriptor и exit 78. Ровно `--help`/`--version` дают статический truthful `altera-metadata-config-probe` version; не выдавать D1 за Claude. Вывод version не открывает никаких input files.

Trusted build/profile pin заранее задаёт ожидаемый canonical per-user TMPDIR и UID. Значение не берётся как authority из native argv или env TMPDIR; фактический путь выбирает coordinator из проверенного local daemon context, не implementer по догадке. Pin является public path metadata, не секретом. Native `--mcp-config` обязан встречаться ровно один раз и указывать ровно на непосредственный child `EXPECTED_TMPDIR/multica-mcp-SUFFIX/mcp-config.json`. Разрешены отдельно протестированные `--mcp-config PATH` и `--mcp-config=PATH`; duplicate/empty/inline JSON/relative/URL/control bytes/extra path levels отклоняются. SUFFIX — непустой ASCII alphanumeric, не `.`/`..`; его содержимое не выводится. Prompt и прочие argv values не читаются как команды/JSON и не выводятся.

Открытие descriptor-relative, без lexical `realpath`-then-open гонки: пройти canonical components без symlink (`openat` + `O_NOFOLLOW|O_DIRECTORY`), удерживать dirfds. Expected TMPDIR и daemon child должны принадлежать текущему UID и иметь private mode 0700; ancestors проверяются как directories без symlink, но shared системным ancestors не навязывается user ownership. Final file открыть `O_RDONLY|O_NOFOLLOW|O_NONBLOCK`; `fstat` требует regular file, UID, exact 0600, nlink=1, bounded size 1..65536 bytes. Читать максимум 65537 bytes через тот же fd. До/после чтения проверить dev/inode/size/mtime/ctime, повторный descriptor-relative lookup не должен показывать замену пути. Исчезновение, изменение, иной mount/file kind/permissions, FIFO/socket/device, symlink в любом компоненте — fail closed без попытки запасного пути. Одновременный writer того же UID полностью не исключается stat-проверками: coordinator обязан сериализовать invocation и доверять daemon как producer. Это не доказательство защиты от уже скомпрометированного same-UID host.

Strict parser: UTF-8, один JSON object, duplicate keys запрещены на каждом уровне, trailing bytes кроме JSON whitespace запрещены; depth ≤16, tokens ≤4096, servers ≤8, output ≤8192 bytes. Превышение лимита — safe refusal. Secret-bearing JSON неизбежно проходит через bounded process memory при чтении разрешённого файла, но secret values не интерпретируются для descriptor, не хэшируются, не выводятся и не сохраняются. Обрабатывать opaque scalar/subtree; отсутствие подробностей отличать от подтверждённой совместимости. Parser errors выводят фиксированные codes, не offending bytes/offset excerpts. Core dump отключить без файловой записи. Никаких fallback logs или raw config hashes.

### D1 descriptor

Одна запись stderr `ALTERA_METADATA_CONFIG_ONLY_V1`, stdout пуст:

- own build/source ID; schema version; `read_status` из фиксированного enum; `path_class: daemon_private_temp` либо `unresolved`; argc и известные flag names без values;
- известные server names только `context7`, `playwright`, `trace`; неизвестные имена — только count, без raw name/hash;
- transport enum `http`/`stdio`/`unknown`; точные recognized descriptor IDs и booleans `command_match`, `args_match`, `endpoint_match`; неизвестные command/args/URL не выводить;
- для reviewed auth/header/env fields — только presence, expected key match и scalar-type match, без значений, длин/хэшей/URL query; неизвестные поля — count + `unreviewed_fields: true`;
- `mapping_candidate: exact|unresolved`, отдельно от `task_acceptance: not_checked`. Любой неизвестный компонент делает итог unresolved. Факт valid JSON не означает safe MCP.

Первый descriptor catalog не должен выдавать public candidates за assigned values. Context7 recognized candidates, переданные root: `https://mcp.context7.com/mcp` и `/mcp/oauth`, оба exact HTTPS URL без userinfo/query/fragment/port override. Источник кандидатов: https://github.com/upstash/context7/blob/master/docs/resources/all-clients.mdx. Выводить только `context7_public_mcp` или `context7_public_oauth`. Headers, в частности authorization/API-key field, — presence-only; неизвестное написание/тип/дополнительный auth transport остаётся unresolved.

Для Playwright нет подтверждённых assigned command/args. До сборки root может утвердить небольшой literal candidate catalog публичных launch descriptors (полный command token и полный argv vector); D1 выводит только candidate ID при полном совпадении. Не принимать произвольный `npx`, package version/range, shell, host path, `--cdp-endpoint`, browser executable/profile/extension как equivalent. Если catalog не содержит actual input, D1 безопасно завершает unresolved; это конкретный недостающий descriptor, не повод печатать строку. Trace catalog также отдельный: факт установки Linux trace 3.25.0 не доказывает семантику inherited Mac command.

### Минимальные локальные тесты D1

- [ ] Создать strict valid synthetic private tree/config; открытый stdin pipe не задерживает exit 78. Help/version открывают ноль config files. Build hash и binary hash зафиксированы до регистрации.
- [ ] Secret canaries во всех headers/env/unknown keys/URLs/argv никогда не появляются в stdout/stderr ни буквально, ни как digest; stdout пуст; descriptor bounded и truthful.
- [ ] Все escapes: relative/inline/duplicate MCP flag; соседний TMPDIR; symlink root/child/file; 0755 directory, 0644 file, wrong owner fixture при доступном test harness, hardlink, FIFO/socket/device, oversize/deep/duplicate JSON/trailing data. Все отказывают без blocking read, child/network/write. Нельзя объявлять owner test выполненным, если fixture нельзя создать.
- [ ] File replacement/truncation tests во время read через контролируемый race harness получают refusal; validity не зависит от pathname после открытия. Evidence показывает только synthetic metadata.
- [ ] Known candidate match vs one-byte command/arg/endpoint mismatch; URL redirects не выполняются вообще. Unknown names/fields не утекли. Valid JSON с неизвестным server не превращается в разрешённый mapping.
- [ ] Независимый review immutable source/binary/imports и raw local proofs. Только root после этого решает unbound profile registration, quiescence, temporary binding, one diagnostic run, drain/restore. Использовать урок D0: plain `--unassign`, не несовместимое `--unassign --no-start`; no daemon restart/general runtime probe, no host-Claude fallback. После удаления daemon temp JSON повторно читать нечего.

## Milestone B: live trusted adapter после verified descriptor

Предлагаемый новый `scripts/agent-runtime/native-adapter.py` получает fixed profile args: canonical coordinator-owned invocation manifest и expected manifest SHA-256, затем native argv. Profile fixed args не должны быть заменяемы поздними native/custom flags: manifest parsing отделён positional delimiter, duplicates/conflicts отвергаются. Adapter не принимает свободный source/run path из prompt/env. Сам manifest содержит полный source SHA/tree/dirty state с untracked kind/mode/hash, owned immutable policy/image ID, role/model/effort, ожидаемый native cwd и authorized MCP descriptor IDs. Trusted run record может связывать только digest редактированных несекретных policy descriptors; raw daemon TOML/JSON и любые secret-bearing поля не хэшируются. Root должен подтвердить, что точный installed profile API действительно поддерживает такие fixed args; иначе pin manifest location/digest в отдельном launcher artifact, не выдумывать capability.

Manifest готовится для одной зарезервированной invocation, root-owned private out-of-source directory, не общий mutable profile manifest. Freshness/одноразовость: до запуска сверить current cwd, source state, policy/image/config descriptors; claim отдельного invocation через atomic exclusive coordinator state вне контейнера. Второй launch/retry с тем же manifest отказывается; новое evidence directory не сбрасывает failures. Если daemon меняет instruction/skills files до child launch, stale snapshot отвергается: coordinator делает новый approved capture после preflight, не игнорирует diff и не переписывает исходный checked SHA. Автоматического refresh источника по неизвестному task нет.

D1 descriptor не authorizes будущий изменённый файл. Adapter заново выполняет тот же bounded path/file/JSON validation **внутри live invocation**, сверяет exact catalog и roster, держит считанный buffer, затем создаёт новую policy в разрешённом private run root. Unknown server/transport/header/command/args/URL/env/settings → exit 78 до модели. Не переносить raw daemon JSON как исполняемый host config.

- Context7: строить HTTP config только из exact verified endpoint. Если required auth обнаружена, trusted adapter может лишь перенести явно разрешённые opaque credential field bytes из live JSON в dedicated private RO secret file без logs/content hashes, после отдельной проверки schema/authority. Без такого проверенного контракта mapping blocked; не заменять assigned OAuth на API key или другой endpoint. OAuth callback/token-store/persistence и Linux support проверяются отдельно, не следуют из endpoint match.
- Playwright: заменить только reviewed descriptor на фиксированный version-pinned Linux executable/argv внутри image; browser и его subprocesses находятся там же, state только RW cache/tmp. Никаких host CDP, user browser profile, extension bridge, native desktop socket, downloads/executables из unknown argv. Требуемые capabilities сравниваются с assigned descriptor; неизвестные flags не отбрасываются молча.
- Trace: отдельная explicit local policy `/usr/local/bin/trace-mcp serve --preset review`, index RW cache, source RO. Обосновать сохранение role context/tool availability отдельно от workspace roster; arbitrary inherited host MCP запрещён.
- Network: нынешний provider proxy не разрешает Context7; понадобится узкое exact host CONNECT правило после выбора endpoint. Public DNS/IP validation и запрет host/private/link-local endpoints действуют независимо от браузерных настроек и при каждом redirect/new CONNECT. Playwright `allowed-origins` не является security boundary и не покрывает redirects (root source: https://github.com/microsoft/playwright-mcp/blob/main/README.md). Нужен отдельный конкретный список browser targets для canary; общий internet/host gateway не fallback. Если тестируется local app, app должен быть в отдельно разрешённом container target, не на host service, и это отдельный network design/canary.

Source — независимый snapshot по logical native `in_place` cwd, source/.git/policy RO; original/common Git и host HOME не монтируются. Evidence/cache/tmp раздельно RW, token/coordinator gate/docker socket/host RPC вне модели. Claude фиксирован `claude-opus-4-6`, medium; Codex — `gpt-5.6-terra`, medium/default tier. Один конечный validated `--settings` с `disableAllHooks:true`, strict mapped MCP; repo hooks не менять. Managed hooks требуют отдельного доказательства совместимости.

Credentials: использовать уже доказанный отдельный persistent Claude credential artifact как один RO mount, не читать его ради диагностики. Coordinator проверяет login freshness штатным CLI в boundary. Refresh делает отдельная фиксированная coordinator operation с dedicated credential store без checker/source/tool authority, single-writer lock и atomic publication новой RO credential generation. Точный supported refresh flow ещё не доказан; невозможность refresh → recoverable auth failure, не RW credential mount модели, не paid API fallback. D1 не участвует в auth.

- [ ] Focused RED/GREEN: duplicates/fixed args overrides, stale source/manifest/image, reused invocation, unknown descriptor, config replaced after D1, secrets never logged, only generated allowed Linux policy. Existing runtime/guard suites покрывают mode/kind/tier restrictions.

В том же owned milestone исправить прежнюю неточность runtime-isolation.md про обязательный rebuild для guard. Real no-model Docker OS-denials и protocol roundtrip/native stream JSON, exact stdin/stdout/stderr, signals/exit/backpressure проверяются для нового runtime/policy. Подделка completion не считается native успехом.
- [ ] Реальные MCP canaries: trace map/outline; Context7 request на actual assigned transport; Playwright только container browser к конкретному разрешённому target, host/private/redirect/CDP denials в OS/network boundary. Public transport reachability не доказывает auth/tool response.
- [ ] Real Claude context marker из preserved CLAUDE.md, test hook с observable synthetic marker: control подтверждает запуск, checker setting подавляет его; сохранённые project settings hash совпадают. Отдельный actual native stream-json run подтверждает integration, original model/medium, RO shell denial и evidence. Native run root запускает лишь после local proofs/review; no unbounded role reassignment.
- [ ] Trusted collector связывает actual native run/actor/profile, checked full SHA/dirty scope, image/policy/build IDs и фактический exit; принимает только новые разрешённые evidence paths. Внешние start → record → immutable archives/commit → bind-artifacts → finish по существующему gate; model не имеет Multica token или gate write path. Native completed не равно task acceptance.

## Точные unresolved inputs для root review

1. Metadata-only probe сообщает только lexical daemon TMPDIR candidate/UID для D1 build pin. Canonical identity устанавливается позже отдельной trusted filesystem-проверкой через descriptor-relative traversal, ownership/private-mode и held descriptors. Не actual credential path/value.
2. Literal candidate catalog command/args для assigned Playwright и inherited trace; actual Context7 choice `/mcp` vs `/mcp/oauth` и presence/schema auth fields выясняет D1. При unresolved не печатать unknown values; root должен предложить новый публичный literal candidate либо отдельное ограниченное metadata amendment.
3. Exact fixed-profile-args capability installed Multica и способ per-invocation manifest pin/claim без нового scheduler. Текущий D0 успех этого не доказывает.
4. Достаточная Linux policy для Context7 OAuth (если observed), pinned Playwright package/browser и точные browser targets; current provider-only egress этого не реализует.
5. Supported credential refresh и managed hooks behavior; standalone login/model pass не закрывает их.

**Exit criterion следующего dispatch:** сначала локально reviewable D1 source/binary/proof без model/native operations. Дальнейший adapter/native milestone начинается только после exact observed descriptor и отдельного root dispatch. Этот brief создан без code/index/HEAD edits, external operations или credential/cache reads.
