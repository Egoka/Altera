Если текущий Node не поддерживает нужную сборку, предъявить фактический дефект/варианты, не молча сменить несколько зависимостей.

Покажи actual SDL violation как отдельное невыполненное требование, а не выдуманный успешный тест. Не исполнять destructive flows на неизвестной среде. Значения статусов бэклога не менять без acceptance.
