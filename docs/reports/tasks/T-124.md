## Результат

- **Сессия не теряется через 15 минут.** BFF обменивает refresh на новый access перед рендером
  страницы, когда навигация пришла без access-cookie, и по ответу `UNAUTHENTICATED` с одной
  попыткой повтора запроса (ADR-0023 п. 3, `session-lifecycle.md` §2.5). Обновлённая пара
  подставляется и в ответ, и в заголовки запроса: SSR читает cookie из запроса, иначе `auth.global`
  увёл бы вошедшего на вход, а BFF пошёл бы к API без токена.
- **Один обмен на сессию.** Реестр обменов в процессе Nitro отдаёт одновременным и чуть
  разошедшимся во времени запросам вкладок результат одного обмена. Без него вторая вкладка
  предъявила бы уже ротированный токен, и сервер отозвал бы все сессии как при краже (§2.4).
- **Ротация сравнивает и заменяет.** `rotateSession` меняет `tokenHash` условным `updateMany`
  по прежнему хэшу и `revokedAt: null`. Проигравший параллельный обмен получает исход повторного
  предъявления либо `revoked`/`expired`, но не `unknown`; пара победителя не теряется поверх пары
  проигравшего.
- Сохраняемый контракт не тронут: мутации `refreshSession`, `logout`, `logoutAll`, хранение
  refresh только хэшем, отзыв по `sid` на каждом запросе, отсутствие токенов в браузерном JS.

### RED до исправления

Со снятым условием на `tokenHash` сценарий AC-2 на PostgreSQL даёт две успешные ротации; на
двойнике падают оба новых теста `rotateSession`. С отключённым обменом все три браузерных
сценария падают — `/me` не отдаёт сводку.

## Остаток

- **Независимое ревью** с маркером `ALTERA_REVIEW_V1` на финальном head.
- **Реестр обменов живёт в памяти процесса Nitro**: при нескольких экземплярах веб-сервера защита
  от ложного reuse работает в пределах одного. Экземпляр сейчас один (прод-окружения в РФ нет,
  T-103); общий счёт обменов — отдельная задача.
- **Лимит «до 10 устройств»** (`[ДОПУЩЕНИЕ]` `session-lifecycle.md` §6) в задачу не входил.
- **Перенос access-токена из тела ответа в cookie целиком** не делался: по границам задачи это
  либо часть ADR-0023 по признанию архитектора, либо отдельная задача.
- **Правило §2.4 не смягчено**: API по-прежнему отзывает все сессии, если один токен предъявлен
  дважды; от ложного срабатывания защищает общий обмен в BFF.
- **Приёмка T-023** (ALTE-97) идёт в её карточке: эта задача её разблокирует.
