## Выполненное

Главная (`index.vue`), страница материала (`[slugTypeContent]/[slugArticle].vue`) и страница
автора (`authors/[slug].vue`): `title`/`description`, canonical, hreflang, Open Graph и JSON-LD
по §10 трёх спецификаций (`docs/spec/20-public/{home,article,author}.md`).

- Материал: canonical = серверный `publicPath`; hreflang — пара только при опубликованной сестре
  (ADR-0002); JSON-LD `Article` + `BreadcrumbList`; предпросмотр и снятый — `noindex` без
  canonical/hreflang/JSON-LD.
- Автор: canonical с `page` через `withQuery`; hreflang — пара всегда; JSON-LD `Person` +
  `BreadcrumbList`; снятый аккаунт — без canonical/hreflang/JSON-LD.
- Главная: canonical `/` или `/en`; hreflang `ru`/`en` + `x-default`; JSON-LD `WebSite` +
  `Organization`.
