## Результат

- **Адрес клиента** BFF берёт из элемента `X-Forwarded-For`, который добавил доверенный прокси
  площадки (`web/server/utils/clientAddress.ts`), а не из самого левого, присланного клиентом. Без
  заголовка остаётся адрес соединения; значение не похожее на адрес не передаётся вовсе. Число
  прокси — `trustedProxyHops` приватного runtime config (`NUXT_TRUSTED_PROXY_HOPS`, по умолчанию 1).
- **Исключение по петлевому адресу убрано**: петлевой адрес — такая же клиентская корзина.
  Системные вызовы `rate-limits.md` §3 через это middleware не проходят вовсе (`/health` и проба
  порта отвечают до Yoga, воркер живёт внутри процесса), и это закреплено тестами.
- **Алиасы**: `rootFieldCounts` считает каждое вхождение корневого поля, стоимость складывается по
  корзинам и применяется одним обращением к хранилищу (`INCRBY` / `ON CONFLICT DO UPDATE`).
  Превышение отклоняет весь документ.
- **Отчёт и receipt T-024** восстановлены (AC-4).
- Пороги не менялись: их утверждение — T-116 (журнал §36 п. 1).
