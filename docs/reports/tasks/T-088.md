`GET /health` на API и новый `/health` в Nuxt отдают состояние зависимостей (`components`: `db`,
`redis`, `psp`, `ai`, `mail`, `storage` — статус `up`/`down`/`disabled`, адаптер и задержка) и
возраст последней успешной резервной копии базы и медиа (`backups`). Просрочка копии и любой `down`
дают `degraded` без 503, пишут `system.health` уровнем `warn` и формируют оповещение всем
активным `owner` и `admin` (журнал §40 п. 2); канал доставки отложен (§40 п. 1) — в записи
`channel: "deferred"`, отправки нет. Отметки прогонов копирования ставит эксплуатация командой
`pnpm --filter server run backup:record` в новую таблицу `backup_runs`.

`/health` в Nuxt — Nitro-маршрут: состояние веба и ответ API, `no-store`, всегда HTTP 200, чтобы
площадка не перезапускала веб из-за недоступного API.
