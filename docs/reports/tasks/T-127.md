## Результат

- **Приглашение писать не обещает бесплатность именно первого материала.** Первый запуск бесплатен
  целиком, базовые авторские возможности открываются бессрочно при первом «Создать статью»
  (журнал §24.1, §25.1, `plan-free.md` п. 6а), поэтому прежняя строка «Первый материал можно
  написать бесплатно» обещала читателю платность со второго. Новое приглашение зовёт написать
  первый материал (`dashboard.md` §1, §5) и о деньгах не говорит.
- **Без статей сводка всегда ведёт к созданию статьи.** Ветка «Выбрать план» → `/pricing` из зоны 5
  убрана: по `dashboard.md` §5 она появляется только после включения платности (журнал #5), а до
  неё уводила читателя с истёкшей выдачей на страницу без цен. Права на создание закрыты принятой
  T-128: истёкшая админская выдача базовой не считается, поэтому первое нажатие создаёт бессрочную
  базовую выдачу и кнопка не ведёт в отказ.
- **Ответ `/me` не кешируется**: `routeRules` отдают `cache-control: private, no-store`
  (`dashboard.md` §4). `/en/me` не существует — страницы `me/*` не локализуются.
- Сохраняемый контракт не тронут: состояния и строки `dashboard.md` §8 на месте, при истёкшей
  выдаче остаются `plan_limit`, «План закончился», режим чтения и «Продлить» → `/pricing`. Из
  закреплённого поведения заменён только сценарий `30-account-dashboard.spec.ts:238` — так требует
  AC-2.
