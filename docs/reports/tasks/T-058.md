## Результат

Обработчик ошибок Nuxt появился как `error.vue` вместо мёртвого `error-t.vue`: 404 — страница
#21 с полной шапкой, ссылками «куда пойти», тремя карточками подборки и кнопкой «сообщить о
битой ссылке»; 500 — страница #23 без единого запроса к API, с кодом запроса в поле копирования
и письмом в редакцию. Офлайн-страница `/offline` читает сохранённое из Cache Storage и сама
уходит на запрошенный адрес по возвращении сети. Код запроса показывается только при
техническом сбое (журнал §28.4) и на 404 не попадает даже в полезную нагрузку.
