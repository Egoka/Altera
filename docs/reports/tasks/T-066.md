## T-066: Обложки — обязательны перед публикацией, кадрирование с предпросмотром и фокусом

**Task**: T-066 / ALTE-148
**Tested SHA**: 2b7f45e75700018ab8fbf24d8cda4ad48be7a569
**PR**: https://github.com/Egoka/Altera/pull/350

Обложка — одна запись медиа на материал и общая для языковых версий (ADR-0002): связь
`Article.coverAssetId`. Подача без обложки отвечает `VALIDATION_ERROR` с полем `cover`
(журнал §29.1). Кадрирование идёт по фокусной точке `MediaAsset.focalX/focalY` под соотношения
карточек `lede` 2:1 и `large` 3:2; `small` делит кадр с `large` и отличается `sizes`, а не
файлом (`image-variants.md` §2 п. 5). Кадр ставится как CSS `object-position`, поэтому
предпросмотр совпадает с нарезкой `sharp`. Метка кадра входит в ключ варианта, фокус — нет:
набор помнит фокус, которым нарезан, и смена фокуса пересобирает только кадры.

Лента отдаёт `ArticleCover { url, variants, alt }`; карточка строит `<picture>` из кадра своего
варианта и `NuxtImg` не зовёт (ADR-0030 п. 2). Дефолтных изображений в лентах нет; заполнитель
«Без обложки» показывает только строка кабинета автора (`article-covers.md` п. 4).
