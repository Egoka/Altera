## Результат

Модуль `server/src/storage/` добавляет интерфейс `ObjectStorage` и ключи по `storage-layout.md`: без имён файлов, только UUID и технические расширения. Есть две реализации. Локальная пишет файлы, подписывает ссылки HMAC и раздаёт `/media/*`. S3-совместимая работает на SigV4 без SDK. Политика доступа делает публичным только вариант готового медиа опубликованной статьи или неархивированного аккаунта. Оригиналы и всё остальное выдаются только по подписанной ссылке. Сбой хранилища — `PROVIDER_UNAVAILABLE: storage`. Выбор реализации — `STORAGE_DRIVER`; в production без значения хранилище `unconfigured`, а `local` запрещён.
