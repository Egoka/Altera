## Результат

- **Адреса на `/en` остаются английскими.** Компоненты, которые собирают адрес из слага
  (карточка материала, подпись автора, кикер рубрики, карточки рубрики и автора, списки и облако
  тегов, мега-меню, шапка, футер), строят его через `localePath`. Страницы лент, каталогов и
  автора локализуют пагинацию, фильтры, сброс фильтров, действия пустых состояний и оба
  `navigateTo` с `redirectCode: 301`.
- **Компоненты, получающие готовый адрес, его не переписывают** (`EmptyState`, `PageHeader`,
  `FeedControls`, `Pagination`): на странице автора действие пустого состояния нарочно ведёт в
  другую локаль, и повторная локализация вернула бы читателя обратно.
- **Меню шапки знает локаль и есть в ответе SSR.** `publicSections(locale: Locale!)` отбирает и
  считает рубрики по `sourceLocale` (журнал §20.9); шапка выводит `nameEn`, пустой перевод
  оставляет имя по умолчанию. Запрос идёт при отрисовке страницы (`useAsyncData` вместо
  `onMounted`), мега-меню скрывается `v-show`. `enabled: false` по-прежнему не обращается к API.
- **Кеш страницы автора сбрасывается по делу.** Общий тег `authorCacheTag(handle)` в нижнем
  регистре; сброс при архивировании, восстановлении и деактивации аккаунта и при смене хэндла —
  ответ 410 не ждёт конца TTL (`author.md` §4).
- Сохраняемый контракт не тронут: стратегия `prefix_except_default`, маршруты реестра, SSR без
  служебных полей.
