## Результат

Вход по одноразовой ссылке не создаёт сессию заблокированному администратором аккаунту ни одним
путём: `acceptConsent` проверяет архив так же, как `verifyMagicLink`. Переход по ссылке из
веб-почты (`Sec-Fetch-Site: cross-site`) завершает вход — обмен токена стал единственным сужённым
исключением из проверки происхождения в BFF, остальные мутации по-прежнему отклоняются.
SSR-обмен переносит `Set-Cookie` внутреннего подзапроса Nitro в ответ навигации, поэтому после
`/auth/verify` в браузере есть httpOnly refresh-cookie. Отметка `usedAt` ставится условным
`updateMany` с проверкой числа строк, поэтому два параллельных обмена одного токена дают не
больше одной сессии.
