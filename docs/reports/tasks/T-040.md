## T-040: обвязка редактора `/me/articles/{id}/edit` — метаданные, обложка, автосохранение, конфликт, подача

**Task**: T-040 / ALTE-151
**Tested SHA**: 6eed3c98304bfbc7c98cc9760eb009f23637cb0f
**PR**: https://github.com/Egoka/Altera/pull/357
**Отчёт**: [docs/reports/2026-09-28-t040-editor-shell-report.md](../2026-09-28-t040-editor-shell-report.md)

Редактор языковой версии по `docs/spec/30-account/author/article-edit.md`: верхняя панель со
статусом, индикатором сохранения и главным действием по состоянию, баннер состояния, метаданные
(заголовок, лид, обложка, рубрика, формат, теги), область блоков, боковая панель
«Проверка / Ревизии / SEO / Языки» в `?tab=` и липкие действия на телефоне. Автосохранение — раз
в 10 с при изменениях, ручное — снимком по кнопке; каждое сохранение создаёт ревизию
(журнал §6.7, ADR-0007).

API версии — первый писатель от `ArticleTranslation`, а не от наследной строки `articles`:
`translation`, `saveTranslation`, `submitTranslation`, `withdrawTranslation`, `revisions`,
`restoreRevision`, `setTaxonomy`, `setSlug`, `authoringTaxonomy`, `mediaAsset`. Миграция
`20260929130000_translation_first_editor` даёт trigger `t015_sync_legacy_article` выключаться
параметром сеанса `altera.legacy_sync`: без этого правка `articles.status` стирала бы текст
автора и задваивала историю. BFF `/api/graphql` научился пропускать `multipart/form-data` без
разбора тела — до этого обложку из браузера загрузить было нельзя (отмечено планом T-066).
Адрес редактора называет языковую версию (`routes.md` #36), каталог страниц кабинета
переименован в `[id]`.
