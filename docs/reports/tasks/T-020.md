## Результат

Миграция `20260928120000_legacy_body_content_document` переводит `article_translations.body` и
`article_revisions.body` в документ `content` (ADR-0001, ADR-0029) через SQL-функцию
`t020_legacy_body_to_document`. Trigger T-015 заменён: legacy-запись в `articles.body` даёт
документ, а не JSON-строку. Скрипт `pnpm verify:legacy-bodies` проверяет конвертируемость всех
тел через `readDocument` из `@altera/content`.

Репетиция проведена дважды на локальных копиях: весь набор E-03 от начала (Р1, 6 статей) и копия
населённой базы (Р2, 487 статей / 555 версий / 1411 ревизий) — 0 неконвертируемых из 2453 тел.
