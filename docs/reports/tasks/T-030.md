последние материалы, закладки и служебные ссылки. API дал `AccountUser.hasArticles` и
`AccountUser.subscription`; план выводится из выдач `PlanGrant` (журнал §8.22, §25.1), только для

`/admin`, самостоятельный архив — `/me/archived`, гость — вход; отказ `me` — страница 500 с
`requestId`. Без статей — «Создать статью» → `/me/articles/new` без плана (§24.1).
