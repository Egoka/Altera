## Результат

Модуль `server/src/error-collector/` пишет сбои в собственную неизменяемую историю `backend_error_events`: UPDATE запрещён триггером. Вхождения группируются по сигнатуре — поток, сервис, код, маршрут и первые кадры стека без адресов. Затем вхождение уходит во внешний сборщик через адаптер. Единственная реализация адаптера — `noop` (`ERROR_COLLECTOR_DRIVER`, поставщик — Q-01). В историю попадают: `error.unhandled` из маскировщика GraphQL с тем же `requestId`, что в ответе; `job.failed` из воркера; `page.error` с фронта через мутацию `reportPageError` и клиентский плагин. Ошибки словаря не записываются, ПДн маскируются, идентификатора пользователя в записи нет.
