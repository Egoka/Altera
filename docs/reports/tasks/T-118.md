## Результат

Страница «О проекте» показывает честный список «что ещё не работает» из опубликованного текста
владельца: раздел второго уровня с якорем `not-working` выносится отдельной зоной, остальной текст
остаётся как прежде и вынесенный раздел не дублирует (журнал §37 п. 1). У материала появилась
кнопка «Пожаловаться»: до разбора сценария жалоб (отложен, F-06) она ведёт на `/contact` с адресом
материала в `?path=` (журнал §37 п. 9). Отдельного поля у API нет: список обновляется вместе с
текстом и публикуется тем же действием `/admin/legal`, поэтому источник у зоны и у текста один.
