## Что сделано

- `server/src/graphql/feed/` — публичный `feed(scope: home, locale)`: топ из пяти последних по дате
  первой публикации с подписью «по дате публикации» (журнал §20.4), «Новое» в окне новизны
  (трое суток `[ДОПУЩЕНИЕ]`, до 12 карточек), «Популярное» не отдаётся до контура вовлечённости
  (F-02). Пустая подборка в ответ не попадает — страница не решает, какую зону скрыть.
- Без повторов между блоками (журнал §22.4) обеспечено структурно: кандидаты читаются одним
  запросом по дате, топ забирает первые пять, «Новое» — следующие внутри окна.
- Кеш `query.feed` по `{scope, locale}`, TTL 300 с, тег `home`; его уже сбрасывают публикация,
  снятие, массовые операции и правки таксономии. Ответ не зависит от сессии (ADR-0019).
- Удалены заменённые `featuredArticles`, `latestArticles`, `popularArticles`.
- `web/app/pages/index.vue` — SSR-запрос подборок и строки состояний `home.md` §8: готовая
  страница, «Пусто» (приглашение авторам со ссылкой на `/pricing`), «Ошибка данных»
  (`ErrorState` с кодом запроса), скелеты при клиентской навигации.
- Компоненты подборок стали props-driven, фикстуры главной удалены, блок «Востребованное» снят
  (в `home.md` §5 его нет; журнал §20.1, §20.3 запрещает дополнительные блоки стартовой главной).
- «Писать» в шапке ведёт в `/me/articles/new`: первый запуск бесплатный (журнал §25.1).

## Границы и допущения

- Топ по рейтингу и «Популярное за неделю» — F-02; подписи «по рейтингу за сутки» и «популярное
  за неделю» в `FeedCaption` не заведены, чтобы не придумывать текст до появления подборок.
- Мутации закладок — T-033; `useSeoMeta`, sitemap и RSS — T-099, T-100; страница `/pricing` — T-060.
- Локаль отбирается по `Article.sourceLocale`: публикуемых языковых версий в `ArticleTranslation`
  на этой ревизии нет, поэтому `isTranslation` вычисляется, но пока всегда `false`. Источник
  сменится вместе с переводом API на языковые версии (T-020).
- Уровень автора выводится из `planTier` (`pro` → `pro`, иначе `standard`) —
  `[ДОПУЩЕНИЕ: техническое отображение]`, согласованное с контрактом `ReadingArticle` (T-093).
  `author.md` §7 называет уровни `basic` / `pro`; расхождение имён — для синхронизации реестров.
- «Ошибка данных» показывается внутри страницы без подмены HTTP-кода: переход на страницу #23
  при полном отказе строит T-058.
- Реестр `pages.md` #1 упоминает `topAuthors`, которого нет в `home.md` §5 и который запрещает
  журнал §20.1; реализация следует `home.md`, синхронизация реестра — T-110.
