## Результат

«Удалить аккаунт» реализовано как архивирование (журнал §5.1–2, §25.7, §35 п. 1): шаги 2–5
flow #12. Подтверждение по ссылке из письма одной транзакцией ставит `archivedAt` и
`archiveMode = self`, отзывает все сессии, каскадно архивирует статьи с актором «сам
пользователь» и пишет аудит `user.archive.self` и `article.archive`. При следующем входе
ограниченная сессия открывает только `/me/archived`, откуда пользователь восстанавливает
аккаунт сам (`user.restore.self`); статьи остаются в архиве, план идёт без возврата.

Новое: модель `AccountArchiveRequest` и миграция `20260927150000_account_archive_request`,
модуль `server/src/account/archive.ts`, GraphQL-модуль `account-archive`, письмо
`account_archive_confirm`, корзина лимита `account.archive.user` (1 в сутки), страницы
`/me/delete`, `/me/delete/confirm`, `/me/archived` и компонент `StateScreen`.
