## What was built

### `/admin/grants`

FishtVue Table + Split panel page. Columns: user name (clickable), handle, tier (badge), status (badge), start date, end date (shows "Бессрочно" when null). Detail side panel opens on row click, showing all fields plus a Revoke button for active/queued grants.

GrantPlan modal: user handle (required), tier select (standard/pro), start date, end date (empty = indefinite), reason (required). Submit disabled until handle + reason filled. On submit, new row inserted with status `queued`.

### `/admin/subscriptions`

Same table layout showing the same grant data. First-launch info banner explains paid subscriptions are a separate phase. Detail panel links to `/admin/grants` for grant management. No GrantPlan button (read-only in this scope).

### Navigation

Two new menu items added to `web/app/components/admin/header.vue`: Grants (lucide:gift) and Subscriptions (lucide:credit-card).

### i18n

15 new `admin.*` keys + `common.confirm` added to both `ru.json` and `en.json`. All template Cyrillic text externalized; i18n-locales test passes.
