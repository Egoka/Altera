## Что сделано

- `server/src/audit/registry.ts` — реестр 63 утверждённых audit-кодов и их зон. Набор кодов сверяется
  с замороженным реестром `docs/spec/00-registries/events-and-logs.md` тестом биекции
  (`server/tests/audit-zone-registry.test.ts`), поэтому список нельзя рассинхронизировать вручную.
  Зоны — три темы `docs/spec/50-access/visibility.md` п. 10; распределение кодов по темам —
  `[ДОПУЩЕНИЕ]`, выведенное из темы зоны и колонок «Кто инициирует»/«Файл» реестра, с ссылками на
  номера строк в комментариях. Код без зоны закрыт для служебных ролей: его видят `admin` и `owner`.
- `server/src/admin/audit.ts` — список с курсорной пагинацией (`limit` 20, максимум 100), карточка,
  сводка по фильтру и экспорт CSV. Авторизация и все фильтры применяются до Prisma-запроса; период по
  умолчанию 7 дней. Запрошенная чужая зона видимость не расширяет; код вне зоны даёт пустую выдачу,
  запись вне зоны — `NOT_FOUND`.
- `server/src/graphql/audit/` — `auditLog`, `auditEntry`, `auditSummary`, мутация `exportAudit`.
  Контрактный тест проверяет, что среди мутаций аудита есть только экспорт и что тип выгрузки не
  содержит полей с ПД.
- `web/app/pages/admin/audit/index.vue`, `useAdminAudit`, `utils/audit.ts` — страница с фильтрами в
  адресе (`?zone=`, `?action=`, `?actor=`, `?entity=`, `?subject=`, `?requestId=`, `?period=`, `?id=`),
  боковой панелью записи, `noindex` и всеми состояниями §9.
- Экспорт CSV — только `admin` и `owner`; лимит 10 в час на сотрудника считается по самому журналу
  (число собственных записей `stats.export` за час), превышение — `RATE_LIMITED` с `retryAfter`.
  Успешный экспорт создаёт ровно одну запись `stats.export` с полями строки #40 (`report`, `rows`).
  В файле только время, код, роль актора, признак «система», тип сущности и `requestId`.
- Миграций нет: используется существующая модель `AuditLog`, UPDATE и DELETE запрещены триггерами.

## Границы и допущения

- Признак «критичная запись» и фильтр `?critical=1` не входят в задачу (T-079 §3; журнал §26.1, Q-08),
  поэтому в списке и сводке их нет.
- Строка §9 «Конфликт» неприменима по самой спецификации: журнал не редактируется, UI для неё нет.
- Пагинация курсорная (`[ДОПУЩЕНИЕ]` §4), поэтому в адресе сохраняется `?cursor=`-совместимая пара
  времени и идентификатора вместо `?page=`.
- Фильтр «Актор» показывает служебные записи из сводки по текущему фильтру: отдельный запрос списка
  сотрудников не используется, чтобы чтение аудита не порождало `admin.read.personal`.
- Верхняя граница одной выгрузки — 1000 строк `[ДОПУЩЕНИЕ]`: спецификация числа строк не задаёт.
- `analyst` без экспорта — `[ДОПУЩЕНИЕ]` самой спецификации (`audit-log.md` §1, §5, §9); матрица #94
  описывает экспорт статистики, а не аудита.
