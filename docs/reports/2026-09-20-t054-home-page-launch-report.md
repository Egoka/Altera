## 1. Результат

Главная строится из одного публичного запроса `feed(scope: home, locale)`.

**Сервер** — новый домен `server/src/graphql/feed/`:

- `feed` возвращает `scope`, `locale` и `sections[]` в фиксированном порядке отбора
  топ → новое → популярное. Пустая подборка в ответ не попадает, поэтому страница не решает,
  какую зону скрыть (`home.md` §5).
- Первый этап: топ — пять последних по дате первой публикации с подписью «по дате публикации»
  (журнал §20.4); «Новое» — материалы окна новизны (трое суток `[ДОПУЩЕНИЕ]`) до 12 карточек;
  «Популярное» не отдаётся до контура вовлечённости (F-02).
- Без повторов между блоками (журнал §22.4) обеспечено структурно: кандидаты читаются одним
  запросом в порядке даты, топ берёт первые пять, «Новое» — следующие внутри окна, поэтому
  освободившееся место сразу занимает следующий материал.
- Локаль — строгая граница выдачи: отбор идёт по `sourceLocale`, ответ не зависит от сессии.
- Кеш: `cache:v3:data:query.feed:<хэш{scope, locale}>`, TTL `CACHE_TTL_SECONDS.publicList`
  (300 с), тег `home`. Публикация, снятие, массовые операции и правки таксономии уже сбрасывают
  этот тег через `buildArticleCacheTags` и резолверы рубрик и тегов.
- Удалены заменённые `featuredArticles`, `latestArticles`, `popularArticles`: доспецификационные
  запросы главной, из которых `popularArticles` возвращал не популярность, а дату.

**Веб**:

- `pages/index.vue` получает подборки через `useAsyncData` + `useGraphQL` (SSR), различает строки
  состояний `home.md` §8: готовая страница, «Пусто» (приглашение авторам со ссылкой на
  `/pricing`), «Ошибка данных» (`ErrorState` с кодом запроса), скелеты при клиентской навигации.
- `PagesStartFeatured` (lede + четыре `large`), `PagesStartLatest` (группы `buildFeedGroups`,
  произвольное число материалов) и `PagesStartPopular` (карточки `rank`) стали props-driven;
  фикстуры и заглушки из них удалены.
- Карточные обёртки `ArticleLede/Base/Large/Small/Text/Group` типизированы публичным
  `ReadingArticle` вместо административного `ArticleCardFragment`.
- «Писать» в шапке ведёт в `/me/articles/new`: первый запуск бесплатный (журнал §25.1), гостя
  дальше перекладывает на `/login?next=…` существующий `createArticleDraftAndOpenEditor`.
- Словари ru/en получили подпись подборки и текст приглашения; ключ удалённого блока убран.

## 3. Границы и ограничения

- Топ по рейтингу и «Популярное за неделю» не реализуются: это F-02 (`ArticleScore`, контур
  вовлечённости). Подписи «по рейтингу за сутки» и «популярное за неделю» в перечислении
  `FeedCaption` не заведены, чтобы не придумывать текст до появления подборок.
- Мутации закладок в scope не входят (T-033): карточка умеет показывать кнопку, включает её
  задача закладок.
- `useSeoMeta`, JSON-LD, sitemap и RSS главной остаются за T-100 и T-099; заголовок страницы
  прежний (`Altera`).
- Ссылка приглашения ведёт на `/pricing` по `home.md` §5; сама страница появится в T-060.
- Локаль отбирается по `Article.sourceLocale`: публикуемых языковых версий в
  `ArticleTranslation` на этой ревизии нет, поле `isTranslation` вычисляется, но пока всегда
  `false`. Источник сменится вместе с переводом API на языковые версии (T-020).
- Уровень автора выводится из `planTier` (`pro` → `pro`, иначе `standard`) —
  `[ДОПУЩЕНИЕ: техническое отображение]`, согласованное с уже слитым контрактом
  `ReadingArticle` (T-093). `author.md` §7 называет уровни `basic` / `pro`; расхождение имён —
  для синхронизации реестров.
- «Ошибка данных» показывается внутри страницы (`ErrorState` с кодом запроса, шапка и футер
  работают) без подмены HTTP-кода: переход на страницу #23 при полном отказе строит T-058.

## 4. Вопросы владельцу

1. **Блок «Востребованное» снят с главной.** `home.md` §5 фиксирует шесть зон без него, журнал
   §20.1 и §20.3 запрещают дополнительные блоки на стартовой главной. Блок жил на фикстурах и
   участвовал в живом ревью вёрстки 2026-09-13/14 — если он нужен как продуктовая зона, это
   отдельное решение и отдельная строка спецификации.
2. **Реестр `pages.md` #1 упоминает `topAuthors`**, чего нет в `home.md` §5 и что противоречит
   журналу §20.1 («блока авторов нет»). Реализация следует `home.md`; синхронизация реестра —
   T-110.
