## Правки содержания утверждённых строк (главное)

- **Роли** (`roles.md`): иерархии по включению нет; `editor` — только собственные
  редакционные статьи, без проверки чужих и без таксономии; `moderator` — ручная ветка,
  снятие на доработку, ручная публикация, окончательный отказ, архив без восстановления, не
  правит чужой текст, не архивирует аккаунты; `analyst` — полная индивидуальная картина автора
  с ПДн и финансовый контур; `admin` — операционное чтение плюс архивирование/восстановление
  аккаунтов, таксономия, финансовый контур, без публикации и ролей; `owner` — несколько
  равноправных, индивидуальные исключения, «удалить навсегда».
- **Жизненный цикл** (матрица #20, #23–27, #100–102; flows #3–5, #15): первая подача → AI
  (бинарно, с критическими причинами при отказе) → автопубликация; отказ → правка → ручная
  ветка без AI; одноразовое часовое окно «перередактировать»; неограниченное снятие ревьюером с
  рекомендациями; ручная публикация сразу публично; окончательный отказ с чтением и
  копированием; все версии — снимками; история решений и сообщений.
- **Архив вместо удаления** (матрица #26–27, #51–52, #103, #105; flows #11–12, #15–16): актор
  и уровень прав, низшая роль не отменяет архив высшей; аккаунт: самостоятельный архив без
  самовосстановления, административный архив = блокировка с каскадом статей; медиа закрывается
  вместе со статьёй.
- **Подписка** (`plans.md`, матрица #56, #60–65, #108–109; flows #6–7): без льготного периода;
  возврат не сокращает период; понижение со следующего периода; повышение сразу с отложенным
  остатком и без доплаты; ручные дни — в конец периода; год = 10 месяцев; pro-инструменты в
  составе pro; вторая языковая версия — standard вручную, pro через AI.
- **Админка**: разделы AI-процессов (#14), Аудита (#16) и новый Письма (#21) — этап 1;
  настройки провайдеров — этап 4; сводка для всех служебных ролей по своей зоне; таксономия —
  admin; финансовый контур — analyst и admin; администраторы — owner.
- **Аудит** (события #67, #75): чтение ПДн через административные инструменты и каждое
  административное изменение с полями до/после.

ADR-0039 (AI-балл), ADR-0042 (ровно один owner; аналитик без мутаций; иерархия), ADR-0044
(льготный период), ADR-0045 (двухступенчатая проверка каждой ревизии, оспаривание), ADR-0046
(ручной перевод только редакцией), ADR-0035 (доплата, гранты как исключение), ADR-0014
(блокировка как отдельный режим), а также `docs/vision/04-roles-and-access.md`,
`05-editor.md` §2 и §4, `07-commerce.md` §4, `01-product.md` §6 описывают отменённые журналом
правила. Журнал по своему статусу «не заменяет ADR» — для формализации нужны ADR-0047+ и
ревизия 3 названных документов. До этого в спецификациях заходов 2–9 источник — журнал и
реестры; ссылка на ADR даётся с пометкой «в части, не противоречащей журналу».
