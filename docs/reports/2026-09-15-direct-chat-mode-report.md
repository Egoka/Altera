## Границы

Нужна новая прямая сессия Claude: старый разговор уже содержит загруженные операционные
инструкции и снимок hooks. Canary доказывает устранение воспроизведённого сценария,
а не качество всех будущих решений модели. Старые checkout на прежних commit содержат
прежние настройки; новые задачи должны получать исправление из свежего app.
Полная продуктовая приёмка, успешный deploy и завершение старого parent этим отчётом не заявляются.
