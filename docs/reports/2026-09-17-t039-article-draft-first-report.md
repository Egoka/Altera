# T-039: новый материал создаётся черновиком

## Результат

- `createArticle` принимает только необязательные `sectionId` и `locale`, создаёт статью со
  статусом `draft`, пустой перевод и первую ручную ревизию. Отсутствующая или недоступная
  рубрика не блокирует создание и не сохраняется в черновике.
- Маршрут `/me/articles/new` стал действием: создаёт черновик и заменяет текущую запись
  истории маршрутом `/me/articles/{id}/edit`. Переданный `section` используется как
  необязательная начальная рубрика.
- `requestReview` отклоняет черновик без рубрики ошибкой `VALIDATION_ERROR` с полем
  `sectionId`.
- Добавлен защищённый `tagAutocomplete`: поиск активных тегов по имени, английскому имени
  или slug, минимум два символа и серверный предел 20 результатов.
- Автор может создать тег без ручного slug; сервис формирует его из имени и сохраняет
  прежние проверки роли, активного плана и уникальности через реестр slug.

## Критерии готовности

- AC-1 — passed: серверные тесты проверяют создание черновика без рубрики с первой ревизией,
  игнорирование недоступной рубрики и `VALIDATION_ERROR` при подаче без рубрики.
- AC-2 — passed: тесты проверяют ограниченный регистронезависимый автокомплит только активных
  тегов для авторизованного автора и создание нового тега автором без переданного slug.
- Маршрут-действие — passed: web-тест проверяет мутацию с необязательной рубрикой и переход
  на URL редактора созданной статьи.
