## 1. Что сделано

   `CLAUDE.md`, двух рабочих заметок владельца (только чтение). Итоги — раздел 4.
2. **Роадмап ревизии 3** `docs/issues/00-roadmap.md`: таблица «что изменилось», стадии
   A «Бесплатный запуск» → B–E (порядок после запуска — вопрос Q-13), граф зависимостей эпиков,
   критерий достаточности запуска, точки решений; шесть этапных файлов ревизии 2 получили плашку
   «заменено бэклогом ревизии 3» и не переписывались.
3. **Бэклог `docs/backlog/`**: `README.md` (индекс, идентификаторы, статусы, формат задачи,
   правила изменения, «Текущее состояние»), шаблоны задачи и эпика, 18 эпиков `E-`, 112 атомарных

   10 будущих этапов `F-` без атомарных задач, `matrix.md` (задача → роль → навыки → проверка →
   зависимости → параллельность → статус), `coverage.md` (решения #1–59 и §24–§29, OPEN-QUESTIONS,
   все 147 файлов спецификаций → путь), `ready-candidates.md` (15 кандидатов и порядок первых
   работ). Ни одна задача не отмечена `готова`.
4. **Операционная модель Multica** `docs/multica/operating-model.md` (роли и границы, чтение
   задачи, стадии и evidence, формат готовой задачи, единственный writer и параллелизм,

   владельцев); изменчивые списки не копировались.
6. **ADR и vision**: указатель `docs/decisions/README.md` приведён к строкам статуса самих ADR
   (43 строки); ADR-0045 получил строку статуса «частично заменено журналом Г1 #8, #14, §6» вместо
   `[ВОПРОС ВЛАДЕЛЬЦУ]`; в десять vision-документов добавлена врезка «Расхождения с журналом
   Г1–Г9» с перечнем недействующих пунктов и ссылками на действующие спецификации, включая правило
   `alt` (§29.11, §29.13) и статусы `in_review`/`rework`. Текст ADR и vision не переписывался.
7. **`docs/spec/OPEN-QUESTIONS.md`** §2 п. 15: отметка о выполнении ревизии роадмапа и ссылка на
   задачу T-109 для vision.

## 2. Что не сделано и почему

- Полная переработка vision-документов (3324 строки) — задача T-109; здесь только врезки.
- ADR-0047+ по журналу — задача T-108; правило «ADR не пишутся при синхронизации» сохранено.
- Строки-черновики Г6 (`routes.md` #74, `pages.md` #43, матрица #120–121) не переведены в
  «утверждён» — это решение владельца (Q-08).
- Противоречия спецификаций, требующие решения владельца (Q-09 этап `/me/delete`, Q-12
  `saveTranslationPublished`), не «исправлены» в спецификациях; технические расхождения без
  продуктового выбора вынесены в задачу T-110.
- Задачи в Multica не создавались, автопилоты не включались, роли не менялись — по условию прохода.

## 3. Отклонения от плана

- Добавлен блокер Q-13 «порядок этапов после запуска» (в плане было 10–12 блокеров): журнал не
  задаёт порядок стадий B–E, а роадмап без него был бы новым решением.
- Число задач — 112 при ориентире 70–90: декомпозиция по строкам реестров дала больше атомарных
  единиц, чем предполагалось; укрупнять не стал, чтобы задача читалась без чата.
- Черновая декомпозиция проектировщика использовалась как перекрёстная проверка; из неё взяты
  четыре противоречия спецификаций (раздел 4.3), не вошедшие в первоначальную инвентаризацию.

## 6. Как проверено

Генератор и проверка — скрипты в рабочей папке сессии (не в репозитории); результат:

```
$ python3 -X utf8 gen.py --check
ERRORS: 0
journal gaps: []
spec gaps: []
tasks: 112 Counter({'зависит': 77, 'решение владельца': 17, 'кандидат': 15, 'отложена': 3})

$ python3 -X utf8 check_backlog.py
задач: 112 эпиков: 18 блокеров: 13 этапов: 10
ошибок: 0
```

Проверка покрывает: десять обязательных полей у каждой задачи; допустимые статусы и отсутствие
`готова`; разрешение всех ссылок `T-/E-/Q-/F-` в бэклоге, роадмапе, `CLAUDE.md` и модели
Multica; существование всех путей `docs/…`, упомянутых в этих файлах; относительные ссылки
внутри `docs/backlog/`; отсутствие циклов зависимостей; слова словаря ревизии 1 и оценки/цены
в задачах; совпадение строк `matrix.md` и `README.md` с набором файлов задач.

```
$ grep -rn "ровно один\|на сутки\|AI-оценк" CLAUDE.md
```
— попадания только в контексте «отменены журналом».

```
$ git status --short | grep -v "^?? docs/backlog\|^?? docs/multica"
```

— изменены только перечисленные в разделе 5 файлы; untracked-файлы других сессий и заметки
