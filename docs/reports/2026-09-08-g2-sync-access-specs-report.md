## Допущения, требующие внимания владельца

- `admin` создаёт служебные записи любой роли, кроме `owner`, но не меняет и не снимает роли
  (трактовка #47 при сохранении #13).
- Снятая служебная запись остаётся записью без прав с признаком служебного происхождения, чтобы
  `owner` мог вернуть ей роль; альтернатива — архивирование (единственный новый
  `[ВОПРОС ВЛАДЕЛЬЦУ]`, `escalation-and-demotion.md` §6).
- Форма оспаривания доступна при любом административном архиве, не только при экстренном.
- Признак редакционной статьи — поле `Article.kind`; `editor` восстанавливает редакционную
  статью, только если сам архивировал.
