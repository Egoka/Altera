## Шаг 2. Маркер ревьюера — исходник исправлен, инструкция агента ждёт владельца

За 2026-09-26 шесть одобрений (T-032, T-033, T-036, T-077, T-090, T-101) пришли прозой без
`ALTERA_REVIEW_V1`: ревьюер публиковал комментарий, а итоговым ответом run был пересказ. Контроллер
читает только итоговый ответ. В `docs/multica/autonomy/reviewer-prompt.md` добавлен порядок завершения:
комментарий и уборка — до вердикта, после них инструменты не вызываются, маркер — последняя строка
итогового ответа (рекомендация `docs/multica/done-finalization.md`, «Сопутствующее»).

Инструкция агента-ревьюера `db94a617` в Multica не изменена: запись в агента отклонена правами этой
сессии. Снимок «до» — `docs/multica/snapshots/2026-09-26-reviewer-marker/before.json`. Инструкция
агента отличается от исходника только путём к контракту, который подставляет установщик; применить
правку можно командой из PR. Финализатор и без неё делает один повторный запрос при ответе без маркера.
