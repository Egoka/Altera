## Допущения, требующие внимания владельца

- Открытие карточки платежа считается чтением ПДн с аудитом (как карточка пользователя).
- Чтение самого журнала аудита не аудируется (иначе рекурсия).
- E-mail получателя в «Письмах» маскирован, раскрытие — с аудитом; тела писем не хранятся.
- Повтор письма и задания — только `owner`; ссылки входа и коды не повторяются.
- Базовые выдачи первого запуска показаны вкладкой в «Грантах» без действий.
