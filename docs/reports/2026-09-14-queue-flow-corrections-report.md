## Проверка и границы

при занятом writer, no-start, поиск потерянного перехода без metadata/PR, защита от повторного

`git diff --check` завершился с кодом 0. Обязательные локальные hooks и GitHub CI проверяются
при публикации этой ревизии; их источником служит связанный PR.

Readback доказывает сохранение конфигурации, но не выполнение агентом нового поведения.
Один проверочный проход очереди запланирован после публикации документов в app. Его результат
проверяется по native run, созданным Todo и event/run ID передачи, отдельно от статуса completed.
История проверки доступна в [очереди Multica](https://multica.ai/altera/autopilots/c40fbc10-3bb3-4181-b244-14b87e8ae3f1).
Изоляция и exactly-once enforcement M4 этим изменением не заявляются.
