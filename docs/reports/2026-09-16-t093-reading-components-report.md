# T-093: компоненты чтения и публичная навигация

## Результат

- Добавлен единый `ArticleCard` с вариантами `lede`, `large`, `small` и `rank`, адаптерами прежних карточек, состоянием без изображения и метками `pro`/«Перевод».
- Добавлены атомы метаданных, кнопка закладки для гостя/авторизованного пользователя и состояния пустого, ошибочного и загружаемого списка.
- Шапка и mega-menu получают рубрики из нового минимального публичного GraphQL-контракта `publicSections`; административный запрос `sections` не раскрыт гостю.
- Футер заменён на компактную навигацию с реальными внутренними маршрутами и актуальной подписью проекта.

## Критерий готовности

- AC-1 — passed: снимки вариантов и состояний зафиксированы в `web/tests/__snapshots__/reading-components.nuxt.test.ts.snap`; Playwright подтверждает построение меню из перехваченного ответа navigation API.

Среда: Node `24.12.0`, pnpm `10.18.3`.

- `pnpm format` — exit 0.
- `pnpm codegen` — exit 0; GraphQL-артефакты воспроизводимо сгенерированы.
- `pnpm lint` — exit 0.
- `pnpm test` — exit 0: server 119 passed / 9 skipped; web 131 passed.
- `pnpm --filter nuxt-app typecheck` — exit 0.
- `pnpm --filter server run build:ci` — exit 0.
- `pnpm --filter nuxt-app build` — exit 0; остались только известные предупреждения Browserslist, Tailwind sourcemaps и локального `sharp` binary.
- `pnpm exec playwright test tests/e2e/navigation.spec.ts` в `web` — exit 0, 1 passed.

Preflight подтвердил GitHub/origin, отдельный worktree, baseline и версии инструментов. Он был запущен уже после внесения изменений, поэтому ожидаемо не прошёл проверку clean start; также в локальной среде отсутствует `LOG_HASH_SECRET`. Сервер и БД не запускались, миграций нет, поэтому эти два ограничения не подменяются статусом passed и не блокируют выполненные статические и тестовые проверки.
