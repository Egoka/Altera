### 2.1 Почему разовость хранится отдельным полем, а не выводится из статуса

Проверка «уже использовано» не может опираться только на `status !== published`: после
доработки и повторной автопубликации статус снова становится `published`, а право уже
использовано и не должно вернуться (журнал #9: «доступно только один раз»). Поэтому мутация
проверяет постоянное поле `reeditedAt` (устанавливается один раз и никогда не сбрасывается),
а не только текущий статус и окно.

### 2.2 Общий код ошибки для «окно закрыто» и «уже использовано»

Access-matrix #100 и `articles.md` §4 называют один код `FORBIDDEN` для обоих исходов, не различая
их текстом — `canReedit` объединяет обе проверки в один предикат и один `createApiError`, без
отдельного кода на «уже использовано».

  §25.13) и явно вне критериев готовности (§5 источника).
