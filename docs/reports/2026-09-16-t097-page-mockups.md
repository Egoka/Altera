# T-097 — Макеты страниц запуска и состояний

**Дата**: 2026-09-16  
**Задача**: ALTE-49 / T-097  
**Ревизия**: 1  
**Исполнитель**: Дизайнер  
**Этап**: 1 (страницы запуска)

Настоящий документ — текстовые макеты страниц: зонирование, компоненты, состояния
и поведение в трёх точках останова. Источники: `docs/vision/06-design-system.md` §3–6
и поштучные спецификации `docs/spec/20-public/`, `30-account/`, `40-admin/`.
Реализацию ведут задачи страниц; данный документ — основа для независимого review.

## Система токенов и типографики (применяется ко всем страницам)

**Цвета** (`main.css @theme`):

| Токен | Светлая | Тёмная |
|---|---|---|
| `--color-paper` | тёплый белый | почти чёрный |
| `--color-ink` | почти чёрный | тёплый белый |
| `--color-ink-muted` | серый | серый |
| `--color-accent` | `#ff5a1f`-семейство | приглушённый |
| `--color-rule` | светло-серый | тёмно-серый |
| `--color-surface` | карточки, формы | карточки, формы |

Тёмная тема: `html.dark` через `@nuxtjs/color-mode`; переключатель в `AppHeader`.

**Шрифты**:

| Роль | Гарнитура |
|---|---|
| H1 страниц, H2 секций | Waterway |
| Заголовки материалов и карточек, дек, тело | Garamond Libre |
| Подписи, кикеры, байлайны | Cormorant SC (капитель) |
| Логотип | Bergamasco |
| Интерфейс: навигация, кнопки, формы, кабинет, админка | `font-sans` (системный) |

**Сетка**: контейнер `max-w-7xl`, отступы `px-4 sm:px-6 lg:px-8`;
мера текста `max-w-3xl`; карточки 1/2/3 колонки на `<md`/`md`/`lg`.

## 1. Главная (`/`, `/en`)

**Источник**: `docs/spec/20-public/home.md`

### Зоны (Desktop `lg ≥ 1024`)

```
┌─────────────────────────────────────────────────────────┐
│  AppHeader: логотип · рубрики · поиск · Войти · Писать  │
├───────────────────────────────────────────┬─────────────┤
│  FeedSection «Главное»                    │             │
│  ┌──────────────── lede ────────────────┐ │  «Новое»    │
│  │  обложка 2/3 ширины, заголовок, дек  │ │  FeedSection│
│  │  Byline, ProBadge, закладка          │ │  small-     │
│  └──────────────────────────────────────┘ │  карточки   │
│  ┌── large ──┐ ┌── large ──┐             │  1–12       │
│  │  2 колонки│ │           │             │             │
│  └───────────┘ └───────────┘             │  «Популярное│
│  ┌── large ──┐ ┌── large ──┐             │  за неделю» │
│  └───────────┘ └───────────┘             │  скрыт до   │
│                                           │  этапа 2    │
├───────────────────────────────────────────┴─────────────┤
│  AppFooter                                               │
└─────────────────────────────────────────────────────────┘
```

**Зоны**:
1. `AppHeader` — логотип, `SectionNav` (рубрики из API), поиск (этап 3), «Войти» или аватар+меню, «Писать», переключатель языка.
2. **Главный топ** (`FeedSection` + `ArticleCard`): 1 `lede` + 4 `large`. Подпись «по дате публикации» на этапе 1.
3. **«Новое»** (`FeedSection` + `ArticleCard` `small`): до 12 карточек без повторов из топа.
4. **«Популярное за неделю»** (`FeedSection` + `ArticleCard` `rank`): 1–10 с номерами. **Скрыт до этапа 2**.
5. **Приглашение** (`EmptyState`): «Здесь пока пусто — станьте первым автором» + ссылка `/pricing`. Видимо только когда нет ни одной публикации.
6. `AppFooter` — о проекте, правила, оферта, политика ПД, возвраты, реквизиты, контакты, RSS.

**Tablet `md 768–1023`**:
- Топ: `lede` на всю ширину, 4 `large` в 2 колонки.
- «Новое» — 2 колонки.
- «Популярное» — горизонтальная лента под «Новым».

**Mobile `< 768`**:
- Одна колонка; `large` карточки становятся `small` с изображением справа.
- Шапка сворачивается в меню-бургер; шапка липкая при прокрутке вверх.
- Порядок зон: топ → новое → популярное → футер.

### Состояния

| Состояние | Отображение |
|---|---|
| **Загрузка** (клиентская навигация) | `LoadingSkeleton` по зонам 2–4; шапка и футер готовы |
| **Пусто** (нет публикаций в локали) | Шапка + зона 5 (приглашение) + футер |
| **Ошибка** (`feed` не ответил) | `ErrorState` с `requestId` + ссылка «написать в редакцию»; шапка и футер работают |
| **Частичная ошибка** (одна секция) | Секция скрыта, остальные отображаются; лог `page.error` |
| **Длинный заголовок** | Заголовок `lede` обрезается после 3 строк (`line-clamp-3`), дек — 2 строки |
| **Без изображения** | `ArticleCard` — placeholder с инициалами рубрики, фиксированный `aspect-ratio` |
| **Бейдж pro** | `ProBadge` оранжевый в `Byline` карточки |
| **Перевод** | Пометка «Перевод» в кикере карточки |
| **Закладка — нет сессии** | Иконка открыта; клик → приглашение войти с `?next=/` |
| **Закладка — занято** | Иконка заполнена; оптимистичный апдейт |
| **Служебная роль** | Кнопка «в Админку» в шапке для `moderator`/`admin`/`owner`; закладок нет (журнал #58) |
| **Locale ru** | Шапка: «Войти», «Писать»; язык `ru`; RSS `/rss.xml` |
| **Locale en** | Шапка: «Sign in», «Write»; язык `en`; путь `/en`; RSS `/en/rss.xml` |
| **Светлая / тёмная тема** | Переключатель в шапке; все токены через `html.dark` |

## 2. Лента рубрики (`/{рубрика}`, `/en/{section}`)

**Источник**: `docs/spec/20-public/section-feed.md`

### Зоны (Desktop)

```
┌─────────────────────────────────────────────────────────┐
│  AppHeader (активная рубрика в SectionNav)              │
├─────────────────────────────────────────────────────────┤
│  SectionHeader: название рубрики · описание · кол-во    │
├─────────────────────────────────────────────────────────┤
│  FeedControls: «по дате публикации» · фильтр формата    │
│  · фильтр тега · кнопка «сбросить»                     │
├─────────────────────────────────────────────────────────┤
│  Список — группы ArticleCard (large + small)            │
│  ритм рубрики SECTION_RHYTHM, 24 карточки               │
│  строка: автор · дата                                   │
├─────────────────────────────────────────────────────────┤
│  Pagination                                             │
├─────────────────────────────────────────────────────────┤
│  Другие рубрики — горизонтальный ряд                    │
├─────────────────────────────────────────────────────────┤
│  AppFooter                                              │
└─────────────────────────────────────────────────────────┘
```

**Зоны**:
1. `AppHeader` + `SectionNav` (текущая рубрика выделена).
2. `SectionHeader`: название (Waterway), описание, число материалов, обложка при наличии.
3. `FeedControls`: подпись принципа «по дате», фильтр формата, фильтр тега (слаг или из `topTags`), «сбросить».
4. Список `ArticleCard` (`large`, `small`) по ритму `SECTION_RHYTHM`; строка карточки: автор · дата (рубрика известна из шапки).
5. `Pagination` по страницам (`limit=24`); скрыта при одной странице.
6. Горизонтальный ряд остальных рубрик со счётчиками.
7. `AppFooter`.

**Tablet**:
- 2 колонки внутри группы; слот «текст+изображение» на всю строку; фильтры на 2 строки.

**Mobile**:
- 1 колонка; фильтры — кнопка «Фильтры» с раскрывашкой; зона 6 — горизонтальная прокрутка.

### Состояния

| Состояние | Отображение |
|---|---|
| **Загрузка** | Скелеты карточек, панель фильтров активна |
| **Пусто по фильтру** | `EmptyState` «ничего не найдено, сбросить фильтры»; зона 6 (другие рубрики) |
| **Ошибка** | `ErrorState` + `requestId`; шапка рубрики, если загружена |
| **404** (неизвестный слаг / архив / нет публикаций в локали) | Страница «не найдено» |
| **Без изображения** | Карточка без изображения, фон `--color-surface` |
| **Длинный заголовок** | `line-clamp-2` для `large`, 1 строка для `small` |
| **Locale en** | Путь `/en/{section}`; `hreflang` при наличии сестринской рубрики |
| **Отфильтрованный адрес** | `noindex, follow` |
| **Светлая / тёмная тема** | Токены; фильтровая панель тоже адаптируется |

**Зоны**:
1. `AppHeader`.
2. `PreviewBanner` (только `?preview=`): статус версии, ссылка в кабинет / очередь; обратный отсчёт «перередактировать до ЧЧ:ММ» автору.
3. `ArticleHeader` (`max-w-3xl`, по центру): `SectionKicker`, `format`, заголовок Garamond, дек, `Byline` с аватаром, `ProBadge`, время чтения, `LanguageSwitch`, `BookmarkButton`.
4. Обложка: `ProseFigure` с подписью и атрибуцией; без обложки — зона скрыта.
5. `ProseArticle` (`max-w-3xl`): `ProseParagraph`, `ProseHeading`, `ProseQuote`, `ProseList`, `ProseFigure`, `ProseDivider`; «широкий» — до контейнера, «полный» — во всю ширину viewport.
6. `ArticleFooter`: `DateStamp` «опубликовано / обновлено», `TagChips`, `ShareButton`, `BookmarkButton`; счётчик прочтений (от 100).
7. `AuthorHeader` компактный: аватар, имя, «о себе», ссылка на `/authors/{handle}`, `FollowButton` (этап 3).
8. «Ещё по теме» — `relatedArticles` карточками `small` (сетка 4); скрыта если пусто.
9. `AppFooter`.

**Tablet**:
- Мера `max-w-3xl` по центру; «ещё по теме» — 2 колонки.

**Mobile**:
- 1 колонка; `BookmarkButton` и `LanguageSwitch` под деком в шапке; зоны 7+8 подряд; липких элементов нет.

### Состояния

| Состояние | Отображение |
|---|---|
| **Загрузка** | Скелет шапки и 3 абзацев |
| **Ошибка** | `ErrorState` с `requestId` |

| **410** (снятый, архивированный после публикации) | Страница «материал удалён» |

| **Без обложки** | Зона 4 скрыта; шапка материала — без отступа снизу |
| **Длинный заголовок** | Без обрезки (полный заголовок); дек — `line-clamp` нет |
| **Без тегов** | `TagChips` скрыта |
| **Счётчик скрыт** (менее 100) | Число не отображается |
| **Перевод** | В зоне 3: «перевод опубликован {дата}»; `LanguageSwitch` виден только при опубликованной сестре |
| **Locale en** | Путь `/en/{section}/{slug}` |
| **PreviewBanner — автор** | Плашка с обратным отсчётом «перередактировать до ЧЧ:ММ»; «перередактировать» — диалог-подтверждение |

| **Ограничение плана в предпросмотре** | В плашке: «редактирование недоступно: план истёк» + `/pricing` |
| **Светлая / тёмная тема** | Prose: `--color-ink`, `--color-paper`; изображения без фильтра |

│   аккаунт»           │  подписка на авторов,            │
│  поле e-mail         │  путь в авторы → /pricing        │
│  [x] согласие с      │                                  │
│  оферта v{N} и ПД    │                                  │
│  [Получить ссылку]   │                                  │
│  «пароля нет: ссылка │                                  │
│  придёт на почту»    │                                  │
│                      │                                  │
│  — после отправки —  │                                  │
│  VerifyState:        │                                  │

**Зоны**:
1. `AppHeader` сокращённый: только логотип + переключатель языка.
2. `LoginForm`: заголовок, поле `type=email`, `ConsentCheckbox` с версиями текстов, кнопка «Получить ссылку», подпись «пароля нет».
3. `VerifyState` «письмо отправлено»: адрес, «проверьте папку Спам», кнопка повтора с таймером, «изменить адрес».
4. Пояснение: зачем аккаунт, ссылка `/pricing`.
5. `AppFooter` сокращённый.

**Tablet**:
- Форма по центру `max-w-md`; пояснение под формой.

**Mobile**:
- 1 колонка; поле и кнопка во всю ширину; `inputmode=email`; автофокус.

### Состояния

| Состояние | Отображение |
|---|---|
| **Загрузка** (`legalVersions`) | Форма с неактивной кнопкой; версии загружаются в `ConsentCheckbox` |
| **Ошибка версий** | `ErrorState` «попробуйте позже» вместо формы (без версий согласие невалидно) |
| **Не отмечено согласие** | Кнопка «Получить ссылку» заблокирована |
| **Неверный формат почты** | Inline-ошибка «Укажите корректный e-mail» |
| **После отправки** | `VerifyState`; таймер `retryAfterSec` |
| **Повтор отправлен** | Таймер сбросился; «повторная ссылка отправлена» |
| **Лимит запросов** | Форма: «слишком много запросов, попробуйте через N минут» (`RATE_LIMITED`) |
| **Почта недоступна** | `PROVIDER_UNAVAILABLE`: «письма временно не отправляются» + `requestId` |
| **С сессией** | 302 на `?next=` или `/me` — страница не отображается |
| **Архивированный аккаунт** | Форма работает как обычно; блокировка — на `/auth/verify` |
| **Locale en** | Заголовок: «Sign in or create an account»; путь `/en/login` |
| **Светлая / тёмная тема** | Форма наследует `--color-surface` и `--color-ink` |
