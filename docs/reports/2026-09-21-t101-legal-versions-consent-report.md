## Что сделано

### Сервер

`server/src/legal/texts.ts` — механизм версий. `publishLegalVersion` в одной транзакции берёт
следующий номер вида и локали, переводит действующую редакцию в `previous` и создаёт новую со
статусом `published`, датой публикации и признаком существенности; опубликованная редакция не
правится. Перед публикацией разметка проверяется: скрипты, `iframe`, `style`, обработчики
событий и `javascript:`-ссылки отклоняются, пустой текст и пустое описание изменений — тоже.
`readPublicLegalText` отдаёт действующую или прежнюю редакцию, архив, якоря разделов второго
уровня для оглавления и список локалей для `hreflang`; если в локали текст не опубликован,
показывается другая локаль с пометкой; черновик и неизвестная редакция — «не найдено».

`server/src/auth/legal.ts` — состояние согласия. `readConsentStates` сравнивает принятую
редакцию оферты и политики ПД с действующей: повторное согласие нужно, если после принятой
вышла **существенная** редакция, или если аккаунт при опубликованном тексте не принимал ни одной.
Прежняя реализация T-022 требовала согласия при любой новой версии; по ADR-0028 п. 2 и
`legal-texts.md` §5 несущественная правка действует без него. `findOutdatedConsent` при входе
использует то же правило; регистрация по-прежнему пишет согласие с действующими версиями.

`server/src/graphql/legal` — контракт §4 спецификаций:

| Операция                               | Ответ                                                                                                                                                                                         | Ошибки                                                            |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `legalText(kind, locale, version)`     | `LegalDocument`: вид, показанная и запрошенная локаль, редакция, дата, существенность, что изменилось, `isCurrent`, HTML, якоря, архив, `availableLocales`; `null` — вид нигде не опубликован | `NOT_FOUND` (редакция)                                            |
| `AccountUser.consents` (`me.consents`) | по оферте и политике: действующая и принятая редакция, время принятия, `reconsentRequired`                                                                                                    | `UNAUTHENTICATED`, `FORBIDDEN` (чужой или архивированный аккаунт) |

Ответ `legalText` публичный и кешируется по тегу `legal:<kind>` (ADR-0019). Карта сайта
перечисляет опубликованные `/legal/*` с датой публикации и парой локалей, без `?version=`.
Команда `pnpm --filter server legal:publish --kind … --locale … --file … --summary …
[--material]` публикует редакцию релизом кода до раздела `/admin/legal` (T-083 §7) и сбрасывает
кеш вида и карты сайта.

### Веб

`components/legal/Page.vue` (`LegalPage`) собирает зоны §5: заголовок с редакцией, датой и «что
изменилось», пометки об откате локали и о прежней редакции, принятую редакцию для аккаунта,
оглавление, текст, архив редакций и связанные документы. Зоны аккаунта читаются в браузере
отдельным запросом `GetMyConsents`, поэтому серверный HTML страницы одинаков для всех.
`TableOfContents` — липкая колонка на `lg` и раскрывашка ниже; `NoticeCard` — пояснения.
Печать скрывает шапку, футер, оглавление, архив и кнопки; якоря учитывают фиксированную шапку,
раздел по якорю подсвечивается.

Страницы: `/legal/terms`, `/legal/privacy` (зона «Ваши данные»: экспорт, смена почты, удаление;
архивированному — только связь с редакцией), `/legal/content-rules`, `/legal/license` (блок
«коротко» из трёх утверждений §5 и раздел `#ai-training` о запрете обучения ИИ — журнал §24.2).
Раздел выводится страницей, пока его нет в опубликованном тексте, и не дублируется, когда он
появится в тексте T-102. В футер добавлены «Пользовательское соглашение» и «Лицензия на
контент».

### Строки состояний §8

| Строка               | Что показано                                                                        | Код       |
| -------------------- | ----------------------------------------------------------------------------------- | --------- |
| Загрузка             | скелет текста при клиентском переходе                                               | 200       |
| Пусто                | текст другой локали с пометкой                                                      | 200       |
| Ошибка данных        | `ErrorState` с `requestId`                                                          | 500       |
| Нет доступа          | неприменимо: документ публичный, гость читает                                       | 200       |
| Не найдено / удалено | неизвестная или неверная редакция — 404; неизвестный якорь правил — редакция сверху | 404 / 200 |
| Ограничение плана    | неприменимо                                                                         | 200       |
| Заблокирован         | архивированный аккаунт читает как гость                                             | 200       |
| Paywall              | зарезервировано, не наступает                                                       | 200       |

Документ, не опубликованный ни в одной локали, показывает пустое состояние «Документ готовится
к публикации» с `noindex`: до T-102 это действительное состояние страниц.

## Отклонения и допущения

- «Принять новую версию» на странице (`[ДОПУЩЕНИЕ]` `legal-terms.md` §5, §9) заменено пометкой:
  согласие с существенной редакцией запрашивается при следующем входе — так описано в
  `legal-texts.md` §5, и мутация `acceptConsent` действует только в потоке входа.
- Зона «Лицензии изображений» (`legal-license.md` §5 п. 6) скрыта как пустая: запроса
  `mediaLicenses` в API нет.
- Раздел `#ai-training` показывается формулировкой из журнала §24.2 и `legal-license.md` §4 до
  появления окончательного текста владельца (T-102).
- Страницы `/contact`, `/me/export`, `/me/delete`, `/legal/paid-services`, `/legal/refunds`, на
  которые ссылаются зоны, в репозитории пока нет.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` об английском тексте как переводе «для сведения» (`legal-terms.md` §12)
  остаётся открытым: пометка «официальная версия — на русском» не выводится.
