## Предложено сверх обязательного (владелец просил предложить)

- **Разделы админки**: гранты и промокоды (#10), фоновые задания (#13), рассылка (#19),
  настройки системы (#20) — обоснования в конце `admin-sections.md`.
- **Страницы**: сводка кабинета, сессии, смена почты, оплата отдельной страницей, выгрузка
  данных, 410 и офлайн, RSS/sitemap как объект спецификации.
- **Маршруты**: `/me/export`, `/me/delete`, `/admin/grants`, `/admin/jobs`,
  `/admin/newsletter`, маяк прочтения `/api/read`, вебхук провайдера, ссылка возврата на
  доработку из письма.
- **Flows**: правка опубликованного материала (главный источник нагрузки на ревьюера,
  ADR-0045), AI-перевод, блокировка, закладки и подписка на автора.
- **Коды ошибок**: `PLAN_LIMIT` (нет плана или исчерпан лимит), `PROVIDER_UNAVAILABLE`
  (провайдер платежей/AI/почты недоступен) — через `error-dictionary.md`.
- **Сущность**: `ReadExclusion` уже в модели (заход 0); здесь — действия `reads.exclude`.

## Что не сделано и почему

Ничего из плана не пропущено. Спецификации по строкам — заходы 2–9. Каталог блоков —
отдельный проход (`95-blocks/`).

## Отклонения от плана

Нет. Таблица «Предложено сверх обязательного» в `admin-sections.md` переведена в
ненумерованный вид, чтобы скрипт полноты не считал ссылки на разделы второй раз.

## Как проверено

```
for f in <реестры>; do grep -cE '^\| [0-9]+ \|' $f; grep -oE '^\| [0-9]+ \|' $f | sort | uniq -d; grep -cE '\|  \||\| \|' $f; done
```

Результат: строки — как в таблице выше; дубликатов номеров — 0 (после правки таблицы
предложений); пустых ячеек — 0.

```
grep -oE 'ADR-[0-9]{4}' … | sort -u | while read a; do ls docs/decisions/$a-*.md; done
grep -oE '_templates/[a-z-]+\.md' … | while read t; do [ -e docs/spec/$t ]; done
```

Результат: все упомянутые ADR (0002…0046) и шаблоны существуют.

Пути в колонке «Файл» — будущие файлы заходов 2–9; их существование не проверялось намеренно
(правило полноты применяется к строкам со статусом выше «черновик» **после** создания файла).

**Гейт Г1.** Владелец правит реестры прямо в файлах: вычёркивает строки с пометкой «отменено:

этого — заход 2 (роли и политики доступа) по промту, собранному из
`docs/prompts/fable-spec-NN-template.md`.
