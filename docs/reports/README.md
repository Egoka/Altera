# Отчеты о выполненных работах

Эта папка содержит отчеты о выполненных работах: по планам из `docs/plans/`, а также по
рефакторингу, исправлениям и улучшениям проекта.

Папка обязательная: **план не считается завершённым, пока по нему не создан отчёт.**

## Имя файла

```
docs/reports/ГГГГ-ММ-ДД-краткое-имя-report.md
```

Дата — день завершения работы (может отличаться от даты плана), слаг — тот же, что у
плана: `2026-09-05-connect-web-to-api-report.md`.

## Шапка файла

```markdown
# Отчёт: <название плана>

- **Дата**: ГГГГ-ММ-ДД
- **План**: docs/plans/ГГГГ-ММ-ДД-краткое-имя.md
- **Ветка**: server/api
- **Коммиты**: <хэши, относящиеся к работе>
- **Результат**: выполнено полностью | выполнено частично | отменено
```

## Содержание отчёта

1. **Что сделано** — по пунктам плана.
2. **Что не сделано и почему** — честно, включая отложенное.
3. **Отклонения от плана** — где и почему пошли иначе.
4. **Затронутые файлы** — список.
5. **Как проверено** — конкретные команды и их результат. Утверждение «работает» без
   выполненной проверки в отчёт не попадает.
6. **Что осталось** — следующие шаги, если они есть.
