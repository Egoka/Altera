## Контекст

(`docs/2026-09-09-media-upload-processing-notes.md`, `docs/2026-09-09-provider-observability-notes.md`);
решения вносятся в журнал как §29. Синхронизация — только по ним, без новых чисел, провайдеров и
лимитов. Заметки владельца не редактируются, на них ставятся ссылки.

2. `85-media-and-binary/*`: обложка обязательна и индивидуальна (§29.1); мастер-оригинал без EXIF
   (§29.2); `PROVIDER_UNAVAILABLE: storage` (§29.3); AVIF + WebP (§29.4); аватар сразу, откат
   рецензентом с аудитом (§29.5); выгрузка с мастер-оригиналами без вариантов (§29.6); чеки —

   (§29.8); возраст резервной копии в состоянии системы (§29.9); без водяных знаков (§29.10);
   AI-описание `alt` при загрузке (§29.11); целевой конвейер и статусы обработки по заметке (§29.12).
3. Смежные: `article-edit.md`, `write-and-publish.md`, `review-queue.md`, `profile-edit.md`,
