## 1. Цель

Подготовить девять независимых, пока пропускаемых Playwright-регрессий. Шаги каждого сценария должны однозначно соответствовать строкам таблицы «Шаги» его flow-спецификации, чтобы включение после готовности зависимых задач не меняло сценарий.

## 2. Контекст

В `web/tests/e2e/` уже есть по одному файлу для целевых flow. До выполнения работы требуется сверить их с таблицами из `docs/spec/10-flows/` и разделить объединённые действия на спецификационные шаги. ADR-0031 требует e2e для ключевых сценариев и честный CI; до появления фикстур сценарии обязаны оставаться skipped.

## 3. Шаги

1. Сверить каждый из девяти файлов с соответствующей таблицей «Шаги» и реестром flows.
2. Исправить структуру `test.step`, чтобы заголовок и действия представляли строки таблицы, включая именованные ветви (`5а`, `5б`, `1с`, `3о`, `Р1`–`Р3`, `С`).
3. Сохранить по одному `test.skip(true, reason)` в каждом сценарии; не добавлять реальные фикстуры или продуктовый код.
4. Запустить `pnpm --filter nuxt-app run test:e2e` и зафиксировать фактические числа и результат.
5. Сохранить парный отчёт с evidence по AC-1 и AC-2.

## 4. Критерии готовности

- **AC-1**: девять отдельных файлов покрывают flow #1, #3, #4, #5, #11, #12, #13, #15 и #16; набор `test.step` соответствует строкам соответствующих таблиц. Проверка: построчное ревью файлов против спецификаций.
- **AC-2**: все девять сценариев остаются skipped, а Playwright-запуск завершён с exit code 0. Проверка: `pnpm --filter nuxt-app run test:e2e`.

## 5. Что сознательно не входит

Фикстуры, реализация экранов и API, включение сценариев, flow #2, #6, #7 и #9, а также тестирование опубликованной среды.

## 6. Риски

- Фикстуры и элементы интерфейса ещё не реализованы. Снижение: каждый сценарий явно skipped с зависимостями.
- Спецификация содержит развилки. Снижение: основные строки и именованные ветви выражены отдельными шагами; не создаются неподтверждённые данные.

- **Реализация / тестировщик / run `01a0a37f-9645-7470-91ac-062ae12607d7`**: вход — этот план и утверждённые flow-спецификации; выход — девять сценариев и отчёт.
