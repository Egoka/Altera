# Лента автора: однорядные группы и хронология по месяцам

- **Дата**: 2026-09-13
- **Ветка**: web/home-grid (рабочее дерево общее со второй сессией владельца)
- **Базовый коммит**: eafe748
- **Отчёт**: docs/reports/2026-09-13-author-feed-report.md (заполняется по завершении)
- **Статус**: завершён

## 1. Цель

Список материалов на странице автора (`/authors/{handle}`) собирается тем же механизмом
групп, что лента рубрики, но из однорядных раскладок, где порядок чтения совпадает с порядком по
дате, и делится по месяцам публикации с подписями — читатель чувствует хронологию. Служебная
строка карточек показывает рубрику и дату; дата на страницах рубрик и авторов набрана в стиле
прежней даты автора и краснеет только при наведении.

## 2. Контекст

- Страница `web/app/pages/authors/[slug].vue`: шапка `HeaderUser` и три моковых карточки
  `ArticleAuthor` типа `ArticleListItem` в колонке `max-w-3xl` с линейками; отладочный
  `console.log("slug", slug)`.
- Лента рубрики после eafe748: `buildFeedGroups`, `SECTION_RHYTHM`, `CardMeta = "type" | "date"`,
  атом `ShowDate` капителью Cormorant. Служебная строка с двумя вариантами не вмещает третий
  («рубрика · дата»), нужен набор частей.
- Спецификация `docs/spec/20-public/author.md` §5 зона 4: «карточки large для первых двух
  [ДОПУЩЕНИЕ], далее small с кикером рубрики»; §9 — колонки; §12 — то же допущение. Сортировка
  по новизне до Г4 (журнал §20.4).
- Решения владельца 2026-09-13: тот же приём, что для рубрики; комбинации проще, с ощущением
  хронологии; служебная строка — рубрика · дата; стиль даты как у прежней даты автора
  (`font-sans uppercase text-xs/6 font-bold`), красный только при наведении.

## 3. Шаги

1. Тесты: `AUTHOR_RHYTHM` проходит `validateRhythm` на своей вместимости и на стыке круга;
   `groupByMonth` держит порядок, не теряет материалы и делит по месяцу публикации;
   `formatArticleMonth` даёт «Сентябрь 2026» / «September 2026».
2. `AUTHOR_RHYTHM` из однорядных раскладок в `feedRhythm.ts`; `groupByMonth` в
   `feedGroups.ts`; `formatArticleMonth` в `articleDate.ts`.
3. Служебная строка как набор частей: `MetaPart = "author" | "type" | "date"`,
   `CardMeta = MetaPart[]`, атом `ArticleMeta` с разделителями вместо трёх одинаковых блоков в
   карточках; `ShowDate` в стиле прежней даты автора, красный при наведении; страница рубрики
   переходит на `['author', 'date']`.
4. Страница автора: секции месяцев с подписью и линейкой, группы по ритму автора,
   `['type', 'date']`; демо-данные — 24 материала главной с подстановкой автора и
   детерминированными датами; `ArticleAuthor` и отладочный вывод со страницы убираются.
5. Проверка глазами на 1280, 768 и 375; главная и рубрика без регрессий; консоль без
   сообщений валидаторов и гидратации.
6. Спецификация `author.md`: зона 4, §9, §12 — допущение заменяется решением.
7. Отчёт.

## 4. Критерии готовности

- `pnpm test` в `web` зелёный с новыми тестами.
- На `/authors/{handle}` при 1280 px: два месяца с подписями, внутри — только однорядные группы,
  порядок карточек по дате убывает слева направо и сверху вниз, все 24 материала на месте,
  служебная строка «рубрика · дата», дата приглушённая, при наведении красная.
- Главная — «автор · рубрика», рубрика — «автор · дата» с датой в новом стиле.
- `pnpm format:fix && pnpm lint && pnpm test` проходят.

## 5. Что сознательно не входит

- Панель ленты, пагинация, подписка на автора, состояния загрузки и ошибки; список авторов.
- Замена моковой шапки автора с чужим текстом; удаление файла `article/author.vue`.
- Подключение GraphQL.

## 6. Риски

| Риск | Чем снимаем |
|---|---|
| Соседние однорядные группы читаются одинаково | сигнатуры соседей и стыка круга проверяются тестом |
| Месяц из одного материала даёт пустую сетку | хвост ложится в `solo-wide`, тест сборки на остаток 1 уже есть |
| Перевод служебной строки на набор частей ломает главную и рубрику | умолчание `['author', 'type']`, страницы проверяются глазами |
| Подпись месяца зависит от часового пояса | ключ месяца и подпись считаются одним и тем же способом, что и дата карточки; даты демо стоят на полдень UTC |
