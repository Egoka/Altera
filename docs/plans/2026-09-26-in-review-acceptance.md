## Что требует controller для Done

`controller.py done` проверяет по живым источникам: `issue_scope` (карточка в проекте,
`metadata.task_id`), схему receipt, все AC `passed` с evidence, PR в `app` с `merge_sha` в `app`,
зелёный агрегат `test` на head, **review — завершённый native run агента из `reviewer_ids` в той же
карточке с последней строкой `ALTERA_REVIEW_V1`**, implementer run той же карточки, полный список
файлов PR, выкладку (для PR с `server/`, `packages/`, lock-файлами — probe-run release-агента с
`get_deploy` не старше часа и `/health` с тем же SHA) и `finalization` — sha256 Markdown-итога в `app`,
содержащего Task ID и head SHA.

Предварительный инвентарь: у 14 задач нет receipt, у многих receipt не содержит `merge_sha`, ни у одной
нет review-run в карточке. Значит, ни одна задача сейчас не проходит controller по бумагам.
