# Бюджет попыток стадии: решение владельца вместо допущения

- **Дата**: 2026-09-09
- **Ветка**: docs/platform-design
- **Базовый коммит**: 26c3973
- **Отчёт**: docs/reports/2026-09-09-stage-attempt-budget-report.md (заполняется по завершении)
- **Статус**: завершён

## 1. Цель

Условие выхода из цикла перестаёт быть допущением агента и становится правилом сквада:
две подряд неуспешные попытки одной и той же проверки внутри стадии останавливают работу.

## 2. Контекст

`docs/multica/operating-model.md` описывает останов по конфликту (§5) и по блокеру владельца
(§7), но не задаёт бюджет попыток. Для agent loop это условие выхода: без него неуспешная
итерация повторяется, пока не исчерпается контекст, и накопленные ошибки выдаются за результат.

При сборке слоя исполнения (`docs/reports/2026-09-09-agent-loop-harness-report.md`) число было
вписано в десять файлов ролей как `[ДОПУЩЕНИЕ, требует подтверждения владельца]`, потому что в
журнале и операционной модели его нет. Владелец подтвердил бюджет в две попытки 2026-09-09.

Решение операционное, а не продуктовое: оно относится к порядку работы сквада
(operating-model §7 «изменение состава сквада, ролей, расписаний»), а не к правилам продукта,
поэтому фиксируется в операционной модели, а не в рабочем журнале решений.

## 3. Шаги

1. В `docs/multica/operating-model.md` §5 добавить пункт «Бюджет попыток стадии» с формулировкой
   правила, границей его применения и указанием, что параметр подтверждён владельцем 2026-09-09.
2. В десяти файлах `.claude/agents/multica-*.md` заменить пометку
   `[ДОПУЩЕНИЕ, требует подтверждения владельца]` ссылкой на правило операционной модели.
3. Убедиться, что в файлах ролей не появилось других числовых параметров.

## 4. Границы

Входит: формулировка правила в операционной модели и ссылка на него в файлах ролей.

Не входит: таймауты в минутах, лимиты на число задач, глобальный лимит итераций сессии и любые
другие числа — владелец подтвердил один параметр, остальные не задаются. Не входит правка
рабочего журнала решений и ADR. Не входит включение автопилотов.

- `grep` по файлам ролей: других чисел-параметров не появилось.
- `pnpm format`, `pnpm lint`, `pnpm test` — код 0.
