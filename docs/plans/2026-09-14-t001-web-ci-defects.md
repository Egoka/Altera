## Цель

Устранить ошибки типизации Nuxt-приложения и обеспечить заголовок `Altera` на главной странице,
чтобы обязательные web typecheck/build и существующий homepage smoke могли пройти на актуальной
ревизии ветки.

## Контекст и решение

CI воспроизводит ошибки на границах типов: значения даты используются как route target,
параметры маршрута не сужены до строки, optional URL фотографии не совпадает с текущим
`ArticleResponse`, шаблон обращается к нетипизированному `$router`, а страницы `me` ссылаются на
несуществующее именованное middleware `auth`. Исправления должны следовать уже работающим
паттернам репозитория: явное строковое представление route params, `useRouter()`/`useRoute()` из
Nuxt, существующее middleware и явный `useHead()` страницы. Типовые расхождения нельзя скрывать
через `any` или необоснованные assertions.

## Критерии готовности

- **AC-WEB-TYPES**: `pnpm --filter nuxt-app run typecheck` завершается с exit code 0 и без
  исходных ошибок `vue-tsc`.
- **AC-HOME-TITLE**: существующий сценарий
  `web/tests/e2e/homepage.smoke.spec.ts` видит document title `Altera` и завершается успешно.
- **AC-REGRESSION**: `pnpm format`, `pnpm lint`, `pnpm test` и
  `pnpm --filter nuxt-app run build` завершаются с exit code 0; фактическое число тестов
  фиксируется из вывода.
- **AC-SCOPE**: diff содержит только перечисленные web-исправления, этот план и парный отчёт;
  постороннее изменение `AGENTS.md` не затронуто.

## Что сознательно не входит

- Изменение GraphQL-схемы, серверной модели, CI-конфигурации или поведения авторизации.
- Ослабление типов, тестов либо middleware-проверок.
- Слияние в `app` до независимого review актуальной ревизии; выпуск ведёт релиз-инженер.

## Риски

- Преобразование route params может скрыть отсутствующий параметр: используется детерминированная
  строка по принятому Nuxt-паттерну, а typecheck подтверждает контракт компонента.
- Замена middleware может изменить доступ: выбирается существующее middleware, соответствующее
  назначению защищённых страниц `me`, без изменения его реализации.
- Optional `photoUrl` нельзя маскировать assertion: данные нормализуются или контракт корректируется
  только после сверки реального источника и потребителей.

## Стадии и handoff

Разработка выполняется агентом `Altera — разработчик` в текущем local run. Evidence стадии:
scoped commit, этот план, парный отчёт, точные команды/exit codes и dirty fingerprint. После
изменения revision требуется независимое тестирование/review; прежний вердикт для `a674a35` или
`e6a4e1b` на новый код не переносится.
