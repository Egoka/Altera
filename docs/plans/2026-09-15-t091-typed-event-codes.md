# T-091: сверка кодов событий с реестром

- **Базовый коммит:** `df5963e`
- **Источник:** `docs/backlog/tasks/T-091-typed-event-codes.md`
- **Цель:** зафиксировать Vitest-контракт, по которому утверждённые `log`- и `error`-коды в реестре точно совпадают с серверными константами.

## План

1. Добавить серверный тест, который читает `docs/spec/00-registries/events-and-logs.md`, разбирает строки markdown-таблиц и выбирает только строки со статусом `утверждён` и типом `log` либо `error`.
2. Извлечь все backtick-коды из ячейки «Код события», включая несколько кодов и сокращения с ведущей точкой относительно предыдущего полного кода.
3. Сравнить отсортированные множества утверждённых `log`-кодов с `LOG_EVENT_CODES`, а `error`-кодов — с ключами `ERROR_DEFINITIONS`.
4. Доказать чувствительность проверки контролируемой временной мутацией одной константы: тест должен упасть, после восстановления — пройти.
5. Запустить `pnpm --filter server test`, оформить отчёт с фактическим выводом и закоммитить только артефакты T-091.

## Ожидаемые файлы
