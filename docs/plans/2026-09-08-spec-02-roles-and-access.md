# Заход 2: роли и политики доступа

- **Дата**: 2026-09-08
- **Ветка**: docs/platform-design
- **Базовый коммит**: e349251
- **Отчёт**: docs/reports/2026-09-08-spec-02-roles-and-access-report.md
- **Статус**: завершён, ожидает гейт Г2 (отчёт — docs/reports/2026-09-08-spec-02-roles-and-access-report.md)

## 1. Цель

Четырнадцать спецификаций в `docs/spec/50-access/`: восемь ролей по утверждённым строкам
`00-registries/roles.md` (`roles/{guest,reader,author,editor,moderator,analyst,admin,owner}.md`)
и шесть политик (`visibility`, `permission-checks`, `permission-exceptions`,
`session-lifecycle`, `rate-limits`, `escalation-and-demotion`) по строкам
`00-registries/access-matrix.md`. Все — по шаблонам `_templates/role.md` и
`_templates/policy.md`, в статусе «на утверждении». Гейт Г2 (лёгкий): матрица подтверждена.

## 2. Контекст

Гейт Г1 закрыт коммитом `e349251`: реестры приведены к журналу решений
`docs/decisions/role-review-working-log-2026-09-08.md`. Источник правил для этого захода —
журнал и реестры; ADR-0003, 0014, 0018, 0022–0024, 0035, 0042 — в части, не противоречащей
журналу (ADR-0047+ для формализации журнала ещё не написаны — см. отчёт Г1).

## 3. Шаги

1. Роли: guest, reader, author, editor.
2. Роли: moderator, analyst, admin, owner.
3. Политики: visibility, permission-checks, permission-exceptions.
4. Политики: session-lifecycle, rate-limits, escalation-and-demotion.
5. Обновить статусы в `roles.md` (файл создан) и колонку «Файл политики» матрицы там, где путь
   уточнён; проверка полноты и объёмов; отчёт; коммит; гейт Г2.

## 4. Критерии готовности

- 14 файлов существуют; каждый ≥ 80 строк (роль) / ≥ 60 строк (политика), все разделы шаблона
  заполнены.
- Каждая строка матрицы, ссылающаяся на `50-access/*`, имеет файл.
- Ни одного правила сверх журнала и реестров без пометки `[ДОПУЩЕНИЕ]`.

## 5. Что сознательно не входит

- Отложенные темы (жалобы, промокоды, рассылки) — только ссылка на статус «отложено».
- Формат запроса индивидуального исключения (журнал #18) — не регламентируется.
- Экраны и кнопки админки — заходы 7–8.

## 6. Риски

- Журнал молчит о части действий (см. `[ДОПУЩЕНИЕ]` в матрице) — переносятся в §8 файлов
  ролей как вопросы владельцу.
