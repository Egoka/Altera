# Переработка стартовой страницы: воздух, иерархия, вариативная сетка

- **Дата**: 2026-09-13
- **Ветка**: web/home-grid
- **Базовый коммит**: 804d84d
- **Отчёт**: docs/reports/2026-09-13-home-grid-report.md (заполняется по завершении)
- **Статус**: выполняется

## 1. Цель

Довести стартовую страницу до характера, заданного владельцем: чистый минимализм, достаточно
воздуха при сохранённой связности, чёткая геометрия с одним намеренным нарушением, проработанная
типографическая иерархия. Настраиваемая сетка получает больше вариаций, чтобы лента перестала
быть монотонной.

## 2. Контекст

Заход проектирования через Claude Design закончился выводом владельца: макеты выходят хуже, чем
уже собранная вёрстка. Рамка сменилась — существующий сайт это черновик, доводим его в коде.

Владелец назвал три проблемы: монотонность сетки, скученность контента (особенно мета, прижатая к
разделителям) и слабая иерархия. При разборе кода нашлись причины, часть из которых — настоящие
дефекты, а не вкусовые претензии:

- `web/app/components/article/large.vue:39` и `small.vue:19` используют класс `text-md`, которого
  в Tailwind не существует: кегль молча падает до 16 px, и заголовок компактной карточки
  становится равен деку крупной. Контраст размеров исчезает именно поэтому.
- `web/app/components/article/base.vue:26` — `leading-1` даёт межстрочный интервал 4 px при кегле
  18–20 px, строки заголовка накладываются.
- `web/app/components/article/group.vue:108,124,131` — `pt-4 mt-2 border-t`: 8 px над линейкой и
  16 под ней, причём сверху вплотную стоит мета, прижатая `mt-auto` ко дну фиксированного бокса.
  Это ровно то место, на которое жалуется владелец.
- В коде семь схем горизонтальных отступов; левые кромки шапки, контента и футера не совпадают ни
  на одном разрешении.
- Знание о раскладке сетки продублировано в трёх таблицах `group.vue`: `layouts`, `areaMappings`
  и `needsBorder`.
- Владелец заменил пустые файлы гарнитуры Bergamasco на настоящие, но переименовал
  `BergamascoLight.ttf` в `Bergamasco Light.ttf`, а `main.css:15` ссылается на старое имя —
  светлое начертание, которым набрано слово в логотипе, не грузится.

Решения владельца, принятые при планировании: спецификация `home.md` §5 обновляется под
вариативную сетку; дефекты чинятся во всех страницах, а не только на главной; горизонтальные
отступы сводятся к одной схеме по всему сайту.

## 3. Шаги

1. Починить ссылку на файл гарнитуры и зафиксировать настоящие файлы Bergamasco.
2. Дефекты и воздух: несуществующий `text-md`, `leading-1`, `mb-5` на инлайновом элементе,
   мёртвые `ref`, три разных цвета линеек, отсутствующий `gap-y`, несимметричные отступы вокруг
   разделителей, фиксированные высоты боксов карточек. Типографическая шкала с настоящим
   контрастом кегля и насыщенности. Значения берутся у субагента `multica-designer`.
3. Одна схема горизонтальных отступов: контейнер объявляется один раз, шапка, контент и футер
   получают общие поля.
4. Единый источник раскладок: `web/app/types/layout.ts` и `web/app/utils/articleLayouts.ts`,
   производные функции вместо трёх параллельных таблиц, юнит-тест на совпадение со старым
   поведением.
5. Одна CSS-сетка вместо трёх веток шаблона.
6. Двенадцать колонок, новые раскладки, ритм ленты с валидатором.
7. Синхронизация спецификаций и отчёт.

## 4. Критерии готовности

- Стадии 2 и 3 дают видимое улучшение на 390, 768, 1024 и 1440.
- Стадии 4 и 5 не дают никакой видимой разницы — это их критерий приёмки.
- Юнит-тесты: производные функции реестра совпадают со старыми таблицами по всем двенадцати
  комбинациям; `validateLayout` зелёный на всех записях; `validateRhythm` зелёный на настоящем
  конфиге ленты.
- Страницы `/tags/{слаг}`, `/{рубрика}`, `/authors/{handle}` проверены глазами после правок
  общих компонентов.
- `pnpm format:fix && pnpm lint && pnpm test` проходят.

## 5. Что сознательно не входит

- Подключение GraphQL: клиента в проекте нет, данные остаются фикстурами.
- Слияние четырёх вариантов карточки в один компонент.
- Страница материала.
- Приведение палитры в `main.css` к выверенной — отдельная задача.

## 6. Риски

| Риск | Чем снимаем |
|---|---|
| Правка общих карточек сломает страницы тегов, рубрик и авторов | Эти страницы проверяются глазами после стадий 2 и 3 |
| Непрямоугольный слот молча ломает всю раскладку: браузер отбрасывает объявление целиком | `validateLayout` в юнит-тесте и в dev-режиме при монтировании |
| `grid-template-areas` через кастомное свойство может не сработать | Проверяется в браузере первым шагом стадии 5, до того как на этом построится остальное |
| Треки `fr` не дают заявленных пропорций рядов | Высоты рядов задаются определёнными значениями через токены, а не долями |
| В коммит попадёт чужая незакоммиченная работа из `docs/` | Файлы всегда перечисляются поимённо, `git add -A` по каталогам не используется |
