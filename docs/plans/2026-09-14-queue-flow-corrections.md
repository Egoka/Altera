# Исправление движения очереди и передачи стадий

- Baseline: `905206570542adf45a86af50f71fbc1b3d175481`.
- Основание: владелец согласовал подготовку Todo независимо от занятого writer,
  подтверждённую передачу результата, восстановление потерянной передачи и один PR на новую задачу.
- Scope: инструкции Multica, операционные документы, один проверочный проход очереди.

1. Снять актуальные инструкции и состояние запуска, сохранить существующую работу.
2. Разделить admission, восстановление handoff и dispatch. Уточнить подтверждение следующего run.
3. Закрепить отдельную ветку/PR для каждой новой T-задачи; текущую общую ветку не переписывать.
4. Применить инструкции с readback, опубликовать документы через PR с CI.
5. Выполнить один проход очереди, проверить фактический admission и отсутствие повторной делегации.

Критерии: занятый writer не блокирует Todo; созданная Todo не запускается сама; завершённый
исполнитель без следующей стадии обнаруживается даже без открытого PR/metadata; передача
подтверждается native ID; одинаковое событие не порождает дубликаты; новый PR содержит один T-ID.
