# План проверки CI для T-001

**Базовый коммит:** `6cc011d`

## Цель

Получить воспроизводимое evidence критериев T-001: CI использует версию Node из `.nvmrc` и
выполняет lint, тесты, сборки web/server и проверку типов Vue.

## Границы

- Проверить `.nvmrc`, корневой `package.json` и GitHub Actions workflow.
- Выполнить предписанные локальные команды без запуска `server build`, поскольку он применяет
  миграции.
- При расхождении менять только CI-конфигурацию, `.nvmrc`, корневой `package.json` или ESLint
  ignores; продуктовый код и тесты не изменять.

## Шаги

1. Зафиксировать состояние ветки и сверить версии Node/pnpm и шаги workflow с критериями T-001.
2. Запустить `pnpm format`, `pnpm lint`, `pnpm test`, web build/typecheck и `server build:ci`;
   сохранить фактические результаты для отчёта.
3. Если обнаружится расхождение, внести минимальную конфигурационную правку и повторить
   затронутые проверки в рамках бюджета попыток.
4. Подготовить отчёт с evidence конфигурации и локальных проверок, закоммитить только файлы
   T-001, отправить ветку и получить ссылку/результат CI.
