# План T-033: закладки — страница `/me/bookmarks` и кнопка на материале

- **Задача**: ALTE-89 / T-033, источник `docs/backlog/tasks/T-033-bookmarks.md`
- **Baseline**: `origin/app` = `4ea27a63d0fac9ccc9eb38cde522d9b17b58799b`, ветка `feat/t033-bookmarks`
- **Спецификации**: `docs/spec/30-account/reader/bookmarks.md`,
  `docs/spec/10-flows/bookmark-and-follow.md`, `docs/spec/20-public/article.md`,
  реестр событий `docs/spec/00-registries/events-and-logs.md` #56

## 1. Что уже есть

Модель `Bookmark` и миграция `20260916190000_bookmarks_base_authorship` приняты в T-017: пара
`userId`/`articleId`, индекс по `userId, createdAt DESC`, CHECK `bookmarks_personal_account_check`
и триггер `bookmarks_sync_owner_eligibility` уже запрещают закладку служебному аккаунту на уровне
базы. Схема не меняется — новой миграции в этой задаче нет.

В вебе есть `ReadingBookmarkButton` и проп `bookmarked` у `ArticleCard`, но они ни к чему не
подключены: нет ни запросов, ни страницы.

## 2. Объём работы

### Сервер
1. Новый домен `server/src/graphql/bookmark/` (`schema.graphql` + `resolver.ts`) и сервис
   `server/src/bookmarks/service.ts`:
   - `myBookmarks(cursor, limit, unavailable)` — курсорная выдача по `createdAt DESC`,
     `counts { total, unavailable }`, `pageInfo { endCursor, hasNextPage }`;
   - `myBookmark(articleId)` — состояние кнопки на материале;
   - `addBookmark(articleId)` — идемпотентно; `removeBookmark(articleId)`.
2. Доступ: `ensureAuthenticated`; роли только `reader` и `author`, служебный аккаунт и
   архивированный аккаунт получают `FORBIDDEN` с `action` `bookmark.add` / `bookmark.remove` /
   `bookmark.list` (журнал #58).
3. `available` = материал опубликован. Недоступный материал остаётся в выдаче с `available: false`.
4. События `bookmark.add` / `bookmark.remove` (#56) — тип `metric`, а не `log`. Добавляется
   реестр `server/src/observability/metric-events.ts` и необязательный метод `metric()` у
   `AppLogger`; агрегаты и сигнал рейтинга (F-02) в объём не входят.

### Веб
5. Операции `web/app/graphql/operations/me/bookmarks.graphql`, перегенерация codegen,
   экспорт в `web/app/query/index.ts`.
6. Страница `web/app/pages/me/bookmarks/index.vue`: заголовок со счётчиком, переключатель
   «все / недоступные», карточки с датой добавления и кнопкой «убрать», «показать ещё»,
   состояния загрузки / ошибки / пусто, `noindex, nofollow`.
7. Недоступная карточка — приглушённая, чёрно-белая, не кликабельная, с отметкой «недоступна»
   и крестиком удаления (журнал §25.10).
8. Кнопка закладки на странице материала, подключённая к мутациям.
9. Ключи `ru`/`en` в `web/i18n/locales`.

## 3. Проверки критериев готовности

1. **Архивированный материал остаётся в закладках «недоступным»** — серверный тест на
   `myBookmarks` (возвращает `available: false`, счётчик `unavailable`) и Playwright-сценарий
   `web/tests/e2e/22-bookmarks.spec.ts` (карточка серая, не кликабельная, с крестиком).
2. **Служебная роль получает `FORBIDDEN` на `bookmark.add`** — серверный тест на резолвер.

Дополнительно: тест реестра событий на коды `metric`, тесты веб-разметки карточки закладки.
