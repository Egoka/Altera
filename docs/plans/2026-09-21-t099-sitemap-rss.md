# T-099 — Sitemap по локалям и RSS

- **Задача**: `docs/backlog/tasks/T-099-sitemap-rss.md` (эпик E-15), issue ALTE-99
- **Спецификация**: `docs/spec/20-public/feeds-and-sitemap.md`
- **Baseline**: `origin/app` = `2871bf25c6797c002e72b5562f27f9c594633880`, ветка `web/t099-feeds`
- **Результат**: `/sitemap.xml`, `/sitemap-ru.xml`, `/sitemap-en.xml`, `/rss.xml`, `/en/rss.xml`

## 1. Что делаю

### API (`server/src/graphql`)

1. `feed`: значение `latest` в `FeedScope` и аргумент `limit` (§4 — `feed(scope: latest, locale,
   limit)`). Лента latest — опубликованные материалы локали по дате первой публикации, до 50
   элементов (`[ДОПУЩЕНИЕ]` §12). Кеш — общий, тег `home` (его уже сбрасывает публикация и
   снятие, `buildArticleCacheTags`).
2. Новый модуль `graphql/sitemap`: запрос `sitemapEntries(locale)` (§4). Элемент — путь без
   префикса локали, `lastmod`, приоритет (§5.3 `[ДОПУЩЕНИЕ]`: главная 1.0, материалы 0.8,
   списки 0.5) и список локалей, в которых адрес публичен, — источник `hreflang`.
   Состав (§4): главная, опубликованные материалы, непустые рубрики, теги с материалами,
   авторы с публикациями, каталоги `/sections`, `/tags`, `/authors` и `/pricing`.
   Не входят: черновики, снятые, архивированные, пустые рубрики, `/me/*`, `/admin/*`,
   `/auth/*`, `/search`, предпросмотр, адреса с параметрами, версии другой локали (§20.5).

### Веб (`web/server`)

3. `web/server/utils/feeds.ts` — чистые сборщики XML и запросы к API: экранирование, путь
   локали (`prefix_except_default`), RSS-канал, sitemap-индекс, `urlset` с `xhtml:link`
   альтернативами.
4. Маршруты Nitro: `rss.xml`, `en/rss.xml`, `sitemap.xml`, `sitemap-ru.xml`, `sitemap-en.xml`.
   `Content-Type` — `application/rss+xml` и `application/xml`; `Cache-Control` — час (§10).
   Недоступный API — 503 `INTERNAL_ERROR` (§8), без подмены пустым ответом.
5. `<link rel="alternate" type="application/rss+xml">` в шапке (§3, §6): ссылка на ленту
   текущей локали.

## 3. Границы

Вне задачи: RSS рубрики и автора (`[ДОПУЩЕНИЕ]` §3, отдельных задач эпика), разбиение sitemap
свыше 50 000 адресов (при текущем объёме не достигается — порог проверяется, но второй файл не
генерируется), отдача последней успешной версии при сбое базы (§8 `[ДОПУЩЕНИЕ]`, нужен слой
кеша ответов), строка `Sitemap:` в `robots.txt` — для неё нужен канонический адрес сайта,
которого в конфигурации проекта нет; выношу вопросом владельцу.
