- **Дата**: 2026-09-08

- **Базовый коммит**: 1c32514

- **Статус**: завершён (отчёт — docs/reports/2026-09-08-g3-sync-public-pages-report.md)

## 1. Цель

Привести шестнадцать спецификаций `docs/spec/20-public/` к решениям Г3 (журнал §20.1–19, правки
#4, #50, §5.2), перевести их в «утверждён», обновить затронутые реестры и файлы `50-access/`,
закрыть отчёт захода 3 и гейт Г3.

## 2. Контекст

Владелец ответил на все шестнадцать вопросов захода 3: главная из трёх независимых подборок
(§20.1–3); ленты рубрик до Г4 только по новизне (§20.4); языки не смешиваются (§20.5); дата в
конце статьи и «обновлено» только при изменении (§20.6); число подписчиков публично в
сокращённом виде (§20.7); истёкший план не влияет на рейтинг (§20.8); пустые рубрики скрыты,
теги с одной статьёй видны (§20.9–10); основной язык аккаунта, язык статьи выбирает автор
(§20.11); категория причины на экране оспаривания (§20.12); карточка `pro` без чисел (§20.13–14);
кнопка «сообщить о битой ссылке» на 404 (§20.15); заголовок на 410 (§20.16); без страницы
статуса и офлайн-кнопки (§20.17–18); раздел наблюдения за ошибками в админке (§20.19);
самостоятельно архивированный аккаунт восстанавливает сам автор на экране состояния (#4, #50,
§5.2). Судьба служебной записи после снятия роли остаётся открытой.

## 3. Шаги

   #79–80), `flows.md` (#12), `pages.md` (#12; новая #42), `routes.md` (#13; новые #72–73),
   `admin-sections.md` (новая #22), `plans.md`, `roles.md`, `60-ranking/README.md` (#4, #8, #9).
2. `50-access/`: `reader.md`, `author.md`, `guest.md`, `session-lifecycle.md`,
   `escalation-and-demotion.md` (пометка временности допущения).
3. Шестнадцать файлов `20-public/`: правила по §20, статус «утверждён», снятие отвеченных
   вопросов.
4. Проверка, отчёт захода 3, отчёт этого плана, коммит.

## 4. Критерии готовности

- В `20-public/` нет `[ВОПРОС ВЛАДЕЛЬЦУ]` по темам §20; все 16 файлов «утверждён».
- Новые строки реестров ссылаются на файлы заходов 5b, 6, 8b.

## 5. Что сознательно не входит

- Формула рейтинга и правила отбора подборок главной — заход 4.
- Наполнение подробных карточек тарифов (§20.14) — отдельное проектирование.

## 6. Риски
