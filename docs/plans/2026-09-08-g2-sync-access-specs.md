# Гейт Г2: синхронизация спецификаций ролей и доступа с журналом

- **Дата**: 2026-09-08
- **Ветка**: docs/platform-design
- **Базовый коммит**: 3b74a63
- **Отчёт**: docs/reports/2026-09-08-g2-sync-access-specs-report.md
- **Статус**: завершён (отчёт — docs/reports/2026-09-08-g2-sync-access-specs-report.md)

## 1. Цель

Привести четырнадцать спецификаций `docs/spec/50-access/` к решениям Г2, внесённым владельцем в
`docs/decisions/role-review-working-log-2026-09-08.md` (решения #45–59, правки #7, #13, §1–2, §5,
§13–14, новые §17–19), перевести их из «на утверждении» в «утверждён», обновить затронутые строки
реестров, закрыть отчёт захода 2 и гейт Г2.

## 2. Контекст

Заход 2 (коммит `3b74a63`) оставил 19 вопросов владельцу. Владелец ответил на все существенные:
редакционные статьи принадлежат журналу (#45); авторов не повышают в служебные роли, служебные
учётные записи создаёт `admin`/`owner` (#46–47); экстренная блокировка с формой оспаривания и
продолжающимся сроком плана (#48); «удалить навсегда» без второго согласующего (#49); план при
самостоятельном архивировании продолжается (#50); ревьюер видит базовый профиль автора (#51);
аналитик читает AI-раздел (#52); `admin` архивирует статьи без восстановления (#53); исключения
бессрочны по умолчанию (#54); сессия при истечении плана остаётся (#55); `admin` видит AI (#56);
лимиты едины и не настраиваются (#57); закладки только у `reader`/`author` (#58); аудит только на
чтение с автоматическим контекстом (#59).

## 3. Шаги

1. Реестры: `access-matrix.md` (строки #8, #13–15, #18, #26–27, #75, #81, #88, #107; новые
   #111–113), `events-and-logs.md` (#14, #27, #66, #67; новые #76–78), `flows.md` (#10–12),
   `pages.md` (#12; новая #41), `routes.md` (#13; новый #71), `roles.md` (строки 4–7, правила),
   `plans.md` (правило о сроке при архиве).
2. Четырнадцать файлов `50-access/`: правила по решениям #45–59, статус «утверждён», снятие
   отвеченных `[ВОПРОС ВЛАДЕЛЬЦУ]`, замена допущений, ставших решениями.
3. Проверка: объёмы и разделы, пути реестров, отсутствие «на утверждении», отсутствие отменённых
   понятий вне отрицаний.
4. Отчёт захода 2 — дополнение «Гейт Г2 закрыт»; отчёт этого плана; коммит.

## 4. Критерии готовности

- Ни одного `[ВОПРОС ВЛАДЕЛЬЦУ]` по темам, на которые журнал ответил; оставшиеся — только по темам,
  которых журнал не касается.
- Все 14 файлов в статусе «утверждён»; минимумы шаблонов соблюдены.
- Каждая новая строка реестра ссылается на файл, который создаёт заход 3 или 6 (файл без строки и
  строка без файла не допускаются по завершении соответствующего захода).

## 5. Что сознательно не входит

- Отложенные темы: жалобы, механика промокодов, правила рассылок, формула рейтинга.
- Формализация журнала в ADR-0047+ и ревизия `04-roles-and-access.md` — отдельный заход.

## 6. Риски

- Решение #47 (служебную учётную запись создаёт `admin` или `owner`) и #13 (`admin` не управляет
  ролями) требуют трактовки: создание новой служебной записи с ролью — `admin`/`owner`; смена и
  снятие роли, назначение `owner` — только `owner`. Помечено `[ДОПУЩЕНИЕ]`.
