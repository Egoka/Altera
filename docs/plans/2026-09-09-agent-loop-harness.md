# Слой исполнения автономного цикла: харнесс Claude Code под операционную модель Multica

- **Дата**: 2026-09-09
- **Ветка**: docs/platform-design
- **Базовый коммит**: 2641747
- **Отчёт**: docs/reports/2026-09-09-agent-loop-harness-report.md (заполняется по завершении)
- **Статус**: завершён

## 1. Цель

Правила из `docs/multica/operating-model.md` начинают исполняться машиной, а не только читаться
агентом. После работы в репозитории есть версионируемый слой исполнения: роли сквада существуют
как субагенты с раздельными правами, передача стадий оформлена командами с обязательным
evidence, ритуал «план + отчёт» проверяется хуком, а автономный цикл не тратит итерации на
запросы разрешения по безопасным командам.

## 2. Контекст

Аудит 2026-09-09 (эта сессия) установил:

- Каталога `.claude/` в проекте нет; `.gitignore:97` игнорирует его целиком, поэтому любая
  конфигурация ролей не версионируется и не переживает worktree.
- Десять ролей `docs/multica/operating-model.md` §1 не существуют как исполнители. Правило
  «независимый ревьюер не участвует в реализации той же задачи» (§1, §3) при одном агенте в одной
  сессии не выполнимо по построению.
- Шесть стадий §3 с обязательным evidence не имеют точки входа: передача стадии выполняется
  пересказом в чате.
- `~/.claude/settings.json` содержит блок `autoMode.environment`, описывающий **другой** проект
  (BILITY INVEST / `gitlab.bility.ru/bilinv/bilinv`, Laravel, защищённая ветка `main`, пути
  секретов `backend/.env`). Блок глобальный, поэтому применяется и к Altera, где защищённая ветка
  `app`, а секреты — `server/.env`.
- `CLAUDE.md` — 232 строки; раздел «Продуктовые рамки» объявлен копией ADR-0043 с оговоркой «при
  расхождении главнее ADR», то есть допускает расхождение копии с источником.

Вне границ этого плана и зафиксировано отдельно: `pnpm test` разворачивается в `pnpm -r test`, ни
`server/package.json`, ни `web/package.json` не объявляют скрипт `test`, поэтому проверка
завершается успехом при нуле тестов; CI дополнительно маскирует старт сервера через
`timeout 2s pnpm start || true` (`.github/workflows/pull_request.yml`). Пока это не закрыто
(T-001, T-112), автопилот «Очередь разработки» не включается.

## 3. Шаги

1. `.gitignore`: снять игнор с версионируемой части `.claude/` (`settings.json`, `agents/`,
   `commands/`, `hooks/`), оставить в игноре `settings.local.json` и рантайм-каталоги.
2. `.claude/settings.json`: allowlist безопасных команд проекта (проверки, чтение git, Prisma
   generate), deny на push и на коммит в `app`, свой `autoMode.environment` под Altera.
3. `.claude/agents/`: субагенты под роли сквада §1 с раздельными правами — исполняющие роли с
   правом записи, проверяющие роли (тестировщик, независимый ревьюер) без права правки кода.
4. `.claude/commands/`: команды передачи стадий §3, каждая требует evidence предыдущей стадии.
5. `.claude/hooks/ritual-check.sh` на событие Stop: если в сессии менялись файлы `server/`, `web/`
   или `packages/` — предупредить об отсутствии парных файлов плана и отчёта.
6. `~/.claude/settings.json`: снять блок `autoMode.environment` чужого проекта, сохранив его копию
   для переноса владельцем в проект Invest.
7. `CLAUDE.md`: сократить до операционных правил, продуктовые рамки заменить ссылкой на ADR-0043 и
   рабочий журнал, чтобы копия не расходилась с источником.
8. Проверка: `pnpm format:fix`, `pnpm lint`, отчёт по ритуалу.

## 4. Границы

Входит: конфигурация харнесса, определения ролей и команд, хук ритуала, правка `.gitignore` и
`CLAUDE.md`.

Не входит: продуктовый код `server/` и `web/`; тесты и CI (T-001, T-112); включение автопилотов
(решение владельца по `docs/multica/autopilot-checklists.md`); изменение операционной модели,
спецификаций, журнала и статусов задач; push и слияние в `app`.

## 5. Проверка

- `.claude/settings.json` — валидный JSON, читается `node -e "JSON.parse(...)"`.
- `git check-ignore -v .claude/settings.json` — файл больше не игнорируется.
- `.claude/hooks/ritual-check.sh` исполняется и возвращает 0 на текущем состоянии репозитория.
- `pnpm lint` без новых ошибок.
- Все определения субагентов имеют frontmatter с `name`, `description`, `tools`.
