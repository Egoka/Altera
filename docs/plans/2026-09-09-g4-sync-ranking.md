# Гейт Г4: синхронизация модели рейтинга с журналом

- **Дата**: 2026-09-09
- **Ветка**: docs/platform-design
- **Базовый коммит**: 8954557
- **Отчёт**: docs/reports/2026-09-09-g4-sync-ranking-report.md
- **Статус**: завершён (отчёт — docs/reports/2026-09-09-g4-sync-ranking-report.md)

## 1. Цель

Привести одиннадцать спецификаций `docs/spec/60-ranking/` к решениям Г4 (журнал §21–23) и
документу владельца `60-ranking/engagement-tracking.md`, убрать выдуманные веса, окна и формулы,
исправить противоречащие допущения в реестрах, политиках доступа, публичных страницах и
статусах ADR, закрыть Г4 по фундаментальным принципам и вынести детальную математику движка в
отложенную работу.

## 2. Контекст

Журнал §21 закрепляет: сигналы вовлечённости (качественное прочтение, закладки, повторное
чтение, источник перехода, распространение) вместо простого счётчика; накопительный рейтинг
автора со снимком при публикации; постоянный Pro-балл по снимку плана; без штрафов; свежесть —
отдельный затухающий до нуля за месяц компонент с разными кривыми Standard/Pro (числа не
утверждены); числовой рейтинг и объяснение позиции публично не показываются; поиск — только
релевантность Meilisearch; счётчики от 100 округлённо; фиксированные веса без интерфейса
настройки; единый движок, пересчёт раз в час, устойчивость к сбоям. §22 — главный топ за 24
часа с добором, без повторов между блоками, переключатель «по рейтингу / по дате» после
запуска. §23 — событийный контур с `visitorId`, полностью автоматический, без ручных исключений.
Полный каталог сигналов и формула — отложено (§21.39).

## 3. Шаги

1. Переписать 11 файлов `60-ranking/` под §21–23 без чисел и формул; статус «утверждён (гейт
   Г4 — принципы)»; добавить строку реестра для `engagement-tracking.md`.
2. Реестры: `60-ranking/README.md`, `access-matrix.md` (#7, #9, #13, #68–72, новые строки
   распространения), `events-and-logs.md` (#31–32, #48, #55–57, #62, #82; новые события
   вовлечённости), `admin-sections.md` #15, `plans.md`, `pages.md`, `routes.md` (ссылки
   распространения).
3. Политики и страницы: `visibility.md` п. 7, роли, `20-public/*` (объяснение позиции убрано,
   счётчики от 100, переключатель сортировки, главная без повторов, поиск без рейтинга).
4. ADR-0027, 0034, 0038, 0039, 0040, 0041 — строки статуса «частично заменён журналом Г4»;
   `CLAUDE.md` — пометка о приоритете журнала.
5. Отчёт захода 4 — раздел «Гейт Г4 закрыт по принципам»; отчёт синхронизации; коммит.

## 4. Критерии готовности

- В `60-ranking/` нет численных весов, окон и формул, кроме явно утверждённых журналом
  (24 часа топа, месяц свежести, порог 100 счётчиков, час пересчёта, два года cookie).
- Детальная модель вынесена как «отложено: подробная спецификация движка».

## 5. Что сознательно не входит

- Подробная спецификация движка (сущность → сигнал → момент → срок → агрегация → вклад).
- Спецификация поиска Meilisearch (заход 5b, `20-public/search.md`).

## 6. Риски

- `engagement-tracking.md` §9 говорит о версионируемой конфигурации с аудитом, журнал §21.32 — о
  фиксированных правилах без интерфейса; принято: версия правил движка фиксируется релизом,
  административного редактирования нет.
