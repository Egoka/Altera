# Гейт Г5: синхронизация планов и биллинга с журналом

- **Дата**: 2026-09-09
- **Ветка**: docs/platform-design
- **Базовый коммит**: 11c8641
- **Отчёт**: docs/reports/2026-09-09-g5-sync-billing-report.md
- **Статус**: завершён (отчёт — docs/reports/2026-09-09-g5-sync-billing-report.md)

## 1. Цель

Привести девять политик `docs/spec/70-plans-and-billing/`, два сценария `10-flows/`, реестры,
связанные политики доступа, страницы, файлы рейтинга и статусы ADR к решениям Г5 (журнал §8.12–23;
§8.3–6 отменены), закрыть Г5 по принятым правилам и явно вынести отложенное: платный запуск,
цены, бухгалтерский контур, почта.

## 2. Контекст

Журнал §8: цены — гипотезы, хранятся централизованно (12); платный запуск в первой версии —
стратегический вопрос бизнес-модели (13); первый провайдер — Т-Касса (14); пять попыток списания
10:00–23:00, истечение с 00:00 следующего дня (15); ручной `pro` равен оплаченному (16);
редакционные статьи — всегда базовый режим (17); кнопка «Запросить возврат», после одобрения —
немедленное прекращение (18); чеки, налоги, бухгалтерия — предрелизная проверка (19); бывший
автор сохраняет авторские разделы и аналитику на чтение (20–21); очередь оплаченных периодов
по приоритету годовой pro → месячный pro → годовой standard → месячный standard (22); повторные
письма — этап почты (23). Отменены: немедленное отключение после первой неудачи, «возврат не
сокращает период», понижение со следующего периода, остаток `standard` после `pro`.

## 3. Шаги

1. `70-plans-and-billing/*` и `10-flows/pay-and-upgrade.md`, `subscription-expires.md` — правила
   по §8, статусы «утверждён (гейт Г5)», снятие отвеченных вопросов.
2. Реестры: `plans.md` (таблица правил), `access-matrix.md` (#59–62; новая строка запроса
   возврата), `events-and-logs.md` (#21, #50), `flows.md` (#6–7), `admin-sections.md` (#9),
   `pages.md` (#31).
3. Связанные: `50-access/roles/author.md`, `reader.md`, `60-ranking/pro-score.md`,
   `20-public/pricing.md`; ADR-0010, 0035, 0044 — строки статуса; `CLAUDE.md` — пометка.
4. Отчёт захода 5a — раздел «Гейт Г5 закрыт»; отчёт синхронизации; коммит.

## 4. Критерии готовности

- В спецификациях нет правил «без льготного периода после первой неудачи», «возврат не сокращает
  период», «понижение со следующего периода», «остаток standard».
- Отложенные темы перечислены явно и не развёрнуты.

## 5. Что сознательно не входит

- Бизнес-модель и решение о платном запуске — заход 5b (открывается этим вопросом).
- Технический источник цен, налоговые настройки, правила почты.

## 6. Риски

- Очередь периодов (§8.22) меняет модель `Subscription`: несколько записей на аккаунт в разных
  состояниях — помечено `[ДОПУЩЕНИЕ]` в `subscription-lifecycle.md`.
