# Автоматическое создание PR и слияние в app

- Основание: прямое поручение владельца 2026-09-14 создавать PR после успешной работы и
  сливать в `app`, когда проверки зелёные, без дополнительного запроса на каждую задачу.
- Baseline: `97633e53faebb0855c266173fff25f2e8f2cd06a` (проверить HEAD перед коммитом).
- Scope: процесс выпуска, инструкции Multica и сохранение подтверждений настройки.

1. Уточнить действующий порядок PR → CI → независимая приёмка → merge.
2. Указать точный SHA, обязательные проверки, защиту от повторного PR/merge и ожидание CI.
3. Согласовать инструкции релиз-инженера, оркестратора, squad, очереди и восстановления.
4. Проверить readback и опубликовать документацию обычным PR с зелёным CI.

Критерии: на принятую работу создаётся один PR в app; pending/missing/red CI не допускает
merge; новая ревизия требует новых проверок и ревью; ожидание возобновляется по событию или
действующему расписанию без ручного поручения и без второй активной стадии.
Правила продуктовых решений, production-выпуска и Done этим поручением не расширяются.
