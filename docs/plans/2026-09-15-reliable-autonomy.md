# Надёжная автономия: внедрение

Основание — согласованный владельцем план от 15 сентября 2026. Работа ведётся
в `codex/autonomy-controller`, отдельном worktree от `app`; чужое основное дерево сохранено.
PR: https://github.com/Egoka/Altera/pull/56.

| Этап                   | Реализация                                                                                       | Условие завершения                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| 1. Сверка и итог       | Исторический аудит сохранён; сборщик перечитывает Multica/GitHub; один JSON и Markdown на задачу | Источники и неизвестные поля видны в пробном отчёте                          |
| 2. Done                | Контроллер проверяет CI/SHA, независимый native verdict, merge, deploy/health и Git-артефакт     | Негативные тесты и фактический полный цикл                                   |
| 3. Окружение и события | Preflight, PostgreSQL 17/Redis в CI, профиль до вызова модели, SQLite journal                    | Новый event вызывает один запуск, повтор — программный no_action             |
| 4. Отчёт               | Детерминированные агрегаты, PROGRESS, идемпотентный publisher, 10:00 Europe/Moscow               | Пробный PR и повтор без нового PR/commit, расписание прочитано обратно       |
| 5. Уборка              | Проверки clean/active/merged/squash, журнал и Git CAS                                            | Реальное ограничение новых запусков перед удалением; до этого только dry-run |
| 6. Переключение        | Снимок настроек, пауза очереди/recovery, проверка нового профиля                                 | Проверенный полный цикл, затем включение расписаний                          |

Текущие технические ограничения сохраняются в отчёте: прежние CLI-права агентов
позволяют обходить управляемый контроллер; безопасный общий admission fence уборки
ещё не подтверждён. Промпт не выдаётся за ACL. Старые ALTE-11/adapters не возобновляются.
Обычные обращения владельца не подключают этот процесс.

Проверки: Python unittest для контроллера, событий, публикации, сбора и реальной Git-уборки;
проверки readiness БД/Redis; lint/format/build; GitHub CI; native stream-json canary;
публикация отчёта и проверка live Render. Отсутствие доступа или failed deploy блокирует Done.
