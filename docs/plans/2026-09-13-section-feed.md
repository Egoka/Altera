# Лента рубрики: вариативная сетка вместо однообразного списка

- **Дата**: 2026-09-13
- **Ветка**: web/home-grid (рабочее дерево общее со второй сессией владельца, переключение
  ветки сломало бы ей дерево; отдельная ветка не заводится)
- **Базовый коммит**: 82d3b96
- **Отчёт**: docs/reports/2026-09-13-section-feed-report.md (заполняется по завершении)
- **Статус**: завершён

## 1. Цель

Список материалов на странице рубрики (`/{рубрика}`, например `/technology`) перестаёт быть
тридцатью одинаковыми строками в узкой колонке: он собирается из тех же групп раскладок, что и
главная, со своим ритмом, и служебная строка карточек показывает автора и дату вместо автора и
рубрики. Механизм сборки умеет любое число материалов, поэтому годится для настоящей ленты с
пагинацией и для последней неполной страницы.

## 2. Контекст

- Страница `web/app/pages/[slugTypeContent]/index.vue`: шапка `HeaderType` и список из 30
  моковых `ArticleType` в `max-w-3xl` с линейками (`index.vue:47-66`). Замечание владельца:
  «однообразно, давай добавим креатива», область — только список, шапка остаётся.
- Реестр раскладок `web/app/utils/articleLayouts.ts` и компонент `ArticleGroup`
  (`web/app/components/article/group.vue`) после захода по главной (коммиты 4ae08f5, 82d3b96)
  умеют широкие, средние и узкие экраны; ритмы главной — `web/app/utils/feedRhythm.ts`.
- Спецификация `docs/spec/20-public/section-feed.md` §5 зона 4 описывает состав списка как
  допущение («три large, далее small»), §9 — колонки по breakpoints; размер страницы 24 —
  допущение §12. Сортировка только по новизне (журнал §20.4).
- Служебная строка карточек (`ShowAuthor` · `ShowType`) набрана капителью Cormorant;
  красная дата `ShowTime` из старой карточки в эту строку не ложится.
- Решения владельца 2026-09-13: приём — вариативная сетка как на главной; служебная строка —
  автор · дата.

## 3. Шаги

1. Тесты сборки групп (`web/tests/feedGroups.test.ts`): полный цикл ритма на 24 материала;
   хвост 1–5 берёт запасную раскладку ровно под остаток; запасная раскладка не повторяет
   предыдущую группу ни именем, ни сигнатурой; ритм рубрики проходит `validateRhythm` на 24.
2. `web/app/utils/feedGroups.ts`: `buildFeedGroups(articles, rhythm)` и таблица запасных
   раскладок по вместимости; `SECTION_RHYTHM` в `feedRhythm.ts` (вместимость 24); раскладка
   `solo-wide` в реестре для остатка в один материал.
3. Свойство `meta: "type" | "date"` у `ArticleGroup`, `ArticleBase`, `ArticleLarge`,
   `ArticleSmall`; атом `ShowDate` в стиле служебной строки с датой по локали.
4. Страница рубрики: список из групп во всю ширину контейнера, демо-данные из материалов главной
   (24, рубрика подставляется, даты детерминированы), `meta="date"`.
5. Проверка глазами на 1280, 768 и 375; консоль без сообщений валидаторов.
6. Спецификация `section-feed.md`: допущения зоны 4, §9 и §12 заменяются принятым решением.
7. Отчёт.

## 4. Критерии готовности

- `pnpm test` в `web` зелёный, включая новые тесты сборки и ритма рубрики.
- На `/technology` при 1280 px список состоит из групп реестра с разными раскладками, все 24
  материала на месте, карточки показывают «автор · дата»; при 768 и 375 применяются правила
  средних и узких экранов группы.
- Главная не изменилась: её ритмы и служебная строка «автор · рубрика» прежние.
- `pnpm format:fix && pnpm lint && pnpm test` проходят.

## 5. Что сознательно не входит

- Панель фильтров и подпись принципа сортировки (зона 3), пагинация (зона 5), ряд других рубрик
  (зона 6), состояния загрузки и ошибки — данные по-прежнему фикстуры.
- Страницы тегов и авторов: тот же механизм подключается к ним отдельным заходом.
- Замена моковой шапки рубрики с чужим текстом.
- Подключение GraphQL.

## 6. Риски

| Риск | Чем снимаем |
|---|---|
| Хвост страницы даёт дырявую сетку | сборка выбирает запасную раскладку ровно под остаток; тест на остатки 1–5 |
| Запасная раскладка повторяет предыдущую группу | правило «не тот же id и не та же сигнатура» с тестом |
| Дата в служебной строке ломает капитель или локаль | отдельный атом `ShowDate` в стиле строки, формат по локали `ru`/`en` |
| Правки общих карточек затронут главную | свойство `meta` по умолчанию `type`, главная проверяется глазами |
