# Перебазирование основания под ревизию 2 продуктовых рамок (заход 0)

- **Дата**: 2026-09-06
- **Ветка**: docs/platform-design
- **Базовый коммит**: e4552b4
- **Отчёт**: docs/reports/2026-09-06-vision-rebase-report.md
- **Статус**: выполняется

## 1. Цель

Документация основания (`docs/decisions/`, `docs/vision/`, `docs/issues/`) соответствует
ревизии 2 продуктовых рамок из `CLAUDE.md`: ни один документ не описывает витрину, два
контура, правило-арбитр, хронологическую ленту или донаты как действующую модель. Вторая
фаза может ссылаться на ADR по номеру и пользоваться единым словарём.

## 2. Контекст

Ревизия 1 (2026-09-05, коммиты `848aab7`, `636538c`, `7c0ce79`) построена на гибридной модели,
правиле-арбитре и «без алгоритмов». Владелец 2026-09-06 отменил все три (см.
`docs/prompts/fable-rebase-2026-09-06.md` §1) и ответил на семь вопросов захода:

| Вопрос | Ответ владельца |
|---|---|
| Истечение подписки | Статьи остаются опубликованными; правка, создание и публикация — только после продления |
| AI-проверка при провале | Первичная проверка — AI, вторичная — человек (модератор/администратор); все версии изменений сохраняются |
| AI-оценка | Автор видит балл и критерии; модератор переопределяет |
| Pro-буст | Каждая новая публикация, все ленты, без пометки для читателя |
| Роль `analyst` | Только агрегаты, без персональных данных |
| Роль `editor` | Остаётся — работа с текстом и таксономией |
| Переводы и планы | Вторую языковую версию делает платформа (AI) для pro-авторов |

Толкование ответа про проверку, вынесенное на гейт Г0: **каждая публикуемая ревизия проходит
две ступени — AI, затем человек**; уровни доверия как ворота публикации при этом теряют смысл.

- Каждый заменённый ADR содержит строку статуса с номером преемника и датой.
- В `docs/vision/01,04,06,07` ревизии 2 слова «контур», «витрина», «отбор», «заказ»,
  «правило-арбитр», «поддержка автора» — только в таблице «Что изменилось».
- Все пути в markdown-ссылках новых и изменённых документов существуют.
- В роадмапе ревизии 2 нет оценок в человеко-днях и сценария деградации.
