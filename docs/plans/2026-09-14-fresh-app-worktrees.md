# Свежая база app для каждой новой задачи

- Основание: прямое поручение владельца начинать новую задачу со свежего коммита app и только затем создавать worktree.
- Baseline: `3bfeecc23ac87394d6693c02e9c5f2e210214185`, получен через `git fetch origin app`.
- Scope: общие инструкции проекта и тексты ролей/автопилотов Multica.

1. Создать worktree этой правки от полученного app SHA; проверить чистоту и совпадение HEAD.
2. Зафиксировать порядок fetch → полный SHA → новая ветка/worktree → проверка HEAD/чистоты → старт.
3. Уточнить границу новой задачи и продолжения прежних стадий; сохранить существующие изменения.
4. Применить правило в Multica с readback и проверкой неизменности остальных настроек.
5. Подготовить парный отчёт, независимую проверку и PR в app с обязательным CI.
