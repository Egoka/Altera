## Цель

Точечная синхронизация пяти файлов спецификаций с журналом решений §25.1 и §25.6.

## Изменения по файлам

### 1. home.md §7

**Проблема**: В таблице «Действия» строка «Писать» ведёт «гость и читатель → `/pricing`».
По журналу §25.1: при первом нажатии «Создать статью» читателю автоматически открываются
базовые авторские возможности без оплаты; план-free.md п. 6а это подтверждает.

**Правка**: Разделить «гость» и «читатель»:
- гость → `/pricing` (нужна регистрация)
- читатель → `/me/articles/new` (первый запуск, §25.1, plan-free.md п. 6а)

### 2. authors-index.md §5 и §7

**Проблема**: Аналогичная — «Стать автором» ведёт гостя и читателя → `/pricing`;
по §25.1 читатель должен попадать в создание материала напрямую.

**Правка §5 (зона 2)**: Обновить текстовое описание кнопки — разделить гость/читатель.

**Правка §7**: Разбить строку «Стать автором» или уточнить результат для каждой роли.

### 3. grants-and-promo.md

**Проблема**: Правило 1 (`срок обязателен, VALIDATION_ERROR без него`) и строка таблицы §3
(«Выдача плана без срока | невозможно») противоречат plan-free.md п. 6а, где базовая
выдача при первом «Создать статью» бессрочная (`endsAt = NULL`).

**Правка**: 
- В правиле 1 добавить примечание-исключение для автоматической базовой выдачи.
- В таблице §3 добавить строку-исключение для бессрочной базовой выдачи при первом запуске.
- Пометка `[ДОПУЩЕНИЕ]` сохраняется согласно plan-free.md п. 6а.

### 4. access-matrix.md строка #36

**Проблема**: Строка `reviewNote.create / reviewNote.resolve` не имеет ссылки на журнал §25.6,
который закрепил эту функцию как часть ручной ветки ревью (заметки рецензента у блоков статьи).

**Правка**: Добавить `(журнал §25.6)` в описание и "; Г6" в статус строки.

### 5. engagement-tracking.md

**Проблема**: Файл написан владельцем и не имеет стандартной шапки по шаблону `_templates/ranking.md`:
отсутствует строка **Реестр**, поле **ADR** оформлено как **Решения**, поля **Этап** нет.

**Правка**: Заменить шапку на стандартную:
- **Реестр**: `60-ranking/README.md` #13
- **Статус**: форматировать по образцу других файлов в 60-ranking
- **ADR**: ADR-0027, ADR-0038 (заменены журналом §23)
- **Этап**: 2 (по аналогии с `views-counting.md` и `article-score.md`)
