Прошлый заход остановился на Q-02: каталог блоков не был утверждён. Гейт блокеров 2026-09-26

## 3. Границы

Входит: новый workspace-пакет `packages/content` и его тесты.

Не входит: TipTap-расширения редактора (T-040), Vue-компоненты страницы материала (T-056),
вызов `validateDocument` из резолверов сервера (T-049), спецификации `docs/spec/95-blocks/`
(отдельный проход журнала §31 п. 3).

## 4. Состав пакета

```text
packages/content/
  src/
    types.ts       типы документа и узлов
    schema.ts      декларативный каталог узлов и марок (единственный источник)
    validate.ts    validateDocument + ограничения глубины и размеров
    migrate.ts     версия схемы и ленивые миграции
    extract.ts     экстракторы
    render.ts      дерево рендера, toHTML, toMarkdown
    create.ts      фабрики узлов со стабильным attrs.id
    index.ts
  tests/
```

Узлы этапа 1: `doc`, `paragraph`, `heading` (level 2, 3), `blockquote` (kind plain, pull),
`bulletList`, `orderedList`, `listItem`, `figure` (assetId, size normal/wide/full),
`horizontalRule`, `text`. Марки: `bold`, `italic`, `link` (href).

У `figure` нет атрибутов `alt`, `caption`, `attribution`: единое `alt` и подпись с атрибуцией
берутся из медиафайла (журнал §29.13, ADR-0053, §31 п. 1). Рендер получает их через
`resolveAsset`.

## 5. Шаги

1. Пакет в `pnpm-workspace.yaml`, `package.json`, `tsconfig`, `vitest.config.ts`.
2. Типы и декларативная схема по каталогу.
3. `validateDocument`: неизвестный узел, марка, атрибут — отказ `CONTENT_INVALID`;
   отдельное понятное сообщение для `alt`/`caption`/`attribution` у изображения.
4. Ограничения глубины и размеров (ADR-0029 п. 1).
5. Версия схемы в корне и реестр миграций (ADR-0029 п. 4).
6. Экстракторы: `toPlainText`, `extractHeadings`, `buildTableOfContents`, `extractImages`,
   `extractCover`, `firstParagraph`, `countWords`, `readingTime`.
7. Рендер: дерево `RenderNode` с именами компонентов из `05-editor.md` §7, `toHTML`, `toMarkdown`.
8. Тесты: снимок рендера на каждый узел каталога (критерий 1), отказ валидации при `alt`
   в узле изображения (критерий 2), фикстуры документов, round-trip экспорта.
9. Проверки: `pnpm install --frozen-lockfile` (lockfile меняется — без `--frozen-lockfile`),
   `pnpm format`, `pnpm lint`, `pnpm test`.

## 6. Числовые параметры — `[ДОПУЩЕНИЕ]`

ADR-0029 требует «ограничения глубины и размеров», но чисел владелец не задавал. Значения по
умолчанию помечаются `[ДОПУЩЕНИЕ]` и выносятся в параметры функции, чтобы замена не трогала код:
глубина вложенности 2 (следует из ADR-0017), число узлов 5000, суммарная длина текста 200 000
символов. Скорость чтения 200 слов в минуту взята из существующего кода
(`server/src/graphql/article/resolver.ts`), а не придумана заново.

## 7. Критерии готовности

1. Каждый узел каталога имеет снимок-тест рендера.
2. Документ с `alt` в узле изображения не проходит валидацию.

## 8. Риски

- Спецификации `95-blocks/` пишутся параллельно и могут потребовать правок схемы (журнал §31 п. 3);
  схема объявлена данными, поэтому правка блока — это правка одной записи.
- Пакет пока никто не импортирует: интеграция с сервером и вебом идёт в T-049, T-040, T-056.
