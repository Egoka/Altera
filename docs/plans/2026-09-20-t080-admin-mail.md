## 1. Что уже есть

- `MailMessage` и `MailDeliveryEvent` в `server/prisma/schema.prisma` (T-021): копия письма
  хранится в `sanitizedBody`, секрет заменяется пометкой в `server/src/mail/messages.ts`.
- Оболочка админки, пункт меню `mail` в `web/app/utils/admin.ts`, middleware `admin` (T-069).
- Аудит чтения ПДн `admin.read.personal` в `server/src/graphql/user/resolver.ts` (T-029).

Нет: запросов `adminMails`, `adminMail`, `mailSummary`, мутаций повтора, страниц
`/admin/mail` и `/admin/mail/{id}`.

## 2. Объём работы

### Сервер

1. `server/src/admin/mail.ts` — чтение истории и повтор отправки:
   - доступ — `admin.enter`; полный состав (адрес, содержание) — `analyst`, `admin`, `owner`;
     `editor` (`isEditorial`) и `moderator` (статьи в проверке) — только письма своих статей,
     без адреса и содержания, вне зоны — `NOT_FOUND`;
   - фильтры: шаблон, статус, период (по умолчанию 7 дней), получатель, объект, поиск по теме
     и `messageId`; сортировка по времени убыв.; `limit` 20, максимум 100;
   - аудит `admin.read.personal` при открытии карточки и при поиске по получателю;
   - повтор — право `job.retry` (по умолчанию только `owner`), только статус `failed`,
     шаблоны с секретами исключаются, повторно повторить нельзя (`CONFLICT` по записи аудита),
     массовый повтор — максимум 100 (`VALIDATION_ERROR`), аудит `job.retry` на каждое письмо.
2. `server/src/graphql/mail/{schema.graphql,resolver.ts}` — `adminMails`, `adminMail`,
   `mailSummary`, `resendMail`, `resendMails`.
3. Тесты `server/tests/admin-mail.test.ts` и `server/tests/admin-mail-secrets.test.ts`.

### Веб

4. `web/app/graphql/operations/admin/mail.graphql`, `pnpm codegen`.
5. `web/app/composables/useAdminMail.ts`.
6. `web/app/pages/admin/mail/index.vue` и `web/app/pages/admin/mail/[id].vue`; состояния
   §9 спецификации: загрузка, пусто, ошибка и плашка ожидания провайдера, отсутствие прав,
   конфликт, превышение лимита.
7. Ключи i18n в `web/i18n/locales/{ru,en}.json`.
8. Playwright `web/tests/e2e/22-admin-mail.spec.ts` — строки состояний §9 и роли.
