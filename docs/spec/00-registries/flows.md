## Правила

- Коды `PLAN_LIMIT` (нет нужного плана или исчерпан лимит плана) — новый код словаря ADR-0032,
  вводится через `80-observability/error-dictionary.md`; остальные — из ADR-0032.
- Каждый flow ссылается на страницы по номерам `pages.md` и на разделы админки по номерам
  `admin-sections.md`; схема Mermaid обязательна (`_templates/flow.md`).
- Предложено сверх минимума промта: #4 (правка опубликованного — главный источник нагрузки на
  ревьюера, ADR-0045), #8, #11, #14.
