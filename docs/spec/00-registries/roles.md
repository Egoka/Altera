## Правила

- Иерархия по включению `editor < moderator < admin < owner`; `analyst` — параллельная роль
  только для чтения (ADR-0042).
- `reader` и `author` — производные от плана; admin-роли от плана не зависят и создают
  материалы без подписки.
- Грейд автора (`basic | pro`) — не роль, а вычисление из плана (ADR-0037).
