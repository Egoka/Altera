# Реестр страниц

- **Заход**: 1 (2026-09-06). **Основание**: `routes.md`, `docs/vision/06-design-system.md` §6,
  ADR-0034, ADR-0035, ADR-0041, ADR-0044, ADR-0045. Колонки — `README.md`.
- Одна строка — одна страница (материал — одна строка на два языковых маршрута). Разделы
  админки — в `admin-sections.md`.
- Мобильный: «обычный» — та же страница в одну колонку; «особый» — иное поведение или
  ограниченный набор действий.

## Правила

- Страницы кабинета читателя доступны любому аккаунту, включая admin-роли; страницы кабинета
  автора — при активной подписке или гранте, для бывшего автора — режим чтения (ADR-0044).
- Число зон — ориентир для заходов 3 и 6, а не норма.
- Предложено сверх `06-design-system.md` §6: сводка кабинета (#26), сессии (#28), смена почты
  (#29), оплата как отдельная страница (#32), выгрузка (#33), 410 и офлайн (#22, #24), RSS и
  sitemap как «страница» для спецификации (#25).
