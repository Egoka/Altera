# Реестр разделов админки

- **Заход**: 1 (2026-09-06); **гейт Г1**: 2026-09-08 по журналу
  `docs/decisions/role-review-working-log-2026-09-08.md`. **Основание**: журнал §3, §7,
  §12–16; `routes.md` #41–60, #70. Колонки — `README.md`.
- Минимальная роль — по дефолтным наборам журнала §1 (иерархии по включению нет); `owner`
  имеет доступ ко всему и не перечисляется. «Read-only для analyst»: да — открыт без действий;
  нет — открыт с действиями по роли; недоступен — не показывается.
- Детальная матрица кнопок, полей, фильтров и массовых операций для каждого раздела
  проектируется при описании самого раздела (журнал §7); здесь — состав и опасные операции.
  «Удалить» везде означает обратимый архив; «удалить навсегда» — только `owner`, с вводом имени
  сущности и аудитом (журнал #1).
- Аудит: коды `action` — `events-and-logs.md`. Любое чтение персональных данных в админке
  аудируется (журнал #6).
