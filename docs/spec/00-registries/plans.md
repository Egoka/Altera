## Правила жизненного цикла (журнал §8)

| Событие | Правило | Журнал |
|---|---|---|
| Неуспешный платёж при продлении | в дату окончания — пять автоматических попыток списания с 10:00 до 23:00; без успеха план сохраняется до конца даты и истекает с 00:00 следующего дня (прежнее «сразу, без льготного периода» — отменено §8.3) | §8.15 |
| Возврат средств | «Запросить возврат» в кабинете; до решения сотрудника план не меняется; после одобренного возврата подписка прекращается сразу (прежнее «не сокращает период» — отменено §8.4) | §8.18 |
| Очередь оплаченных периодов | все оплаченные и неиспользованные периоды не сгорают; активен период с наивысшим приоритетом: годовой pro → месячный pro → годовой standard → месячный standard; покупать период при действующей подписке можно; pro поверх standard — сразу, standard поверх pro — после pro; отдельных правил понижения и остатка нет (§8.5–6 отменены) | §8.22, §24.4 |
| Возврат неактивного периода очереди | по запросу без отдельной причины; активный и завершившийся периоды — по обычным правилам возврата | §24.4 |
| Первый запуск | бесплатный: базовое авторство и публикация доступны зарегистрированным пользователям; платные подписки, цены и обработка платежей — отдельный этап | §24.1 |
| Переход на новый план | оплачивается полная стоимость новой подписки; доплата за разницу не рассчитывается | #35 |
| Ручная выдача дней сотрудником | дни прибавляются к концу действующего оплаченного периода | #25 |
| Архивирование аккаунта (самостоятельное или административная блокировка) | план не отменяется и не ставится на паузу; при восстановлении до конца срока доступ возвращается на остаток, иначе остаток истекает без возврата; самостоятельно архивированный аккаунт восстанавливает сам пользователь после входа, заблокированный — только по оспариванию | #48, #50, §5.2 |
| Истёкший план и рейтинг | окончание плана не влияет на рейтинг автора и статей; автор остаётся в каталоге при наличии публикаций | §20.8 |
| Окончание плана и сессия | сессия остаётся, пользователь — читатель; каждый вызов, требующий плана, отклоняется сервером (`PLAN_LIMIT`), интерфейс показывает уведомление | #55 |
| Годовая подписка | цена десяти месяцев, двенадцать месяцев доступа | #32 |
| Смена цены | существенное изменение условий: письмо и выбор в кабинете (подтвердить, сменить план, отказаться); без подтверждения автопродление выключается, оплаченный период действует до конца; после подтверждения — продление по новой цене | §28.10 |
| Первый провайдер | Т-Касса; другие провайдеры — отдельные адаптеры, не блокируют запуск | §8.14 |
| Ручная выдача `pro` | полностью равна оплаченной по правам и Pro-компонентам; отличается только основание с аудитом | §8.16 |
| Служебные роли и Pro | редакционные статьи — всегда базовый режим; служебная запись `pro` не покупает и не получает | §8.17 |
| Права истёкшего плана | авторские разделы и актуальная личная аналитика — на чтение, если есть хотя бы одна статья | §8.20–21 |
| Отложено | цены (§8.12); включение платности — отдельное решение владельца (§24.1); чеки, налоги, бухгалтерия — предрелизная проверка перед включением платежей (§8.19); повторные письма — этап почты (§8.23) | — |
| Финансовый контур | `analyst`, `admin`, `owner`: выдача, продление, изменение, отмена подписки; финансовые данные; промокоды; условия и цены планов; возвраты; каждое решение аудируется с причиной, платёжными данными, сотрудником и значениями до/после | #19 |

## Закрытые вопросы Г1

- Профессиональные инструменты — в составе `pro`, отдельного плана нет (журнал #31).
- Годовая скидка — 10 месяцев за 12 (журнал #32); доплата при смене плана не рассчитывается
  (журнал #35); остатки — очередь периодов (Г5, §8.22).
- Вторая языковая версия — `standard` вручную, `pro` через AI (журнал #33).
