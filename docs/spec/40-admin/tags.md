# Раздел админки: Теги

- **Реестр**: `00-registries/admin-sections.md` #3 · `00-registries/routes.md` #43
- **Статус**: утверждён (гейт Г7, 2026-09-09)
- **ADR**: ADR-0004, ADR-0005 (в части, не противоречащей журналу §12: теги создаёт редакция, не
  автор), ADR-0032; журнал §3, §12, #1, #29; `20-public/tags-index.md`, `tag-feed.md`,
  `30-account/author/article-edit.md` (теги — автодополнение и создание автором, §26.3)
- **Этап**: 1

## 1. Назначение и минимальная роль

Справочник тегов (`Tag`): создать, переименовать, слить дубликаты, архивировать и
восстановить. Автор выбирает тег через автодополнение или вводит новый — если тега нет, он
создаётся сразу и доступен без очереди предложений и ручной проверки (журнал §26.3 —
прежнее правило «теги создают только служебные роли» отменено). Минимальная роль — `admin` (журнал §12, #29); `owner` — плюс «удалить навсегда»
(журнал #1). `analyst`, `editor`, `moderator` — раздел недоступен. «Удалить» = обратимый архив
(журнал §3.1): архивированный тег исчезает из выбора и публичных лент тега; материалы сохраняют
связь до восстановления `[ДОПУЩЕНИЕ]`. Публично тег с одним материалом виден (§20.9).

## 2. Маршруты

- `/admin/tags` — список; карточка — боковая панель по `?id=` `[ДОПУЩЕНИЕ: без отдельного
  маршрута, `routes.md` #43]`; `?status=active|archived`, `?q=`, `?sort=`.
- `noindex`; без сессии — 302 на `/login?next=…`; без права `taxonomy` — 403; обычный аккаунт —
  403 (§25.2).

|---|---|---|---|---|---|---|
| Создать тег | `admin`, `owner`; автор — из редактора (§26.3) | название уникально (без учёта регистра `[ДОПУЩЕНИЕ]`) | `createTag(name, nameEn?)` | активен сразу | `tag.update` (матрица #85 → код #35 `tag.*`); создание автором — лог, не аудит `[ДОПУЩЕНИЕ]` | — |

## 6. Массовые операции

| Операция | Максимум выбранных | Роль | Подтверждение | Откат | Аудит |
|---|---|---|---|---|---|
| Слить выбранные в один | 50 `[ДОПУЩЕНИЕ]` | `admin`, `owner` | модальное окно с целью и числом материалов | нет (источники в архиве с пометкой, восстановление невозможно) | `tag.merge` на каждый источник |
| Архивировать выбранные | 50 | `admin`, `owner` | модальное окно с числом материалов | восстановление поштучно | `tag.archive` ×N |

## 7. Опасные операции и подтверждения

- **Слияние** — необратимо для источников: модальное окно с перечнем источников, целью и
  суммой материалов; для массового — то же.
- **Архив тега с материалами** — модальное окно с числом материалов.
- **Удалить навсегда** — только `owner`, из архива, ввод названия (журнал #1); недоступно
  `admin` при любом подтверждении.

## 8. Аудит действий

Коды: `tag.merge`, `tag.archive`, `tag.restore` (#35; переименование и создание — `tag.update`
внутри #35 `[ДОПУЩЕНИЕ: код в составе строки]`), `entity.delete.permanent` (#68), оболочка
`admin.change` (#75) с `diff`. Слияние пишет `sourceIds`, `targetId`, число перенесённых связей.
Не аудируется: просмотр списка, поиск (ПДн нет); чтение карточки автора из предложения — через
раздел #6 с `admin.read.personal` (#67).

## 9. Состояния

| Состояние | Когда | Что показано |
|---|---|---|
| Загрузка | список | скелет таблицы |
| Пусто | нет тегов / фильтр пуст | `EmptyState` с «создать тег» / «по фильтру ничего» |
| Ошибка | список или мутация | `ErrorState` с `requestId`; выбор сохраняется |
| Нет прав на часть действий | `admin` — «удалить навсегда» отсутствует; архив, сделанный `owner`, — без «восстановить» | кнопок нет, пояснение |
| Конфликт (объект изменён другим администратором) | переименование в занятое название; слияние в архивированный или уже слитый тег; сохранение поверх новой версии | `CONFLICT` с пояснением; «обновите список» |
| Лимит / превышение | выбрано больше максимума для массовой операции | сообщение «выберите не более N» |

## 10. Мобильный

Чтение и поиск; переименование и архив поштучно; слияние и массовые операции — только десктоп
`[ДОПУЩЕНИЕ]`; «удалить навсегда» — только десктоп.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Карточка в боковой панели; уникальность без учёта регистра; слитый тег не
  восстанавливается; максимум 50 в массовых операциях; слияние и «удалить навсегда» — десктоп;
  коды создания и переименования — в составе строки #35; создание тега автором — лог.
- Закрыто Г7 (§26.3): теги создают и авторы (автодополнение или новый тег сразу); слияние,
  переименование, архив и «удалить навсегда» — `admin`/`owner`; ADR-0005 п. 3 в этой части
  снова действует (строка статуса обновлена). Слаг тега занят навсегда (§26.10).
- `[ДОПУЩЕНИЕ]` Английское название тега (`nameEn`, ADR-0005) необязательно; публичная лента
  тега на английском использует его при наличии, иначе — русское название
  (`20-public/tag-feed.md`).
- Закрыто Г7 (§26.3): очереди предложений нет — авторы создают теги сами; дубликаты редакция
  сливает.
- `[ДОПУЩЕНИЕ]` Тег, созданный автором и не использованный ни одним материалом после удаления
  из черновика, остаётся в справочнике активным до решения редакции (архив или слияние) — без
  автоматической чистки.
