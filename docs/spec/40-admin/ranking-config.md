# Раздел админки: Рейтинг: состояние движка

- **Реестр**: `00-registries/admin-sections.md` #15 · `00-registries/routes.md` #55
- **Статус**: утверждён (гейт Г8b, 2026-09-09)
- **ADR**: ADR-0034, ADR-0038 (заменён `engagement-tracking.md`), ADR-0040 (заменён: Pro-балл
  постоянный); журнал §21.29, §21.32, §21.35–36, §21.39–40, §23.6, §27.3; `60-ranking/recompute.md`,
  `anti-fraud.md`, `engagement-tracking.md` §10–11, `README.md`; матрица #68; события #48, #82, #84
- **Этап**: 2 (с движком рейтинга)

## 1. Назначение и минимальная роль

Наблюдение за движком рейтинга: версия правил (живёт в коде — §21.32), прогоны (стартовый,
часовой, полный при релизе правил), их длительность, ошибки и автоматические повторы (§21.29,
§21.40, §27.3), доля автоматических исключений и аномалии (`anti-fraud.md`, §23.6),
сохранённые значения `ArticleScore` / `AuthorScore` на чтение. Ничего не настраивается и не
запускается: смена весов, ручной пересчёт, ручные исключения и бусты отменены (§21.32, §23.6,
§21.16, §27.3). Минимальная роль — `analyst`, `admin` (чтение), `owner` (тоже только чтение);
`moderator`, `editor` — недоступен; `analyst` — read-only без действий, как и все.

## 2. Маршруты

- `/admin/ranking` — состояние; `?tab=runs|anomalies|scores` `[ДОПУЩЕНИЕ]`, `?period=`,
  `?q=` (статья или автор для просмотра сохранённого значения), `?page=`.
- Из сводки (#1), статистики (#11, вкладка «рейтинг»), раздела ошибок (#22 — сбои прогонов),
  карточки статьи (#4 — общий результат).
- `noindex`; без сессии — 302; роли без доступа — 403.

## 3. Сущности и данные

| Сущность | Поля в списке | Поля в карточке | Источник (запрос) | Персональные данные (кто видит) |
|---|---|---|---|---|
| Состояние движка | версия правил (`rulesVersion`), время и длительность последнего прогона, следующий по расписанию, число затронутых сущностей, статус (ок / повтор после сбоя), доля автоматических исключений за период | — | `rankingState` | нет |
| Прогон (`RankingRun`) | вид (стартовый / часовой / полный), начало, конец, статус, затронуто, ошибка (класс) и автоматический повтор | детали ошибки — ссылка в #22 | `rankingRuns(period)` | нет |
| Аномалия (`EngagementAnomaly`) | объект (статья / автор), день, сработавшие сигналы (классы, без сырых признаков — `engagement-tracking.md` §10), состояние разбора (автоматическое исключение #84 / нет) | — | `engagementAnomalies(period)` | статья и хэндл автора — служебные роли раздела; IP и идентификаторы читателей не показываются |
| Сохранённые значения | статья или автор, общий результат, признак Pro, `computedAt`, `stale`; состав по компонентам конкретной статьи — только `owner`, `admin`, `analyst` для диагностики, без возможности менять расчёт (журнал §28.9); рецензент и модератор состав не видят | — | `articleScore(id)`, `authorScore(id)` | нет |

Аномалии и исключения — только автоматические (§23.6); ручного возврата вклада нет. Состав
по компонентам сохранённого значения — служебным ролям (матрица #7), авторам — только общий
результат (§25.5).

## 6. Массовые операции

Массовых операций нет: раздел только для чтения.

## 7. Опасные операции и подтверждения

Опасных операций нет. Изменение правил движка — релиз кода с решением владельца о переработке
продукта (§21.32), не действие в админке.

## 8. Аудит действий

Аудит не пишется, кроме `stats.export` (#40): ПДн в разделе нет (аномалии показывают статью и
хэндл — публичные данные). Логи-источники: `ranking.run.started` / `.done` / `.failed` (#48),
`engagement.anomaly` (#82); аудит системы — `engagement.exclusion` (#84).

## 9. Состояния

| Состояние | Когда | Что показано |
|---|---|---|
| Загрузка | получение состояния | скелеты |
| Пусто | движок ещё не запускался (этап 1) / аномалий нет | «движок появится на этапе 2» / «аномалий нет» |
| Ошибка | состояние не получено; последний прогон со сбоем | `ErrorState`; сбой прогона — статус «повтор после сбоя», выдача использует последнее успешное значение (§21.29) |
| Нет прав на часть действий | не применимо: действий нет | — |
| Конфликт (объект изменён другим администратором) | не применимо: раздел не редактирует | — |
| Лимит / превышение | экспорт чаще лимита | `RATE_LIMITED` |

## 10. Мобильный

Полный набор: чтение состояния, прогонов и аномалий; экспорт — десктоп `[ДОПУЩЕНИЕ]`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Вкладки; период 7 дней; журнал прогонов бессрочно; экспорт — десктоп.
- `[ДОПУЩЕНИЕ]` Аномалии показываются с классами сигналов, без сырых технических признаков и
  порогов (`engagement-tracking.md` §10); пороги — отложено (§23).
- `[ДОПУЩЕНИЕ]` На этапе 1 раздел отвечает состоянием «пусто» с пояснением, маршрут существует
  (`routes.md` #55 — этап 2), чтобы навигация админки не менялась между этапами.
- Отложено (§21.39, Г4 углублённый этап): формула, веса, окна, лимиты, слой открытия
  (§21.25) — в коде движка, не в админке.
- Отложено (`health-and-alerts.md`): оповещение владельцу и администратору (§28.5) о повторных
  сбоях прогона.
- Закрыто Г8b (§28.9): состав компонентов конкретной статьи — только `owner`, `admin`, `analyst`.
- Закрыто Г4, Г8a (§21.29, §21.32, §21.35–36, §21.40, §23.6, §27.3): только наблюдение; веса не
  настраиваются; ручного пересчёта и ручных исключений нет; последнее успешное значение и
  автоматический повтор.
- Закрыто Г8b (§28.9): состав компонентов конкретной статьи — `owner`, `admin`, `analyst`,
  только чтение; рецензент и модератор не видят.
