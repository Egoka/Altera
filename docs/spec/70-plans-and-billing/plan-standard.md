# Политика: План `standard`

- **Область**: планы и биллинг
- **Статус**: утверждён (гейт Г5, 2026-09-09); цена — отложено (§8.12)
- **ADR**: ADR-0035, ADR-0037, ADR-0044, ADR-0046 (в части, не противоречащей журналу §8, §20.8,
  §21.34)
- **Этап**: 1 при платном запуске (§8.13 — отложено)

## 1. Назначение

`standard` — первый платный план, «путь в авторы» (`plans.md` #2; журнал §8): активный
`standard` даёт роль `author` с грейдом `basic`, право создавать, редактировать и публиковать
свои статьи. Файл фиксирует состав, лимиты-гипотезы, цену-гипотезу и поведение при истечении;
цены проверяются на гейте Г5 по `docs/vision/07-commerce.md` §3. На него ссылаются `pricing.md`,
`roles/author.md`, `subscription-lifecycle.md`, `role-derivation.md`.

## 2. Правила

1. **Получение**: оплата на `/pricing` → `Subscription.active` → вебхук провайдера →
   `planTier = standard`, `planUntil = currentPeriodEnd`, роль `author` (`role-derivation.md`);
   либо ручная выдача (`grants-and-promo.md`). Проверяется вебхуком и планировщиком.
2. **Состав** (`plans.md` #2; журнал #5, #33): всё из `free`; создание, редактирование, отправка
   к публикации и повторная публикация своих статей; редактор со всеми блоками этапа; медиа к
   статьям; AI-проверка допустимости; вторая языковая версия **вручную** (журнал #33); личная
   аналитика своих статей — состав по плану отложен (`60-ranking/explainability.md` §3).
3. **Чего нет по сравнению с `pro`**: AI-перевод, Pro-балл статей, кривая свежести `pro`,
   профессиональные инструменты (журнал #31, #33, §21.15, §21.34); запрос — `PLAN_LIMIT` с
   `requiredTier = pro`.
4. **Лимиты-гипотезы** `[ДОПУЩЕНИЕ]`: материалов в очереди проверки одновременно ≤ 5; медиа ≤ 2 ГБ;
   значения — коды в `Plan.features`, читает хелпер прав; превышение — `PLAN_LIMIT`.
5. **Цена** (§8.12): диапазон 490–990 ₽ в месяц — временная гипотеза, не утверждена; год — цена
   десяти месяцев за двенадцать (журнал #32); полная стоимость при любом переходе, без доплаты
   (журнал #35). Значение хранится централизованно, не в экранах и логике; технический источник —
   при реализации.
6. **Смена плана** (§8.22): отдельной операции понижения или повышения нет — купленный период
   встаёт в очередь по приоритету (годовой `pro` → месячный `pro` → годовой `standard` →
   месячный `standard`); при активном `pro` период `standard` ждёт; при активном `standard`
   купленный `pro` активируется сразу, а остаток `standard` ждёт в очереди и не сгорает.
7. **Истечение и отмена** (§8.15, §8.20–21): в дату окончания — пять попыток списания
   10:00–23:00; при неудаче с 00:00 следующего дня — `reader` с правами истёкшего плана
   (`plan-free.md` п. 4): статьи остаются, авторские разделы и аналитика — на чтение; рейтинг не
   меняется (§20.8); сессия остаётся (журнал #55).
8. **Грейд** `basic` вычисляется из плана (ADR-0037); статьи, опубликованные при `standard`,
   Pro-балла не получают и не получат при последующем переходе на `pro` (§21.15 — снимок при
   публикации).
9. **Годовой интервал** — те же права на двенадцать месяцев; отмена — с конца оплаченного года.

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Ручная выдача `standard` на срок | редакция, партнёры, первые авторы | `analyst`, `admin`, `owner` | `plan.grant` |
| Дополнительные дни к периоду | по решению сотрудника; прибавляются к концу периода (журнал #25) | `analyst`, `admin`, `owner` | `subscription.extend.manual` |
| Промокод на первый период | механика применения — отложено | — | `promo.*` |

## 5. Проверяемость

- Тест: успешный вебхук по `standard` даёт роль `author`, грейд `basic`; `article.create` — успех.
- Тест: шестая отправка при пяти в очереди — `PLAN_LIMIT` (значение — конфигурация).
- Тест: `translation.translate.ai` для `standard` — `PLAN_LIMIT` с `requiredTier = pro`.
- Тест: после пяти неудачных попыток — роль `reader` с 00:00 следующего дня, статьи в
  статусе `published`, аналитика читается.
- Метрики: конверсия «профиль автора заполнен → standard», удержание на первом продлении
  (`07-commerce.md` §6).
