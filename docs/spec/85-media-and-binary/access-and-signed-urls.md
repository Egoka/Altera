# Политика: Доступ к файлам и подписанные ссылки

- **Область**: доступ
- **Статус**: утверждён (гейт Г9, 2026-09-09)
- **ADR**: ADR-0008, ADR-0011, ADR-0019 (кеш), ADR-0023 (BFF); журнал §11, #28, §5, §27.6, §28.2;
  `storage-layout.md`, `exports.md`, `receipts-and-documents.md`, `avatars.md`,
  `article-covers.md`; `50-access/visibility.md`; `20-public/article.md` §3 (предпросмотр)
- **Этап**: 1

## 1. Назначение

Кто и как получает файлы из хранилища: что публично и кешируется, что закрыто и выдаётся по
подписанной ссылке, как доступ следует за статусом материала и аккаунта. На политику ссылаются
все политики `85-media-and-binary/`, публичные страницы, редактор, выгрузка, админка.

## 2. Правила

1. **Публичные файлы** — варианты изображений опубликованных материалов и аватары авторов с
   публичным профилем: прямые URL через CDN с долгим кешем `[ДОПУЩЕНИЕ: неизменяемые ключи —
   кеш год]`; ключи непрозрачны (`storage-layout.md` п. 3), угадать чужой файл нельзя.
2. **Закрытые файлы** — оригиналы, медиа черновиков, версий на проверке, архивированных и снятых
   материалов, аватары архивированных аккаунтов, выгрузки, документы: только по подписанной
   ссылке с коротким сроком `[ДОПУЩЕНИЕ: минуты для медиа редактора, 7 дней для выгрузок —
   `exports.md`]`, выданной API после проверки прав (`visibility.md`; матрица #2, #53).
3. **Доступ следует за статусом**: публикация открывает варианты (кеш инвалидируется —
   ADR-0019); снятие, архив (журнал §11, #28) и архив аккаунта (журнал §5) закрывают: CDN
   отвечает 404 `[ДОПУЩЕНИЕ: без кода `ARCHIVED` — у файлов нет страницы]`, страница материала —
   410 `ARCHIVED` (§28.2); восстановление в `published` (§25.7) открывает снова.
4. **Предпросмотр** (`article.md` §3, `?preview=`): медиа неопубликованной версии отдаётся по
   подписанным ссылкам в рендере предпросмотра для автора, `editor`, `moderator`, `admin`,
   `owner`.
5. **Редактор**: автор видит свои загруженные файлы по подписанным ссылкам; `editor` —
   редакционные; чужие — `NOT_FOUND` (не раскрывать существование — `error-dictionary.md` п. 4).
6. **Выгрузки** — только владельцу аккаунта по подписанной ссылке (`exports.md` п. 3); чеки —
   ссылки провайдера (`receipts-and-documents.md`).
7. **Подписанные ссылки не логируются целиком** (`logging-policy.md` п. 4 — токены) и не
   попадают в письма, кроме ссылки на выгрузку `[ДОПУЩЕНИЕ]`. Доступ сотрудника к медиа чужого
   черновика — не чтение ПДн (в файлах ПДн нет — ADR-0011 п. 3): он логируется `http.request` с
   ролью и ID (§28.1); аудит пишется только при открытии карточки с ПДн (§28.7).
8. **Hotlink и скрейпинг**: публичные файлы доступны без ограничения по источнику (запрет
   обучения ИИ — лицензия и `robots.txt`, §24.2, не техническая защита); лимиты — общие
   (`rate-limits.md`).
9. **Прямые ссылки на бакет** в интерфейсе не используются — только CDN-домен или подписанные
   URL; смена провайдера хранилища меняет домен, не ключи (`storage-layout.md`).

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Служебный доступ к оригиналам | эксплуатация (сверка целостности, восстановление) | `owner` вне продукта | вне продукта |
| Дефолтные изображения | из репозитория, всегда публичны | — | — |
| OG-изображение снятого материала | закрыто вместе с материалом | система | — |

## 4. Взаимодействие с другими политиками

- `visibility.md` и матрица — кто видит материал, тот видит его файлы; `error-dictionary.md` —
  404/410 на страницах; `retention-and-orphans.md` — файлы остаются, доступ закрывается;
  `logging-policy.md` — без токенов в логах.

## 5. Проверяемость

- Тест: вариант опубликованного материала — 200 без подписи; после архива — 404; после
  восстановления — 200.
- Тест: оригинал без подписи — 403/404; с подписью автора — 200; с просроченной — отказ.
- Тест: чужой файл черновика — `NOT_FOUND` в API и отказ CDN.

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Долгий кеш публичных вариантов; сроки подписанных ссылок; 404 от CDN для
  закрытых; ссылка на выгрузку в письме.
- Отложено: претензии и скрытие медиа (жалобы, #42).
- Закрыто Г1–Г8b (журнал §11, #28, §5, §24.2, §25.7, §27.6, §28.2): доступ следует за статусом
  материала и аккаунта; секреты не в логах; запрет обучения ИИ — не техническая защита.
- Закрыто Г9 (§29.10): водяных знаков нет; права обозначаются лицензией и атрибуцией.
