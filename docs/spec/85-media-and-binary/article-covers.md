# Политика: Обложки материалов

- **Область**: хранение
- **Статус**: на утверждении
- **ADR**: ADR-0002 (общая обложка на пару версий), ADR-0008, ADR-0030, ADR-0034; журнал #28,
  §11, §20.6; `03-data-model.md` (`Article.coverAssetId`, SetNull); `30-account/author/article-edit.md`
  §5 (зона 3), `20-public/article.md`, `home.md`, `section-feed.md`, `feeds-and-sitemap.md`
- **Этап**: 1

## 1. Назначение

Обложка материала: одна на материал (общая для языковых версий — ADR-0002), используется в
шапке материала, карточках лент, RSS и Open Graph. Как задаётся, из чего строятся варианты, что
при отсутствии, что при архиве. На политику ссылаются редактор, публичные страницы и
`image-variants.md`.

## 2. Правила

1. **Одна обложка на материал** — `Article.coverAssetId → MediaAsset` (SetNull при удалении
   медиа — `03-data-model.md`); задаётся в редакторе (зона «метаданные», `article-edit.md`) с
   лицензией и атрибуцией (ADR-0008); необязательна `[ДОПУЩЕНИЕ]`.
2. **Общая для версий**: обе языковые версии показывают одну обложку (ADR-0002 — общие
   метаданные); подпись и `alt` — по локали из узла или медиа `[ДОПУЩЕНИЕ]`.
3. **Варианты** — по `image-variants.md`; для карточек — обрезка по фокусной точке под
   соотношения `lede`, `large`, `small` (`06-design-system.md` §5 `ArticleCard`); OG-изображение —
   1200×630 из обложки `[ДОПУЩЕНИЕ]`; RSS — вариант в описании (`feeds-and-sitemap.md` §5).
4. **Без обложки**: карточки показывают вариант без изображения (текстовая карточка
   `[ДОПУЩЕНИЕ]`), OG — дефолтное изображение издания из репозитория (`06-design-system.md`
   §10); заполнитель не генерируется.
5. **Смена обложки** после публикации — правка метаданных без снятия (`article-edit.md`,
   матрица #40 / #19); дата публикации не меняется, «обновлено» показывается только при
   изменении текста (§20.6) `[ДОПУЩЕНИЕ: смена обложки не считается доработкой]`.
6. **Архив материала** закрывает медиа, включая обложку (журнал §11, #28): публичные варианты
   перестают отдаваться (`access-and-signed-urls.md`); восстановление в `published` (§25.7)
   возвращает доступ.
7. **Удаление навсегда** материала удаляет обложку вместе с медиа (`permanent-delete.md`).
8. **Права на изображение** — на загрузившем (ADR-0008 п. 4); претензии — сценарий жалоб
   (`media.hide` #42 — отложено).

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Редакционные материалы журнала | обложку задаёт любой действующий `editor` (журнал §17) | `editor` | — (действие над редакционной) |
| Скрыть обложку по претензии | отложено с жалобами (#42) | `moderator`, `owner` | — |
| Дефолтное OG-изображение | обложки нет | система | — |

## 4. Взаимодействие с другими политиками

- `image-variants.md` — варианты и обрезка; `upload-pipeline.md` — загрузка;
  `access-and-signed-urls.md` — публичность; `20-public/article.md` §10 — SEO и OG главнее в
  части метатегов.

## 5. Проверяемость

- Тест: материал с обложкой → OG и карточки используют варианты; без обложки — дефолт.
- Тест: архив материала → вариант обложки недоступен публично (404/403 от CDN
  `[ДОПУЩЕНИЕ]`); восстановление — доступен.
- Тест: смена обложки не меняет `publishedAt` и не поднимает «обновлено».

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Обложка необязательна; `alt` по локали; OG 1200×630; текстовая карточка без
  изображения; смена обложки — не доработка; ответ CDN для закрытых медиа.
- Отложено: претензии и скрытие медиа (жалобы, #42); каталог блоков — изображения в тексте.
- Закрыто Г1, Г3 (журнал #28, §11, §20.6): медиа с материалом; «обновлено» только при изменении.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Обязательна ли обложка для публикации (единообразие лент и главной)?
  Если да — `VALIDATION_ERROR` при подаче без обложки (`article-edit.md` §4); если нет — как
  описано, карточка без изображения.
