# Политика: Конвейер загрузки

- **Область**: хранение
- **Статус**: на утверждении
- **ADR**: ADR-0008 (лимиты, форматы, лицензия и атрибуция обязательны), ADR-0030 (варианты при
  загрузке, `sharp`), ADR-0032; `30-account/author/article-edit.md` §4 (`uploadMedia`),
  `reader/profile-edit.md` (`uploadAvatar`); `50-access/rate-limits.md` п. 9; матрица #39–40;
  журнал §11, §25.4
- **Этап**: 1

## 1. Назначение

Единый путь файла от формы до записи `MediaAsset`: проверки, лимиты, обработка, варианты,
ошибки. На политику ссылаются `article-edit.md`, `profile-edit.md`, `image-variants.md`,
`avatars.md`, `article-covers.md`, `storage-layout.md`.

## 2. Правила

1. **Точка входа** — мутации `uploadMedia(translationId, file, license, attribution, alt)` и
   `uploadAvatar(file)`; загрузка идёт через API, не напрямую в бакет `[ДОПУЩЕНИЕ: прямые
   подписанные загрузки — при потребности]`.
2. **Права**: медиа статьи — автор версии, `editor` для редакционных (матрица #39); аватар — свой
   (`profile.update` #48); при истёкшем плане загрузка — `PLAN_LIMIT` (`article-edit.md`).
3. **Проверки до сохранения**: тип по содержимому, а не по расширению; форматы JPEG, PNG, WebP,
   AVIF, GIF; размер до 20 МБ (ADR-0008 п. 6 `[ДОПУЩЕНИЕ]`); лицензия из справочника
   `MediaLicense` и атрибуция обязательны для медиа статьи (ADR-0008 п. 3) — иначе
   `VALIDATION_ERROR`; `alt` — по умолчанию, узел документа может переопределить.
4. **Лимиты**: 30 файлов в час на аккаунт (`rate-limits.md` п. 9 `[ДОПУЩЕНИЕ]`) —
   `RATE_LIMITED`; квота объёма по плану (`plans.md`, лимиты `mediaGb` `[ДОПУЩЕНИЕ]`) —
   `PLAN_LIMIT`.
5. **Обработка**: удаление EXIF (координаты, устройство, комментарии), сохранение оригинала,
   вычисление `sha256` (дедупликация по владельцу — `storage-layout.md` п. 6), генерация
   вариантов и заполнителя (`image-variants.md`), запись `MediaAsset` с `storageKey`; всё в одном
   запросе, синхронно `[ДОПУЩЕНИЕ: без очереди на старте — ADR-0030]`.
6. **Аватар** дополнительно проходит автоматическую проверку (журнал §25.4): результат `ok` —
   применяется сразу; `needs_review` — прежний аватар остаётся до решения рецензента; `rejected`
   — не применяется (`avatars.md`; события `profile.check` #85).
7. **Ошибки**: неподдерживаемый тип или размер — `VALIDATION_ERROR` с `field: file`, `rule`;
   сбой обработки (`sharp`) — `INTERNAL_ERROR` с `requestId`, файл не сохраняется; хранилище
   недоступно — `PROVIDER_UNAVAILABLE` `[ДОПУЩЕНИЕ: `provider: storage` — код провайдера в реестре
   #11 перечисляет psp / ai / mail; расширение — вопрос владельца при заморозке §28.3]`.
8. **Привязка**: медиа статьи привязано к материалу через узлы документа и обложку (журнал #28);
   загруженный, но не вставленный файл — кандидат в сироты (`retention-and-orphans.md`).
9. **Логи**: `http.request` (#41) с длительностью; аудита нет (действие автора над своими
   данными — `audit-vs-logs.md`); замена файла — `media.replace` (#34, этап 4).

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Дефолтные изображения системы | из репозитория, без загрузки | разработчик | — |
| Замена файла с сохранением ссылок (`media.replace`, #43) | этап 4 | автор, `editor`, `owner` | `media.replace` (#34) |
| Видео, аудио, файлы | этап 5 (`MediaKind`) | — | — |

## 4. Взаимодействие с другими политиками

- `50-access/rate-limits.md` — лимиты главнее; `70-plans-and-billing/plan-*.md` — квоты;
  `image-variants.md` — обработка; `access-and-signed-urls.md` — где файл доступен после
  загрузки; `error-dictionary.md` — коды.

## 5. Проверяемость

- Тесты: файл без лицензии — `VALIDATION_ERROR`; неверный MIME под расширением — отказ; 31-й файл
  в час — `RATE_LIMITED`; повторный файл — та же запись.
- Тест: в сохранённом оригинале нет EXIF-координат.
- Метрика: доля неудачных загрузок и медиана длительности (раздел #22, `http.request`).

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Загрузка через API; синхронная обработка; квота `mediaGb`; лимит 30 в час;
  20 МБ; `PROVIDER_UNAVAILABLE` для хранилища.
- Отложено (этап 4–5): замена файла, видео и аудио; прямые подписанные загрузки.
- Закрыто Г1, Г6 (журнал #28, §25.4): медиа привязано к статье; аватар — автопроверка.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Расширить ли код `PROVIDER_UNAVAILABLE` (#11) значением `storage` для
  недоступного объектного хранилища? Если да — строка реестра дополняется вашим решением
  (реестр заморожен — §28.3); если нет — недоступность хранилища отдаётся как `INTERNAL_ERROR`.
