# Политика: Конвейер загрузки

- **Область**: хранение
- **Статус**: утверждён (гейт Г9, 2026-09-09)
- **ADR**: ADR-0008 (лимиты, форматы, лицензия и атрибуция обязательны), ADR-0030 (варианты при
  загрузке, `sharp`), ADR-0032; журнал §29.2–5, §29.11–12 (`docs/2026-09-09-media-upload-processing-notes.md` — целевой конвейер); `30-account/author/article-edit.md` §4 (`uploadMedia`),
  `reader/profile-edit.md` (`uploadAvatar`); `50-access/rate-limits.md` п. 9; матрица #39–40;
  журнал §11, §25.4
- **Этап**: 1

## 1. Назначение

Единый путь файла от формы до записи `MediaAsset`: проверки, лимиты, обработка, варианты,
ошибки. На политику ссылаются `article-edit.md`, `profile-edit.md`, `image-variants.md`,
`avatars.md`, `article-covers.md`, `storage-layout.md`.

## 2. Правила

1. **Точка входа** — мутации `uploadMedia(translationId, file, license, attribution)` и
   `uploadAvatar(file)`; загрузка идёт через API, не напрямую в бакет `[ДОПУЩЕНИЕ: прямые
   подписанные загрузки — при потребности]`.
2. **Права**: медиа статьи — автор версии, `editor` для редакционных (матрица #39); аватар — свой
   (`profile.update` #48); при истёкшем плане загрузка — `PLAN_LIMIT` (`article-edit.md`).
3. **Проверки до сохранения**: тип по содержимому, а не по расширению; форматы JPEG, PNG, WebP,
   AVIF, GIF; размер до 20 МБ (ADR-0008 п. 6 `[ДОПУЩЕНИЕ]`); лицензия из справочника
   `MediaLicense` и атрибуция обязательны для медиа статьи (ADR-0008 п. 3) — иначе
   `VALIDATION_ERROR`; `alt` автор не задаёт — его создаёт конвейер (п. 6а), узел документа его не
   переопределяет (журнал §29.13).
4. **Лимиты**: 30 файлов в час на аккаунт (`rate-limits.md` п. 9 `[ДОПУЩЕНИЕ]`) —
   `RATE_LIMITED`; квота объёма по плану (`plans.md`, лимиты `mediaGb` `[ДОПУЩЕНИЕ]`) —
   `PLAN_LIMIT`.
5. **Целевой конвейер** (журнал §29.12; заметка владельца): файл не становится публичным сразу —
   попадает в карантинную зону и очередь обработки; шаги: проверка фактического типа, целостности,
   размера и числа пикселей → безопасность, дубликаты (`sha256`), допустимость прозрачности и
   анимации → удаление EXIF (включая геолокацию), ориентация, единый цветовой профиль →
   **мастер-файл** (§29.2) → серверное сжатие, заполнитель, thumbnails и адаптивные варианты
   (`image-variants.md`) → фокусная точка и кадрирование, где требуется месту использования →
   проверки лицензии, атрибуции и правил (аватар — автопроверка, не блокирующая — §29.5) →
   AI-описание `alt` (п. 6а) → состояние обработки: `загрузка`, `в очереди`, `обрабатывается`,
   `готово`, `ошибка`; публичный доступ — только после обязательных шагов; частичная ошибка —
   повторная задача восстанавливает недостающие варианты, не теряя мастер-файл. Конкретные
   сервисы, схема очереди, лимиты, ретраи, GIF/PDF/видео/аудио — отдельный проход; AI-улучшение
   качества автоматически не включается.
5а. **Свойства медиа** для автора: подпись, атрибуция, лицензия, фокус, кадрирование (матрица
   #40); `alt` автору только показывается, редактирование недоступно (§29.13).
6. **Аватар** после базовой технической обработки применяется публично сразу, без ожидания
   автоматической или ручной проверки (журнал §29.5); автопроверка (§25.4) идёт следом и не
   блокирует; предыдущая версия сохраняется, рецензент при необходимости возвращает её с
   аудитом (`avatars.md`; события `profile.check` #85).
6а. **AI-описание** (журнал §29.11): каждое загруженное изображение проходит отдельный шаг лёгкой
   AI-модели, которая определяет, что изображено, и сохраняет описание в `alt` самого медиафайла;
   это обработка медиа, не анализ статьи и не зависит от её текста; создаётся один раз и
   хранится только в свойствах медиафайла; публичный вывод всегда использует это единое `alt`;
   автор его не редактирует, размещение в статье не переопределяет (§29.13); в редком исключении
   описание исправляет только `admin` непосредственно у медиафайла — аудит `admin.change` (#75,
   `entity: mediaAsset`, поле `alt` до/после), нового кода события нет (§28.3); выбор модели,
   языки, качество и поведение при ошибке генерации — отдельный проход; запись — `ai.job.*`
   (#46, `kind: alt`), раздел `40-admin/ai-processes.md`.
7. **Ошибки**: неподдерживаемый тип или размер — `VALIDATION_ERROR` с `field: file`, `rule`;
   сбой обработки — `INTERNAL_ERROR` с `requestId`, состояние `ошибка`, мастер-файл сохранён, если
   успел создаться; хранилище недоступно — `PROVIDER_UNAVAILABLE` с `provider: storage` (журнал
   §29.3; реестр #11).
8. **Привязка**: медиа статьи привязано к материалу через узлы документа и обложку (журнал #28);
   загруженный, но не вставленный файл — кандидат в сироты (`retention-and-orphans.md`).
9. **Логи**: `http.request` (#41) с длительностью; аудита нет (действие автора над своими
   данными — `audit-vs-logs.md`); замена файла — `media.replace` (#34, этап 4).

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Дефолтные изображения системы | из репозитория, без загрузки | разработчик | — |
| Замена файла с сохранением ссылок (`media.replace`, #43) | этап 4 | автор, `editor`, `owner` | `media.replace` (#34) |
| Видео, аудио, файлы | этап 5 (`MediaKind`) | — | — |

## 4. Взаимодействие с другими политиками

- `50-access/rate-limits.md` — лимиты главнее; `70-plans-and-billing/plan-*.md` — квоты;
  `image-variants.md` — обработка; `access-and-signed-urls.md` — где файл доступен после
  загрузки; `error-dictionary.md` — коды.

## 5. Проверяемость

- Тесты: файл без лицензии — `VALIDATION_ERROR`; неверный MIME под расширением — отказ; 31-й файл
  в час — `RATE_LIMITED`; повторный файл — та же запись.
- Тест: в мастер-файле нет EXIF-координат; состояние проходит `в очереди → обрабатывается → готово`.
- Метрика: доля неудачных загрузок и медиана длительности (раздел #22, `http.request`).

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Загрузка через API; квота `mediaGb`; лимит 30 в час; 20 МБ; карантинный
  префикс.
- Отложено (этап 4–5): замена файла, видео и аудио; прямые подписанные загрузки.
- Закрыто Г1, Г6, Г9 (журнал #28, §25.4, §29.2–5, §29.11–12): медиа привязано к статье;
  мастер-файл; `storage` в коде провайдера; аватар сразу; AI-описание `alt`; целевой конвейер со
  статусами по заметке.
- Отложено (§29.12): выбор сервисов, матрица размеров, сжатие, лимиты, очередь, ретраи,
  GIF/PDF/видео/аудио, модель `alt`, AI-улучшение качества — отдельный проход.
