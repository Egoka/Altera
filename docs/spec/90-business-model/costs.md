# Бизнес-модель: Расходы

- **Область**: бизнес-модель
- **Статус**: на утверждении
- **ADR**: ADR-0011, ADR-0019, ADR-0024, ADR-0030; `docs/vision/08-operations.md` §10,
  `07-commerce.md` §11; журнал §8.14, §8.19, §21.21, §23.7
- **Этап**: 0–1

## 1. Назначение

Структура постоянных и переменных расходов проекта до и после запуска; значения — гипотезы до
счетов. На файл ссылаются `unit-economics.md` (переменные), `metrics.md` (безубыточность),
`08-operations.md` §10.

## 2. Правила

1. **Постоянные ежемесячные** `[ДОПУЩЕНИЕ: состав; значения — по счетам]`:

| Статья | Что | Источник |
|---|---|---|
| Прод в РФ | управляемый PostgreSQL с резервными копиями, хостинг API и Nuxt, S3-совместимое хранилище | ADR-0011, `08-operations.md` §10 |
| Поиск | Meilisearch — управляемый или собственный экземпляр (журнал §21.21) | отдельная спецификация поиска |
| Почта | транзакционные письма через провайдера с РФ-контуром | ADR-0024; этап почты (§8.23) |
| Домен, TLS, DNS | — | — |
| Мониторинг и сборщик ошибок | журнал ошибок бэкенда (§20.19) — свой раздел, внешний сборщик по потребности | `admin-sections.md` #22 |
| Платёжный провайдер | абонентская часть, если есть по договору с Т-Кассой (§8.14) | договор |
| Юридическое и бухгалтерское сопровождение | предрелизная проверка (§8.19), консультации по 152-ФЗ | `legal-152-54.md` |

2. **Переменные** — на автора и на трафик (`unit-economics.md`): комиссия провайдера, AI-проверка,
   AI-перевод, медиа, письма; на трафик — исходящий трафик хранилища и CDN `[ДОПУЩЕНИЕ]`.
3. **AI как статья расходов** (`07-commerce.md` §11): каждая запись задания хранит `costMinor`;
   бюджет на месяц — параметр с уведомлением владельцу при 80 % `[ДОПУЩЕНИЕ]`; превышение
   бюджета не отключает обязательную AI-проверку (журнал #8) — ставит задания в очередь
   (`rate-limits.md` п. 11 `[ДОПУЩЕНИЕ]`).
4. **Труд** — один разработчик плюс AI-агенты (`01-product.md` §3); в расходы проекта до штатной
   команды не входит; ревьюер и редакция — этап 4.
5. **Инфраструктура до запуска** — Neon для разработки без ПДн (ADR-0011), бесплатные тарифы где
   возможно; прод в РФ включается до открытой регистрации.
6. **Безубыточность** = постоянные расходы / средняя маржа на автора (`unit-economics.md` п. 9) —
   число авторов, при котором проект окупает инфраструктуру; считается в `metrics.md`.
7. **Ретенция данных как расход**: сырые события вовлечённости живут короткий период, агрегаты
   бессрочно (`engagement-tracking.md` §12); медиа — по квотам планов; резервные копии — по
   политике `08-operations.md` §5.
8. **Сценарий Б**: постоянные расходы те же с первого дня без дохода — аргумент в
   `overview.md`.

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Превышение бюджета AI | задания в очередь, уведомление владельцу | система | лог |
| Внешний сборщик ошибок | по потребности | `owner` | — |

## 4. Взаимодействие с другими политиками

- `unit-economics.md` — переменные; `metrics.md` — безубыточность и порог доли AI.
- `08-operations.md` §10 — бюджет инфраструктуры; главнее он в части хостинга.
- `70-plans-and-billing/payment-provider.md` — комиссия.

## 5. Проверяемость

- Ежемесячная сверка счетов провайдеров с суммами `costMinor` и объёмами хранилища.
- Метрика: постоянные расходы на одного активного автора; доля AI в цене плана.

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Состав статей, порог уведомления 80 %, очередь при превышении бюджета,
  коэффициенты трафика.
- Отложено (§8.19): бухгалтерское сопровождение; (§8.23) провайдер почты и стоимость рассылок.
