# Бизнес-модель: Метрики жизнеспособности

- **Область**: бизнес-модель
- **Статус**: утверждён (гейт Г5b, 2026-09-09)
- **ADR**: ADR-0027, ADR-0042; `docs/vision/07-commerce.md` §6, `docs/issues/00-roadmap.md` §7;
  журнал #26–27, §10, §23.6
- **Этап**: 1

## 1. Назначение

Набор показателей, по которым владелец решает о цене, составе планов и продолжении; пороги —
гипотезы из `07-commerce.md` §6. Показатели считаются SQL из базы и дневных агрегатов
вовлечённости; внешней аналитики нет (ADR-0027). На файл ссылаются `overview.md`, `funnel.md`,
`40-admin/statistics.md` (8a).

## 2. Правила

1. **Метрики и пороги** (`07-commerce.md` §6; значения `[ДОПУЩЕНИЕ]`):

| Метрика | Порог | Окно |
|---|---|---|
| Конверсия «профиль автора заполнен → первая публикация» (первый запуск, §24.1); «→ оплата» — с включением платности | ≥ 5 % | 8 недель |
| Переход `standard → pro` | ≥ 10 % при ≥ 30 активных `standard` | 12 недель |
| Удержание на первом продлении | ≥ 50 % | когорта |
| Доля возвратов | ≤ 5 % платежей | месяц |
| Доля неудачных серий списаний (§8.15) | ≤ 10 % | месяц |
| MRR | растёт месяц к месяцу | квартал |
| Стоимость AI на автора | ≤ 20 % цены плана | месяц |
| Авторов с активным планом и ≥ 1 публикацией | растёт | этап 1 |
| Медиана «отправлено → решение» | по SLA правил публикации | этап 1 |
| Безубыточность: авторов при текущей марже | достигается к сроку владельца | — |

2. **Только валидные данные** (журнал #26–27, §10, §23.6): успешные платежи без исключённых;
   события вовлечённости после автоматических фильтров и исключений; служебные и тестовые
   аккаунты вне расчёта.
3. **Метрики этапов роадмапа** (`00-roadmap.md` §7) — верхний уровень: этап 1 — авторы с
   планом и публикацией, конверсия, медиана решения; этап 2 — доля лент по рейтингу,
   детерминизм пересчёта; этап 3 — поиски и доля нулевых выдач, подписчики авторов,
   AI-переводы.
4. **Аудитория**: уникальные посетители по `visitorId` (`engagement-tracking.md` §19 —
   собственная метрика, не абсолютное число), квалифицированные прочтения, вторая страница за
   визит; публично показываются только счётчики от ста (§21.30–31).
5. **Кто видит**: `analyst`, `admin`, `owner` — раздел «Статистика» (`admin-sections.md` #11);
   `analyst` — полная индивидуальная картина автора с аудитом (журнал #11); экспорт CSV без ПДн.
6. **Периодичность**: дневные агрегаты; недельные когорты; месячный снимок отчёта, не меняющийся
   задним числом (`engagement-tracking.md` §13, §19).
7. **Решения по порогам** — владелец (`07-commerce.md` §3): пересмотр цены, состава плана,
   лимитов AI; спецификации порог не меняют.

## 3. Исключения

| Исключение | Условие | Кто может | Аудит |
|---|---|---|---|
| Исключение платежа из расчёта | ошибочный или тестовый | `analyst`, `admin`, `owner` | `payment.exclude` |
| Исключение событий | автоматически | система | `engagement.exclusion` |

## 4. Взаимодействие с другими политиками

- `funnel.md` — ступени; `unit-economics.md`, `costs.md` — безубыточность.
- `60-ranking/explainability.md` — что из метрик публично.
- `50-access/visibility.md` — аудит чтения ПДн в карточке автора.

## 5. Проверяемость

- Контрольный расчёт метрик на сиде с известными значениями; тест исключений.
- Ежемесячный снимок совпадает с повторным расчётом за тот же месяц.

## 6. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Все пороги — из `07-commerce.md` §6; срок безубыточности — владелец.
- Закрыто Г5b (§24.1): финансовые метрики появляются с включением платности; до этого — метрики ценности.
