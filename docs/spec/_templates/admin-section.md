## 7. Опасные операции и подтверждения

Что считается опасным в этом разделе (необратимое, затрагивает чужие данные, деньги, роли,
опубликованный контент). Тип подтверждения для каждого: модальное окно с вводом названия,
подтверждение письмом, двухшаговое с задержкой. Кто не может выполнить даже с подтверждением.
