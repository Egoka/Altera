  (§21.1–6); накопительный рейтинг автора и постоянный Pro-балл — снимком при публикации
  (§21.15–16, §21.26); штрафов нет (§21.17); свежесть — отдельный компонент, ноль через месяц

  поиск — только релевантность Meilisearch (§21.21); веса фиксированы в движке без интерфейса
  (§21.32); единый движок, пересчёт раз в час, устойчивость к сбоям (§21.35–37, §21.40); учёт
  событий полностью автоматический (§23.6).
- **Отложено** (§21.39, §21.34, §21.25, §22.3, §23.5): полный каталог сущностей и сигналов,

  материалов, пороги добора топа и аномалий — отдельная подробная спецификация движка.

## Гейт Г4

Закрыт **по фундаментальным принципам** 2026-09-09. Детальная математическая модель движка —
отложенная работа: отдельная подробная спецификация «сущность → сигнал → момент учёта → срок
действия → правила агрегации → вклад в рейтинг» (§21.39), проработка кривых свежести по планам
(§21.34) и слоя открытия новых материалов (§21.25). До неё ленты сортируются по дате (§20.4).
