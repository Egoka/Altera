## Гейт Г4

После захода 4 владелец утверждает: состав и принцип каждой секции главной (#8), значения весов
и окон по умолчанию (#1, #3, #5), лимит бустов (#7), список аномалий и порог автоматической
пометки (#10), словарь фраз объяснения (#11). До Г4 ленты сортируются по дате.
