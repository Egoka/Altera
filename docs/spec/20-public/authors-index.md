# Страница: Список авторов

- **Реестр**: `00-registries/pages.md` #5 · `00-registries/routes.md` #6
- **Статус**: на утверждении
- **ADR**: ADR-0002, ADR-0018, ADR-0019, ADR-0037
- **Этап**: 1 (по числу публикаций и дате), 2 (по рейтингу автора)

## 1. Назначение

Каталог авторов с опубликованными материалами, отсортированный по рейтингу автора
(`60-ranking/author-score.md`; на этапе 1 — по числу опубликованных материалов и дате
последней публикации `[ДОПУЩЕНИЕ]`). Главное действие — найти автора и перейти на его страницу.
Сейчас `/authors` — пустая страница [ФАКТ: `docs/vision/00-reality-check.md` §5.3].

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | карточки авторов: аватар, имя, хэндл, бейдж pro, число материалов, первое предложение «о себе», две последние публикации `[ДОПУЩЕНИЕ]` | листать, фильтровать по букве или рубрике, перейти на страницу автора | видеть ПДн; подписаться отсюда (приглашение войти) |
| Читатель (free) | то же плюс состояние подписки (3) | подписаться прямо из карточки (3) | видеть ПДн |
| Автор (standard / pro) | то же; себя — с пометкой «это вы» | всё, что читатель | подписаться на себя |
| Администраторы (по ролям, если отличаются) | то же, что гость; `analyst`/`admin`/`owner` — ссылка «все пользователи» → `/admin/users` (там чтение аудируется) | перейти на страницу автора | подписки и закладки (журнал #58); видеть авторов без публикаций здесь |

Видимость: в списке только аккаунты с ≥ 1 опубликованной версией в любой локали
`[ДОПУЩЕНИЕ]`; архивированные не показываются; служебные учётные записи без публикаций —
не показываются; «Редакция» как автор — отдельной карточкой первой `[ДОПУЩЕНИЕ]`.

## 3. Точки входа и маршруты

- `/authors` и `/en/authors`; query: `?sort=rating|recent|name` (по умолчанию `rating` с
  этапа 2, `recent` на этапе 1), `?section=<слаг>` (авторы, публиковавшиеся в рубрике),
  `?letter=<буква>` `[ДОПУЩЕНИЕ]`, `?page=N`.
- Редиректы: нет; неверные параметры — 404 `[ДОПУЩЕНИЕ]`.
- Приходят: футер, шапка (пункт «Авторы»), секция «Авторы» главной (2), поиск. Уходят: страницы
  авторов, `/pricing` («стать автором»).

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `authors(sort, section, letter, page, locale)` | как в query | `items[] { id, handle, name, avatar, grade, bioShort, publishedCount, lastPublishedAt, recent[] { title, path } }`, `pageInfo`, `caption` | все | общий; инвалидация при публикации, смене профиля, пересчёте рейтинга автора | `VALIDATION_ERROR` |
| `sections` | `locale` | `slug`, `name` (для фильтра) | все | общий | — |
| `followAuthor` / `unfollowAuthor` (3) | `authorId` | `following` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN`, `CONFLICT` |

В публичном типе автора нет e-mail, роли, плана, срока (ADR-0018); грейд — только бейдж;
рейтинг автора числом не отдаётся.

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Заголовок**: «Авторы», счётчик, подпись принципа сортировки словами (`caption`); кнопка
   «Стать автором» → `/pricing` для гостя и читателя.
3. **Панель**: сортировка (рейтинг (2) / недавние / по имени), фильтр по рубрике, алфавитный
   указатель `[ДОПУЩЕНИЕ]`.
4. **Сетка авторов**: `AuthorCard` — аватар, имя, бейдж, хэндл, короткое «о себе», число
   материалов, две последние публикации ссылками, кнопка подписки (3). Пусто — `EmptyState`
   «авторов пока нет — станьте первым» → `/pricing`; пусто по фильтру — «сбросить».
5. **Пагинация** — размер страницы 30 `[ДОПУЩЕНИЕ]`.
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация | скелет сетки | — | 200 |
| Пусто | ни одного автора с публикацией; фильтр без результатов | `EmptyState` с призывом или сбросом | — | 200 |
| Ошибка данных | `authors` не ответил | `ErrorState` с `requestId` | `INTERNAL_ERROR` | 500 |
| Нет доступа | не применимо: список публичен | — | `FORBIDDEN` | 403 — не возникает |
| Не найдено / удалено | неверные параметры query | страница #21 | `NOT_FOUND` | 404 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо к чтению; автор с истёкшим планом остаётся в списке, пока есть публикации | — | — | 200 |
| Заблокирован | архивированный аккаунт видит как гость; сам из списка исчезает | — | — | 200 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не затрагивает список авторов | — | 200 |

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Сортировка этапа 1 — недавние публикации; размер страницы 30; алфавитный
  указатель; две последние публикации в карточке; «Редакция» — первая карточка.
- `[ДОПУЩЕНИЕ]` В списке только авторы с публикациями; фильтр по рубрике и буква — `noindex`.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Показывать ли в каталоге авторов с истёкшим планом наравне с активными
  (у них остаются публикации, но бейдж pro пропадает)? Если да — как описано; если нет — фильтр
  «только активные авторы» и признак `isActiveAuthor` в публичном типе (это раскрывает состояние
  плана, что противоречит ADR-0018).
