# Страница: Список тегов

- **Реестр**: `00-registries/pages.md` #7 · `00-registries/routes.md` #8
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0005, ADR-0019
- **Этап**: 1

## 1. Назначение

Каталог тегов по числу опубликованных материалов: теги — свободные слова авторов, редакция их
сливает и чистит (ADR-0005), поэтому список может быть длинным и требует пагинации и поиска по
началу слова. Тег с одной опубликованной статьёй остаётся видимым (журнал §20.10) — порога по
числу материалов нет. Главное действие — перейти в ленту тега. Сейчас `/tags` — моки [ФАКТ:
`docs/vision/00-reality-check.md` §5.3].

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | теги с ≥ 1 опубликованным материалом, счётчики, облако популярных | листать, фильтровать по букве, искать по началу слова, перейти в тег | видеть архивированные и слитые теги; теги без публикаций |
| Читатель (free) | то же | то же | — |
| Автор (standard / pro) | то же | то же; при создании материала выбирает теги из существующих (журнал #29) | создать тег здесь |
| Администраторы (по ролям, если отличаются) | то же; `admin`/`owner` — ссылка «управлять тегами» → `/admin/tags` (слияние, чистка) | перейти в админку | — |

Видимость: только активные теги с публикациями в локали; слитый тег отсутствует, его адрес — 301.

## 3. Точки входа и маршруты

- `/tags` и `/en/tags`; query: `?q=<префикс>` (поиск по началу, ≥ 2 знаков `[ДОПУЩЕНИЕ]`),
  `?letter=<буква>`, `?sort=popular|name` (по умолчанию `popular`), `?page=N`.
- 404 — лишний сегмент; неверные параметры — 404 `[ДОПУЩЕНИЕ]`.
- Приходят: футер, мега-меню («популярные теги»), подвал материала («все теги»), лента тега.
  Уходят: ленты тегов.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `tags(q, letter, sort, page, locale)` | как в query | `items[] { slug, name, articleCount }`, `pageInfo`, `letters[]` (буквы с тегами) | все | общий по параметрам; инвалидация при публикациях и правке тегов | `VALIDATION_ERROR` |
| `popularTags(locale, limit)` | `limit` 30 `[ДОПУЩЕНИЕ]` | `slug`, `name`, `articleCount` | все | общий | — |

Публичных данных сверх слага, имени и счётчика у тега нет. Счётчик считает опубликованные
версии локали, поэтому один и тот же тег в `ru` и `en` может показывать разные числа; слитые
теги в ответ не входят, их счётчики уже учтены в целевом теге (`admin-sections.md` #3).

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Заголовок** (`PageHeader`): «Теги», число тегов.
3. **Популярное**: облако из `popularTags` — `TagChips` с размером по счётчику в три ступени
   `[ДОПУЩЕНИЕ]`.
4. **Панель**: поле поиска по началу слова (без отправки формы — фильтр по вводу с задержкой
   300 мс `[ДОПУЩЕНИЕ]`), алфавитный указатель `letters[]`, сортировка «популярные / по имени».
5. **Список**: колонки «тег — счётчик», группировка по первой букве при `sort=name`. Пусто —
   `EmptyState` «тегов пока нет»; пусто по запросу — «ничего не найдено».
6. **Пагинация** — 100 тегов на страницу `[ДОПУЩЕНИЕ]`.
7. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация, ввод в поиск | скелет списка; облако остаётся | — | 200 |
| Пусто | нет тегов с публикациями; поиск без результатов | `EmptyState` соответствующего варианта | — | 200 |
| Ошибка данных | `tags` не ответил | `ErrorState` с `requestId` | `INTERNAL_ERROR` | 500 |
| Нет доступа | не применимо: список публичен | — | `FORBIDDEN` | 403 — не возникает |
| Не найдено / удалено | лишний сегмент, неверные параметры | страница #21 | `NOT_FOUND` | 404 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо | — | — | 200 |
| Заблокирован | архивированный аккаунт видит как гость | обычная страница | — | 200 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не затрагивает теги | — | 200 |

## 9. Мобильный и десктоп

- `lg`: облако во всю ширину, список в 3 колонки, указатель букв слева липкий при прокрутке
  `[ДОПУЩЕНИЕ]`.
- `md`: список в 2 колонки; указатель сверху горизонтально.
- `< md`: облако — горизонтальная прокрутка; список в одну колонку; панель — поле поиска
  снаружи, буквы и сортировка в раскрывашке.

## 10. SEO / meta / hreflang

`title` — «Теги — {Издание}»; `description` — шаблон; `canonical` — `/tags` с `page`; `?q=`,
`?letter=` — `noindex, follow` `[ДОПУЩЕНИЕ]`; `hreflang` — пара; JSON-LD `CollectionPage`;
`index`; в `sitemap.xml` только первая страница `[ДОПУЩЕНИЕ]`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Поиск по началу от 2 знаков с задержкой 300 мс; облако из 30 тегов в три
  размера; 100 тегов на страницу; `search.query` для префиксного фильтра не пишется.
- `[ДОПУЩЕНИЕ]` В `sitemap.xml` — только первая страница списка тегов.
- `[ДОПУЩЕНИЕ]` Слитый тег исчезает из каталога сразу после слияния; его адрес отвечает 301
  (`tag-feed.md` §3).
- Закрыто Г3 (журнал §20.10): теги не скрываются по малому числу материалов; порога нет.
