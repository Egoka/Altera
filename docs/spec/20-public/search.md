# Страница: Поиск

- **Реестр**: `00-registries/pages.md` #9 · `00-registries/routes.md` #10
- **Статус**: на утверждении
- **ADR**: ADR-0002, ADR-0018, ADR-0032; ADR-0025 заменён журналом §21.21 (Meilisearch вместо
  PostgreSQL FTS; рейтинг не используется вторым ключом)
- **Этап**: 3

## 1. Назначение

Полнотекстовый поиск на Meilisearch по публичным статьям, публичным профилям авторов, тегам и
рубрикам (журнал §21.21); порядок результатов определяет только релевантность Meilisearch,
внутренний рейтинг статьи вторым ключом не используется. Главное действие — найти материал по
запросу и фильтрам. Индексация, набор полей и правила обновления индексов — отдельная
спецификация поиска (§21.21); здесь — страница и контракт запроса.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | строку поиска, результаты со сниппетами, фильтры (рубрика, формат, тег, автор, период), подсказки | искать, фильтровать, листать, открыть результат | видеть неопубликованное; видеть числа рейтинга |
| Читатель (free) | то же плюс закладки на карточках результатов | закладка | — |
| Автор (standard / pro) | то же | то же | искать свои черновики здесь — только в кабинете |
| Администраторы (по ролям, если отличаются) | то же, что гость | открыть результат | поиск по неопубликованному — только в админке (`/admin/articles`) |

Видимость: индекс содержит только опубликованные версии локали, публичные профили авторов с
публикациями, непустые рубрики и теги с материалами (`50-access/visibility.md` п. 1, §20.9–10);
снятые и архивированные материалы удаляются из индекса при событии.

## 3. Точки входа и маршруты

- `/search?q=` и `/en/search?q=`; query: `q` (≥ 2 знаков `[ДОПУЩЕНИЕ]`), `section`, `format`,
  `tag`, `author` (хэндл), `from`, `to` (даты), `page`.
- Без `q` — пустое состояние с популярными тегами и подсказкой; неверные параметры — игнорируются
  `[ДОПУЩЕНИЕ]`.
- Приходят: `SearchBox` в шапке любой страницы, страница 404 (`not-found.md` §5), список тегов.
  Уходят: материал, автор, рубрика, тег.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `search(q, locale, filters, page)` | как в query | `hits[] { kind: article \| author \| tag \| section, snippet, карточка }`, `total`, `pageInfo`, `facets { sections, formats, tags }` `[ДОПУЩЕНИЕ: фасеты]` | все | короткий `[ДОПУЩЕНИЕ: 60 с]` по запросу | `VALIDATION_ERROR`, `RATE_LIMITED`, `PROVIDER_UNAVAILABLE` (Meilisearch недоступен) |
| `searchSuggest(q, locale)` | префикс | до 8 подсказок: заголовки, авторы, теги `[ДОПУЩЕНИЕ]` | все | короткий | `RATE_LIMITED` |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN` |

Ответ не зависит от сессии (ADR-0019); индекс не содержит e-mail, планов, черновиков и баллов
рейтинга (§21.18).

## 5. Структура экрана по зонам

1. **Шапка сайта** с той же строкой поиска (сфокусирована, заполнена запросом).
2. **Строка и подсказки** (`SearchBox`): ввод, подсказки при вводе, кнопка очистки.
3. **Фильтры** (десктоп — слева; мобильный — раскрывашка «Фильтры»): рубрика, формат, тег,
   автор, период; счётчики фасетов `[ДОПУЩЕНИЕ]`; «сбросить».
4. **Результаты** (`SearchResults`): группировка по типу — сначала материалы, затем авторы, теги,
   рубрики `[ДОПУЩЕНИЕ: порядок групп]`; карточка материала со сниппетом и подсветкой; подпись
   «по релевантности»; число результатов.
5. **Пагинация** — по страницам; размер — конфигурация `[ДОПУЩЕНИЕ: 20]`.
6. **Пусто / ноль результатов**: «ничего не найдено» с подсказкой (проверить опечатку — Meilisearch
   терпим к опечаткам, снять фильтры), популярные теги.
7. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | запрос к Meilisearch | скелет результатов; фильтры активны | — | 200 |
| Пусто | нет `q` — стартовое состояние; ноль результатов | зона 6 | — | 200 |
| Ошибка данных | Meilisearch недоступен | «поиск временно недоступен» с `requestId`; ссылки на рубрики и теги | `PROVIDER_UNAVAILABLE` | 200 `[ДОПУЩЕНИЕ: страница остаётся доступной]` |
| Нет доступа | не применимо: поиск публичен | — | `FORBIDDEN` | — |
| Не найдено / удалено | не применимо: адрес фиксирован; результат, снятый между индексациями, — 410 на переходе | — | `NOT_FOUND` | — |
| Ограничение плана (истёкшая подписка, лимит) | лимит запросов на IP (`rate-limits.md` п. 7) | сообщение с таймером | `RATE_LIMITED` | 200 |
| Заблокирован | архивированный аккаунт ищет как гость | обычная страница | — | 200 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | при включении результаты платных материалов получат метку | — | 200 |

## 9. Мобильный и десктоп

- `lg`: фильтры слева `w-64`, результаты справа; подсказки под строкой.
- `md`: фильтры сверху горизонтально в раскрывашке.
- `< md`: строка во всю ширину с автофокусом; «Фильтры» — кнопка; результаты одной колонкой;
  подсказки — полноэкранный список `[ДОПУЩЕНИЕ]`.

## 10. SEO / meta / hreflang

`noindex` для `/search` с параметрами (`06-design-system.md` §10); `canonical` — `/search` без
параметров; `hreflang` — пара для пустой страницы `[ДОПУЩЕНИЕ]`; JSON-LD `WebSite` с
`SearchAction` живёт на главной (`home.md` §10); не в `sitemap.xml`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Минимум 2 знака; фасеты; порядок групп результатов; 20 на страницу; кеш 60 с;
  подсказки не считаются запросом; при недоступности Meilisearch страница отвечает 200.
- Отложено (§21.21): индексация, поля, правила обновления индексов — отдельная спецификация.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Показывать ли в результатах авторов, теги и рубрики вместе с материалами
  или только материалы, а остальное — в подсказках? Если вместе — группы в зоне 4; если только
  материалы — авторы, теги и рубрики остаются в подсказках.
