# Страница: Страница автора

- **Реестр**: `00-registries/pages.md` #4 · `00-registries/routes.md` #7
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0018, ADR-0019, ADR-0034, ADR-0037
- **Этап**: 1 (профиль и материалы по новизне), 2 (по рейтингу после Г4), 3 (подписка на автора);
  журнал Г3 §20.7–8

## 1. Назначение

Публичный профиль автора (ADR-0018: имя, хэндл, «о себе», аватар, соцсети, грейд; число
подписчиков в сокращённом формате — журнал §20.7) и лента его опубликованных версий локали:
до Г4 по новизне, затем по `60-ranking/feed-principles.md` и `author-score.md`. Окончание
плана на рейтинг автора и статей не влияет (журнал §20.8). Главное действие — открыть материал
автора; с этапа 3 — подписаться на автора. Страница существует у каждого аккаунта, у которого есть хотя бы одна опубликованная
версия `[ДОПУЩЕНИЕ]`; редакционные статьи журнала показываются на странице «Редакция» с хэндлом
издания `[ДОПУЩЕНИЕ]`.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | профиль без ПДн; бейдж pro; число подписчиков в сокращённом виде (`1K`, `1.2K` — журнал §20.7); материалы; словесное объяснение позиции (2) | открыть материал; перейти по соцссылкам | подписаться (приглашение войти); видеть e-mail, план, точное число подписчиков |
| Читатель (free) | то же плюс состояние подписки и закладок | подписаться / отписаться (#15, этап 3); закладки | видеть ПДн |
| Автор (standard / pro) | то же; на своей странице — ссылка «редактировать профиль» → `/me/settings` и «мои материалы» → `/me/articles` | всё, что читатель; подписаться на другого автора | подписаться на себя; видеть свои неопубликованные материалы здесь |
| Администраторы (по ролям, если отличаются) | то же, что гость; `analyst`, `admin`, `owner` — ссылка «карточка в админке» → `/admin/users/{id}` (чтение там аудируется, журнал #6) | открыть материал | подписка и закладки (журнал #58) |

Видимость: только `published` версии автора в локали; архивированный аккаунт — страница 410
(журнал #4: статьи архивированы каскадно) `[ДОПУЩЕНИЕ: 410, а не 404 — адрес был публичным]`.

## 3. Точки входа и маршруты

- `/authors/{handle}` и `/en/authors/{handle}`; `handle` — латиница, цифры, дефис, 3–30 знаков
  `[ДОПУЩЕНИЕ]`, регистр не учитывается (301 на канонический); query `?page=N`; `?sort=` — после
  Г4 (журнал §20.4).
- 301 по истории хэндлов (`routes.md` #7); неизвестный хэндл — 404; архивированный аккаунт — 410;
  аккаунт без опубликованных материалов — 404 `[ДОПУЩЕНИЕ]`.
- Приходят: `Byline` материала, блок «Об авторе», список авторов, секция «Авторы» главной (2),
  поиск, соцсети автора. Уходят: материалы, рубрики, соцсети, `/login` при подписке гостем.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `author(handle)` | `handle` | `id`, `handle`, `name`, `bio`, `avatar`, `links[] { kind, url }`, `grade` (`basic` / `pro`), `publishedCount`, `followerCountShort` (строка `1K` / `1.2K`, журнал §20.7; ниже 1000 — точное число `[ДОПУЩЕНИЕ]`), `firstPublishedAt`, `handleHistory` (301), `isArchived` (410) | все | общий; инвалидация при смене профиля, плана, публикации, подписке (с задержкой до минуты `[ДОПУЩЕНИЕ]`) | `NOT_FOUND` |
| `feed(scope: author, handle, locale, page)` | как в query | `items[]`, `pageInfo`, `caption` («по дате публикации») | все | общий; инвалидация при публикации/снятии автора | `NOT_FOUND`, `VALIDATION_ERROR` |
| `followAuthor` / `unfollowAuthor` (3) | `authorId` | `following` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN`, `CONFLICT` (сам на себя) |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN` |

Никогда в публичных типах: e-mail, роль, план, срок, сессии (`50-access/visibility.md` п. 4);
контрактный тест SDL. Рейтинг автора числом не показывается; число подписчиков — только в
сокращённом виде (журнал §20.7); грейд виден бейджем.

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Шапка автора** (`AuthorHeader`, полный): аватар, имя, `ProBadge`, хэндл, «о себе» (пусто —
   только имя), ссылки на соцсети иконками, «публикуется с {месяц год}», число материалов,
   «{1.2K} подписчиков» (с этапа 3, журнал §20.7), кнопка подписки (3) для `reader`/`author`;
   владельцу — «редактировать профиль».
3. **Панель ленты** (`FeedControls`, вариант «автор»): подпись «по дате публикации» (до Г4 без
   переключателя — журнал §20.4).
4. **Список материалов**: карточки `large` для первых двух `[ДОПУЩЕНИЕ]`, далее `small` с
   кикером рубрики; `RankExplainer` (2). Пусто — не возникает для существующей страницы
   (условие существования — §1); пусто в локали — `EmptyState` «на этом языке материалов нет»
   и переключатель языка.
5. **Пагинация**.
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация | скелет шапки автора и карточек | — | 200 |
| Пусто | в текущей локали материалов нет, в другой есть | шапка автора, `EmptyState` с переключателем языка | — | 200 |
| Ошибка данных | `author` или `feed` не ответил | `ErrorState` с `requestId` | `INTERNAL_ERROR` | 500 |
| Нет доступа | не применимо: профиль публичен | — | `FORBIDDEN` | 403 — не возникает |
| Не найдено / удалено | неизвестный хэндл, аккаунт без публикаций → 404; архивированный аккаунт → 410 | страницы #21 / #22 (текст «страница автора недоступна») | `NOT_FOUND` | 404 / 410 |
| Ограничение плана (истёкшая подписка, лимит) | автор с истёкшим планом: страница и материалы остаются (журнал #5); бейдж pro исчезает с окончанием `pro` (ADR-0037); на порядок материалов и рейтинг автора окончание плана не влияет (журнал §20.8) | обычная страница | — | 200 |
| Заблокирован | архивированный аккаунт видит чужие страницы как гость; его собственная — 410 | — | — | 200 / 410 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | при включении карточки платных материалов получат метку | — | 200 |

## 9. Мобильный и десктоп

- `lg`: шапка автора в две колонки (аватар и текст слева, кнопка и ссылки справа); список —
  3 колонки `small`, `large` во всю ширину.
- `md`: шапка в одну колонку; 2 колонки карточек.
- `< md`: аватар над именем по центру; кнопка подписки во всю ширину; одна колонка карточек.

## 10. SEO / meta / hreflang

`title` — «{Имя} — автор {Издания}»; `description` — «о себе» или шаблон; `canonical` —
`/authors/{handle}` с `page`; `hreflang` — пара `ru`/`en` всегда (профиль общий,
ленты по локали); Open Graph — аватар или дефолт, `og:type = profile`; JSON-LD `Person`
(`name`, `url`, `sameAs` из соцссылок, `image`) и `BreadcrumbList`; `index`; в `sitemap.xml`
только авторы с публикациями; RSS автора — по дате (3, `feeds-and-sitemap.md`) `[ДОПУЩЕНИЕ]`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Страница есть только у аккаунтов с публикациями; архивированный — 410; хэндл
  3–30 знаков латиницей; рейтинг автора числом не показывается; сокращение подписчиков — от
  1000, обновление с задержкой до минуты.
- `[ДОПУЩЕНИЕ]` Редакционные статьи журнала собираются на странице «Редакция» с хэндлом издания.
- `[ДОПУЩЕНИЕ]` Первые две карточки `large`; RSS автора выпускается на этапе 3.
- Закрыто Г3 (журнал §20.7): число подписчиков публично в сокращённом формате; (§20.8)
  окончание плана не влияет на рейтинг.
