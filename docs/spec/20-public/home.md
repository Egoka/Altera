# Страница: Главная

- **Реестр**: `00-registries/pages.md` #1 · `00-registries/routes.md` #1
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0019, ADR-0034, ADR-0036, ADR-0038, ADR-0040 (в части, не
  противоречащей журналу: AI не участвует в рейтинге — журнал #41)
- **Этап**: 1 (подборки по дате и просмотрам), 2 (главный топ по рейтингу)

## 1. Назначение

Главная — три независимые подборки материалов из всех рубрик (журнал §20.1–2): **главный топ**
из пяти наиболее сильных и свежих материалов, **«Новое»** и **«Популярное» за прошедшую
неделю**. Одинаковых блоков по рубрикам нет: такая группировка создаёт дубли и мешает
ранжировать материалы между пересекающимися темами (журнал §20.1). Правила отбора для главного
топа и различия между подборками — `60-ranking/home-sections.md` (Г4); дополнительные
тематические блоки могут появиться позже, но не входят в стартовую главную (журнал §20.3).
Главное действие — открыть материал. Персонализации нет: список одинаков для всех. До запуска
движка главный топ и «Новое» — по новизне, «Популярное» — по допустимым сигналам вовлечённости
за неделю (`60-ranking/views-counting.md`); статья не повторяется между блоками (§22.4).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | все секции с опубликованными версиями своей локали; бейдж pro-автора | открыть материал, рубрику, автора; переключить язык; перейти к входу и на `/pricing` | ставить закладки (приглашение войти); видеть числа рейтинга (матрица #7) |
| Читатель (free) | то же плюс активные кнопки закладок на карточках | закладка прямо с карточки (#13) | видеть числа рейтинга |
| Автор (standard / pro) | то же; свои материалы в секциях — как у всех, без пометки | всё, что читатель; кнопка «Писать» ведёт в кабинет | видеть чужие числа рейтинга; влиять на порядок |
| Администраторы (по ролям, если отличаются) | то же, что гость; закладок нет (журнал #58); кнопка «Писать» у `editor`/`owner` ведёт в кабинет | открыть материал; для `moderator`, `admin`, `owner` — ссылка «в админку» в шапке | видеть неопубликованное на главной — секции строятся только из опубликованного |

Условие видимости: только версии в статусе `published` в локали запроса (`50-access/visibility.md`
п. 1); языки не смешиваются (журнал §20.5); кеш общий для всех (ADR-0019).

## 3. Точки входа и маршруты

- `/` — русская главная; `/en` — английская (ADR-0002); других параметров нет; любой
  query-параметр игнорируется и не влияет на кеш `[ДОПУЩЕНИЕ]`.
- Редиректы: `/index`, `/home` → 301 на `/` `[ДОПУЩЕНИЕ]`; `/ru` → 301 на `/`.
- Приходят: прямой заход, логотип в шапке с любой страницы, поисковые системы, соцсети, письмо
  подтверждения входа (после `/auth/verify` без `next`).
- Уходят: страница материала (#3), лента рубрики (#2), страница автора (#4), списки (#5–8),
  `/pricing` (#10), `/login` (#11).

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `feed(scope: home, locale)` | `locale` | три подборки `top`, `new`, `popular`: `key`, `caption` (словесный принцип), `items[]` карточки: `slug`, `sectionSlug`, `title`, `dek`, `cover`, `author { name, handle, grade }`, `publishedAt`, `isTranslation` | все | общий, инвалидация при публикации, снятии, суточном закрытии просмотров, пересчёте рейтинга (`60-ranking/recompute.md`) | `INTERNAL_ERROR` |
| `sections` | `locale` | `slug`, `name`, `articleCount` — только непустые рубрики для шапки (журнал §20.9) | все | общий | — |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` (журнал #58) | не кешируется | `UNAUTHENTICATED`, `FORBIDDEN` (служебная роль), `NOT_FOUND` |
| `me` (для шапки) | — | `role`, `planTier`, `bookmarkedIds` (для карточек) | аккаунт | не кешируется | — |

Гость и читатель не получают ничего, чего нет в публичных типах: ни e-mail автора, ни чисел
рейтинга, ни объяснения позиции (журнал §21.18; `60-ranking/explainability.md`). Данные шапки (`me`)
запрашиваются отдельно от кешируемой ленты, чтобы ответ ленты был одинаков для всех
(ADR-0019).

## 5. Структура экрана по зонам

1. **Шапка** (`AppHeader`): логотип, непустые рубрики из `sections` (журнал §20.9), поиск (3),
   «Войти» или аккаунт, «Писать», переключатель языка. Нет рубрик — только логотип и вход.
2. **Главный топ**: ровно пять материалов (журнал §20.2) — первая карточка `lede`, четыре
   `large`; по итоговому рейтингу среди опубликованных за последние 24 часа, при нехватке — добор более
   старых по рейтингу (журнал §22.1–2; `home-sections.md`); до запуска движка — пять последних по
   дате с подписью «по дате публикации». Меньше пяти материалов — показываются
   те, что есть; пусто — зона скрыта.
3. **Новое**: опубликованное за окно новизны (`home-sections.md`) по дате публикации,
   карточки `small`, до 12 `[ДОПУЩЕНИЕ]`; статья не повторяется между блоками главной — занятые топом исключаются (журнал §22.4).
   Пусто — скрыт.
4. **Популярное за неделю**: по допустимым сигналам вовлечённости за 7 дней
   (`60-ranking/views-counting.md`, `home-sections.md`), карточки `rank` с номерами 1–10 `[ДОПУЩЕНИЕ]`, подпись «по
   числу прочтений за неделю»; до этапа 2 (просмотры) — зона скрыта.
5. **Приглашение** (когда материалов нет вообще): «Здесь пока пусто — станьте первым автором» со
   ссылкой на `/pricing` (`06-design-system.md` §6).
6. **Футер** (`AppFooter`): о проекте, правила, оферта, политика ПД, возвраты, реквизиты,
   контакты, RSS (3).

Порядок подборок фиксирован: топ → новое → популярное; секций по рубрикам и блока авторов нет
(журнал §20.1, §20.3). Страница рендерит подборки в порядке ответа `feed`.

## 9. Мобильный и десктоп

- `lg ≥ 1024`: контейнер `max-w-7xl`; главный топ — `lede` на две трети ширины и четыре `large`
  в две колонки под ним; «Новое» — сетка 3 колонки; «Популярное» — правая колонка рядом с
  «Новым» `[ДОПУЩЕНИЕ]`.
- `md 768–1023`: топ — `lede` во всю ширину, `large` в 2 колонки; «Новое» — 2 колонки;
  «Популярное» под «Новым» горизонтальной лентой номеров.
- `< 768`: одна колонка, порядок 1 → 2 → 3 → 4 → 6; карточки `large` становятся `small` с
  изображением справа; шапка сворачивается в меню; липких элементов нет, кроме шапки на
  прокрутке вверх `[ДОПУЩЕНИЕ]`.
- Изображения: `srcset` по вариантам 480/960/1440 (`06-design-system.md` §3 «Медиа»), LQIP.

## 10. SEO / meta / hreflang

`title` — название издания и слоган из словаря локали; `description` — краткое описание
проекта; `canonical` — `/` или `/en`; `hreflang` — пара `ru`/`en` плюс `x-default` на `/`;
Open Graph — дефолтное изображение издания; JSON-LD `WebSite` с `SearchAction` (3) и
`Organization`; `index`; в `sitemap.xml` с приоритетом 1.0 `[ДОПУЩЕНИЕ]`; RSS главной = лента
локали по дате (`feeds-and-sitemap.md`, 3). Сейчас `useSeoMeta` не используется нигде
[ФАКТ: `docs/vision/00-reality-check.md` §5.4].

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` «Новое» — до 12 карточек без повторов из топа; «Популярное» — 10; раскладка
  «Популярного» правой колонкой — до дизайна и Г4.
- `[ДОПУЩЕНИЕ]` Редиректы `/index`, `/home`, `/ru` на `/`; query-параметры игнорируются.
- `[ДОПУЩЕНИЕ]` Шапка липкая только при прокрутке вверх на мобильном.
- Закрыто Г3 (журнал §20.1–3): секций по рубрикам нет; главная — главный топ из пяти, «Новое»,
  «Популярное» за неделю.
- Закрыто Г4 (§22.1–4): топ по рейтингу за 24 часа с добором более старых; без повторов между
  блоками; пороги добора — отложено.
