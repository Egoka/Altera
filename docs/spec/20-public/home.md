# Страница: Главная

- **Реестр**: `00-registries/pages.md` #1 · `00-registries/routes.md` #1
- **Статус**: на утверждении
- **ADR**: ADR-0002, ADR-0004, ADR-0019, ADR-0034, ADR-0036, ADR-0038, ADR-0040 (в части, не
  противоречащей журналу: AI не участвует в рейтинге — журнал #41)
- **Этап**: 1 (секции по дате), 2 (секции по рейтингу)

## 1. Назначение

Главная показывает лучшее из опубликованного по общему рейтингу статьи (ADR-0034) секциями с
разными выборками: главное по всем рубрикам, топ каждой рубрики, новое за период, авторы —
принцип и состав секций задаёт `60-ranking/home-sections.md` (Г4). Главное действие —
открыть материал. Персонализации нет: список одинаков для всех (журнал: одна лента). На этапе 1,
до рейтинга, все секции сортируются по дате публикации с подписью «по дате публикации»
(`docs/vision/06-design-system.md` §7).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | все секции с опубликованными версиями своей локали; бейдж pro-автора; словесное объяснение позиции (2) | открыть материал, рубрику, автора; переключить язык; перейти к входу и на `/pricing` | ставить закладки (приглашение войти); видеть числа рейтинга (матрица #7) |
| Читатель (free) | то же плюс активные кнопки закладок на карточках | закладка прямо с карточки (#13) | видеть числа рейтинга |
| Автор (standard / pro) | то же; свои материалы в секциях — как у всех, без пометки | всё, что читатель; кнопка «Писать» ведёт в кабинет | видеть чужие числа рейтинга; влиять на порядок |
| Администраторы (по ролям, если отличаются) | то же, что гость; закладок нет (журнал #58); кнопка «Писать» у `editor`/`owner` ведёт в кабинет | открыть материал; для `moderator`, `admin`, `owner` — ссылка «в админку» в шапке | видеть неопубликованное на главной — секции строятся только из опубликованного |

Условие видимости: только версии в статусе `published` в локали запроса (`50-access/visibility.md`
п. 1); кеш общий для всех (ADR-0019).

## 3. Точки входа и маршруты

- `/` — русская главная; `/en` — английская (ADR-0002); других параметров нет; любой
  query-параметр игнорируется и не влияет на кеш `[ДОПУЩЕНИЕ]`.
- Редиректы: `/index`, `/home` → 301 на `/` `[ДОПУЩЕНИЕ]`; `/ru` → 301 на `/`.
- Приходят: прямой заход, логотип в шапке с любой страницы, поисковые системы, соцсети, письмо
  подтверждения входа (после `/auth/verify` без `next`).
- Уходят: страница материала (#3), лента рубрики (#2), страница автора (#4), списки (#5–8),
  `/pricing` (#10), `/login` (#11).

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `feed(scope: home, locale)` | `locale`, состав секций из `RankingConfig` | по секции: `key`, `caption` (словесный принцип), `items[]` карточки: `slug`, `sectionSlug`, `title`, `dek`, `cover`, `author { name, handle, grade }`, `publishedAt`, `isTranslation`, `rankPhrase` (2) | все | общий, инвалидация при публикации, снятии, пересчёте рейтинга (`60-ranking/recompute.md`) | `INTERNAL_ERROR` |
| `sections` | `locale` | `slug`, `name`, `articleCount` | все | общий | — |
| `topAuthors` (2) | `locale`, `limit` | `handle`, `name`, `avatar`, `grade` | все | общий | — |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` (журнал #58) | не кешируется | `UNAUTHENTICATED`, `FORBIDDEN` (служебная роль), `NOT_FOUND` |
| `me` (для шапки) | — | `role`, `planTier`, `bookmarkedIds` (для карточек) | аккаунт | не кешируется | — |

Гость и читатель не получают ничего, чего нет в публичных типах: ни e-mail автора, ни чисел
рейтинга — `rankPhrase` уже словесен (`60-ranking/explainability.md`). Данные шапки (`me`)
запрашиваются отдельно от кешируемой ленты, чтобы ответ ленты был одинаков для всех
(ADR-0019).

## 5. Структура экрана по зонам

1. **Шапка** (`AppHeader`): логотип, рубрики из `sections`, поиск (3), «Войти» или аккаунт,
   «Писать», переключатель языка. Нет рубрик — только логотип и вход.
2. **Главное**: секция-герой из `feed.sections[main]` — первая карточка `lede`, далее до пяти
   `large` `[ДОПУЩЕНИЕ: 1 + 5]`; принцип — `home-sections.md`; подпись словами («лучшее по
   рейтингу за всё время» или «по дате публикации» на этапе 1). Пусто — зона скрыта.
3. **Топ-лист** (правая колонка на десктопе): карточки `rank` с номерами 1–10 `[ДОПУЩЕНИЕ]` по
   общему рейтингу; на этапе 1 — последние по дате с подписью. Пусто — скрыт.
4. **Секции рубрик**: по одной `FeedSection` на рубрику с материалами, до четырёх карточек
   `small` `[ДОПУЩЕНИЕ]`, ссылка «все» в ленту рубрики; рубрики без опубликованных материалов
   не показываются.
5. **Новое**: опубликованное за окно новизны (`home-sections.md`) по рейтингу; на этапе 1 — по
   дате. Пусто — скрыт.
6. **Авторы** (2): `topAuthors` по рейтингу автора (`60-ranking/author-score.md`) — аватар, имя,
   бейдж pro. До этапа 2 — не рендерится.
7. **Приглашение** (когда материалов нет вообще): «Здесь пока пусто — станьте первым автором» со
   ссылкой на `/pricing` (`06-design-system.md` §6).
8. **Футер** (`AppFooter`): о проекте, правила, оферта, политика ПД, возвраты, реквизиты,
   контакты, RSS (3).

Порядок секций и их принципы фиксирует `home-sections.md`; страница не сортирует сама — она
рендерит секции в порядке ответа `feed`.

## 9. Мобильный и десктоп

- `lg ≥ 1024`: контейнер `max-w-7xl`; зона 2 на две трети ширины, зона 3 — правая колонка;
  секции рубрик — сетка 3 колонки.
- `md 768–1023`: зона 3 под зоной 2 горизонтальной лентой номеров; секции — 2 колонки.
- `< 768`: одна колонка, порядок 1 → 2 → 3 → 4 → 5 → 6 → 8; карточки `large` становятся `small`
  с изображением справа; шапка сворачивается в меню; липких элементов нет, кроме шапки на
  прокрутке вверх `[ДОПУЩЕНИЕ]`.
- Изображения: `srcset` по вариантам 480/960/1440 (`06-design-system.md` §3 «Медиа»), LQIP.

## 10. SEO / meta / hreflang

`title` — название издания и слоган из словаря локали; `description` — краткое описание
проекта; `canonical` — `/` или `/en`; `hreflang` — пара `ru`/`en` плюс `x-default` на `/`;
Open Graph — дефолтное изображение издания; JSON-LD `WebSite` с `SearchAction` (3) и
`Organization`; `index`; в `sitemap.xml` с приоритетом 1.0 `[ДОПУЩЕНИЕ]`; RSS главной = лента
локали по дате (`feeds-and-sitemap.md`, 3). Сейчас `useSeoMeta` не используется нигде
[ФАКТ: `docs/vision/00-reality-check.md` §5.4].

материала (ADR-0027). Трекеров нет.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Размеры секций: герой 1 + 5, топ-лист 10, по 4 карточки на рубрику — до Г4.
- `[ДОПУЩЕНИЕ]` Редиректы `/index`, `/home`, `/ru` на `/`; query-параметры игнорируются.
- `[ДОПУЩЕНИЕ]` Шапка липкая только при прокрутке вверх на мобильном.
- `[ДОПУЩЕНИЕ]` Секция «Авторы» появляется с рейтингом автора (этап 2), до него не рендерится.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Показывать ли на главной секцию каждой рубрики или только рубрики с
  числом материалов выше порога? Если каждой — при десяти рубриках главная станет длинной; если
  по порогу — порог фиксируется в `home-sections.md` (Г4).
