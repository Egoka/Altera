# Страница: Лента рубрики

- **Реестр**: `00-registries/pages.md` #2 · `00-registries/routes.md` #2
- **Статус**: на утверждении
- **ADR**: ADR-0002, ADR-0004, ADR-0005, ADR-0019, ADR-0034, ADR-0036
- **Этап**: 1 (по дате), 2 (по рейтингу и переключатель)

## 1. Назначение

Лента рубрики — список опубликованных версий локали внутри одной рубрики по убыванию рейтинга
статьи с учётом соответствия теме (`60-ranking/feed-principles.md`, `topic-relevance.md`);
переключатель «по рейтингу / по дате» и фильтры по формату и тегу. Главное действие — открыть
материал. Рубрика — адресообразующая сущность (ADR-0005): её слаг — первый сегмент пути.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | шапку рубрики, список карточек, фильтры, пагинацию, словесное объяснение позиции (2) | открыть материал, переключить сортировку, фильтровать, листать | ставить закладки; видеть числа рейтинга |
| Читатель (free) | то же с активными закладками | закладка с карточки | видеть числа рейтинга |
| Автор (standard / pro) | то же | всё, что читатель | видеть свои неопубликованные материалы в ленте — только через кабинет |
| Администраторы (по ролям, если отличаются) | то же, что гость; закладок нет (журнал #58); `admin`/`owner` видят ссылку «редактировать рубрику» → `/admin/sections` `[ДОПУЩЕНИЕ]` | открыть материал | видеть архивированные материалы рубрики — только в админке |

Видимость: только `published` версии локали (`50-access/visibility.md` п. 1); архивированная
рубрика для всех — 404 (`admin-sections.md` #2: архив рубрики только без активных материалов).

## 3. Точки входа и маршруты

- `/{рубрика}` и `/en/{section}` — слаги рубрики по локали (ADR-0004); query: `?sort=rating|date`
  (по умолчанию `rating` с этапа 2, `date` на этапе 1), `?format=<слаг>`, `?tag=<слаг>`,
  `?page=N` (N ≥ 1, целое; иначе 404 `[ДОПУЩЕНИЕ]`).
- 301 по истории слагов рубрики (ADR-0004); неизвестный слаг — 404 (страница #21); слаг
  совпадает с зарезервированными путями (`authors`, `tags`, `sections`, `search`, `pricing`,
  `login`, `me`, `admin`, `legal`, `about`, `contact`, `auth`) — рубрика с таким слагом не
  создаётся (`admin-sections.md` #2).
- Приходят: шапка (`SectionNav`), главная («все» в секции рубрики), страница материала
  (кикер рубрики), список рубрик, поиск, поисковые системы. Уходят: материал, автор, тег,
  другая рубрика.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `section(slug, locale)` | `slug`, `locale` | `slug`, `name`, `description`, `cover`, `articleCount`, `formats[]`, `topTags[]`, `slugHistory` (для 301) | все | общий | `NOT_FOUND` |
| `feed(scope: section, slug, locale, sort, format, tag, page)` | как в query | `items[]` карточек (как `home.md` §4), `pageInfo { page, totalPages, hasNext }`, `caption` | все | общий по набору параметров; инвалидация при публикации/снятии в рубрике и пересчёте | `NOT_FOUND`, `VALIDATION_ERROR` (`sort`, `page`) |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN`, `NOT_FOUND` |

Ответ ленты не зависит от сессии (ADR-0019); отметки «в закладках» подмешивает клиент из `me`.

## 5. Структура экрана по зонам

1. **Шапка сайта** (`AppHeader`) с активной рубрикой в `SectionNav`.
2. **Шапка рубрики** (`SectionHeader`): название, описание (пусто — только название), число
   материалов, обложка при наличии.
3. **Панель ленты**: переключатель «по рейтингу / по дате» (этап 2; на этапе 1 — только подпись
   «по дате публикации»), фильтр формата (`formats[]` рубрики), фильтр тега (`topTags[]` +
   ввод слага `[ДОПУЩЕНИЕ]`), кнопка «сбросить». Подпись `caption` словами, что лежит в основе
   порядка (`feed-principles.md`).
4. **Список**: карточки `large` первые три `[ДОПУЩЕНИЕ]`, далее `small`; сетка по breakpoints;
   `RankExplainer` под карточкой (2). Пусто — `EmptyState` «в рубрике пока нет материалов» и
   ссылка на соседние рубрики; пусто по фильтру — «ничего не найдено, сбросить фильтры».
5. **Пагинация** (`Pagination`): по страницам, без бесконечной прокрутки; размер страницы —
   параметр `feed-principles.md` `[ДОПУЩЕНИЕ: 24]`; порядок стабилен между страницами
   (курсор по снимку рейтинга).
6. **Другие рубрики**: горизонтальный ряд остальных рубрик со счётчиками.
7. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация между страницами и фильтрами | скелеты карточек, панель активна | — | 200 |
| Пусто | рубрика без опубликованных материалов; фильтр без результатов | `EmptyState` соответствующего варианта, зона 6 | — | 200 |
| Ошибка данных | `feed` не ответил | `ErrorState` с `requestId`; шапка рубрики, если получена | `INTERNAL_ERROR` | 500 |
| Нет доступа | не применимо: лента публична | — | `FORBIDDEN` | 403 — не возникает |
| Не найдено / удалено | неизвестный слаг; архивированная рубрика | страница #21 | `NOT_FOUND` | 404 (410 не используется: рубрика архивируется только пустой) |
| Ограничение плана (истёкшая подписка, лимит) | не применимо к чтению | — | `PLAN_LIMIT` | — |
| Заблокирован | архивированный аккаунт видит ленту как гость | обычная лента | — | 200 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | при включении карточки получат метку доступа | — | 200 |

Некорректные `sort`, `page` — `VALIDATION_ERROR` от API превращается в 404 страницы `[ДОПУЩЕНИЕ]`.

## 9. Мобильный и десктоп

- `lg`: список в 3 колонки для `small`, `large` — во всю ширину контейнера; панель фильтров в
  одну строку.
- `md`: 2 колонки; фильтры переносятся на вторую строку.
- `< md`: одна колонка; панель сворачивается в кнопку «Фильтры» с раскрывашкой; переключатель
  сортировки остаётся снаружи; зона 6 — горизонтальная прокрутка.

## 10. SEO / meta / hreflang

`title` — «{Рубрика} — {Издание}»; `description` — описание рубрики или первое предложение
шаблона; `canonical` — адрес без `sort`, `format`, `tag`, с `page` при `page > 1`; `hreflang`
на сестринский слаг рубрики; отфильтрованные и отсортированные варианты — `noindex, follow`
`[ДОПУЩЕНИЕ]`; Open Graph — обложка рубрики или дефолт; JSON-LD `CollectionPage` +
`BreadcrumbList`; в `sitemap.xml`; RSS рубрики по дате (3, `feeds-and-sitemap.md`).

## 11. Аналитические события

| Событие (код из `00-registries/events-and-logs.md`) | Триггер | Поля (без ПДн) | Участвует в рейтинге |
|---|---|---|---|
| `http.request` (#41) | запрос страницы, включая фильтры и пагинацию | `route`, `status`, `durationMs` | нет |
| `bookmark.add` / `bookmark.remove` (#56) | закладка | `articleId` | нет |
| `page.error` (#64) | ошибка рендера | `route`, `code`, `requestId` | нет |

Просмотры ленты в рейтинг не входят: прочтение засчитывает только страница материала.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Размер страницы 24, первые три карточки `large`; `page` вне диапазона — 404.
- `[ДОПУЩЕНИЕ]` Фильтр по тегу принимает только слаг из `topTags` или ввод; фильтры и сортировка
  делают адрес `noindex, follow`.
- `[ДОПУЩЕНИЕ]` Ссылка «редактировать рубрику» для `admin`/`owner` в шапке рубрики.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Нужен ли на этапе 1 переключатель «по дате / по рейтингу» с отключённым
  вторым вариантом (показать, что рейтинг появится), или до этапа 2 панель показывает только
  подпись? Если показать — компонент выпускается на этапе 1 в неактивном состоянии; если нет —
  подпись без переключателя.
