# Страница: 404

- **Реестр**: `00-registries/pages.md` #21 · `00-registries/routes.md` #22
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0018, ADR-0032
- **Этап**: 1; журнал Г3 §20.15 (кнопка «Сообщить о битой ссылке»)

## 1. Назначение

Единая страница «не найдено» для любого адреса без сущности: неизвестный слаг рубрики, тега,
хэндл, материал; черновик или версия на проверке для того, кто не имеет права её видеть
(`50-access/visibility.md` п. 2: существование не раскрывается — `NOT_FOUND`, никогда
`FORBIDDEN`); лишние сегменты пути; предпросмотр без сессии. Главное действие — вернуться на
главную или в поиск. Снятые и архивированные материалы сюда не попадают — у них страница 410
(#22). Сейчас в вебе `error.vue` показывает статус без навигации [ФАКТ:
`docs/vision/00-reality-check.md` §5.4].

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | код 404, короткий текст, поиск (3), ссылки на главную, рубрики, авторов, ненавязчивую кнопку «Сообщить о битой ссылке» (журнал §20.15) | перейти по ссылкам; искать; сообщить о битой ссылке в пределах лимита | узнать, существует ли скрытая сущность |
| Читатель (free) | то же | то же | — |
| Автор (standard / pro) | то же; если адрес похож на его собственный материал — ничего особенного: черновик автора доступен только через кабинет и `?preview=` | перейти в кабинет по ссылке в шапке | — |
| Администраторы (по ролям, если отличаются) | то же; `moderator`/`admin`/`owner` — подсказка «если это материал на проверке, откройте его в админке» без ссылки на конкретный объект `[ДОПУЩЕНИЕ]` | перейти в `/admin/articles` | увидеть, что именно скрыто, — только через админку с правами |

Текст одинаков для всех ролей: страница не подтверждает существование объекта. Разница между
«нет такой страницы» и «есть, но скрыта» не показывается ни визуально, ни по времени ответа
`[ДОПУЩЕНИЕ: резолвер отвечает `NOT_FOUND` одинаково быстро в обоих случаях]`.

## 3. Точки входа и маршруты

- Нет собственного адреса: рендерится по месту запрошенного URL со статусом 404; путь
  сохраняется в адресной строке; локаль — из префикса запроса (`/en/...` → английская 404).
- Редиректы отсюда не выполняются; перед 404 сервер проверяет историю слагов и хэндлов
  (ADR-0004) — совпадение даёт 301, а не 404.
- Приходят: устаревшие внешние ссылки, опечатки, удалённые (никогда не публиковавшиеся)
  сущности, прямые ссылки на черновики. Уходят: главная, поиск, рубрики, авторы, `/contact`.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `sections(locale)` | `locale` | `slug`, `name` (для ссылок и шапки) | все | общий | — |
| `feed(scope: home, locale, limit: 3)` `[ДОПУЩЕНИЕ]` | — | три карточки «почитать сейчас» | все | общий | — (ошибка — зона скрыта) |
| `createSupportRequest(topic: broken_link, route, referrer?, message?)` | шаблон маршрута и запрошенный путь без query `[ДОПУЩЕНИЕ]`, домен реферера, необязательный комментарий | `{ ok }` | все (матрица #117) | нет | `RATE_LIMITED`, `VALIDATION_ERROR` |

Страница не передаёт запрошенный адрес в API, кроме явной отправки обращения о битой ссылке
(журнал §20.15): тогда путь без query-параметров уходит в обращение, а в лог — только шаблон
маршрута.

## 5. Структура экрана по зонам

1. **Шапка сайта** (полная — навигация помогает уйти).
2. **Сообщение**: «404 — такой страницы нет»; подпись: «адрес устарел, содержит опечатку или
   материал ещё не опубликован»; `requestId` мелким шрифтом `[ДОПУЩЕНИЕ]`.
3. **Поиск** (3): `SearchBox` с подстановкой последнего сегмента пути как запроса
   `[ДОПУЩЕНИЕ]`; до этапа 3 — зона скрыта.
4. **Куда пойти**: ссылки «на главную», «рубрики», «авторы»; три карточки `small` из главной.
5. **Сообщить о битой ссылке** (журнал §20.15): ненавязчивая текстовая кнопка под зоной 4;
   по нажатию — компактная форма с необязательным комментарием и кнопкой «Отправить»; после
   отправки — «спасибо, мы проверим»; обращение попадает в очередь поддержки (`admin`/`owner`).
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | не применимо: страница отдаётся SSR целиком; карточки зоны 4 — скелет при клиентской навигации | — | — | 404 |
| Пусто | лента для зоны 4 пуста | зоны 1, 2, 3, ссылки без карточек | — | 404 |
| Ошибка данных | `sections` или `feed` не ответили | зона 2 и статические ссылки; шапка без рубрик | — (не меняет статус) | 404 |
| Нет доступа | не применимо: 404 используется вместо 403 для скрытых сущностей (инвариант матрицы) | — | `NOT_FOUND` | 404 |
| Не найдено / удалено | это и есть состояние страницы; удалённое (снятое, архив) — страница #22 | зоны 1–5 | `NOT_FOUND` | 404 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо | — | — | 404 |
| Заблокирован | архивированный аккаунт видит как гость; его собственные адреса — 410 (#22) | — | — | 404 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не применимо | — | — |

## 9. Мобильный и десктоп

- `lg`: сообщение и поиск по центру `max-w-2xl`; карточки в 3 колонки; шапка полная.
- `md`: 2 колонки карточек; поиск во всю ширину меры.
- `< md`: одна колонка; карточки — одна `small` `[ДОПУЩЕНИЕ]`; шапка — меню.

## 10. SEO / meta / hreflang

Ответ со статусом 404 (не 200 — иначе поисковики индексируют мусор); `noindex`; без
`canonical` и `hreflang`; `title` — «Страница не найдена — {Издание}»; не в `sitemap.xml`.
Для SPA-навигации Nuxt также выставляет статус через `setResponseStatus` `[ДОПУЩЕНИЕ]`.

## 11. Аналитические события

| Событие (код из `00-registries/events-and-logs.md`) | Триггер | Поля (без ПДн) | Участвует в рейтинге |
|---|---|---|---|
| `http.request` (#41) | запрос со статусом 404 | `route` (шаблон, не сырой путь `[ДОПУЩЕНИЕ]`), `status`, `referer` — только домен | нет |
| `page.error` (#64) | клиентская 404 при навигации | `route`, `code = NOT_FOUND`, `requestId` | нет |

Всплеск 404 по одному шаблону — сигнал сломанной ссылки (`80-observability/health-and-alerts.md`).

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Три карточки из главной; подстановка сегмента пути в поиск; `requestId` на
  странице; `route` в логе — шаблон, а не сырой путь (сырой путь может содержать ПДн из чужих
  ссылок).
- `[ДОПУЩЕНИЕ]` Подсказка служебным ролям про админку без ссылки на объект; лимит обращений 5 в
  час на IP; в обращение уходит путь без query.
- Закрыто Г3 (журнал §20.15): кнопка «Сообщить о битой ссылке» есть и создаёт обращение в
  поддержку по этому маршруту.
