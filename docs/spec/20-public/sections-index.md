# Страница: Список рубрик

- **Реестр**: `00-registries/pages.md` #6 · `00-registries/routes.md` #5
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0005, ADR-0019
- **Этап**: 1

## 1. Назначение

Каталог рубрик (категорий) издания с описанием, обложкой и числом опубликованных материалов —
навигационная страница, заменяющая нынешний `/types` [ФАКТ: `docs/vision/00-reality-check.md`
§5.3: моки]. Главное действие — перейти в ленту рубрики. Список рубрик ведут только `admin`
и `owner` (журнал #29); порядок — ручной порядок из админки (`admin-sections.md` #2), не
рейтинг.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | только рубрики с ≥ 1 опубликованным материалом в локали (журнал §20.9) | перейти в рубрику; открыть материал из превью | видеть пустые и архивированные рубрики |
| Читатель (free) | то же | то же | — |
| Автор (standard / pro) | то же; при создании материала выбирает рубрику из этого же списка (в кабинете) | то же | создавать рубрики (журнал #29) |
| Администраторы (по ролям, если отличаются) | то же; `admin`/`owner` — ссылка «управлять рубриками» → `/admin/sections` | перейти в админку | видеть архивированные рубрики здесь — только в админке |

Видимость: рубрики со статусом «активна» и хотя бы одной `published` версией в локали (журнал
§20.9) — пустая рубрика становится публичной с первой публикацией; то же правило для
`SectionNav` и мега-меню. Счётчики — только по `published` версиям локали.

## 3. Точки входа и маршруты

- `/sections` и `/en/sections`; query-параметров нет; `/types` → 301 на `/sections`
  (`06-design-system.md` §5) `[ДОПУЩЕНИЕ: 301 сохраняется один релиз]`.
- 404 не возникает: адрес фиксирован; `/sections/{что-то}` — 404 страницы #21.
- Приходят: шапка (`SectionNav` → «все рубрики»), мега-меню, футер, главная. Уходят: ленты
  рубрик, материалы из превью.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `sections(locale)` | `locale` | `slug`, `name`, `description`, `cover`, `articleCount` (≥ 1), `order`, `preview[] { title, path, author }` — до 3 последних материалов (по рейтингу после Г4) `[ДОПУЩЕНИЕ]` | все | общий; инвалидация при изменении рубрик и публикациях | — |

Гость и читатель получают только публичные поля; архивированные и пустые рубрики в ответ не
входят (журнал §20.9).

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Заголовок** (`PageHeader`): «Рубрики», число рубрик, короткое пояснение, что издание
   пишет о разных сторонах жизни (текст из словаря локали `[ДОПУЩЕНИЕ]`).
3. **Сетка рубрик**: карточка рубрики — обложка (или цветная плашка по токену), название,
   описание, счётчик, три превью материалов ссылками; порядок — `order` из админки. Пустые
   рубрики не показываются (журнал §20.9). Нет непустых рубрик — `EmptyState` «материалов пока
   нет» со ссылкой на `/pricing`; для `admin`/`owner` — подсказка, что рубрики появятся с
   первой публикацией.
4. **Футер**.

Пагинации нет: рубрик — единицы (ADR-0005), список короткий `[ДОПУЩЕНИЕ: ≤ 20]`.

изменения после инвалидации кеша `sections`.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация | скелет сетки | — | 200 |
| Пусто | ни одной рубрики с публикацией в локали (журнал §20.9) | `EmptyState`; для `admin`/`owner` — ссылка в `/admin/sections` | — | 200 |
| Ошибка данных | `sections` не ответил | `ErrorState` с `requestId`; шапка без рубрик | `INTERNAL_ERROR` | 500 |
| Нет доступа | не применимо: список публичен | — | `FORBIDDEN` | 403 — не возникает |
| Не найдено / удалено | лишний сегмент пути | страница #21 | `NOT_FOUND` | 404 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо к чтению | — | — | 200 |
| Заблокирован | архивированный аккаунт видит как гость | обычная страница | — | 200 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не затрагивает список рубрик | — | 200 |

## 9. Мобильный и десктоп

- `lg`: сетка 3 колонки; обложки 16:9; порядок — `order` слева направо, сверху вниз.
- `md`: 2 колонки; порядок сохраняется.
- `< md`: одна колонка; превью сворачиваются до одного материала `[ДОПУЩЕНИЕ]`; обложки
  уменьшаются до 3:2 `[ДОПУЩЕНИЕ]`; шапка — меню.
- Липких элементов нет; страница короткая и не требует навигации внутри себя.

## 10. SEO / meta / hreflang

`title` — «Рубрики — {Издание}»; `description` — шаблон с перечнем рубрик; `canonical`;
`hreflang` — пара; JSON-LD `CollectionPage` + `BreadcrumbList`; `index`; в `sitemap.xml`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Три превью — последние до Г4; 301 с `/types`; список без пагинации при ≤ 20
  рубриках; на мобильном — одно превью в карточке.
- Закрыто Г3 (журнал §20.9): пустые рубрики скрыты в каталоге и навигации до первой
  публикации.
