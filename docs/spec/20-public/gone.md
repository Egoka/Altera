# Страница: 410 «снято»

- **Реестр**: `00-registries/pages.md` #22 · `00-registries/routes.md` #23
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0018, ADR-0032; журнал #2–4, #12 (архив, снятие, окончательный
  отказ, каскад при архиве аккаунта)
- **Этап**: 1; журнал Г3 §20.16

## 1. Назначение

Ответ на адрес материала, который был опубликован и больше недоступен: снят ревьюером на
доработку, снят автором в часовом окне «перередактировать» (#100), архивирован автором,
ревьюером, администратором или владельцем (журнал #3, #53), архивирован каскадно вместе с
аккаунтом (журнал #4), окончательно отклонён после публикации (журнал #12). Страница отдаёт
410, чтобы поисковики сняли адрес из индекса, показывает всем посетителям заголовок материала и
нейтральное сообщение, что контент больше недоступен публично (журнал §20.16) — так сохранённая
старая ссылка не путается с ошибкой 404, — и ведёт к автору или рубрике. Главное действие —
перейти к автору или в рубрику. Причина снятия не раскрывается.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | заголовок материала, рубрику, автора (если его страница доступна), дату первой публикации, «материал снят с публикации» | перейти к автору, в рубрику, на главную | читать текст; узнать причину; увидеть, вернётся ли материал |
| Читатель (free) | то же; если материал в закладках — пометка «в ваших закладках» и кнопка убрать `[ДОПУЩЕНИЕ]` | убрать закладку | — |
| Автор (standard / pro) | для своей статьи — расширенный вариант: статус («снята на доработку», «в архиве», «отклонена редакцией»), ссылка в кабинет на историю решений (`/me/articles/{id}/review`) и на редактор, если правка возможна | перейти в кабинет | восстановить отсюда — только в кабинете по правилам журнала #3 |
| Администраторы (по ролям, если отличаются) | как гость; `moderator`, `admin`, `owner` — ссылка «открыть в админке» на карточку статьи | перейти в админку | видеть текст здесь — через `?preview=` на странице материала |

Условие видимости: заголовок и метаданные — публичные поля последней опубликованной версии
(`gone(locale, slug)`); тело не отдаётся никому на этой странице; для архивированного аккаунта
имя автора показывается без ссылки `[ДОПУЩЕНИЕ]`.

## 3. Точки входа и маршруты

- Рендерится по адресу материала `/{рубрика}/{слаг}` (и `/en/...`) со статусом 410 при
  состоянии версии `unpublished`, `archived`, `rejected` после публикации; черновик, никогда не
  публиковавшийся, — 404 (#21).
- 301 по истории слагов выполняется раньше: старый адрес снятого материала ведёт на актуальный
  и там 410.
- Приходят: поисковые системы, внешние ссылки, закладки читателей, RSS-агрегаторы, письма.
  Уходят: страница автора (#4), лента рубрики (#2), главная, кабинет автора.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `gone(locale, sectionSlug, slug)` | из пути | `title`, `section { slug, name }`, `author { name, handle, isPublic }`, `firstPublishedAt`, `unpublishedAt` `[ДОПУЩЕНИЕ: показывать дату снятия]`; для владельца версии и служебных ролей дополнительно `articleId`, `status` | все — публичные поля; расширение — автор версии, `moderator`, `admin`, `owner` | общий для публичных полей; расширение без кеша | `NOT_FOUND` (нет такой версии вообще) |
| `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` | нет | `UNAUTHENTICATED` |

Тело, теги, обложка не отдаются; причина снятия, решения ревьюера — только автору в кабинете
(матрица #102) и служебным ролям в админке.

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Сообщение**: заголовок материала; нейтральный текст «этот материал больше недоступен
   публично» (журнал §20.16); кикер рубрики; `Byline` без аватара; «был опубликован {дата}».
   Для автора своей статьи — статус и ссылки в кабинет.
3. **Куда дальше**: «другие материалы автора» (если страница автора доступна), «лента
   рубрики», «на главную».
4. **Ещё в рубрике**: три карточки `small` из ленты рубрики по рейтингу `[ДОПУЩЕНИЕ]`.
5. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | клиентская навигация | скелет заголовка | — | 410 |
| Пусто | рубрика без других материалов | зона 4 скрыта | — | 410 |
| Ошибка данных | `gone` не ответил | общий текст «материал недоступен» без заголовка | `INTERNAL_ERROR` | 410 `[ДОПУЩЕНИЕ: статус 410 сохраняется]` |
| Нет доступа | не применимо: публичные поля видны всем | — | `FORBIDDEN` | — |
| Не найдено / удалено | версии не существовало — страница #21 | — | `NOT_FOUND` | 404 |
| Ограничение плана (истёкшая подписка, лимит) | автор с истёкшим планом видит свою снятую статью с пометкой «для повторной публикации продлите план» (журнал #5) | расширенный вариант зоны 2 | — | 410 |
| Заблокирован | архивированный аккаунт: все его материалы отвечают этой страницей; сам он видит как гость | зона 2 без ссылки на автора | — | 410 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не применимо | — | — |

## 9. Мобильный и десктоп

- `lg`: зоны 2–3 по центру `max-w-2xl`; карточки в 3 колонки.
- `md`: 2 колонки.
- `< md`: одна колонка; одна карточка `[ДОПУЩЕНИЕ]`.

## 10. SEO / meta / hreflang

Статус 410; `noindex`; без `canonical` и `hreflang` (сестринская версия, если ещё опубликована,
указывается ссылкой в зоне 3 `[ДОПУЩЕНИЕ]`, а не hreflang); `title` — «{Заголовок} — снято —
{Издание}»; не в `sitemap.xml` и RSS; адрес удаляется из `sitemap.xml` при следующей сборке
(`feeds-and-sitemap.md`, 3).

## 11. Аналитические события

| Событие (код из `00-registries/events-and-logs.md`) | Триггер | Поля (без ПДн) | Участвует в рейтинге |
|---|---|---|---|
| `http.request` (#41) | запрос со статусом 410 | `route`, `status`, `articleId` `[ДОПУЩЕНИЕ: поле]` | нет |
| `bookmark.remove` (#56) | снятие закладки | `articleId` | нет |

Маяк `read` не отправляется: страница не содержит текста; просмотры снятого материала в
рейтинг не входят.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Показывается дата снятия; три карточки рубрики; имя автора без ссылки при
  архиве аккаунта; статус 410 сохраняется и при ошибке данных; `articleId` в логе.
- `[ДОПУЩЕНИЕ]` Читателю показывается пометка о закладке с кнопкой убрать.
- Закрыто Г3 (журнал §20.16): заголовок и нейтральное сообщение видны всем посетителям.
