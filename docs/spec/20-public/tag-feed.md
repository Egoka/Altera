# Страница: Лента тега

- **Реестр**: `00-registries/pages.md` #8 · `00-registries/routes.md` #9
- **Статус**: утверждён (гейт Г3, 2026-09-08)
- **ADR**: ADR-0002, ADR-0004, ADR-0005, ADR-0019, ADR-0034
- **Этап**: 1 (по новизне), 2 (по рейтингу после Г4)

## 1. Назначение

Лента тега — все опубликованные версии локали, помеченные тегом; до Г4 — по новизне без
переключателя (журнал §20.4), после — по `60-ranking/feed-principles.md` с соответствием теме
(`topic-relevance.md`). Тег — свободное слово автора, которое редакция сливает и чистит
(ADR-0005), поэтому лента может быть узкой и не имеет описания; тег с одной статьёй — полноценный
тег (журнал §20.10). Язык — строгая граница выдачи: материалы другого языка не подмешиваются
(журнал §20.5). Главное действие — открыть материал.

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | шапку тега, список карточек по новизне, пагинацию | открыть материал, листать | ставить закладки; видеть числа рейтинга; менять сортировку до запуска движка |
| Читатель (free) | то же с закладками | закладка с карточки | видеть числа рейтинга |
| Автор (standard / pro) | то же | всё, что читатель | создавать теги отсюда — новый тег создаётся из редактора (журнал §26.3, матрица #85) |
| Администраторы (по ролям, если отличаются) | то же, что гость; `admin`/`owner` — ссылка «управлять тегом» → `/admin/tags` `[ДОПУЩЕНИЕ]` | открыть материал | закладки (журнал #58) |

Видимость: только `published` версии локали. Слитый тег (`admin-sections.md` #3) отвечает 301
на целевой; архивированный тег — 404.

## 3. Точки входа и маршруты

- `/tags/{слаг}` и `/en/tags/{slug}`; теги общие для локалей, слаг один `[ДОПУЩЕНИЕ: тег не
  переводится]`; query `?page=N`; `?sort=rating|date` — после запуска движка, по умолчанию `rating` (журнал §22.5).
- 301: по истории слагов и при слиянии тегов (ADR-0004); 404 — неизвестный или архивированный
  тег.
- Приходят: теги в подвале материала (`ArticleFooter`), список тегов (#7), поиск, внешние
  ссылки. Уходят: материал, список тегов, рубрика материала.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `tag(slug)` | `slug` | `slug`, `name`, `articleCount`, `mergedInto` (для 301), `relatedTags[]` `[ДОПУЩЕНИЕ]` | все | общий | `NOT_FOUND` |
| `feed(scope: tag, slug, locale, page)` | как в query | `items[]`, `pageInfo`, `caption` («по дате публикации») | все | общий по параметрам; инвалидация при публикации/снятии материала с тегом, слиянии тегов | `NOT_FOUND`, `VALIDATION_ERROR` |
| `addBookmark` / `removeBookmark` | `articleId` | `bookmarked` | `reader`, `author` | нет | `UNAUTHENTICATED`, `FORBIDDEN`, `NOT_FOUND` |

Материалы разных рубрик показываются вместе с кикером рубрики на карточке; гость и читатель
ничего сверх публичных типов не получают.

## 5. Структура экрана по зонам

1. **Шапка сайта**.
2. **Шапка тега** (`TagHeader`): «#название», число материалов; описания у тега нет (ADR-0005) —
   зона показывает только название и счётчик.
3. **Панель ленты** (`FeedControls`, вариант «тег»): подпись «по дате публикации»; фильтров по
   формату и рубрике нет `[ДОПУЩЕНИЕ: тег уже узкий срез]`.
4. **Список**: карточки `small` с кикером рубрики; Пусто в локали —
   `EmptyState` «на этом языке под тегом пока ничего нет» и ссылка на список тегов; материалы
   другого языка не подмешиваются (журнал §20.5).
5. **Похожие теги**: `relatedTags[]` — теги, чаще всего встречающиеся вместе `[ДОПУЩЕНИЕ]`; пусто
   — зона скрыта.
6. **Пагинация**.
7. **Футер**.

## 9. Мобильный и десктоп

- `lg`: 3 колонки `small`; зона 5 справа от шапки тега.
- `md`: 2 колонки; зона 5 под шапкой.
- `< md`: одна колонка; похожие теги — горизонтальная прокрутка чипов.

## 10. SEO / meta / hreflang

`title` — «#{тег} — {Издание}»; `description` — шаблон «Материалы с тегом {тег}: {N}»;
`canonical` с `page` при `page > 1`; `hreflang` — `/tags/{slug}` ↔ `/en/tags/{slug}`
только если в обеих локалях есть материалы `[ДОПУЩЕНИЕ]`; `index` при `articleCount ≥ 1`, иначе
`noindex` `[ДОПУЩЕНИЕ]`; JSON-LD `CollectionPage`; в `sitemap.xml` только теги с материалами;
RSS тега не выпускается (3, `feeds-and-sitemap.md`) `[ДОПУЩЕНИЕ]`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Тег общий для локалей и не переводится; слаг один.
- `[ДОПУЩЕНИЕ]` Похожие теги — по совместной встречаемости; фильтров по формату и рубрике в
  ленте тега нет.
- `[ДОПУЩЕНИЕ]` Пустой в локали тег — `noindex`; RSS тега не выпускается.
- Закрыто Г3 (журнал §20.5): языки не смешиваются — пустое состояние без подмешивания;
  (§20.10) тег с одной статьёй остаётся видимым.
