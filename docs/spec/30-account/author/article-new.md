# Страница: Новый материал

- **Реестр**: `00-registries/pages.md` #36 · `00-registries/routes.md` #35
- **Статус**: на утверждении
- **ADR**: ADR-0002 (язык версии), ADR-0004 (слаг), ADR-0005 (рубрика, формат, тег), ADR-0035;
  журнал §12, #5, #12, §20.10, §24.1; `50-access/rate-limits.md` п. 10; `10-flows/write-and-publish.md`
  (#3)
- **Этап**: 1

## 1. Назначение

Первый шаг создания материала (CLAUDE.md «Статья»): рубрика (`Section`), формат, теги из
существующих (журнал §12 — новые теги создаёт только `admin`/`owner`), язык версии (выбирает
автор — журнал §20.10) и заголовок; автор присваивается автоматически. Главное действие —
«Создать и открыть редактор». Без активного плана после включения платности — предложение
выбрать или продлить план (журнал #5); на первом запуске доступно каждому зарегистрированному
(§24.1).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | — (302 на `/login?next=/me/articles/new`) | — | — |
| Читатель (free) | после включения платности — форму в режиме чтения с плашкой «нужен план» и кнопкой `/pricing` (журнал #5); на первом запуске — обычную форму (§24.1) | — / создать | создать без плана (`PLAN_LIMIT`) |
| Автор (standard / pro) | форму; лимит очереди проверки (≤ 5 материалов в `ai_check`/`review` — `rate-limits.md` п. 10) | создать; выбрать язык версии | создать новый тег; изменить автора |
| Администраторы (по ролям, если отличаются) | `editor` — форму редакционного материала с пометкой «от имени журнала» (журнал §17); остальные служебные — `FORBIDDEN` | `editor` — создать редакционный | `editor` — личный материал |

Условие видимости: справочники таксономии публичны (#11); создание — `article.create` (#17).

## 3. Точки входа и маршруты

- `/me/articles/new`, `/en/me/articles/new`; `?section=` — предвыбор рубрики (со страницы
  рубрики «написать сюда» `[ДОПУЩЕНИЕ]`); `?locale=` не принимается — язык выбирается в форме.
- Редиректы: без сессии — 302 на `/login?next=…`; ограниченная сессия — `/me/archived`; после
  создания — 302 на `/me/articles/{id}/edit`; читатель без плана после включения платности —
  страница остаётся, действие — `/pricing` (`routes.md` #35 «Пл → /pricing»).
- Приходят: «Новый материал» в списке, «Писать» в шапке, сводка, «написать первый материал».
  Уходят: редактор, `/pricing`, `/legal/content-rules`.

Создание сразу пишет первую ревизию-снимок (ADR-0007) и назначает автора текущим аккаунтом
(`ArticleAuthor`); для `editor` — владелец «журнал» (журнал §17). Слаг — из заголовка,
изменяем до первой публикации (#31). Лимит очереди проверки не мешает создавать черновики —
только отправлять (`article-edit.md`).

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Плашка плана** (если нужно): «нужен план» с кнопкой (журнал #5) — после включения
   платности; для истёкшего — «продлить». На первом запуске — скрыта (§24.1).
3. **Форма**: рубрика (обязательно, карточки или список), формат (обязательно, с описанием),
   язык версии (ru / en, по умолчанию — язык аккаунта, §20.10), теги (поиск среди существующих,
   до 5, «новые теги добавляет редакция»), заголовок.
4. **Правила**: одна строка со ссылкой на `/legal/content-rules` и напоминанием о проверке
   перед публикацией (журнал §6.2).
5. **Кнопка «Создать и открыть редактор»**.
6. **Футер**.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Пределы (заголовок 3–160, теги ≤ 5); `?section=`; кеш тегов 5 минут; предложение
  тега через `/contact`; формат обязателен.
- Отложено (каталог блоков — отдельный проход): содержимое редактора здесь не выбирается.
- Закрыто Г1–Г5b (журнал §12, §20.10, #5, §24.1): теги только существующие; язык версии выбирает
  автор; без плана — предложение плана; первый запуск — всем.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Обязателен ли формат при создании или его можно выбрать позже в
  редакторе? Если обязателен — как описано; если нет — формат по умолчанию «статья» и смена в
  редакторе до публикации.
