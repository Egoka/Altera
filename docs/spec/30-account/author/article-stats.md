# Страница: Статистика материала

- **Реестр**: `00-registries/pages.md` #39 · `00-registries/routes.md` #38
- **Статус**: на утверждении
- **ADR**: ADR-0027 (аналитика без трекинга; идентификация — заменена §23.7), ADR-0037, ADR-0038
  (заменён `engagement-tracking.md`); журнал §9–10, #26, §8.20–21, §21.15–16, §21.18–19,
  §21.30, §23; `60-ranking/explainability.md`, `engagement-tracking.md` §7, §10, §18–19,
  `article-score.md`, `pro-score.md`
- **Этап**: 2 (с движком рейтинга); в этапе 1 — только счётчики вовлечённости `[ДОПУЩЕНИЕ]`

## 1. Назначение

Личная аналитика одной своей статьи (журнал §21.19): открытия, квалифицированные прочтения,
повторы, сохранения, источники переходов и распространение по ссылкам — из дневных агрегатов
(`engagement-tracking.md` §19), числовой рейтинг статьи и его разложение по компонентам
(`article-score.md`), признак Pro-балла по снимку плана при публикации (§21.16), снимок
авторского рейтинга. Главное действие — понять, как читают материал. Числа и разложение —
только автору; публично — счётчики от ста округлённо (§21.30); сырые технические признаки и
формула не показываются (`engagement-tracking.md` §10).

## 3. Точки входа и маршруты

- `/me/articles/{id}/stats`, `/en/me/articles/{id}/stats` — `id` материала (статистика по всем
  языковым версиям вместе, с разбивкой по языку `[ДОПУЩЕНИЕ]`); `?range=7d|30d|90d|all`,
  `?locale=` `[ДОПУЩЕНИЕ]`.
- Редиректы: без сессии — 302 на `/login?next=…`; ограниченная сессия — `/me/archived`; чужой
  или неопубликованный материал — 404 (данных нет до публикации).
- Приходят: «Мои материалы», редактор, сводка. Уходят: публичная страница, редактор,
  `/legal/privacy` (что считается), `explainability` — нет публичного объяснения.

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Карточка материала**: заголовок, языки, дата публикации, «открыть», «редактор».
3. **Ключевые числа**: квалифицированные прочтения, открытия, сохранения, повторы, переходы по
   ссылкам распространения — за период; переключатель периода.
4. **Рейтинг**: число, «обновлено {время}» (при сбое — «последнее успешное значение»,
   §21.29), разложение по компонентам (`ScoreBreakdown`), признак «Pro-балл по снимку плана при
   публикации» (§21.16), снимок авторского рейтинга; пояснение «публично не показывается»
   (§21.18).
5. **Динамика** (`pro`): график по дням; `standard` — суммы `[ДОПУЩЕНИЕ: по плану — отложено]`.
6. **Источники**: таблица «источник → прочтения» (прямые, поиск, ленты, ссылки распространения,
   внешние) — `engagement-tracking.md` §5.
7. **Что считается**: одно предложение о квалифицированном прочтении без порогов (значения —
   отложено, §23); ссылка на политику ПД (`visitorId`, §23.7).
8. **Футер**.

## 9. Мобильный и десктоп

Десктоп: плитки в ряд, рейтинг и разложение справа от графика `[ДОПУЩЕНИЕ]`; планшет — две
колонки плиток; телефон — плитки 2×2, график на всю ширину с горизонтальной прокруткой, таблица
источников карточками.

## 10. SEO / meta / hreflang

`title` — «Статистика: {Заголовок} — {Издание}»; `noindex, nofollow`; без `canonical`,
`hreflang`; не в sitemap; `Cache-Control: private`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Периоды 7/30/90/всё; кеш 5 минут; статистика по материалу с разбивкой по языку;
  CSV; разбивка по дням только `pro`; `editor` видит по редакционным; в этапе 1 — только
  счётчики.
- Отложено (§21.39, §23, `engagement-tracking.md` §18 п. 6): формула, веса, пороги
  квалифицированного прочтения, состав аналитики по плану.
- Закрыто Г4 (§21.18–19, §21.29–32): число и разложение — только автору; последнее успешное
  значение при сбое; веса не настраиваются.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Показывать ли автору компоненты рейтинга по названиям (тема, свежесть,
  автор, вовлечённость, Pro) с числами или только итоговое число? Если с числами — `components[]`
  как описано; если нет — одно число и признак Pro, разложение остаётся в админке.
