# Страница: Статистика материала

- **Реестр**: `00-registries/pages.md` #39 · `00-registries/routes.md` #38
- **Статус**: утверждён (гейт Г6, 2026-09-09)
- **ADR**: ADR-0027 (аналитика без трекинга; идентификация — заменена §23.7), ADR-0037, ADR-0038
  (заменён `engagement-tracking.md`); журнал §9–10, #26, §8.20–21, §21.15–16, §21.18–19,
  §21.30, §23, §25.5; `60-ranking/explainability.md`, `engagement-tracking.md` §7, §10, §18–19,
  `article-score.md`, `pro-score.md`; `stats-overview.md` (общая статистика)

## 1. Назначение

Подробная статистика одной своей статьи (журнал §21.19, §25.5): понятные показатели, на которые
автор влияет качеством и регулярностью работы — открытия, квалифицированные прочтения,
повторы, сохранения, источники переходов и распространение по ссылкам — из дневных агрегатов
(`engagement-tracking.md` §19), и общий результат статьи (число рейтинга) с признаком Pro-балла
по снимку плана при публикации (§21.16). Внутренние коэффициенты, формула, защитные фильтры и
технические признаки скрыты (§25.5, `engagement-tracking.md` §10). Публично — счётчики от ста
округлённо (§21.30). Общая картина по всем статьям — `stats-overview.md`.

## 3. Точки входа и маршруты

- `/me/articles/{id}/stats`, `/en/me/articles/{id}/stats` — `id` материала (по всем языковым
  версиям вместе, с разбивкой по языку `[ДОПУЩЕНИЕ]`); `?range=7d|30d|90d|all`, `?locale=`
  `[ДОПУЩЕНИЕ]`.
- Редиректы: без сессии — 302 на `/login?next=…`; ограниченная сессия — `/me/archived`; чужой
  или неопубликованный материал — 404.
- Приходят: «Мои материалы», редактор, общая статистика (`/me/stats`), сводка. Уходят:
  публичная страница, редактор, `/me/stats`, `/legal/privacy` (что считается).

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета; ссылка «общая статистика» (`/me/stats`).
2. **Карточка материала**: заголовок, языки, дата публикации, «открыть», «редактор».
3. **Ключевые показатели**: квалифицированные прочтения, открытия, сохранения, повторы, переходы
   по ссылкам распространения — за период; переключатель периода.
4. **Общий результат**: число, «обновлено {время}» (при сбое — «последнее успешное значение»,
   §21.29), признак «Pro-балл по снимку плана при публикации» (§21.16); пояснение «на результат
   влияют интерес читателей и регулярность публикаций; публично не показывается» (§21.18,
   §25.5) — без коэффициентов и формулы.
5. **Динамика** (`pro`): график по дням; `standard` — суммы `[ДОПУЩЕНИЕ: по плану — отложено]`.
6. **Источники**: таблица «источник → прочтения» (прямые, поиск, ленты, ссылки распространения,
   внешние) — `engagement-tracking.md` §5.
7. **Что считается**: одно предложение о квалифицированном прочтении без порогов (значения —
   отложено, §23); ссылка на политику ПД (`visitorId`, §23.7).
8. **Футер**.

## 9. Мобильный и десктоп

Десктоп: плитки в ряд, общий результат справа от графика `[ДОПУЩЕНИЕ]`; планшет — две колонки
плиток; телефон — плитки 2×2, график на всю ширину с горизонтальной прокруткой, таблица
источников карточками.

## 10. SEO / meta / hreflang

`title` — «Статистика: {Заголовок} — {Издание}»; `noindex, nofollow`; без `canonical`,
`hreflang`; не в sitemap; `Cache-Control: private`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Периоды 7/30/90/всё; кеш 5 минут; статистика по материалу с разбивкой по языку;
  CSV; разбивка по дням только `pro`; `editor` видит по редакционным; в этапе 1 — только
  показатели вовлечённости.
- Отложено (§21.39, §23, `engagement-tracking.md` §18 п. 6): формула, веса, пороги
  квалифицированного прочтения, состав аналитики по плану.
- Закрыто Г4, Г6 (§21.18–19, §21.29–32, §25.5): общий результат и понятные показатели — только
  автору; внутренние коэффициенты, формула, защитные фильтры и признаки скрыты; последнее
  успешное значение при сбое.
