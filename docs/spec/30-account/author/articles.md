# Страница: Мои материалы

- **Реестр**: `00-registries/pages.md` #35 · `00-registries/routes.md` #34
- **Статус**: на утверждении
- **ADR**: ADR-0002 (языковые версии), ADR-0007 (ревизии), ADR-0014, ADR-0044, ADR-0045; журнал
  §4, §6, §8.20–21, §17, #5, #9, #12, #16, #42, §21.19, §24.1, §24.3; `50-access/roles/author.md`,
  `roles/editor.md`; `10-flows/write-and-publish.md` (#3, #4), `archive-and-restore-article.md`
  (#15)
- **Этап**: 1 (список, статусы, архив); 2 — числовой рейтинг своих статей (`article-stats.md`)

## 1. Назначение

Список всех материалов аккаунта во всех языковых версиях со статусами жизненного цикла
(`draft → ai_check → review → published → archived`, плюс признак «отклонена редакцией» — журнал
§4.5), фильтрами «архив» и «отклонённые», состоянием проверки и кнопками: открыть редактор,
создать, «Перередактировать» в часовом окне (журнал #9), «Удалить» = архив (журнал §3.1),
восстановить свою. Главное действие — открыть материал в редакторе. Для `editor` здесь же —
редакционные статьи журнала, общие для всех редакторов (журнал §17).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | — (302 на `/login?next=/me/articles`) | — | — |
| Читатель (free) | без единой статьи — 302 на `/me` с приглашением (журнал §8.21); бывший автор — список в режиме чтения | читать историю, архивировать свои, экспортировать (матрица #37) | создавать, редактировать, восстанавливать из архива (`PLAN_LIMIT`, журнал #5) |
| Автор (standard / pro) | все свои материалы: статус, язык, версии, вердикт проверки, окно «перередактировать», числовой рейтинг своей опубликованной статьи (2, §21.19) | всё из §7 | видеть чужие материалы и числа |
| Администраторы (по ролям, если отличаются) | `editor` — редакционные статьи журнала как «свои» (журнал §17) + личных нет; `moderator`, `admin`, `owner` — не пользуются, работают в `/admin/articles` | `editor` — как автор по редакционным | `editor` — покупать план, публиковать личные (§8.17) |

Условие видимости: свои и, для `editor`, редакционные (матрица #2 «свои»); на первом запуске
раздел доступен каждому зарегистрированному (§24.1).

## 3. Точки входа и маршруты

- `/me/articles`, `/en/me/articles`; `?status=draft|ai_check|review|published|archived|rejected`
  (несколько через запятую `[ДОПУЩЕНИЕ]`), `?q=` — поиск по заголовку в своих `[ДОПУЩЕНИЕ]`,
  `?cursor=`; фильтры «архив» и «отклонённые» — отдельные вкладки (журнал §4).
- Редиректы: без сессии — 302 на `/login?next=…`; ограниченная сессия — на `/me/archived`;
  читатель без статей — 302 на `/me`; `/me/drafts` → 301 `[ДОПУЩЕНИЕ]`.
- Приходят: сводка, шапка («Писать»), письма о решениях по статье, страница материала («в
  кабинет»). Уходят: редактор, `/me/articles/new`, `/me/articles/{id}/review`,
  `/me/articles/{id}/stats`, публичная страница материала.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `me.articles(status[], q, cursor, limit: 20)` | фильтры | `items[] { id, section, format, tags[], translations[] { locale, title, status, rejected, publishedAt, updatedAt, reeditUntil, aiVerdict { decision, reasonsCount }, lastReviewMessageAt, unread }, score (2, только `published`), archivedBy: self \| staff }`, `pageInfo`, `counts { byStatus }` | #2 свои | нет | `UNAUTHENTICATED`, `VALIDATION_ERROR` |
| `reeditTranslation(translationId)` | версия | `status: draft` | #100 свои | — | `FORBIDDEN` (окно закрыто или использовано), `CONFLICT` |
| `archiveArticle(articleId)` | материал | `status: archived` | #26 свои | — | `CONFLICT` (уже в архиве) |
| `restoreArticle(articleId)` | материал | `status: draft` | #27 свои — только если архивировал сам и план активен (журнал §4.2) | — | `FORBIDDEN` (архив сотрудника), `PLAN_LIMIT` |
| `exportArticle(articleId, format: md \| html)` | материал | файл | #37 свои, включая отклонённые (#110) | — | — |

Список — материалы, внутри — языковые версии с собственными статусами (ADR-0002). Причины
отказа и сообщения ревьюера — на странице проверки (#38), здесь — только счётчик и признак
непрочитанного `[ДОПУЩЕНИЕ]`. Число рейтинга видно только автору (§21.19), в списке — у
опубликованных, без разложения.

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Заголовок и «Новый материал»**; для бывшего автора вместо кнопки — «продлить план» (после
   включения платности — журнал #5; на первом запуске кнопка есть у всех — §24.1).
3. **Вкладки**: «все», «черновики», «на проверке» (`ai_check` + `review`), «опубликованные»,
   «отклонённые», «архив» — с числами из `counts`.
4. **Список** (`ArticleRow`): заголовок, язык(и) с флажком второй версии, статус, дата, для
   `published` — рейтинг (2) и обратный отсчёт «перередактировать до …»; для `ai_check` —
   «проверяется»; для отклонённой AI — «есть причины» с ссылкой на #38; для `rejected` —
   «отклонена редакцией, только чтение»; для архива — «архивировал: вы / редакция»; действия по
   строке. Сортировка — `updatedAt` убыв.; «показать ещё».
5. **Пусто**: `EmptyState` с «написать первый материал» (или пояснение фильтра).
6. **Футер**.

## 9. Мобильный и десктоп

Десктоп: строки в одну колонку `max-w-7xl` с действиями справа; планшет — действия в меню
«⋯»; телефон — карточки с заголовком, статусом, датой и меню действий; вкладки — горизонтальная
прокрутка; кнопка «Новый материал» — липкая внизу `[ДОПУЩЕНИЕ]`.

## 10. SEO / meta / hreflang

`title` — «Мои материалы — {Издание}»; `noindex, nofollow`; без `canonical`, `hreflang`; не в
sitemap; `Cache-Control: private, no-store`.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Несколько статусов в фильтре; поиск по заголовку; редирект `/me/drafts`;
  признак непрочитанного; липкая кнопка на телефоне; лимит 20.
- Отложено (§8.21): состав авторских разделов без единой статьи — здесь редирект на `/me`;
  (каталог блоков) — не касается списка.
- Закрыто Г2–Г5b (журнал #5, #53, §8.20–21, §24.1): бывший автор — чтение, архив, экспорт;
  архив сотрудника не восстанавливается автором; первый запуск — раздел у всех.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Показывать ли числовой рейтинг прямо в списке (у опубликованных) или
  только на странице статистики? Если в списке — число без разложения в строке; если нет —
  только ссылка «статистика».
