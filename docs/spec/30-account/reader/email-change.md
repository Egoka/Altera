# Страница: Смена почты

- **Реестр**: `00-registries/pages.md` #29 · `00-registries/routes.md` #29
- **Статус**: утверждён (гейт Г6, 2026-09-09)
- **ADR**: ADR-0022 (вход только по ссылке), ADR-0024 (почтовая зависимость и лимиты), ADR-0032;
  журнал §25.8; `50-access/session-lifecycle.md` п. 10; `10-flows/email-change-and-recovery.md`
  (#13)
- **Этап**: 1

## 1. Назначение

E-mail — единственный способ входа (ADR-0022). Смена по журналу §25.8: пользователь вводит
новый адрес, получает на него код и вводит код в том же окне; после проверки адрес меняется без
повторного входа и без принудительного завершения сессий. Подтверждения со старой почты и
быстрого отката нет. Главное действие — ввести новый адрес и код. Потеря доступа к почте решается
обращением в редакцию (`/contact`, тема «восстановление доступа») с ручной процедурой
`admin`/`owner` и аудитом (матрица #50; `flows.md` #13).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | — (302 на `/login?next=/me/email`) | — | — |
| Читатель (free) | текущий e-mail (маскированный `[ДОПУЩЕНИЕ]`), поле нового адреса, поле кода после отправки, срок действия кода | запросить код; ввести код; отменить | сменить без кода; сменить на занятый адрес |
| Автор (standard / pro) | то же | то же | — |
| Администраторы (по ролям, если отличаются) | то же для своей служебной записи (настройка учётной записи — §25.2 `[ДОПУЩЕНИЕ: состав]`); чужой e-mail — только `admin`/`owner` в `/admin/users/{id}` (#50) | — | — |

Условие видимости: только свой (`email.change` #49); полный текущий e-mail — по клику «показать»
`[ДОПУЩЕНИЕ]`.

## 3. Точки входа и маршруты

- `/me/email`, `/en/me/email`; query нет; отдельного маршрута подтверждения по ссылке нет
  (§25.8) — код вводится в том же окне.
- Редиректы: без сессии — 302 на `/login?next=/me/email`; ограниченная сессия — на
  `/me/archived`.
- Приходят: профиль, сессии, сводка. Уходят: `/me/settings`, `/contact`.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `me.emailChange` | — | `currentEmailMasked`, `pending { newEmailMasked, expiresAt, attemptsLeft }` | #49 свои | нет | `UNAUTHENTICATED` |
| `requestEmailChange(newEmail)` | новый адрес (формат; не равен текущему) | `pending` — код отправлен на новый адрес | свои | — | `VALIDATION_ERROR`, `CONFLICT` (запрос уже открыт), `RATE_LIMITED` (`rate-limits.md` п. 8) |
| `confirmEmailChange(code)` | код из письма | `email` (новый, маскированный), `changedAt` | свои, в той же сессии | — | `VALIDATION_ERROR` (код неверен; после исчерпания попыток — запрос закрывается `[ДОПУЩЕНИЕ: число попыток]`), `NOT_FOUND` (код истёк), `CONFLICT` (адрес занят другим аккаунтом) |
| `cancelEmailChange` | — | `pending: null` | свои | — | — |

Код — одноразовый, с ограниченным сроком (`[ДОПУЩЕНИЕ: срок — общий параметр токенов входа]`),
хранится хэшем. После проверки адрес меняется сразу; сессии не отзываются (§25.8); аудит
`user.email.change` (#17); уведомление на прежний адрес — состав писем определяется проходом
почты (§25.13). Занятость адреса другим аккаунтом сообщается при проверке кода, а не при запросе
`[ДОПУЩЕНИЕ: чтобы не раскрывать адреса]`.

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Текущий адрес**: маскированный, «показать».
3. **Форма нового адреса**: поле, кнопка «Отправить код»; пояснение «код придёт на новый адрес».
4. **Ввод кода** (после отправки, в том же окне): поле кода, срок действия, «отправить код ещё
   раз» (лимит), «отменить»; после успеха — «адрес изменён», зона 2 обновляется, форма
   закрывается.
5. **Потерян доступ к почте**: ссылка на `/contact` с темой «восстановление доступа».
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | получение `me.emailChange` | скелет | — | 200 |
| Пусто | нет открытого запроса | форма зоны 3 | — | 200 |
| Ошибка данных | запрос не ответил | `ErrorState` | `INTERNAL_ERROR` | 500 |
| Нет доступа | нет сессии | 302 на `/login?next=/me/email` | `UNAUTHENTICATED` | 302 |
| Не найдено / удалено | код истёк | зона 4: «код истёк», «отправить ещё раз» | `NOT_FOUND` | 200 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо к плану; лимит запросов кода (`rate-limits.md` п. 8) | сообщение с временем следующей попытки | `RATE_LIMITED` | 200 |
| Заблокирован | ограниченная сессия | 302 на `/me/archived` | `FORBIDDEN` | 302 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | не зависит от paywall | — | 200 |

Дополнительно: адрес занят — `CONFLICT` на шаге кода с предложением другого адреса; попытки
кода исчерпаны — запрос закрыт, «запросить заново».

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Маскирование адреса; срок кода — общий параметр токенов входа; число попыток
  кода; `CONFLICT` только на шаге кода.
- Отложено (§25.13): уведомление на прежний адрес и текст письма с кодом — проход почты; ручная
  процедура восстановления — `flows.md` #13 без автоматизации.
- Закрыто Г6 (§25.8): код на новый адрес в том же окне; без повторного входа и завершения
  сессий; подтверждения со старой почты и отката нет.
