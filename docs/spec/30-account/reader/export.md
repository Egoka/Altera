# Страница: Выгрузка данных

- **Реестр**: `00-registries/pages.md` #33 · `00-registries/routes.md` #39
- **Статус**: на утверждении
- **ADR**: ADR-0011 (152-ФЗ: право на копию данных), ADR-0028, ADR-0044 п. 3–4 (экспорт при
  истёкшем плане), ADR-0029 (пакет контента); журнал §5; `10-flows/delete-account.md` (#12)
- **Этап**: 3 (реестр `routes.md` #39); в этапе 1 — ссылка «написать в редакцию» `[ДОПУЩЕНИЕ]`

## 1. Назначение

Запрос и скачивание архива своих данных: профиль, согласия, закладки, список сессий, платежи
(без реквизитов), статьи во всех версиях и языках в формате пакета контента (ADR-0029) и
Markdown/HTML (матрица #37), медиа статей. Главное действие — «Запросить выгрузку», затем
скачать готовый файл по ссылке. Доступно при любом плане, в том числе истёкшем (ADR-0044,
`plan-free.md` п. 4), и перед «удалением аккаунта» (`delete-account.md`).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | — (302 на `/login?next=/me/export`) | — | — |
| Читатель (free) | состав выгрузки для читателя (профиль, согласия, закладки, сессии), историю запросов | запросить; скачать в срок | получить чужие данные |
| Автор (standard / pro) | то же плюс статьи, версии, медиа, платежи и чеки, личную аналитику агрегатами (§21.19) | то же; выбрать состав `[ДОПУЩЕНИЕ]` | выгрузить сырые события вовлечённости (`engagement-tracking.md` §10) |
| Администраторы (по ролям, если отличаются) | своя учётная запись — как читатель; выгрузка чужих данных — только по запросу субъекта через `/admin/users/{id}` с аудитом (#104) | — | — |

Условие видимости: только свои (`account.export` #53); в выгрузку не входят внутренние заметки
ревьюера сверх переписки, IP, идентификаторы читателей, числа других авторов.

## 3. Точки входа и маршруты

- `/me/export`, `/en/me/export`; ссылка на файл — подписанный адрес с ограниченным сроком
  (`85-media-and-binary/access-and-signed-urls.md`, заход 9), 7 дней `[ДОПУЩЕНИЕ]`.
- Редиректы: без сессии — 302 на `/login?next=/me/export`; ограниченная сессия — на
  `/me/archived` (выгрузка из архива — по обращению в редакцию `[ДОПУЩЕНИЕ]`).
- Приходят: профиль, «удалить аккаунт» (шаг «сначала выгрузите»), политика ПД, лицензия
  («выгрузить мои материалы»). Уходят: `/me/delete`, `/legal/privacy`.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `me.exports` | — | `items[] { id, requestedAt, status: queued \| running \| ready \| failed \| expired, sizeBytes, downloadUrl, expiresAt, scope[] }` | #53 свои | нет | `UNAUTHENTICATED` |
| `requestExport(scope[])` | состав: `profile`, `bookmarks`, `articles`, `media`, `payments`, `analytics` `[ДОПУЩЕНИЕ: набор]` | `export { id, status: queued }` | #53 | — | `CONFLICT` (есть незавершённый), `RATE_LIMITED` (1 запрос в сутки `[ДОПУЩЕНИЕ]`) |
| `exportDownload(id)` | id | подписанная ссылка | свои | — | `NOT_FOUND` (истёк / чужой) |

Сборка — фоновое задание (`job.*`, события #52); готовность — письмо (§8.23 — шаблон отложен) и
состояние на странице; файл — ZIP с JSON и Markdown/HTML статей, медиа оригиналами
`[ДОПУЩЕНИЕ]`; хранится 7 дней, затем `expired`, запись остаётся в истории.

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Пояснение**: что войдёт в выгрузку по роли; ссылка на политику ПД и лицензию.
3. **Состав** (для автора): чекбоксы разделов `[ДОПУЩЕНИЕ]`; для читателя — фиксированный
   состав без выбора.
4. **Кнопка «Запросить выгрузку»**; при незавершённом запросе — индикатор «готовим» с временем
   запроса.
5. **История запросов**: дата, состав, размер, «скачать» до `expiresAt`, «истекла».
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | получение `me.exports` | скелет | — | 200 |
| Пусто | запросов не было | зоны 2–4; история скрыта | — | 200 |
| Ошибка данных | список не получен | `ErrorState` | `INTERNAL_ERROR` | 500 |
| Нет доступа | нет сессии | 302 на `/login?next=/me/export` | `UNAUTHENTICATED` | 302 |
| Не найдено / удалено | ссылка истекла или чужая | строка «истекла», «запросить заново» | `NOT_FOUND` | 200 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо к плану (ADR-0044 п. 3–4); лимит 1 запрос в сутки | сообщение с датой | `RATE_LIMITED` | 200 |
| Заблокирован | ограниченная сессия | 302 на `/me/archived`; выгрузка — через редакцию | `FORBIDDEN` | 302 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | выгрузка не зависит от paywall | — | 200 |

Дополнительно: `failed` — строка с «повторить» и `requestId`; задание дольше часа —
`job.stuck` (#52), пользователю — «готовим дольше обычного».

## 9. Мобильный и десктоп

Одна колонка; таблица истории на телефоне — карточками; кнопка «Запросить» на всю ширину.

## 10. SEO / meta / hreflang

`title` — «Выгрузка данных — {Издание}»; `noindex, nofollow`; без `canonical`, `hreflang`; не в
sitemap; ссылки на файлы — `noindex`, не кешируются CDN.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Состав разделов; ZIP с JSON + Markdown/HTML + медиа; срок 7 дней; лимит 1 запрос
  в сутки; в этапе 1 — ссылка на редакцию вместо страницы; выгрузка из архива — по обращению.
- Отложено (§8.23): письмо о готовности; (заход 9) подписанные ссылки и хранение файлов.
- `[ВОПРОС ВЛАДЕЛЬЦУ]` Включать ли в выгрузку автора переписку с ревьюером и причины отказов?
  Если да — раздел `review` в пакете (это его данные — журнал §6.7); если нет — только тексты и
  метаданные статей.
