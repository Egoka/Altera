# Страница: Закладки

- **Реестр**: `00-registries/pages.md` #30 · `00-registries/routes.md` #30
- **Статус**: утверждён (гейт Г6, 2026-09-09)
- **ADR**: ADR-0041 (закладки), ADR-0027, ADR-0034; журнал §19, #58; `10-flows/bookmark-and-follow.md`
  (#14); `60-ranking/engagement-tracking.md` §7 (закладка — сигнал)
- **Этап**: 1

## 1. Назначение

Список сохранённых материалов аккаунта в порядке добавления — «прочитать позже». Главное действие
— открыть материал; второе — убрать закладку. Ленты по рейтингу здесь нет: порядок — по дате
добавления закладки (`60-ranking/feed-principles.md` не применяется — это личный список).

## 2. Аудитория и роли

| Роль | Видит | Может | Не может |
|---|---|---|---|
| Гость | — (302 на `/login?next=/me/bookmarks`) | — | — |
| Читатель (free) | свои закладки: карточки с рубрикой, заголовком, автором, датой добавления; недоступные (снятые, архивированные) — приглушённые, чёрно-белые, с отметкой «недоступна» и крестиком удаления (журнал §25.10) | открыть доступную; убрать; фильтр «недоступные» | открыть содержание недоступной; видеть чужие закладки; чей-либо счётчик закладок |
| Автор (standard / pro) | то же | то же | — |
| Администраторы (по ролям, если отличаются) | служебные роли закладками не пользуются (журнал #58, §25.2): страница отвечает `FORBIDDEN`; для личного чтения — отдельный обычный аккаунт | — | — |

Условие видимости: только свои (`bookmark.list` #14); закладка на снятый или архивированный
материал сохраняется с плашкой «недоступен» и открывает 410 (`20-public/gone.md`) `[ДОПУЩЕНИЕ]`.

## 3. Точки входа и маршруты

- `/me/bookmarks`, `/en/me/bookmarks`; `?cursor=` — курсорная пагинация (ADR-0004, общие типы
  пагинации); `?unavailable=1` — только недоступные `[ДОПУЩЕНИЕ]`.
- Редиректы: без сессии — 302 на `/login?next=/me/bookmarks`; ограниченная сессия — на
  `/me/archived`; `/bookmarks`, `/saved` → 301 `[ДОПУЩЕНИЕ]`.
- Приходят: сводка кабинета, `BookmarkButton` на материале («сохранено → открыть закладки»),
  меню. Уходят: страницы материалов, страница автора.

## 4. Данные и запросы к API

| Запрос / мутация | Аргументы | Поля | Права | Кеш | Ошибки (коды ADR-0032) |
|---|---|---|---|---|---|
| `me.bookmarks(cursor, limit: 20, unavailable)` | курсор, лимит, фильтр | `items[] { bookmarkedAt, article { id, title, section, author { name, handle }, cover, publishedAt, locale, available } }`, `pageInfo` | #14 свои | нет | `UNAUTHENTICATED`, `FORBIDDEN` (служебная роль), `VALIDATION_ERROR` (курсор) |
| `removeBookmark(articleId)` | id | `bookmarked: false` | #13 свои | — | `NOT_FOUND` |
| `addBookmark(articleId)` (отмена удаления) | id | `bookmarked: true` | #13 | — | `NOT_FOUND`, `RATE_LIMITED` (п. 8) |

Закладка хранится на материал, а не на языковую версию (ADR-0041); показывается версия на языке
интерфейса, при отсутствии — исходная `[ДОПУЩЕНИЕ]`. Число закладок материала — сигнал рейтинга
(`engagement-tracking.md` §7), автору показывается только в его личной аналитике (§21.19),
здесь не выводится.

## 5. Структура экрана по зонам

1. **Шапка сайта** и меню кабинета.
2. **Заголовок и счётчик** «Закладки · N»; переключатель «все / недоступные».
3. **Список**: карточки `ArticleCard` (компактные) с датой добавления и иконкой «убрать»;
   недоступные — приглушённые и чёрно-белые, не кликабельные, с отметкой и крестиком (§25.10);
   недоступные — приглушённые с плашкой. Порядок — `bookmarkedAt` убыв.
4. **Пагинация**: «показать ещё» по курсору.
5. **Пусто**: `EmptyState` «здесь появятся сохранённые материалы» с ссылкой на главную.
6. **Футер**.

## 8. Состояния страницы

| Состояние | Когда | Что показано | Код ошибки | HTTP |
|---|---|---|---|---|
| Загрузка | получение первой страницы | скелет карточек | — | 200 |
| Пусто | нет закладок | `EmptyState` | — | 200 |
| Ошибка данных | список не получен | `ErrorState` с «повторить» | `INTERNAL_ERROR` | 500 |
| Нет доступа | нет сессии / служебная роль (журнал #58) | 302 на `/login?next=…` / сообщение «служебные учётные записи не используют закладки» | `UNAUTHENTICATED` / `FORBIDDEN` | 302 / 403 |
| Не найдено / удалено | материал закладки снят или архивирован | карточка остаётся: приглушённая, чёрно-белая, с отметкой и крестиком; содержание не открывается (§25.10) | — | 200 |
| Ограничение плана (истёкшая подписка, лимит) | не применимо: закладки — у любого аккаунта (ADR-0041); лимит мутаций п. 8 | — | `RATE_LIMITED` | 200 |
| Заблокирован | ограниченная сессия | 302 на `/me/archived` | `FORBIDDEN` | 302 |
| Paywall — **зарезервировано**: чтение бесплатно, состояние описывается одним предложением «как включится позже» | никогда | при включении карточка платного материала получит пометку (ADR-0036) | — | 200 |

## 9. Мобильный и десктоп

Сетка карточек 1 / 2 / 3 колонки по breakpoints (`06-design-system.md` §3); на телефоне —
список строк с обложкой слева; «убрать» — по свайпу не делаем, только иконка `[ДОПУЩЕНИЕ]`.

## 10. SEO / meta / hreflang

`title` — «Закладки — {Издание}»; `noindex, nofollow`; без `canonical`, `hreflang`, Open Graph; не
в sitemap и RSS.

## 12. Открытые вопросы и допущения

- `[ДОПУЩЕНИЕ]` Лимит 20 на страницу; закладка на снятый материал остаётся с плашкой; версия по
  языку интерфейса; «вернуть» 5 с; редиректы `/bookmarks`, `/saved`.
- `[ДОПУЩЕНИЕ]` Фильтр «недоступные» и счётчик в заголовке.
- `[ДОПУЩЕНИЕ]` Служебной роли страница отвечает `FORBIDDEN` с пояснением, а не скрывается из
  меню молча (журнал #58).
- Отложено (этап 3): подписка на авторов — отдельный список не проектируется здесь
  (`bookmark-and-follow.md`).
- Закрыто Г6 (§25.10): недоступная статья остаётся в закладках приглушённой, чёрно-белой, с
  отметкой и крестиком; содержание не открывается.
