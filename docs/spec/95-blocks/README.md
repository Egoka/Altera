# Блоки конструктора статей — зарезервировано

Каталог блоков-компонентов, их настройки, вложенность, хранение и масштабирование — **отдельный
проход** по решению владельца (2026-09-06). В фазе 2 папка не наполняется.

**Порядок прохода (журнал §31).** Проход идёт параллельно с реализацией пакета `content` (T-041):
спецификации блоков дописываются по ходу работы и могут потребовать правок схемы. Спецификации и
код идут вместе; владелец принимает каталог целиком одним решением по работающему сайту, а не по
каждому блоку отдельно (журнал §31 п. 3–4).

**Набор блоков первого бесплатного запуска** — этап 1 ADR-0017 и `docs/vision/05-editor.md` §7
(журнал §31 п. 1): абзац; заголовок уровней 2 и 3; цитата (обычная, выносная); маркированный и
нумерованный списки; изображение с подписью (размеры «обычный», «широкий», «во всю ширину»;
подпись и атрибуция из медиа); разделитель; марки «полужирный», «курсив», «ссылка». Правило
границы свободы ADR-0017 действует без изменений. Блоки этапа 5 (галерея, видео, аудио, врезка,
embed, таблица, колонки, шаблоны) в первый запуск не входят (журнал §31 п. 2).

До этого прохода действуют: модель контента ProseMirror JSON (ADR-0001), пакет `content`
(ADR-0029), каталог блоков и граница свободы автора в первом приближении (ADR-0017,
`docs/vision/05-editor.md` §7–8). Спецификации страниц редактирования статьи
(`30-account/author/article-edit.md`) описывают обвязку редактора — панели, сохранение,
статусы, AI-проверку — и ссылаются сюда, не описывая сами блоки.

Когда проход начнётся, здесь появятся: реестр блоков (`00-catalog.md`), шаблон блока
(`_templates/block.md` — схема данных, настройки, ограничения дизайн-системы, рендер, адаптив,
миграции схемы) и по файлу на блок.
