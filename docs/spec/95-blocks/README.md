# Блоки конструктора статей — зарезервировано

Каталог блоков-компонентов, их настройки, вложенность, хранение и масштабирование — **отдельный
проход** по решению владельца (2026-09-06). В фазе 2 папка не наполняется.

До этого прохода действуют: модель контента ProseMirror JSON (ADR-0001), пакет `content`
(ADR-0029), каталог блоков и граница свободы автора в первом приближении (ADR-0017,
`docs/vision/05-editor.md` §7–8). Спецификации страниц редактирования статьи
(`30-account/author/article-edit.md`) описывают обвязку редактора — панели, сохранение,
статусы, AI-проверку — и ссылаются сюда, не описывая сами блоки.

Когда проход начнётся, здесь появятся: реестр блоков (`00-catalog.md`), шаблон блока
(`_templates/block.md` — схема данных, настройки, ограничения дизайн-системы, рендер, адаптив,
миграции схемы) и по файлу на блок.
