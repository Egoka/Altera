# Этап 3 — Читатель находит и возвращается

- **Файл**: четвёртый по порядку выполнения; этап 3. Ревизия 2 (2026-09-06), заменяет
  ревизию 1 (коммит `7c0ce79`): прочтения и «популярное» ушли в этап 2, подборки отменены
  вместе с витриной, добавлены SEO целиком, i18n интерфейса и AI-перевод.
- **Решения**: ADR-0025, ADR-0026, ADR-0046, ADR-0002, ADR-0014, ADR-0018.
- **Документы**: `docs/vision/06-design-system.md` §8, §10; `05-editor.md` §9; `07-commerce.md` §8.

## 1. Цель и продуктовая гипотеза

**Цель.** Читатель находит материалы через поиск и рубрики, заводит аккаунт ради закладок и
подписки на автора, получает письма и возвращается; страницы индексируются на двух языках;
pro-автор получает вторую языковую версию AI-переводом; сайт доступен и быстр по измеримым
бюджетам; автор может забрать свои тексты и удалить аккаунт сам.

**Гипотеза.** Читатель, нашедший материал через поиск или рубрику, подпишется на автора и
вернётся; AI-перевод даёт pro-авторам англоязычную аудиторию.

## 2. Что входит

- **Поиск** (ADR-0025): `searchVector`, страница `/search` со сниппетами и фильтрами, рейтинг
  как вторичный ключ, подсказки, контрольный набор запросов, бенчмарк.
- **Подписка на автора** (ADR-0026): `AuthorFollow`, кнопка на странице автора, письмо при
  публикации не чаще раза в день на автора, одноразовая отписка, `User.locale`.
- **AI-перевод** (ADR-0046): `TranslationJob`, кнопка «Создать перевод» для pro, перевод
  текста, заголовка, дека, подписей; правка автором; обычная проверка; лимит в сутки;
  `hreflang` и переключатель языка при опубликованных сёстрах.
- **SEO целиком** (`06-design-system.md` §10): hreflang, `sitemap.xml` и `rss.xml` по локалям,
  OG-изображения, JSON-LD, `noindex` служебных страниц.
- **Интерфейс на двух языках**: словари `web/i18n`, все тексты через i18n, переключатель.
- **Экспорт** своих материалов в Markdown и HTML из кабинета — доступен и после истечения
  подписки.
- **Самостоятельное удаление аккаунта** и выгрузка данных (JSON) по ADR-0014; отмена подписки
  при удалении.
- **Навигация из данных**: `/sections`, `/tags`, `/authors` — реальные списки с пагинацией;
  фикстуры удалены полностью.
- **Доступность и бюджеты как гейты CI**: axe в Playwright, Lighthouse CI, скриншот-тесты
  состояний.

## 3. Что сознательно не входит

- Комментарии, реакции (ADR-0026); подборки редакции (отменены с витриной).
- Внешний поисковый движок; персонализация.
- Рассылка редакции — этап 4.
- OAuth (только по измеренной потере на входе, ADR-0022).

## 4. От чего зависит и что разблокирует

**Зависит от**: этапа 2 (рейтинг для поиска и страниц); этапа 1 (проверенный процесс
публикации для переводов); гейта «лимиты AI-переводов».

**Разблокирует**: этап 4 (отчёты по аудитории) и этап 5.

## 5. Definition of Done

1. `/search?q=` работает на `tsvector` с ранжированием и сниппетом; бенчмарк на сиде 10 000
   материалов: p95 < 300 мс (скрипт в репозитории, результат в отчёте).
2. Контрольный набор из 50 запросов (ru/en, словоформы) даёт ожидаемый топ-3
   (фикстура-тест); нулевые выдачи логируются без персональных данных.
3. Подписка на автора: письмо при публикации с одноразовой отпиской; не более одного письма на
   автора в день; `followersNotifiedAt` делает отправку идемпотентной (тесты).
4. AI-перевод: pro создаёт EN-версию из опубликованной RU; standard видит «доступно в pro»;
   лимит в сутки; переведённая версия проходит обе ступени проверки; после публикации обеих —
   hreflang и переключатель (тесты, e2e на фейке провайдера); стоимость записана.
5. `sitemap.xml`, `rss.xml` по локалям валидны; JSON-LD проходит валидатор; `/me`, `/admin`,
   предпросмотр — `noindex` (тесты).
6. Интерфейс: `grep` захардкоженных строк интерфейса в компонентах = 0; переключатель меняет
   язык без перезагрузки; письма — на языке пользователя.
7. Экспорт материала в Markdown и HTML совпадает со снимками (round-trip); доступен при
   `planTier = free` после истечения (тест).
8. Удаление аккаунта из кабинета с подтверждением по письму выполняет анонимизацию и архив по
   умолчанию, вариант «оставить с подписью» работает; подписка отменена; выгрузка отдаёт JSON
   (тесты).
9. axe в Playwright: 0 critical/serious на всех публичных страницах; Lighthouse CI: LCP < 2,5 с
   и JS < 150 КБ на странице материала; превышение — красный CI.
10. `/sections`, `/tags`, `/authors` — реальные списки; `grep -rn "mock" web/app` = 0.

## 6. Риски и способ их снять

| Риск | Снятие |
|---|---|
| Русский стемминг даёт плохую выдачу | Контрольный набор запросов; `pg_trgm` для подсказок; критерий перехода в ADR-0025 |
| Качество AI-перевода | Правка автором обязательна перед отправкой; проверка обеими ступенями; пометка «перевод» |
| Репутация домена при рассылке подписчикам | SPF/DKIM/DMARC, не чаще раза в день, отписка в один клик |
| Деградация производительности при доводке дизайна | Бюджеты как гейт CI с первого дня этапа |
| Доступность превращается в редизайн | Чек-лист и axe по компонентам, а не по страницам |

## 7. Метрики успеха

- Поисков в день; доля нулевых выдач < 20 %.
- Подписчиков на автора; доля прочтений по переходам из писем.
- AI-переводов создано и опубликовано; доля pro-авторов, использующих перевод.
- Возвраты: доля хэшей, встреченных ≥ 2 дня за неделю (агрегат, без профилирования).
- Нарушений доступности в CI: 0; бюджеты соблюдены.
- Число экспортов и удалений аккаунта.
