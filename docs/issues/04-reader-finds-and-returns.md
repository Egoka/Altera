# Этап 3 — Читатель находит и возвращается

- **Файл**: четвёртый по порядку выполнения; этап 3.
- **Решения**: ADR-0016, ADR-0018, ADR-0025, ADR-0026, ADR-0027, ADR-0014.
- **Документы**: `docs/vision/06-design-system.md` §8, §10; `03-data-model.md` §1.3;
  `07-commerce.md` §9.

## 1. Цель и продуктовая гипотеза

**Цель.** Читатель находит материалы через поиск, рубрики и подборки, подписывается на
автора и возвращается; «популярное» считается честно; сайт доступен и быстр по измеримым
бюджетам; автор может забрать свои тексты и удалить аккаунт сам.

**Гипотеза.** Читатель, нашедший материал через поиск или рубрику, подпишется на автора и
вернётся; возвраты видны по агрегатам прочтений без профилирования.

## 2. Что входит

- **Поиск** (ADR-0025): миграция M14, `searchVector`, страница `/search` со сниппетами и
  фильтрами, подсказки, контрольный набор запросов, бенчмарк.
- **Подборки**: `Collection`, страницы `/collections`, админка подборок.
- **Прочтения и «популярное»** (ADR-0027): миграция M12, событие прочтения, суточные соли,
  агрегаты, блок «Популярное» с подписью, housekeeping.
- **Подписка на автора** (ADR-0026): `AuthorFollow`, кнопка на странице автора, письмо при
  публикации не чаще раза в день на автора, одноразовая отписка, `User.locale` для языка
  писем (миграция M13).
- **Экспорт** своих материалов в Markdown и HTML из кабинета (пакет `content`).
- **Самостоятельное удаление аккаунта** и выгрузка данных (JSON) из кабинета по ADR-0014.
- **Навигация из данных**: `/types` → рубрики, `/tags`, `/authors` — реальные списки с
  пагинацией; фикстуры удалены полностью.
- **Доступность и бюджеты как гейты CI**: axe в Playwright, Lighthouse CI, состояния
  загрузки/пустоты/ошибки у всех списков, скриншот-тесты.
- **Генерация OG-изображений** для материалов и авторов.
- **Дизайн-система доведена** до всех публичных страниц (`06-design-system.md` §4–6).

## 3. Что сознательно не входит

- Комментарии, реакции, закладки.
- Внешний поисковый движок; персонализация; рекомендации.
- Рассылка редакции — этап 5; деньги — этап 4.
- OAuth (только по измеренной потере на входе, ADR-0022).

## 4. От чего зависит и что разблокирует

**Зависит от**: этапа 1 (модель v2, страницы); частично этапа 2 (SEO-инфраструктура для OG).

**Разблокирует**: этап 4 (подписка на автора — воронка поддержки; прочтения — метрики).

## 5. Definition of Done

1. `/search?q=` работает на `tsvector` с ранжированием и сниппетом; бенчмарк на сиде 10 000
   материалов: p95 < 300 мс (скрипт в репозитории, результат в отчёте).
2. Контрольный набор из 50 запросов (ru/en, словоформы) даёт ожидаемый топ-3
   (фикстура-тест); нулевые выдачи логируются без персональных данных.
3. `Collection` с упорядоченными материалами; `/collections/{slug}` рендерится; админка
   подборок работает (тест).
4. Событие прочтения не хранит IP и cookie; агрегат `uniqueReads` за 7 дней; блок
   «Популярное» подписан «по числу прочтений за неделю»; метод описан в политике ПД;
   housekeeping удаляет события старше 8 дней и соли старше 2 дней (тест с подменой времени).
5. Подписка на автора: письмо при публикации с одноразовой отпиской (тест); не более одного
   письма на автора в день; `followersNotifiedAt` делает отправку идемпотентной.
6. Экспорт материала в Markdown и HTML из кабинета совпадает со снимками (тест round-trip).
7. Удаление аккаунта из кабинета с подтверждением по письму выполняет анонимизацию и архив
   по умолчанию, вариант «оставить с подписью» работает; выгрузка данных отдаёт JSON (тесты).
8. axe в Playwright: 0 critical/serious на всех публичных страницах; чек-лист клавиатуры и
   контраста заполнен в отчёте; скриншот-тесты состояний загрузки, пустоты, ошибки.
9. Lighthouse CI в PR: LCP < 2,5 с и JS < 150 КБ на странице материала; превышение — красный
   CI.
10. `/types`, `/tags`, `/authors` — реальные списки; `grep -rn "mock" web/app` = 0.

## 6. Риски и способ их снять

| Риск | Снятие |
|---|---|
| Уникальные прочтения против 152-ФЗ | Только хэш с суточной солью, IP не хранится, описание в политике ПД |
| Русский стемминг даёт плохую выдачу | Контрольный набор запросов; `pg_trgm` для подсказок и опечаток; критерий перехода в ADR-0025 |
| Репутация домена при рассылке подписчикам | SPF/DKIM/DMARC, дайджест не чаще раза в день, отписка в один клик |
| Деградация производительности при доводке дизайна | Бюджеты как гейт CI с первого дня этапа |
| Доступность превращается в редизайн | Чек-лист и axe по компонентам, а не по страницам; исправления точечные |

## 7. Оценка

14–20 человеко-дней. Из них: поиск с бенчмарком 3–4; подборки 1–2; прочтения и популярное
2–3; подписка на автора 2–3; экспорт и удаление 2–3; доступность, бюджеты, OG, доводка
страниц 3–5.

## 8. Метрики успеха

- Поисков в день; доля нулевых выдач < 20 %.
- Медиана подписчиков на автора; доля прочтений по переходам из писем.
- Возвраты: доля хэшей, встреченных ≥ 2 дня за неделю (агрегат, без профилирования).
- Нарушений доступности в CI: 0; бюджеты соблюдены.
- Число экспортов и удалений аккаунта (сигнал доверия и оттока).
