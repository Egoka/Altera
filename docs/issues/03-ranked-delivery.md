## 1. Цель и продуктовая гипотеза

**Цель.** Ленты главной, рубрик, тегов и авторов сортируются по материализованному рейтингу
статьи из названных компонентов: соответствие теме, давность, рейтинг автора, просмотры,
AI-оценка, pro-буст. Веса меняются из админки с аудитом; пересчёт детерминирован; автор видит
разложение рейтинга своей статьи, читатель — словесное объяснение; накрутка обнаруживается.

**Гипотеза.** Рейтинговая выдача поднимает наверх лучшие материалы, авторы понимают, почему
их статья там, где она есть, и pro покупают ради заметности.

## 2. Что входит

- **Прочтения** (ADR-0038, ADR-0027): миграция прочтений, событие с порогом, суточные соли,
  `ReadEvent`, `ArticleReadDaily`, housekeeping; прочтения автору по дням в
  `/me/articles/{id}/stats` (pro) и суммой (standard).
- **Рейтинг** (ADR-0034): `ArticleScore(articleId, score, components, configVersion,
  computedAt)`, `AuthorScore`, `RankingConfig` с версией и `changedById`; пересчёт по
  расписанию и по событиям (публикация, буст, оценка, суточное закрытие прочтений); индекс
  под ленты; резолвер `feed(scope, locale, cursor)`; временная сортировка по дате уходит.
- **Компоненты**: соответствие теме (рубрика и теги против контекста ленты), давность с
  затуханием, рейтинг автора (грейд ADR-0037 плюс история), просмотры за окно, AI-оценка
  (ADR-0039) с переопределением, буст (ADR-0040) — по спецификациям `60-ranking/`.
- **Pro-буст**: `ArticleBoost` при публикации pro-автором; аддитивный вход на 24 часа; лимит в
  сутки; досрочное завершение при снятии, блокировке, истечении.
- **Секции главной** по утверждённым принципам (Г4): «Главное», секции рубрик, «Новое»,
  «Авторы»; подписи словами; `RankExplainer` на странице материала.
- **Антинакрутка**: правила аномалий прочтений, пометка подозрительных дней, исключение
  ревьюером с аудитом `reads.exclude`, лог событий.
- **Админка**: «AI-оценки» (список, переопределение, повтор), «Конфигурация рейтинга» (веса,
  окна, буст, версия, история), разложение баллов в статистике для `analyst`.
- **Кабинет автора**: разложение рейтинга статьи, активные бусты, AI-оценка с критериями.

## 3. Что сознательно не входит

- Персонализация и рекомендации (ADR-0034).
- Поиск, SEO целиком, AI-перевод — этап 3.
- Закладки как вход рейтинга (ADR-0041).
- Внешняя аналитика.

## 4. От чего зависит и что разблокирует

**Зависит от**: этапа 1 (материалы, авторы с планом и грейдом, AI-оценки, админка); гейта Г4
(веса, секции, лимит бустов).

**Разблокирует**: этап 3 (поиск с рейтингом как вторичным ключом, страницы по рейтингу) и
этап 4 (отчёты).

## 5. Definition of Done

1. Событие прочтения не хранит IP и cookie; `uniqueReads` по дням; housekeeping удаляет события
   старше 8 дней и соли старше 2 дней (тест с подменой времени); метод описан в политике ПД.
2. Пересчёт детерминирован: одинаковые входы и конфигурация — одинаковый балл (тест на
   фикстуре); монотонность по просмотрам и по AI-оценке (тесты); отсутствие входа (нет
   прочтений, нет оценки) не роняет пересчёт.
3. Смена весов из админки создаёт новую версию `RankingConfig` с аудитом; старые
   `ArticleScore` хранят версию; пересчёт применяет новую (тест).
4. Буст: публикация pro-автором создаёт `ArticleBoost` на 24 часа; сверх лимита — без буста с
   предупреждением; истечение подписки завершает буст досрочно; повторная ревизия буст не
   возобновляет (тесты); читатель пометки не видит, бейдж автора видит.
5. Все публичные ленты идут через `feed` по `ArticleScore`; `grep` резолверов на сортировку по
   `publishedAt` в лентах = 0 (кроме RSS и sitemap); подписи секций из данных.
6. Страница материала показывает `RankExplainer` без чисел; кабинет автора показывает
   разложение с числами и активные бусты (e2e).
7. Антинакрутка: сценарий «100 прочтений с одного диапазона за минуту» помечается; ревьюер
   исключает день, рейтинг пересчитывается, аудит записан (тест).
8. `analyst` видит разложение баллов и агрегаты, не видит пользователей (контрактный тест).

## 6. Риски и способ их снять

| Риск | Снятие |
|---|---|
| Формула не даёт хорошей выдачи на малом числе материалов | Веса — параметры; сравнение выдачи на сиде из 200 материалов до включения; фолбэк на дату при пустых входах |
| Уникальные прочтения против 152-ФЗ | Только хэш с суточной солью, IP не хранится, описание в политике ПД |
| Накрутка просмотров pro-авторами | Аномалии, исключение, лимит бустов, аудит; при повторах — блокировка |
| Пересчёт дорог при росте базы | Инкрементальный пересчёт по событиям, полный — ночью; индекс по `score` |
| Авторы спорят с рейтингом | Разложение в кабинете и словесное объяснение читателю; веса не публикуются |

## 7. Метрики успеха

- Доля лент по рейтингу: 100 %; детерминизм: 0 расхождений.
- Доля материалов с AI-оценкой; доля переопределённых оценок.
- Доля бустнутых публикаций; переход standard → pro после запуска рейтинга.
- Доля дней с исключёнными прочтениями; число обращений авторов по рейтингу.
