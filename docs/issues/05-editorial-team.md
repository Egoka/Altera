# Этап 4 — Редакция работает как команда

- **Файл**: пятый по порядку выполнения; этап 4. Ревизия 2 (2026-09-06); ревизия 1 —
  `06-editorial-team.md` (исторический): сюда переехали замечания к блокам, ревизии в
  интерфейсе и аудит-интерфейс из отменённого этапа 2; отборы и заказные материалы удалены.
- **Решения**: ADR-0007, ADR-0008, ADR-0017, ADR-0026, ADR-0029, ADR-0042, ADR-0045.
- **Документы**: `docs/vision/05-editor.md` §4, §5, §7, §10; `04-roles-and-access.md` §5;
  `03-data-model.md` §1.2, §1.5.

## 1. Цель и продуктовая гипотеза

**Цель.** Несколько ревьюеров и редакторов работают на одном движке без ручных обходов:
замечания к блокам и ревизии в интерфейсе, аудит с фильтрами, медиа-библиотека, библиотека
блоков для фоторассказов и интервью, расширенные отчёты для аналитика, рассылка, шаблоны
материалов.

**Гипотеза.** Редакция из нескольких человек держит SLA проверки; блоки этапа 4 используются
в заметной доле новых материалов.

## 2. Что входит

- **Замечания к блокам**: `ReviewNote(blockId)`, привязка к стабильному `attrs.id`; автор видит
  замечания рядом с блоком, отмечает «исправлено»; редактор закрывает; замечания к удалённому
  блоку — в общем списке.
- **Ревизии в интерфейсе**: список, просмотр, восстановление с `restoredFromId`;
  `editorial`-ревизии подписаны редактором; история решений по материалу.
- **Аудит-интерфейс**: просмотр `audit_log` с фильтрами по объекту и актору; полное покрытие
  списка `04-roles-and-access.md` §5.
- **Библиотека блоков** (ADR-0017; каталог — отдельный проход `docs/spec/95-blocks/`): галерея,
  видео, аудио, врезка, embed из allow-list, таблица, колонки; каждый блок — узел схемы,
  рендерер, интерфейс, снимок-тест; `MediaKind` расширяется.
- **Медиа-библиотека**: сетка, поиск, фильтр по лицензии, переиспользование, замена файла с
  сохранением ссылок, кадрирование и фокусная точка, физическая чистка неиспользуемых;
  жалобы на медиа.
- **Расширенные отчёты**: контент по рубрикам и неделям, аудитория (прочтения, подписчики),
  подписки и выручка, AI-стоимость, рейтинг — SQL и экраны для `analyst`.
- **Рассылка** (ADR-0026): double opt-in, выпуск из топа рейтинга в том же редакторе,
  отправка через провайдера, отписка в один клик.
- **Шаблоны материалов**: заготовки структуры документа по рубрике или формату.
- **Параллельная работа редакции**: пометка «редактирует X» до этапа 5; тесты прав на двух
  учётках; распределение очереди между ревьюерами.

## 3. Что сознательно не входит

- Совместное редактирование в реальном времени и сравнение версий — этап 5.
- Комментарии читателей; редакционные роли по рубрикам.
- Транскодирование видео и аудио: загрузка в поддерживаемых форматах.

## 4. От чего зависит и что разблокирует

**Зависит от**: этапа 2 (рейтинг для выпусков рассылки и отчётов); гейта «учётки редакции».

**Разблокирует**: этап 5.

## 5. Definition of Done

1. Замечание к блоку создаётся редактором, видно автору рядом с блоком, закрывается после
   «исправлено»; замечание к удалённому блоку видно в общем списке (тесты, e2e).
2. Список ревизий, просмотр, восстановление создаёт новую ревизию с `restoredFromId`;
   `editorial`-ревизия подписана (тест).
3. `audit_log` покрывает весь список §5 (тест-перечень); записи не изменяются и не удаляются;
   интерфейс просмотра с фильтрами.
4. Каждый новый блок имеет узел схемы, рендерер, интерфейс, снимок-тест и запись в
   `docs/spec/95-blocks/`; embed вне allow-list отклоняется; контейнер в контейнере
   отклоняется схемой (тесты).
5. Медиа-библиотека: чистка не удаляет ничего, на что есть ссылка из версии, ревизии или
   обложки (тест); замена файла сохраняет ссылки.
6. Отчёты считаются SQL из репозитория и открываются `analyst`; экспорт CSV без ПДн (тест).
7. Рассылка: double opt-in, выпуск собирается из топа, отправляется через провайдера, отписка в
   один клик, согласие с датой и версией (тесты; e2e через Mailpit).
8. Шаблон создаёт заготовку структуры документа; выбирается при создании материала (тест).
9. Два ревьюера работают параллельно: пометка «редактирует X» видна второму; очередь
   распределяется без двойного решения (тест).

## 6. Риски и способ их снять

| Риск | Снятие |
|---|---|
| Взрыв блоков и их вариантов | Спецификация каждого блока до кода; правило границы свободы (ADR-0017) |
| Рассылка и требования к рекламе и ПДн | Double opt-in, только редакционный контент, консультация при появлении рекламы |
| Рост `audit_log` | Ретенция и индексы по объекту и актору; архивация старше года |
| Медиа-чистка удаляет нужное | Только по отсутствию ссылок из всех мест хранения; пометка, удаление через 30 дней |

## 7. Метрики успеха

- Медиана «отправлено → решение» при ≥ 2 ревьюерах ≤ 48 часов.
- Доля новых материалов с блоками этапа 4; коэффициент переиспользования медиа.
- Покрытие аудита: 100 %.
- Подписчики рассылки и доля переходов (без пикселей).
