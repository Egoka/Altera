# E-04: Вход, сессии и лимиты

- **Стадия роадмапа**: Бесплатный запуск
- **Результат**: Единственный вход по ссылке из письма, ротация refresh, выход, httpOnly-cookie через BFF, серверные лимиты частоты, страница сессий без геолокации.
- **Источники**: ADR-0009, ADR-0022, ADR-0023, ADR-0024; `50-access/session-lifecycle.md`, `rate-limits.md`; журнал #55, #57, §25.8–9
- **Зависит от эпиков**: E-02, E-03
- **Блокеры владельца**: Q-01, Q-04
