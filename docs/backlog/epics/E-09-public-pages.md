# E-09: Публичные страницы

- **Стадия роадмапа**: Бесплатный запуск
- **Результат**: Главная с подборками по дате, ленты и списки из данных, страница материала с единым `alt`, страница автора, служебные и юридические страницы, «О проекте», «Письмо в редакцию», цены без цен, оспаривание блокировки; адресация локалей.
- **Источники**: ADR-0002, ADR-0004, ADR-0034; `20-public/*`; журнал §20, §22.4–5, §24.1–2, §28.2
- **Зависит от эпиков**: E-05, E-14
- **Блокеры владельца**: Q-05, Q-09
