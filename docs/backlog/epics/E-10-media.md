# E-10: Медиа

- **Стадия роадмапа**: Бесплатный запуск
- **Результат**: Конвейер загрузки по утверждённым принципам: карантин, мастер-файл без EXIF, AVIF и WebP, аватары с немедленным применением, обязательные обложки, единое AI-`alt`, подписанные ссылки, сироты.
- **Источники**: ADR-0008, ADR-0030; `85-media-and-binary/*`; журнал #28, §29; заметка владельца о конвейере медиа
- **Зависит от эпиков**: E-03, E-08
- **Блокеры владельца**: Q-01, Q-03
