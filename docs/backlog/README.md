# Бэклог Altera: индекс и правила

- **Статус**: подготовлен 2026-09-09 ревизией роадмапа (план `docs/plans/2026-09-09-roadmap-revision-and-backlog.md`); ни одна задача не отмечена `готова` — это делает владелец
- **Источники по старшинству**: журнал решений `docs/decisions/role-review-working-log-2026-09-08.md` → `docs/spec/` (включая `OPEN-QUESTIONS.md`) → ADR, `docs/vision/`, `docs/issues/00-roadmap.md`. При расхождении журнал главнее всего.
- **Операционная модель**: `docs/multica/operating-model.md` — читается перед планированием и исполнением любой задачи.

## 2. Идентификаторы и статусы
- `E-NN` эпик, `T-NNN` задача, `Q-NN` блокер владельца, `F-NN` будущий этап. Номера сквозные и не переиспользуются.
- Статусы задачи: `кандидат` (нет зависимостей и блокеров; предлагается владельцу), `зависит: T-…`, `решение владельца: Q-…`, `отложена: F-…`, `готова` (ставит владелец), `в работе`, `завершена` (после актуальной проверки и независимого ревью, где оно указано).
- Задача со ссылкой на «отложено» или `[ВОПРОС ВЛАДЕЛЬЦУ]` по существу не может быть `кандидат`.

## 3. Формат задачи (десять обязательных полей)
Шапка: эпик, статус, параллельность, роль-исполнитель, участники стадий, навыки. Разделы: 1 результат; 2 источники (журнал, спецификации, ADR); 3 границы и явно исключённое; 4 зависимости и что разблокирует; 5 критерии готовности и способ проверки; 6 доказательство; 7 пометки `[ФАКТ]`/`[ДОПУЩЕНИЕ]`; 8 требует решения владельца. Шаблон — `_templates/task.md`.

Запрещено в задачах: оценки в человеко-днях, цены, числовые лимиты и провайдеры, которых нет в журнале или спецификациях; пересказ спецификаций вместо ссылок; слова словаря ревизии 1 («витрина», «контур», «отбор», «правило-арбитр», «AI-оценка», «балл», «словесное объяснение»).

## 4. Как менять бэклог
1. Новая задача — только из источника (решение журнала, строка реестра, файл спецификации). Задача без источника не создаётся.
2. Изменение статуса `готова` — только владелец; `завершена` — хранитель документации после evidence по операционной модели.
3. После правки файлов задач пересобираются `matrix.md`, `coverage.md`, `ready-candidates.md` и таблицы в `README.md` и эпиках (скрипт из отчёта ревизии).
4. Ответ владельца на `Q-NN` вносится в журнал, затем меняются статусы задач; строка блокера получает «закрыт §N».
5. Устаревшая задача помечается `отменена: причина`, файл не удаляется.
