## 1. Результат

`/offline` переходит только на адреса своего сайта, а страница ошибки показывает 403 и прочие не-404 статусы по их смыслу, а не как сбой сервера.

Доработка по итогам независимого ревью 2026-09-26: T-058 (ALTE-105, PR #187).

## 3. Границы и явно исключённое

- Входит:
  - `?from=` принимается только как путь того же источника: отклоняются `//…`, `/\…`, схемы и управляющие символы.
  - `error.vue`: 403 и другие статусы клиента не показываются страницей 500 с `requestId`.
  - `requestId` ошибки не переиспользуется между ошибками одной SPA-сессии.
- Не входит:
  - Service worker — вне первого запуска (§35 п. 3).
- Сохраняемый контракт: Маршруты `/offline`, `error.vue`, `no-store` для 500.
