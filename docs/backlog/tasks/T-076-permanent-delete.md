# T-076: «Удалить навсегда»: только `owner`, только из архива, ввод имени сущности, полный аудит

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-072, T-073, T-062
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор (каскад); дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma, S3, Nuxt 4

## 1. Результат
`owner` необратимо удаляет пользователя, статью, служебную запись, рубрику или тег из архива после диалога с вводом имени; каскад по типам; аудит и агрегаты остаются; слаг и хэндл заняты навсегда; подтверждения второго сотрудника не требуется; событие `entity.delete.permanent`.

## 2. Источники
- Журнал: #1, #49, §26.10
- Спецификации: `docs/spec/10-flows/permanent-delete.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Мутации и диалог.
- Не входит: Обезличивание финансовых записей (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-072, T-073, T-062
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Удаление неархивированной сущности → `CONFLICT` — проверка: тест.
2. Запись аудита остаётся после удаления сущности — проверка: тест.
