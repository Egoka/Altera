## 1. Результат

Выдача, отзыв и истечение плана сразу меняют роль и кэш плана пользователя; на первом запуске любой зарегистрированный читатель получает базовое авторство при первом «Создать статью» независимо от прежних выдач; базовые выдачи не видны и не отзываются в `/admin/grants`.

Доработка по итогам независимого ревью 2026-09-26: T-037 (ALTE-84, PR #159), T-084 (ALTE-82, PR #135); бейдж pro на публичных страницах.

## 3. Границы и явно исключённое

- Входит:
  - `grantPlan` и `revokePlan` в той же транзакции пересчитывают `role`, `planTier`, `planUntil` по действующим выдачам.
  - Истечение срочной выдачи отражается в кэше (задание очереди или пересчёт при чтении — выбор разработчика).
  - `enableBaseAuthorship`: на первом запуске истёкшая или отозванная админская выдача не закрывает базовое авторство (§24.1; `plan-free.md` п. 3 действует только после включения платности).
  - `listAdminGrants` не показывает базовые выдачи; `revokePlan` их отклоняет (§27.1: только архивированием аккаунта).
  - Тест «истёкший план снимает бейдж» проверяет реальный путь, а не подставленный `planTier`.
- Не входит:
  - Экран грантов, пагинация и фильтры — отдельные замечания T-084, не блокируют.
  - Поведение после включения платности — этап F-01.
- Сохраняемый контракт: `PLAN_LIMIT` для действительно закрытых действий; аудит `plan.grant`, `plan.revoke`, `author.enabled`.

## 5. Критерии готовности и способ проверки

- **AC-1**: читатель с действующей админской выдачей создаёт статью; проверка: серверный тест через `grantPlan`.
- **AC-2**: после отзыва срочной выдачи кэш плана соответствует оставшимся выдачам; проверка: тест на PostgreSQL.
- **AC-3**: читатель с истёкшей админской выдачей на первом запуске получает базовое авторство при первом «Создать статью»; проверка: тест.
- **AC-4**: базовая выдача не возвращается `adminGrants` и не отзывается `revokePlan` (ответ — ошибка); проверка: тест.
- **AC-5**: выданный pro показывает бейдж pro на публичной странице автора, истёкший — снимает; проверка: тест без подстановки `planTier`.
