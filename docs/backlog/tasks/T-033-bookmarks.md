# T-033: Закладки: страница `/me/bookmarks` и кнопка на материале; недоступные материалы серым

- **Эпик**: E-06 Кабинет читателя
- **Статус**: зависит: T-017, T-027
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga

## 1. Результат
Любой аккаунт (кроме служебных) сохраняет материалы в закладки; недоступный материал остаётся в списке серым с перечёркиванием; автору доступно только число закладок; события `bookmark.add/remove`.

## 2. Источники
- Журнал: #58, §25.10
- Спецификации: `docs/spec/30-account/reader/bookmarks.md`, `docs/spec/10-flows/bookmark-and-follow.md`, `docs/spec/20-public/article.md`
- ADR: ADR-0041

## 3. Границы и явно исключённое
- Входит: Страница, кнопка, мутации.
- Не входит: Подписка на автора (F-10); закладки как сигнал рейтинга (F-02).

## 4. Зависимости и что разблокирует
- Зависит от: T-017, T-027
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Архивированный материал остаётся в закладках в состоянии «недоступен» — проверка: тест + Playwright.
2. Служебная роль получает `FORBIDDEN` на `bookmark.add` — проверка: тест.

## 6. Доказательство результата
Тесты, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
