# T-030: Сводка кабинета `/me`

- **Эпик**: E-06 Кабинет читателя
- **Статус**: зависит: T-022, T-026
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue, i18n

## 1. Результат
Сводка кабинета по `dashboard.md`: состояние аккаунта, кнопка «Создать статью» (первый запуск — без плана), ссылки на разделы; служебные роли видят вход в админку, не кабинет автора.

## 2. Источники
- Журнал: §24.1, §25.1, §25.2
- Спецификации: `docs/spec/30-account/reader/dashboard.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Страница и запрос сводки.
- Не входит: Разделы кабинета — отдельные задачи.

## 4. Зависимости и что разблокирует
- Зависит от: T-022, T-026
- Разблокирует: T-036

## 5. Критерии готовности и способ проверки
1. Все строки состояний `dashboard.md` воспроизводимы — проверка: Playwright.
2. Для служебной записи сводка ведёт в `/admin` — проверка: e2e.

## 6. Доказательство результата
Playwright, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
