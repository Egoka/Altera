# T-084: Гранты `/admin/grants` и подписки `/admin/subscriptions` в режиме первого запуска: только ручные выдачи

- **Эпик**: E-12 Админка II
- **Статус**: зависит: T-069, T-017
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue, GraphQL Yoga

## 1. Результат
Ручная выдача плана и дней (`plan.grant`/`plan.revoke`) с аудитом; раздел подписок показывает только выдачи и пояснение об отдельном этапе платности; базовое авторство первого запуска в разделе не показывается (только признак в карточке пользователя); промокоды не реализуются.

## 2. Источники
- Журнал: #19, #25, §8.16, §24.1, §27.1
- Спецификации: `docs/spec/40-admin/grants-and-promo.md`, `docs/spec/40-admin/subscriptions.md`, `docs/spec/70-plans-and-billing/grants-and-promo.md`
- ADR: ADR-0035 (частично заменён журналом Г5–Г5b)

## 3. Границы и явно исключённое
- Входит: Выдачи и просмотр.
- Не входит: Промокоды, платежи, возвраты, цены (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-069, T-017
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Выдача без срока — по спецификации `grants-and-promo.md` (`VALIDATION_ERROR`), при этом базовая выдача первого запуска бессрочна — противоречие снимает T-110; до этого тест на бессрочную выдачу помечен `todo`.
2. Все строки состояний обоих разделов для первого запуска воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Playwright, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
