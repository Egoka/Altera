# T-005: Линт-правила и гигиена: запрет `console.log`, `.output` вне линта, удаление мёртвого кода

- **Эпик**: E-01 Инженерная база и честный CI
- **Статус**: кандидат
- **Параллельность**: да: только линт-конфигурация и удаление мёртвых файлов; конфликтует с любой активной кодовой цепочкой в `web/`
- **Роль-исполнитель**: разработчик
- **Участники стадий**: ревью — независимый ревьюер
- **Навыки**: ESLint, Nuxt 4

## 1. Результат
ESLint запрещает `console.log` вне логгера, игнорирует `.output`; демо-страницы доступны только в dev; мёртвые компоненты, `process.client` и `@neondatabase/serverless` удалены; `migrate deploy` вынесен из `build`.

## 5. Критерии готовности и способ проверки
1. `pnpm lint` проходит; `console.log` в `server/src` вызывает ошибку линта — проверка: временная вставка.
2. Маршруты `routes.md` #69 (`/fonts-showcase`, `/components-showcase`, `/test-error`) отвечают 404 в прод-сборке — проверка: curl после T-004.
3. `pnpm --filter server build` не запускает `prisma migrate deploy` — проверка: скрипт `build`.
