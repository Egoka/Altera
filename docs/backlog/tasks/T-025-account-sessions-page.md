# T-025: Страница «Сессии и устройства» `/me/sessions` без геолокации по IP

- **Эпик**: E-04 Вход, сессии и лимиты
- **Статус**: зависит: T-023
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue

## 1. Результат
Пользователь видит список своих сессий (устройство, время, текущая), завершает одну или все; местоположение по IP не показывается; служебная роль `analyst` сессий не видит.

## 2. Источники
- Журнал: §25.9, §26.6
- Спецификации: `docs/spec/30-account/reader/sessions.md`
- ADR: ADR-0009

## 3. Границы и явно исключённое
- Входит: Страница и запросы/мутации.
- Не входит: Просмотр сессий пользователя из админки — не входит (§26.6).

## 4. Зависимости и что разблокирует
- Зависит от: T-023
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Все строки состояний `sessions.md` воспроизводимы — проверка: Playwright.
2. В ответе API нет поля геолокации — проверка: контрактный тест.

## 6. Доказательство результата
Playwright, контрактный тест. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.

## 8. Требует решения владельца
