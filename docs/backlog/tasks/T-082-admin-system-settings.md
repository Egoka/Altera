# T-082: Настройки системы `/admin/settings`: чтение без секретов, `settings.change` с аудитом

- **Эпик**: E-12 Админка II
- **Статус**: зависит: T-069
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue

## 1. Результат
Раздел показывает системные настройки без секретов; `admin` читает, изменения только по правам с аудитом `settings.change`; настройки провайдеров — отдельный этап.

- Журнал: #36, §28.11

- ADR: не применимо

- Не входит: Управление интеграциями (F-08).

## 4. Зависимости и что разблокирует

2. Все строки состояний `system-settings.md` воспроизводимы — проверка: Playwright.
