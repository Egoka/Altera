# T-068: Медиа-сироты: потеря связи после замены или отвязки, регулярное удаление без активных связей, без уведомления автора

- **Эпик**: E-10 Медиа
- **Статус**: зависит: T-047, T-063
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Фоновые задания, S3

## 1. Результат
Файл без активных связей становится сиротой; регулярное задание физически удаляет только медиа без связей; автор не уведомляется; медиа архивированной статьи закрыто вместе с ней, но не удаляется.

## 2. Источники
- Журнал: #28, §29.8
- Спецификации: `docs/spec/85-media-and-binary/retention-and-orphans.md`
- ADR: ADR-0008

## 3. Границы и явно исключённое
- Входит: Выборка сирот, задание удаления.
- Не входит: Замена файла с сохранением ссылок (F-04).

## 4. Зависимости и что разблокирует
- Зависит от: T-063, T-047
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Медиа архивированной статьи не попадает в выборку сирот — проверка: тест.
2. Удаление сироты не создаёт уведомления — проверка: тест истории писем.

## 6. Доказательство результата
Тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Интервал обслуживания определяется отдельным проходом (§29.8).
