## 1. Результат

Сводка `/me` не обещает, что бесплатен только первый материал, и не ведёт в тупик «Выбрать план»: на первом запуске пользователь всегда видит путь к созданию статьи.

Доработка по итогам независимого ревью 2026-09-26: T-030 (ALTE-107, PR #193).

- Входит:
  - Текст приглашения писать — по спецификации («Написать первый материал»), без слов о бесплатности только первого.
  - Состояние «выдача истекла, статей нет»: «Создать статью» видна; «Выбрать план» не показывается до включения платности.
  - `Cache-Control: private, no-store` для `/me` (§4).
- Не входит:
  - Логика прав на создание — T-128.
- Сохраняемый контракт: Состояния и строки `dashboard.md` §8; e2e `web/tests/e2e/30-account-dashboard.spec.ts`.
