# T-055: Лента рубрики, лента тега, списки рубрик, тегов и авторов из данных

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-054, T-014
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga

## 1. Результат
Страницы `/{рубрика}`, `/tags/{слаг}`, `/sections`, `/tags`, `/authors` на данных с пагинацией и фильтрами по спецификациям; пустые и архивные рубрики и теги скрыты; порядок «по дате» до запуска рейтинга.

## 2. Источники
- Журнал: §20.9, §22.5
- Спецификации: `docs/spec/20-public/section-feed.md`, `docs/spec/20-public/tag-feed.md`, `docs/spec/20-public/sections-index.md`, `docs/spec/20-public/tags-index.md`, `docs/spec/20-public/authors-index.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Пять страниц и их запросы.
- Не входит: Подписка на автора (F-10); выбор порядка «по рейтингу» (F-02).

## 4. Зависимости и что разблокирует
- Зависит от: T-054, T-014
- Разблокирует: T-057

## 5. Критерии готовности и способ проверки
1. Все строки состояний пяти спецификаций воспроизводимы — проверка: Playwright.
2. Архивная рубрика отвечает 301 на преемника — проверка: curl после T-070.

## 6. Доказательство результата
Playwright, curl. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
