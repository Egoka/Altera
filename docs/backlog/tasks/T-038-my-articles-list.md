# T-038: «Мои материалы» `/me/articles` с фильтрами архив и отклонённые

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: зависит: T-015, T-026
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue

## 1. Результат
Список материалов автора по статусам с фильтрами `archived` и `rejected`, отклонённые доступны для чтения и копирования; общие показатели без внутренних коэффициентов.

## 2. Источники
- Журнал: #12, §25.5
- Спецификации: `docs/spec/30-account/author/articles.md`
- ADR: не применимо

- Входит: Страница и запрос `myArticles`.
- Не входит: Общий результат статьи в списке — OPEN-QUESTIONS #6 (Q-08), до решения не показывается.

## 4. Зависимости и что разблокирует

## 5. Критерии готовности и способ проверки

2. Отклонённый материал открывается только на чтение — проверка: тест.

## 6. Доказательство результата
