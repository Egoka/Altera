# T-072: Статьи `/admin/articles` по версиям: карточка, архив сотрудником, окончательный отказ

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-069, T-045, T-050
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue, GraphQL Yoga

## 1. Результат
Список версий с фильтрами и поиском, карточка (лид, обложка, ревизия на чтение, история решений, кто архивировал); архив `moderator`/`admin`/`owner` без разархивирования, восстановление только `owner`; текст не редактируется; точные числа чтений.

- Спецификации: `docs/spec/40-admin/articles.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Раздел и мутации сотрудника.
- Не входит: Удалить навсегда (T-076); решения ревьюера (T-050).

- Зависит от: T-069, T-045, T-050

## 5. Критерии готовности и способ проверки

2. `admin` не может восстановить статью — проверка: тест.
