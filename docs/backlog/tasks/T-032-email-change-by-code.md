# T-032: Смена почты по коду без завершения сессий

- **Эпик**: E-06 Кабинет читателя
- **Статус**: зависит: T-021, T-023
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, модуль почты

## 1. Результат
Смена адреса: код на новый адрес в том же окне, уведомление на старый, без повторного входа и без отзыва сессий; `user.email.change` в аудите; восстановление доступа по flow #13.

## 2. Источники
- Журнал: §25.8
- Спецификации: `docs/spec/30-account/reader/email-change.md`, `docs/spec/10-flows/email-change-and-recovery.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Страница `/me/email`, мутации, письма через T-021.
- Не входит: Тексты писем (F-05) — `[ДОПУЩЕНИЕ]`.

## 4. Зависимости и что разблокирует
- Зависит от: T-021, T-023
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. После смены адреса все сессии остаются активными — проверка: тест.
2. Все строки состояний `email-change.md` воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
