# T-065: Аватары: загрузка, кадрирование, немедленное применение, предыдущая версия, откат ревьюером

- **Эпик**: E-10 Медиа
- **Статус**: зависит: T-063
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: sharp, GraphQL Yoga

## 1. Результат
Аватар после технической обработки применяется публично сразу; предыдущая версия сохраняется; ревьюер может вернуть её с журналированием; удаление аватара → инициалы; служебные записи без аватара.

## 2. Источники
- Журнал: §25.4, §29.5
- Спецификации: `docs/spec/85-media-and-binary/avatars.md`, `docs/spec/30-account/reader/profile-edit.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Загрузка, применение, откат.
- Не входит: Автоматическая проверка (T-031 через адаптер T-048).

## 4. Зависимости и что разблокирует
- Зависит от: T-063
- Разблокирует: T-031, T-057

## 5. Критерии готовности и способ проверки
1. После загрузки новый аватар виден гостю без ожидания проверки — проверка: e2e.
2. Откат ревьюером пишет запись журнала и возвращает предыдущую версию — проверка: тест.

## 6. Доказательство результата
Тесты, e2e. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
