# T-066: Обложки: обязательны перед публикацией, индивидуальны, кадрирование с предпросмотром и фокусом

- **Эпик**: E-10 Медиа
- **Статус**: зависит: T-064
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: sharp, Nuxt 4

## 1. Результат
Обложка — обязательное поле подачи; выбор кадрирования с предпросмотром по фокусной точке, варианты под карточки; общая для языковых версий; дефолтных обложек в лентах нет.

## 2. Источники
- Журнал: §29.1
- Спецификации: `docs/spec/85-media-and-binary/article-covers.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Обложка в редакторе и вариантах.
- Не входит: Правка обложки опубликованной без снятия — противоречие `article-covers.md` п. 5 с матрицей #19 (Q-12).

## 4. Зависимости и что разблокирует
- Зависит от: T-064
- Разблокирует: T-040

## 5. Критерии готовности и способ проверки
1. Подача без обложки → `VALIDATION_ERROR` — проверка: тест.
2. Карточка в ленте не показывает заполнитель для опубликованного материала — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
