# T-086: Словарь кодов ошибок и структурированный логгер

- **Эпик**: E-13 Наблюдаемость
- **Статус**: кандидат
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, pino или аналог, TypeScript

## 1. Результат
Все ошибки API — `GraphQLError` с `extensions.code` из словаря (#1–11, #89 `ARCHIVED`), внутренние маскируются в `INTERNAL_ERROR`; `PROVIDER_UNAVAILABLE` со значением провайдера, включая `storage`; JSON-логгер с обязательными полями по политике; ПД в логах только хэшами.

## 2. Источники
- Журнал: §28.2, §29.3
- Спецификации: `docs/spec/80-observability/error-dictionary.md`, `docs/spec/80-observability/logging-policy.md`, `docs/spec/00-registries/events-and-logs.md`
- ADR: ADR-0032

## 3. Границы и явно исключённое
- Входит: Словарь, логгер, обёртка ошибок.
- Не входит: Трассировка (T-087); сборщик (T-089).

## 4. Зависимости и что разблокирует
- Зависит от: нет
- Разблокирует: T-047, T-087, T-088, T-089, T-091

## 5. Критерии готовности и способ проверки
1. Неизвестная ошибка резолвера приходит клиенту как `INTERNAL_ERROR` без стека — проверка: тест.
2. Тест «в логах нет e-mail в открытом виде» проходит.
