# T-075: Статистика `/admin/statistics`: рост, контент, AI, топ-таблицы, точные значения

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-069, T-049
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
