# T-036: Подписка `/me/subscription` в режиме первого запуска; `/me/subscription/checkout` отвечает 404

- **Эпик**: E-06 Кабинет читателя
- **Статус**: зависит: T-030
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; редакция — редактор и бренд-стратег (текст карточки); тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4

## 1. Результат
Страница показывает базовый план без оплаты и пояснение «платные планы появятся позже»; платёжные мутации отвечают `FORBIDDEN`; маршруты checkout/result отвечают 404 до включения платности.

## 2. Источники
- Журнал: §24.1
- Спецификации: `docs/spec/30-account/reader/subscription.md`, `docs/spec/30-account/reader/checkout.md`
- ADR: ADR-0035 (частично заменён журналом Г5–Г5b)

## 3. Границы и явно исключённое
- Входит: Страница в режиме запуска; заглушки маршрутов.
- Не входит: Вся платность (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-030
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. `/me/subscription/checkout` → 404 — проверка: curl.
2. Строки состояний `subscription.md` для первого запуска воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
curl, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
