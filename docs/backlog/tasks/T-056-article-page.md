# T-056: Страница материала: рендер документа, единое `alt`, закладка, предпросмотр по токену, 410

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-041, T-027, T-064
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, SSR, пакет `content`

## 1. Результат
Страница `/{рубрика}/{слаг}` по `article.md`: SSR-рендер документа пакетом `content`, обложка и изображения с единым `alt` из медиафайла, закладка, переключатель на опубликованную языковую пару, плашка окна перередактирования автору, предпросмотр `?preview=` для допущенных ролей, снятый или архивный → 410.

## 2. Источники
- Журнал: §20.6, §28.2, §29.13
- Спецификации: `docs/spec/20-public/article.md`, `docs/spec/20-public/gone.md`, `docs/spec/85-media-and-binary/image-variants.md`
- ADR: ADR-0029

## 3. Границы и явно исключённое
- Входит: Страница, резолвер `article`, предпросмотр.
- Не входит: События вовлечённости и публичный счётчик (F-02); кнопка «Пожаловаться» (F-06, OPEN-QUESTIONS #9).

## 4. Зависимости и что разблокирует
- Зависит от: T-041, T-027, T-064
- Разблокирует: T-100

## 5. Критерии готовности и способ проверки
1. Все строки состояний `article.md` воспроизводимы — проверка: Playwright.
2. В HTML `alt` изображения равен `alt` медиафайла и не берётся из документа — проверка: тест рендера.
3. Предпросмотр гостю → 404 — проверка: curl.

## 6. Доказательство результата
Playwright, тесты, curl. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
