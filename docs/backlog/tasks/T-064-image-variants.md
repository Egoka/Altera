# T-064: Варианты изображений AVIF и WebP, placeholder, thumbnails, `srcset`; отказ от `/_ipx/`

- **Эпик**: E-10 Медиа
- **Статус**: решение владельца: Q-03
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; дизайн — дизайнер (точки останова); тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: sharp, `<picture>`, Nuxt

## 1. Результат
Из мастер-файла создаются размытый placeholder, thumbnail и адаптивные варианты в AVIF и WebP по централизованной матрице; компонент вывода с `<picture>`, `srcset`/`sizes`, единым `alt`; `/_ipx/` не используется.

## 2. Источники
- Журнал: §29.4, §29.10, §29.12
- Спецификации: `docs/spec/85-media-and-binary/image-variants.md`, `docs/2026-09-09-media-upload-processing-notes.md`
- ADR: ADR-0030

## 3. Границы и явно исключённое
- Входит: Генерация вариантов и компонент вывода.
- Не входит: Ручное AI-улучшение (F-04).

## 4. Зависимости и что разблокирует

- Разблокирует: T-056, T-066

## 5. Критерии готовности и способ проверки
1. Для тестового изображения созданы оба формата всех размеров матрицы — проверка: тест.
2. В прод-сборке нет запросов к `/_ipx/` — проверка: Playwright + grep.
