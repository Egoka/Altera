# T-019: Миграция: задания, журнал AI-процессов, история писем, записи ошибок, версии юртекстов и согласия

- **Эпик**: E-03 Модель данных v2
- **Статус**: зависит: T-011
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma-миграции

## 1. Результат
Таблицы: очередь заданий со статусами и попытками; журнал AI-процессов (вид, статус, стоимость только для агрегатов); история писем с адресом, темой, содержимым; записи ошибок бэкенда со статусами «новая / в работе / решена»; версии юридических текстов и согласия пользователя с версией.

## 5. Критерии готовности и способ проверки
1. Секреты и токены не имеют полей в истории писем и записях ошибок — проверка: ревью схемы.
2. Миграция применяется на копии — проверка: репетиция.
