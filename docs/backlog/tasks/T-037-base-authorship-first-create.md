# T-037: Базовое авторство при первом «Создать статью»

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: зависит: T-017, T-026, T-039
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, Prisma

## 1. Результат
Первое нажатие «Создать статью» бессрочно включает базовые авторские возможности без оплаты и одобрения, создаёт черновик и открывает редактор; событие `author.enabled`; служебные записи авторство не получают.

## 2. Источники
- Журнал: §24.1, §25.1, §25.2, §25.3
- Спецификации: `docs/spec/10-flows/become-author.md`, `docs/spec/70-plans-and-billing/plan-free.md`, `docs/spec/30-account/author/article-new.md`
- ADR: ADR-0035 (частично заменён журналом Г5–Г5b)

## 3. Границы и явно исключённое
- Входит: Мутация первого создания, включение авторства, событие.
- Не входит: Выбор плана и оплата (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-017, T-026, T-039
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Читатель после первого создания проходит `ensureActiveAuthor` — проверка: тест.
2. Служебная запись при попытке получает `FORBIDDEN` — проверка: тест.

## 6. Доказательство результата
Тесты, e2e flow #2 (часть первого запуска). Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
