# T-088: Health API и Nuxt с зависимостями и возрастом резервной копии; оповещения владельцу и администратору

- **Эпик**: E-13 Наблюдаемость
- **Статус**: решение владельца: Q-11
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; релиз — релиз-инженер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Node, планировщик, модуль почты

## 1. Результат
`GET /health` API и `/health` Nuxt отдают состояние базы, кеша, хранилища, почты, AI и возраст последней резервной копии базы и медиа; деградация пишет `system.health` и оповещает владельца и администратора.

## 2. Источники
- Журнал: §28.5, §29.9
- Спецификации: `docs/spec/80-observability/health-and-alerts.md`, `docs/spec/85-media-and-binary/backups.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Health, проверки, оповещения через модуль почты.
- Не входит: Внешняя проверка доступности (T-106); зона провайдеров (F-08).

## 4. Зависимости и что разблокирует
- Зависит от: T-086, T-047, T-021
- Разблокирует: T-081, T-104, T-106

## 5. Критерии готовности и способ проверки
1. Просроченная резервная копия даёт статус деградации и оповещение — проверка: тест с подменой даты копии.
2. `/health` не раскрывает секретов — проверка: контрактный тест.

## 6. Доказательство результата
Тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
