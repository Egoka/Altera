# T-039: Новый материал: черновик создаётся сразу, рубрика обязательна до подачи

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: зависит: T-014, T-015, T-026
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga

## 1. Результат
Нажатие «плюс» создаёт черновик и открывает редактор; рубрика и теги выбираются в редакторе; подача без рубрики отклоняется; теги создаются автором через автокомплит.

## 2. Источники
- Журнал: §25.3, §26.3
- Спецификации: `docs/spec/30-account/author/article-new.md`, `docs/spec/40-admin/tags.md`
- ADR: ADR-0005 (уточнён журналом)

## 3. Границы и явно исключённое
- Входит: Мутация создания, маршрут `/me/articles/new` как действие, автокомплит тегов.
- Не входит: Тело редактора (T-040, T-041).

## 4. Зависимости и что разблокирует
- Зависит от: T-014, T-015, T-026
- Разблокирует: T-037, T-040

## 5. Критерии готовности и способ проверки
1. `createArticle` возвращает черновик без рубрики; `submit` без рубрики → `VALIDATION_ERROR` — проверка: тесты.
2. Автокомплит создаёт новый тег от автора — проверка: тест.

## 6. Доказательство результата
Тесты, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
