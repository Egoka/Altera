# T-101: Механизм версий юридических текстов и согласий; страницы `/legal/terms`, `/legal/privacy`, `/legal/content-rules`, `/legal/license`

- **Эпик**: E-16 Юридические тексты и согласия
- **Статус**: зависит: T-019, T-022
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, Prisma

## 1. Результат
Версии текстов с датой публикации и признаком существенности; согласие фиксируется при регистрации с версией; при новой существенной версии — повторное согласие; страницы с якорями категорий и печатными стилями; лицензия содержит запрет обучения ИИ.

## 2. Источники
- Журнал: §24.2, §24.3
- Спецификации: `docs/spec/20-public/legal-terms.md`, `docs/spec/20-public/legal-privacy.md`, `docs/spec/20-public/legal-content-rules.md`, `docs/spec/20-public/legal-license.md`, `docs/spec/90-business-model/legal-152-54.md`
- ADR: ADR-0028

## 3. Границы и явно исключённое
- Входит: Механизм и страницы.
- Не входит: Содержание текстов (T-102, Q-07); `/legal/paid-services`, `/legal/refunds` (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-019, T-022
- Разблокирует: T-059, T-083

## 5. Критерии готовности и способ проверки
1. Регистрация сохраняет версию согласия — проверка: тест.
2. Все строки состояний четырёх спецификаций воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
