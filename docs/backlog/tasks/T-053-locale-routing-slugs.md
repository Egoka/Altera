# T-053: Адресация локалей: русский без префикса, английский под `/en`, слаги навсегда, переключатель языка

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-009
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, @nuxtjs/i18n, маршрутизация

## 1. Результат
Публичные адреса по `routes.md`: `ru` без префикса, `en` под `/en`; кабинет и админка без префикса; слаги и хэндлы не меняются и не переиспользуются; переключатель языка ведёт на опубликованную пару или на главную.

## 2. Источники
- Журнал: §20.10, §26.10
- Спецификации: `docs/spec/00-registries/routes.md`, `docs/spec/20-public/home.md`
- ADR: ADR-0002, ADR-0004 (дополнен журналом Г7)

## 3. Границы и явно исключённое
- Входит: Конфигурация i18n-маршрутов, компонент переключателя, правила адресов.
- Не входит: Словари интерфейса (T-095).

## 4. Зависимости и что разблокирует
- Зависит от: T-009
- Разблокирует: T-054, T-095

## 5. Критерии готовности и способ проверки
1. `/` отдаёт русскую, `/en` — английскую версию; `/ru` → 301 на `/` — проверка: curl.
2. Адрес удалённого материала не выдаётся новому — проверка: тест уникальности.

## 6. Доказательство результата
curl, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
