# T-040: Обвязка редактора `/me/articles/{id}/edit`: метаданные, обложка, автосохранение с `baseRevisionId`, конфликт, подача

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: зависит: T-039, T-041, T-066
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, TipTap/ProseMirror, GraphQL Yoga

## 1. Результат
Редактор: заголовок, лид, рубрика, формат, теги, обложка, тело в области блоков; автосохранение с `baseRevisionId` и `CONFLICT` при двух вкладках; предпросмотр; подача на проверку; режим чтения для отклонённых; медиа — через T-063; SEO-поля.

## 2. Источники
- Журнал: §25.3, §25.6, §29.1
- Спецификации: `docs/spec/30-account/author/article-edit.md`, `docs/spec/85-media-and-binary/article-covers.md`
- ADR: ADR-0001, ADR-0033, ADR-0017

## 3. Границы и явно исключённое
- Входит: Обвязка редактора без состава блоков.
- Не входит: Состав блоков и их интерфейсы (T-041, Q-02); сравнение версий, AI-перевод (F-09).

## 4. Зависимости и что разблокирует
- Зависит от: T-039, T-041, T-066
- Разблокирует: T-046, T-049

## 5. Критерии готовности и способ проверки
1. Сохранение с устаревшим `baseRevisionId` → `CONFLICT` и баннер — проверка: тест + Playwright.
2. Подача без обложки отклоняется — проверка: тест.
3. Все строки состояний `article-edit.md` воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
