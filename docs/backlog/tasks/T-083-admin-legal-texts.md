# T-083: Юридические тексты `/admin/legal`: версии, публикация, `legal.update`

- **Эпик**: E-12 Админка II
- **Статус**: зависит: T-069, T-101
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue

## 1. Результат
Раздел управления версиями юридических текстов с историей и публикацией; аудит `legal.update`; согласие пользователя фиксируется с версией.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/40-admin/legal-texts.md`
- ADR: ADR-0028

## 3. Границы и явно исключённое
- Входит: Раздел.
- Не входит: Содержание текстов (Q-07).

## 4. Зависимости и что разблокирует
- Зависит от: T-069, T-101
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Публикация версии делает её действующей на `/legal/*` — проверка: e2e.
2. Все строки состояний `legal-texts.md` воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
e2e, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
По спецификации раздел этапа 4; до него версии публикуются релизом кода (T-101) — включение в срез запуска подтверждает владелец (Q-09).

## 8. Требует решения владельца
