# T-009: BFF-прокси `POST /api/graphql` и адрес API в `runtimeConfig`

- **Эпик**: E-02 Соединение веба и API
- **Статус**: кандидат
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4 (Nitro server routes), GraphQL

## 1. Результат
Браузер обращается только к Nuxt `POST /api/graphql`; Nuxt проксирует на API по серверному адресу из `runtimeConfig`; CORS API ограничен адресом Nuxt; заголовок защиты от CSRF выставляет BFF.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/00-registries/routes.md`, `docs/vision/02-target-architecture.md`
- ADR: ADR-0023, ADR-0020

## 3. Границы и явно исключённое
- Входит: Серверный маршрут Nuxt, конфигурация, composable для вызова.
- Не входит: httpOnly-cookie сессии (T-023).

## 4. Зависимости и что разблокирует
- Зависит от: нет
- Разблокирует: T-010, T-022, T-053, T-087, T-093

## 5. Критерии готовности и способ проверки
1. Запрос `{ __typename }` через `/api/graphql` из браузера возвращает ответ API — проверка: Playwright.
2. Адрес API отсутствует в клиентском бандле — проверка: grep по `.output/public`.

## 6. Доказательство результата
Playwright-тест, grep. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
