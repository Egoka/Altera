# T-031: Профиль: имя, хэндл, аватар, язык; автоматическая проверка имени и аватара

- **Эпик**: E-06 Кабинет читателя
- **Статус**: зависит: T-013, T-048, T-065
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор (проверка через AI-адаптер); дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga, загрузка файлов

## 1. Результат
Пользователь редактирует имя, хэндл (уникален навсегда), аватар и основной язык; имя и хэндл обязательны до первой публикации; имя и аватар проходят автоматическую проверку (`profile.check`), спорные случаи решает ревьюер (`profile.review.decide`); аватар применяется сразу, предыдущая версия сохраняется.

## 2. Источники
- Журнал: §25.4, §26.10, §29.5
- Спецификации: `docs/spec/30-account/reader/profile-edit.md`, `docs/spec/85-media-and-binary/avatars.md`, `docs/spec/00-registries/access-matrix.md`
- ADR: ADR-0018

## 3. Границы и явно исключённое
- Входит: Страница, мутации, проверка через адаптер T-048, состояние проверки.
- Не входит: Загрузка аватара как медиа (T-065).

## 4. Зависимости и что разблокирует
- Зависит от: T-013, T-048, T-065
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Публикация без имени и хэндла отклоняется с кодом по словарю — проверка: тест.
2. Смена хэндла не освобождает старый — проверка: тест.
3. Все строки состояний `profile-edit.md` воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
