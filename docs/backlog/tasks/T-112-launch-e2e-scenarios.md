# T-112: Подготовка e2e-сценариев запуска по flow-спецификациям

- **Эпик**: E-01 Инженерная база и честный CI
- **Статус**: зависит: T-002
- **Параллельность**: да: готовит тесты и сценарии, продуктовый код не меняет; исполнение тестов — по мере готовности задач
- **Роль-исполнитель**: тестировщик
- **Участники стадий**: ревью — независимый ревьюер
- **Навыки**: Playwright, чтение спецификаций

## 1. Результат
Для flow #1, #3, #4, #5, #11, #12, #13, #15, #16 написаны сценарии Playwright в виде шагов и ожидаемых состояний по спецификациям; сценарии помечены `skip` до готовности задач и включаются по мере их завершения.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/10-flows/register-and-login.md`, `docs/spec/10-flows/write-and-publish.md`, `docs/spec/10-flows/moderation.md`, `docs/spec/10-flows/archive-account.md`, `docs/spec/10-flows/delete-account.md`, `docs/spec/10-flows/email-change-and-recovery.md`, `docs/spec/10-flows/archive-and-restore-article.md`, `docs/spec/10-flows/permanent-delete.md`, `docs/spec/00-registries/flows.md`
- ADR: ADR-0031

## 3. Границы и явно исключённое
- Входит: Сценарии, фикстуры и порядок включения.
- Не входит: Flow платности (#2, #6, #7) и жалоб (#9) — будущие этапы.

## 4. Зависимости и что разблокирует
- Зависит от: T-002
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Каждый flow из списка имеет файл сценария с шагами, совпадающими с таблицей шагов спецификации — проверка: ревью по спецификации.
2. Сценарии в `skip` не ломают CI — проверка: прогон.

## 6. Доказательство результата
Файлы сценариев, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Сценарии не заменяют критерии готовности задач; они — общий регресс запуска.

## 8. Требует решения владельца
нет. Сценарии не заменяют критерии готовности задач; они — общий регресс запуска.
