# T-120: Предложение метрик дашборда владельца и расчёта «регулярности» автора

- **Эпик**: E-11 Админка I
- **Статус**: кандидат
- **Параллельность**: да: не меняет продуктовый код
- **Роль-исполнитель**: аналитик
- **Участники стадий**: ревью — владелец (утверждение)
- **Навыки**: Продуктовая аналитика

## 1. Результат
Владелец получил предложение состава метрик своего дашборда (§26.1) и способа расчёта показателя «регулярность» общей статистики автора; после утверждения они становятся правилом.

## 2. Источники
- Журнал: §26.1, §37 п. 7, п. 14
- Спецификации: `docs/spec/40-admin/dashboard.md`, `docs/spec/30-account/author/stats-overview.md`

## 3. Границы и явно исключённое
- Входит: предложение с обоснованием из уже собираемых данных.
- Не входит: реализация.

## 4. Зависимости и что разблокирует
- Зависит от: нет
- Разблокирует: реализация метрик дашборда владельца и поля `regularity` после утверждения

## 5. Критерии готовности и способ проверки
1. Предложение сверено с собираемыми данными — проверка: ревью.
2. Владелец утвердил — проверка: запись в журнале.

## 6. Доказательство результата
Проверки по критериям §5, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Задача заведена по решениям владельца в гейте блокеров 2026-09-26. Предлагает аналитик, утверждает владелец (§37 п. 7, 14).
