# T-063: Конвейер загрузки: карантин, проверка, мастер-файл без EXIF, статусы обработки

- **Эпик**: E-10 Медиа
- **Статус**: решение владельца: Q-03
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор (обязательно); тестирование — тестировщик; ревью — независимый ревьюер; релиз — релиз-инженер (`sharp` в сборке)
- **Навыки**: sharp, очередь заданий, S3

## 1. Результат
`uploadMedia(translationId, file, license, attribution)` без `alt`: приём в карантин, проверка типа по содержимому, целостности и размеров, удаление EXIF и геолокации, ориентация и цветовой профиль, мастер-файл как постоянный оригинал; статусы `загрузка` → `в очереди` → `обрабатывается` → `готово` / `ошибка`; частичная ошибка повторяется без потери мастера; публичный доступ только после успеха.

## 2. Источники
- Журнал: §29.2, §29.3, §29.12, §29.13
- Спецификации: `docs/spec/85-media-and-binary/upload-pipeline.md`, `docs/spec/85-media-and-binary/storage-layout.md`, `docs/2026-09-09-media-upload-processing-notes.md`
- ADR: ADR-0030, ADR-0008

## 3. Границы и явно исключённое
- Входит: Шаги конвейера по утверждённым принципам; лицензия и атрибуция обязательны.
- Не входит: Матрица размеров (T-064); видео, аудио, GIF, PDF, ретраи, лимиты размера и пикселей (F-04, Q-03).

## 4. Зависимости и что разблокирует
- Зависит от: T-062, T-047
- Разблокирует: T-064, T-065, T-067, T-068

## 5. Критерии готовности и способ проверки
1. В мастер-файле нет EXIF — проверка: тест с файлом, содержащим геометку.
2. Загрузка без лицензии или атрибуции → `VALIDATION_ERROR` — проверка: тест.
3. Все статусы обработки достижимы в тестах, включая повтор после частичной ошибки.

## 6. Доказательство результата
Тесты, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Лимиты размера файла и пикселей, время обработки и ретраи не заданы (§29.12, заметка владельца).

## 8. Требует решения владельца
Q-03 — Проход конвейера медиа: матрица размеров, лимиты, очередь, ретраи, интервал сирот (см. `docs/backlog/owner-blockers.md`). Почему без этого задача не готова — в разделе 7.
