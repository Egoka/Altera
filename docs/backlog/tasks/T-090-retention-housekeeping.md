# T-090: Сроки хранения и housekeeping: сессии, токены, автосохранения, история ошибок; ПД в логах

- **Эпик**: E-13 Наблюдаемость
- **Статус**: зависит: T-047, T-023
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Планировщик, Prisma

## 1. Результат
Регулярное задание удаляет истёкшие сессии и токены, старые автосохранения, устаревшую техническую историю ошибок по политике хранения; аудит и история решений не удаляются; лог без ПД.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/80-observability/retention-and-pd.md`, `docs/spec/50-access/session-lifecycle.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Задание housekeeping.
- Не входит: Медиа-сироты (T-068).

## 4. Зависимости и что разблокирует
- Зависит от: T-047, T-023
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Записи аудита не затрагиваются заданием — проверка: тест.
2. Сроки берутся из одного места конфигурации — проверка: ревью.

## 6. Доказательство результата
Тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
