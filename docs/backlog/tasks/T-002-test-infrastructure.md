В `server` и `web` настроен Vitest; есть первый контрактный тест SDL (схема собирается, публичные типы не содержат `email`); настроен Playwright со smoke-сценарием открытия главной; CI запускает всё это.

## 5. Критерии готовности и способ проверки
1. `pnpm --filter server test` и `pnpm --filter web test` выполняют ≥ 1 тест и проходят.
2. Контрактный тест падает, если в публичном типе `Author`/`User` появляется поле `email` — проверка: временное добавление поля.
3. Playwright smoke открывает `/` и проверяет заголовок — проверка: прогон в CI.
