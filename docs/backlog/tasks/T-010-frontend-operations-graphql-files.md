# T-010: Операции фронта в `.graphql` и их валидация против схемы в CI

- **Эпик**: E-02 Соединение веба и API
- **Статус**: завершена (PR #42, merge a1f7711c; приёмка ALTE-21)
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL, graphql-codegen

## 1. Результат
Все операции фронта лежат в `.graphql`-файлах, валидны против SDL сервера; ручные строки в `web/app/query/**` удалены; CI-тест валидирует все операции.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/vision/00-reality-check.md`
- ADR: ADR-0012

## 3. Границы и явно исключённое
- Входит: Перенос и переписывание операций под существующую схему; тест валидации.
- Не входит: Новые поля API под спецификации (в задачах доменов).

## 4. Зависимости и что разблокирует
- Зависит от: T-008, T-009
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Тест «все `web/**/*.graphql` валидны против схемы» проходит; при невалидной операции — падает.
2. `web/app/query/index.ts` не экспортирует строковых операций — проверка: grep.
