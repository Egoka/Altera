# T-013: Миграция: имя, хэндл, аватар, основной язык аккаунта; уникальность хэндла навсегда

- **Эпик**: E-03 Модель данных v2
- **Статус**: зависит: T-011
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma-миграции, PostgreSQL

## 1. Результат
У пользователя есть отображаемое имя, публичный хэндл (уникален навсегда, включая архив и удаление), аватар (ссылка на медиа), основной язык аккаунта; состояние автоматической проверки имени/аватара; резерв прежних хэндлов без переиспользования.

## 2. Источники
- Журнал: §20.11, §25.4, §26.10, §29.5
- Спецификации: `docs/spec/30-account/reader/profile-edit.md`, `docs/spec/20-public/author.md`, `docs/spec/85-media-and-binary/avatars.md`
- ADR: ADR-0004 (дополнен журналом Г7), ADR-0018

## 3. Границы и явно исключённое
- Входит: Поля профиля, уникальность хэндла с историей, состояние проверки, предыдущая версия аватара (§29.5).
- Не входит: Медиа-актив аватара (T-016); UI профиля (T-031).

## 4. Зависимости и что разблокирует
- Зависит от: T-011
- Разблокирует: T-031

## 5. Критерии готовности и способ проверки
1. Повторное использование освобождённого хэндла отклоняется на уровне базы — проверка: тест.
2. Коллизия хэндла при регистрации разрешается без ошибки — проверка: тест.

## 6. Доказательство результата
Миграция, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
