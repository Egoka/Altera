# T-012: Миграция: сессии с хэшем токена и хэшированные magic-link-токены

- **Эпик**: E-03 Модель данных v2
- **Статус**: зависит: T-011
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma-миграции, криптографические хэши

## 1. Результат
Таблица сессий с хэшем refresh-токена, устройством, датами и признаком отзыва; токены входа хранятся хэшем с ограничением по сроку из настроек; поля для восстановления и смены почты по коду.

## 2. Источники
- Журнал: §25.8, §25.9
- Спецификации: `docs/spec/50-access/session-lifecycle.md`, `docs/spec/30-account/reader/sessions.md`, `docs/spec/30-account/reader/email-change.md`
- ADR: ADR-0009, ADR-0022

## 3. Границы и явно исключённое
- Входит: Схема сессий и токенов; IP-геолокация не хранится (§25.9).
- Не входит: Логика ротации и выхода (T-023); UI (T-025).

## 4. Зависимости и что разблокирует
- Зависит от: T-011
- Разблокирует: T-022, T-023

## 5. Критерии готовности и способ проверки
1. В схеме нет поля с геолокацией по IP — проверка: ревью схемы.
2. Токены входа не хранятся в открытом виде — проверка: тест на хэш.
3. Миграция применяется на копии базы — проверка: репетиция.

## 6. Доказательство результата
Миграция, тест, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Сроки токенов — из существующих переменных окружения (`MAGIC_LINK_EXPIRY_MINUTES`, `JWT_*_EXPIRY`); новых чисел не вводится.

## 8. Требует решения владельца
нет. Сроки токенов — из существующих переменных окружения (`MAGIC_LINK_EXPIRY_MINUTES`, `JWT_*_EXPIRY`); новых чисел не вводится.
