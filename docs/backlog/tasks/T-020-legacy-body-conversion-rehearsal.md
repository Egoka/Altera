# T-020: Конверсия существующих тел статей в документ `content` и репетиция миграций на копии

- **Эпик**: E-03 Модель данных v2
- **Статус**: решение владельца: Q-02
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер; релиз — релиз-инженер
- **Навыки**: Prisma, PostgreSQL, скрипты миграции данных

## 1. Результат
Скрипт `verify:legacy-bodies` проверяет конвертируемость всех строковых тел; конверсия в JSON-документ выполнена; полный набор миграций E-03 отрепетирован на копии базы с данными, результат зафиксирован.

## 2. Источники
- Журнал: #15
- Спецификации: `docs/vision/08-operations.md`
- ADR: ADR-0001, ADR-0029

## 3. Границы и явно исключённое
- Входит: Скрипт проверки, конверсия, репетиция.
- Не входит: Схема блоков (Q-02): конверсия использует минимальный узел «абзац» `[ДОПУЩЕНИЕ]` до утверждения каталога.

## 4. Зависимости и что разблокирует
- Зависит от: T-015, T-016, T-017, T-018, T-019
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. `pnpm verify:legacy-bodies` сообщает 0 неконвертируемых тел — проверка: вывод.
2. Репетиция `migrate deploy` на копии прошла без ошибок; число статей до и после совпадает — проверка: вывод и SQL.

## 6. Доказательство результата
