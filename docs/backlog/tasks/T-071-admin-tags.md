# T-071: Теги: слияние, архив, восстановление; создание — авторами

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-070
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue, GraphQL Yoga

## 1. Результат
Раздел `/admin/tags`: список, слияние с 301 источников, архив и восстановление `admin`/`owner`; создание тега из админки не требуется — теги создают авторы через автокомплит; аудит `tag.*`.
