# T-008: GraphQL-кодоген из SDL сервера и `codegen --check` в CI

- **Эпик**: E-02 Соединение веба и API
- **Статус**: кандидат
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор (структура пакетов); ревью — независимый ревьюер
- **Навыки**: graphql-codegen, TypeScript, GraphQL Yoga

## 1. Результат
Типы операций фронта генерируются из SDL сервера; ручные типы удалены; `codegen --check` в CI падает при расхождении.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)

## 3. Границы и явно исключённое
- Входит: Настройка кодогена, генерация, CI-шаг.
- Не входит: Переписывание самих операций (T-010).

## 4. Зависимости и что разблокирует

## 5. Критерии готовности и способ проверки
1. `pnpm codegen --check` зелёный в CI и красный при изменении SDL без перегенерации — проверка: два прогона.
2. В `web/app` нет ручных TypeScript-типов, дублирующих схему — проверка: grep по удалённым файлам.

## 6. Доказательство результата
