# T-098: `robots.txt` с запретом обучения ИИ; `noindex` служебных страниц

- **Эпик**: E-15 SEO и фиды
- **Статус**: кандидат
- **Параллельность**: нет: меняет продуктовый код (небольшой объём)
- **Роль-исполнитель**: SEO-специалист
- **Участники стадий**: разработка — разработчик; ревью — независимый ревьюер
- **Навыки**: SEO, Nuxt

## 1. Результат
`robots.txt` разрешает поисковых роботов, запрещает роботов обучения ИИ, закрывает кабинет, админку, предпросмотр и служебные адреса; страницы кабинета и админки отдают `noindex`.

## 2. Источники
- Журнал: §24.2
- Спецификации: `docs/spec/20-public/feeds-and-sitemap.md`, `docs/spec/20-public/legal-license.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: robots и noindex.
- Не входит: Список идентификаторов роботов — конфигурация `[ДОПУЩЕНИЕ]` по спецификации.

## 4. Зависимости и что разблокирует
- Зависит от: нет
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. `curl /robots.txt` содержит правила по спецификации — проверка: тест.
2. Страницы `/me/*` отдают `noindex` — проверка: Playwright.

## 6. Доказательство результата
Тест, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
