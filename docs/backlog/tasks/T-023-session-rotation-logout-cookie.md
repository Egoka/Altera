# T-023: Сессии: ротация refresh, выход, выход везде, обнаружение повторного предъявления, httpOnly-cookie через BFF

- **Эпик**: E-04 Вход, сессии и лимиты
- **Статус**: зависит: T-012, T-022
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, Nuxt server routes, cookie, JWT

## 1. Результат
`refreshSession` ротирует токен и отзывает старый; повторное предъявление отозванного токена отзывает всю цепочку (`session.reuse_detected`); `logout` и `logoutAll`; refresh хранится в httpOnly-cookie, выставляемой BFF; окончание базового авторства сессию не отзывает (#55).

## 3. Границы и явно исключённое
- Входит: Мутации сессий, cookie, отзыв.
- Не входит: Страница сессий (T-025).

## 4. Зависимости и что разблокирует

- Разблокирует: T-025, T-032, T-073, T-090

## 5. Критерии готовности и способ проверки
1. Повторное предъявление старого refresh отзывает все сессии пользователя — проверка: тест.
2. Cookie недоступна из JavaScript — проверка: Playwright (`document.cookie`).
3. `logoutAll` оставляет только текущую сессию или ни одной по спецификации — проверка: тест.
