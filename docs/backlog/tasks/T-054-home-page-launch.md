# T-054: Главная `/` и `/en`: три подборки первого этапа по дате, шапка с меню из рубрик

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-027, T-053, T-093
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga, кеш

## 1. Результат
Главная по `home.md`: главный топ по дате до запуска движка (подпись «по дате публикации»), «Новое» без повторов, «Популярное» скрыто до контура вовлечённости; закладка с карточки; «Писать» ведёт в создание материала на первом запуске; резолвер `feed` с кешем и инвалидацией.

## 2. Источники
- Журнал: §20.1, §20.4, §22.4, §24.1, §25.1
- Спецификации: `docs/spec/20-public/home.md`, `docs/spec/60-ranking/home-sections.md`, `docs/spec/60-ranking/feed-principles.md`, `docs/spec/00-registries/pages.md`
- ADR: ADR-0034 (частично заменён журналом Г4)

## 3. Границы и явно исключённое
- Входит: Страница, резолвер лент, кеш.
- Не входит: Топ по рейтингу и «Популярное» (F-02).

## 4. Зависимости и что разблокирует
- Зависит от: T-027, T-053, T-093
- Разблокирует: T-055, T-058, T-060, T-099, T-100

## 5. Критерии готовности и способ проверки
1. Все строки состояний `home.md` воспроизводимы — проверка: Playwright.
2. Материал не повторяется в двух подборках — проверка: тест резолвера.
3. Фикстуры главной удалены — проверка: grep по `web/app`.

## 6. Доказательство результата
Playwright, тесты, grep. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
