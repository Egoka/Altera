# T-087: Сквозной `requestId` и событие `http.request` с `userId` и снимком роли

- **Эпик**: E-13 Наблюдаемость
- **Статус**: зависит: T-086, T-009
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt server routes, GraphQL Yoga

## 1. Результат
`requestId` генерируется на входе в Nuxt, передаётся в API и возвращается клиенту; `http.request` содержит маршрут по шаблону, статус, длительность, внутренний `userId` и роль; задания хранят `originRequestId`; клиенту `requestId` показывается только при технических сбоях.

## 5. Критерии готовности и способ проверки
1. Ответ 500 содержит `requestId`, ответ `NOT_FOUND` — нет — проверка: тесты.
2. Запись `http.request` содержит роль — проверка: тест логгера.
