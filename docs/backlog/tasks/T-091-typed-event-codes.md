# T-091: Типизированные коды событий из замороженного реестра

- **Эпик**: E-13 Наблюдаемость
- **Статус**: зависит: T-086
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: TypeScript

## 1. Результат
Константы кодов событий и ошибок соответствуют реестру один к одному; новый код невозможно добавить без изменения реестра; тест сверяет константы с таблицей реестра.

## 2. Источники
- Журнал: §28.3
- Спецификации: `docs/spec/80-observability/log-event-registry.md`, `docs/spec/00-registries/events-and-logs.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Константы и тест сверки.
- Не входит: Новые коды — только решением владельца.

## 4. Зависимости и что разблокирует
- Зависит от: T-086
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Тест сверки констант с реестром проходит; код вне реестра — падение теста.

## 6. Доказательство результата
Тест. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
