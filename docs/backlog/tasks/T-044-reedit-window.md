# T-044: Перередактирование после автопубликации: одноразовое окно, ссылка из письма

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: зависит: T-049, T-051
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, планировщик

## 1. Результат
После автопубликации автор один раз в течение окна (журнал #9: один час) снимает статью на доработку; повторная подача проходит AI-проверку; после использования кнопка не предоставляется; ссылка `?token=` из письма о снятии на доработку (routes #68); событие `translation.reedit`.

## 5. Критерии готовности и способ проверки

2. По истечении окна действие недоступно — проверка: тест с подменой времени.
