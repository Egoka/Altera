# T-100: Meta, canonical, hreflang, Open Graph и JSON-LD на публичных страницах

- **Эпик**: E-15 SEO и фиды
- **Статус**: зависит: T-054, T-056, T-057
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: useSeoMeta, JSON-LD

## 1. Результат
Каждая публичная страница отдаёт `title`, `description`, canonical, hreflang для опубликованных пар, OG-изображение из обложки, JSON-LD по типу страницы.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/20-public/article.md`, `docs/spec/20-public/home.md`, `docs/spec/20-public/author.md`
- ADR: ADR-0002

## 3. Границы и явно исключённое
- Входит: SEO-слой.
- Не входит: ничего сверх результата; смежное — в задачах эпика
