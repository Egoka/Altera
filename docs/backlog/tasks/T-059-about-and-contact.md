# T-059: «О проекте» и «Письмо в редакцию» с обращениями в поддержку

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-024, T-021, T-101
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: редакция — редактор и бренд-стратег; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga

## 1. Результат
`/about` из статического текста с блоком рубрик; `/contact` создаёт обращение с темой, адресом и `requestId`, событие `support.request.created`, уведомление сотрудникам; лимиты по `rate-limits.md`.

## 2. Источники
- Журнал: §20.15
- Спецификации: `docs/spec/20-public/about.md`, `docs/spec/20-public/contact.md`, `docs/spec/80-observability/request-tracing.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Две страницы, мутация обращения.
- Не входит: Текст «О проекте» и список «что не работает» (OPEN-QUESTIONS #1, Q-08); статус обращения в кабинете (OPEN-QUESTIONS #2, Q-08); экран очереди обращений в админке — место не решено (Q-08).

## 4. Зависимости и что разблокирует
- Зависит от: T-024, T-021, T-101
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Обращение сохраняется и содержит `requestId`, если он передан — проверка: тест.
2. Все строки состояний обеих спецификаций воспроизводимы — проверка: Playwright.

## 6. Доказательство результата
Тесты, Playwright. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
