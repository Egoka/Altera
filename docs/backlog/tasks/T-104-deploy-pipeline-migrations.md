# T-104: Деплой по коммиту в `app`, миграции отдельным шагом релиза, откат

- **Эпик**: E-17 Прод в РФ, бэкапы и релиз
- **Статус**: зависит: T-103, T-001, T-088
- **Параллельность**: да: конфигурация CI/CD; не меняет продуктовый код
- **Роль-исполнитель**: релиз-инженер
- **Участники стадий**: разработка — разработчик; ревью — независимый ревьюер
- **Навыки**: CI/CD, контейнеры, Prisma migrate

## 1. Результат
Конвейер выкладки: сборка образов под пиновую версию Node с `sharp`, `prisma migrate deploy` отдельным шагом, проверка health после выката, откат образа.

## 2. Источники
- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/vision/08-operations.md`
- ADR: ADR-0031

## 3. Границы и явно исключённое
- Входит: Конвейер выкладки.
- Не входит: ничего сверх результата; смежное — в задачах эпика

## 4. Зависимости и что разблокирует
- Зависит от: T-103, T-001, T-088
- Разблокирует: T-106

## 5. Критерии готовности и способ проверки
1. Выкладка тестового коммита проходит и `/health` зелёный — проверка: лог конвейера.
2. Откат возвращает предыдущий образ — проверка: репетиция.

## 6. Доказательство результата
Логи конвейера, отчёт. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
