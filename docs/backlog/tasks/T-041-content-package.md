# T-041: Пакет `content`: схема документа, валидация, экстракторы, рендер

- **Эпик**: E-07 Кабинет автора и обвязка редактора
- **Статус**: решение владельца: Q-02
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор (обязательно); тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: ProseMirror-схемы, TypeScript, SSR-рендер

## 1. Результат
`packages/content`: схема узлов по каталогу блоков, `validateDocument`, экстракторы (текст для AI, обложка, изображения), рендерер для страницы материала; узел изображения не содержит собственного `alt`.

## 2. Источники
- Журнал: §29.13
- Спецификации: `docs/spec/95-blocks/README.md`, `docs/spec/30-account/author/article-edit.md`, `docs/spec/20-public/article.md`
- ADR: ADR-0001, ADR-0017, ADR-0029

## 3. Границы и явно исключённое
- Входит: Пакет и его тесты.
- Не входит: Каталог блоков как продуктовое решение (Q-02).

## 4. Зависимости и что разблокирует
- Зависит от: T-016
- Разблокирует: T-040, T-048, T-056

## 5. Критерии готовности и способ проверки
1. Каждый узел каталога имеет снимок-тест рендера — проверка: тесты.
2. Документ с `alt` в узле изображения не проходит валидацию — проверка: тест.

## 6. Доказательство результата
Тесты пакета, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Без утверждённого каталога блоков состав узлов не определён.

## 8. Требует решения владельца
Q-02 — Каталог блоков редактора (см. `docs/backlog/owner-blockers.md`). Почему без этого задача не готова — в разделе 7.
