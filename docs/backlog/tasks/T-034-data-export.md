## 1. Результат
Пользователь заказывает выгрузку: профиль, материалы (документы), медиа — мастер-оригиналы и метаданные без thumbnails, переписка по проверке с ролями участников; выгрузка собирается заданием и выдаётся по подписанной ссылке.
