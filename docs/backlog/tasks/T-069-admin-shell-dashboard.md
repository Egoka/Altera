# T-069: Оболочка админки и сводка `/admin` по ролям, событие `admin.enter`

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-026, T-094
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4 (layout `admin`), FishtVue, GraphQL Yoga

## 1. Результат
Layout админки с навигацией по дефолтным наборам ролей, middleware доступа, событие `admin.enter`; сводка показывает каждой служебной роли только её рабочие данные; читатель и автор в админку не попадают.
