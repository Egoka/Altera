# T-027: Модуль видимости: черновики и архив не отдаются гостю, `ARCHIVED` → 410, `email` вне публичных типов

- **Эпик**: E-05 Роли и проверки доступа
- **Статус**: зависит: T-015, T-026
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: GraphQL Yoga, Nuxt

## 1. Результат
Все публичные запросы проходят через один модуль видимости: гость видит только `published`; снятый или архивированный материал отвечает кодом `ARCHIVED` и страницей 410; `email` удалён из публичных типов и доступен только через `me`; предпросмотр по токену (`routes.md` #4).

## 2. Источники
- Журнал: §28.2
- Спецификации: `docs/spec/50-access/visibility.md`, `docs/spec/20-public/gone.md`, `docs/spec/00-registries/routes.md`, `docs/spec/50-access/roles/guest.md`
- ADR: ADR-0018, ADR-0032

## 3. Границы и явно исключённое
- Входит: Модуль видимости, контрактный тест, страница 410.
- Не входит: Прочие публичные страницы (E-09).

## 4. Зависимости и что разблокирует
- Зависит от: T-015, T-026
- Разблокирует: T-033, T-054, T-056, T-062, T-111

## 5. Критерии готовности и способ проверки
1. `article(slug)` для черновика гостю → `NOT_FOUND`, для архива → `ARCHIVED` и HTTP 410 на странице — проверка: тесты и curl.
2. Контрактный тест T-002 на `email` зелёный.

## 6. Доказательство результата
Тесты, curl, вердикт ревью. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
