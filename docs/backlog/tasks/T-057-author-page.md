# T-057: Страница автора `/authors/{handle}`

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-055, T-065
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, GraphQL Yoga

## 1. Результат
Страница автора с публикациями, аватаром, бейджем грейда, без e-mail и служебных полей; архивированный автор → 410; страница есть только у аккаунтов с публикациями.

## 2. Источники
- Журнал: §20.7, §20.8
- Спецификации: `docs/spec/20-public/author.md`, `docs/spec/50-access/visibility.md`
- ADR: ADR-0018

## 3. Границы и явно исключённое
- Входит: Страница и резолвер `author`.
- Не входит: Подписка на автора (F-10).

## 4. Зависимости и что разблокирует
- Зависит от: T-055, T-065
- Разблокирует: T-100

## 5. Критерии готовности и способ проверки
1. Все строки состояний `author.md` воспроизводимы — проверка: Playwright.
2. Ответ не содержит `email`, роли, плана — проверка: контрактный тест.

## 6. Доказательство результата
Playwright, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
