# T-070: Категории: рубрики и форматы, архив рубрики только с преемником, 301

- **Эпик**: E-11 Админка I
- **Статус**: зависит: T-069, T-014, T-018
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, FishtVue, GraphQL Yoga

## 1. Результат
Раздел `/admin/sections`: создание, изменение, порядок, архив рубрики с обязательным преемником и переносом статей, восстановление; форматы; аудит `section.*`/`format.update` с полями до/после.

## 2. Источники
- Журнал: #29, §26.2
- Спецификации: `docs/spec/40-admin/categories.md`
- ADR: ADR-0005 (уточнён журналом)

## 3. Границы и явно исключённое
- Входит: Раздел и мутации.
- Не входит: ничего сверх результата; смежное — в задачах эпика

## 4. Зависимости и что разблокирует
- Зависит от: T-069, T-014, T-018
- Разблокирует: T-071

## 5. Критерии готовности и способ проверки
1. Все строки состояний `categories.md` воспроизводимы — проверка: Playwright.
2. Архив без преемника отклоняется; после архива адрес рубрики → 301 — проверка: тест + curl.

## 6. Доказательство результата
Playwright, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
