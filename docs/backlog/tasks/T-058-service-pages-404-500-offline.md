# T-058: Служебные страницы 404, 500 и офлайн

- **Эпик**: E-09 Публичные страницы
- **Статус**: зависит: T-054, T-087
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: дизайн — дизайнер; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt 4, service worker (офлайн)

404 с карточками и «сообщить о битой ссылке»; 500 без запросов к API с `requestId` только при техническом сбое; офлайн-страница по спецификации.
