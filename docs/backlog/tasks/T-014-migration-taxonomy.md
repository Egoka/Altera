# T-014: Миграция: рубрики (`Section`), форматы, теги с архивом и преемником рубрики

- **Эпик**: E-03 Модель данных v2
- **Статус**: зависит: T-011
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma-миграции, PostgreSQL

## 1. Результат
`ContentType` переименован в `Section` со статусом архива и обязательным преемником при архиве; `Format` — необязательный жанр; `Tag` — свободный, создаётся автором, сливается и архивируется `admin`/`owner`; слаги рубрик и тегов уникальны навсегда.

## 2. Источники
- Журнал: #29, §25.3, §26.2, §26.3, §26.10
- Спецификации: `docs/spec/40-admin/categories.md`, `docs/spec/40-admin/tags.md`, `docs/spec/20-public/sections-index.md`, `docs/spec/20-public/tags-index.md`
- ADR: ADR-0005 (уточнён журналом), ADR-0004

## 3. Границы и явно исключённое
- Входит: Схема таксономии, конверсия существующих `ContentType`/`SectionTag`.
- Не входит: Интерфейсы админки (T-070, T-071); автокомплит в редакторе (T-040).

## 4. Зависимости и что разблокирует
- Зависит от: T-011
- Разблокирует: T-015, T-039, T-055, T-070

## 5. Критерии готовности и способ проверки
1. Архив рубрики без преемника отклоняется — проверка: тест ограничения.
2. Существующие рубрики и теги сохранены после миграции — проверка: сравнение количества до/после на копии.

## 6. Доказательство результата
Миграция, тесты, вывод репетиции. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Формат необязателен (§25.3); рубрика обязательна до подачи — правило проверяется в T-039/T-049, схема допускает черновик без рубрики.
