# T-007: Детерминированный сид: роли, первый `owner`, рубрики, форматы, теги, материалы во всех статусах

- **Эпик**: E-01 Инженерная база и честный CI
- **Статус**: зависит: T-015, T-017
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: тестирование — тестировщик; ревью — независимый ревьюер; документация — хранитель документации
- **Навыки**: Prisma, TypeScript

## 1. Результат
`prisma db seed` создаёт первого `owner` (журнал: сид создаёт первого), служебные записи всех ролей, рубрики и форматы, теги, авторов и материалы во всех статусах модели v2; сид идемпотентен и используется тестами.

## 2. Источники
- Журнал: #10, #47
- Спецификации: `docs/spec/00-registries/roles.md`, `docs/vision/08-operations.md`
- ADR: ADR-0005

## 3. Границы и явно исключённое
- Входит: Скрипт сида и его подключение в `package.json`; фикстуры для тестов.
- Не входит: Тестовые данные платности (F-01).

## 4. Зависимости и что разблокирует
- Зависит от: T-015, T-017
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. `prisma db seed` на пустой базе завершается успешно и повторно не дублирует записи — проверка: два запуска подряд.
2. В базе ровно по одной служебной записи каждой роли и ≥ 1 материал в каждом статусе — проверка: SQL-выборка в отчёте.

## 6. Доказательство результата
Вывод сида, SQL-выборка, тест, использующий сид. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».
