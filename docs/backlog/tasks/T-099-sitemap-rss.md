# T-099: Sitemap по локалям и RSS

- **Эпик**: E-15 SEO и фиды
- **Статус**: зависит: T-054
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: SEO — SEO-специалист; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Nuxt server routes, XML

## 1. Результат
`/sitemap.xml`, `/sitemap-{locale}.xml` и `/rss.xml` по локалям из опубликованных материалов.

- Журнал: прямого решения нет; задача техническая (границы — спецификации ниже)
- Спецификации: `docs/spec/20-public/feeds-and-sitemap.md`
- ADR: не применимо

## 3. Границы и явно исключённое

- Не входит: ничего сверх результата; смежное — в задачах эпика

## 4. Зависимости и что разблокирует
- Зависит от: T-054
