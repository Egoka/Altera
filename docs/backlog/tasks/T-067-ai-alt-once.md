# T-067: AI-описание `alt` один раз при загрузке, только у медиафайла, правка только `admin` с аудитом

- **Эпик**: E-10 Медиа
- **Статус**: решение владельца: Q-01
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Интеграция с моделью распознавания, очередь заданий

## 1. Результат
После обработки изображения задание вызывает лёгкую модель, результат сохраняется в `alt` медиафайла; автор его не редактирует, узел документа не переопределяет; вывод всегда использует `alt` медиафайла; исправление только `admin` у медиафайла с аудитом `admin.change` (`entity: mediaAsset`); нового кода события нет.

## 2. Источники
- Журнал: §28.3, §29.11, §29.13
- Спецификации: `docs/spec/85-media-and-binary/upload-pipeline.md`, `docs/spec/00-registries/access-matrix.md`, `docs/spec/00-registries/events-and-logs.md`
- ADR: не применимо

## 3. Границы и явно исключённое
- Входит: Задание, адаптер модели с `fake`, мутация `admin`.
- Не входит: Выбор модели, языки, стоимость, поведение при ошибке генерации — отдельный проход (Q-01, Q-03).

## 4. Зависимости и что разблокирует
- Зависит от: T-063, T-048
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Мутация изменения `alt` от `author` и `moderator` → `FORBIDDEN`; от `admin` — запись `admin.change` — проверка: тесты.
2. `alt` не входит в аргументы `uploadMedia` и `updateMediaMeta` — проверка: контрактный тест.
