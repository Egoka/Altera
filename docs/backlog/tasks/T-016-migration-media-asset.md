# T-016: Миграция: медиафайл с мастер-оригиналом, вариантами, единым `alt`, лицензией и привязкой

- **Эпик**: E-03 Модель данных v2
- **Статус**: зависит: T-015
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: архитектура — архитектор; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: Prisma-миграции, PostgreSQL

## 1. Результат
`MediaAsset`: ключи мастер-оригинала и вариантов, статус обработки (`загрузка` → `в очереди` → `обрабатывается` → `готово` / `ошибка`), `alt` (единственное, задаётся AI, правит только `admin`), лицензия, атрибуция, фокусная точка, привязка к версии статьи или аватару; отдельных «библиотечных» объектов нет.

## 2. Источники
- Журнал: #28, §29.2, §29.11, §29.13
- Спецификации: `docs/spec/85-media-and-binary/storage-layout.md`, `docs/spec/85-media-and-binary/upload-pipeline.md`, `docs/spec/85-media-and-binary/image-variants.md`
- ADR: ADR-0008, ADR-0030

## 3. Границы и явно исключённое
- Входит: Схема медиа; узел документа не имеет собственного `alt`.
- Не входит: Сам конвейер (T-063); варианты (T-064).

## 4. Зависимости и что разблокирует
- Зависит от: T-015
- Разблокирует: T-020, T-041, T-062

## 5. Критерии готовности и способ проверки
1. В схеме `alt` есть только у `MediaAsset` — проверка: ревью схемы и схемы документа `content`.
2. Медиафайл без активной связи различим запросом (для T-068) — проверка: тест выборки сирот.

## 6. Доказательство результата
Миграция, тесты. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Матрица размеров и лимиты хранятся не в схеме (Q-03).

## 8. Требует решения владельца
нет. Матрица размеров и лимиты хранятся не в схеме (Q-03).
