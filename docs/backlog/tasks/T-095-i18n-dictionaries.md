# T-095: Словари интерфейса ru/en для всех страниц запуска; язык аккаунта — язык писем

- **Эпик**: E-14 Дизайн-система и i18n
- **Статус**: зависит: T-053, T-096
- **Параллельность**: нет: меняет продуктовый код
- **Роль-исполнитель**: разработчик
- **Участники стадий**: редакция — редактор и бренд-стратег; тестирование — тестировщик; ревью — независимый ревьюер
- **Навыки**: @nuxtjs/i18n

## 1. Результат
Все тексты интерфейса — через i18n; словари `ru` и `en` полны; переключатель без перезагрузки; письма на языке аккаунта.

## 2. Источники
- Журнал: §20.10, §20.11
- Спецификации: `docs/spec/30-account/reader/profile-edit.md`, `docs/spec/00-registries/routes.md`
- ADR: ADR-0002

## 3. Границы и явно исключённое
- Входит: Словари и подключение.
- Не входит: Переводы контента (ручная вторая версия — F-09).

## 4. Зависимости и что разблокирует
- Зависит от: T-053, T-096
- Разблокирует: нет прямых зависимых задач

## 5. Критерии готовности и способ проверки
1. Тест: ключи словарей `ru` и `en` совпадают.
2. grep по шаблонам не находит русских строк вне i18n.

## 6. Доказательство результата
Тест, grep. Отчёт по ритуалу проекта (`docs/reports/`) с разделом «Как проверено».

## 7. Пометки
Все утверждения — по спецификациям; кодовых фактов, требующих отдельной проверки, не заявлено.
