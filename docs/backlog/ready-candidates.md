# Кандидаты в готовые задачи

- **Назначение**: перечень задач без зависимостей и без блокеров владельца, которые после проверки владельцем могут получить статус `готова` (`docs/multica/operating-model.md` §4). Отметку ставит владелец (Q-10).
- **Решение владельца 2026-09-09**: шесть задач переведены в `готова`. T-005 выведена из
  кандидатов: её критерий 2 проверяем только после T-004, поэтому объявлена зависимость
  `зависит: T-004` (`docs/multica/operating-model.md` §4.4).
- **Правило единственного writer**: одновременно в работе может быть только одна задача с параллельностью «нет: меняет продуктовый код»; остальные кандидаты этого типа ждут её завершения.
