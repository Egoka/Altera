# ADR-0032: Ошибки API и логирование

- **Статус**: принято 2026-09-05
- **Этап**: 0

## Контекст

- Публичные резолверы бросают `new Error("Author not found")`, которое Yoga маскирует в
  «Unexpected error» [ФАКТ: `server/src/graphql/user/resolver.ts:87`]; админские — `GraphQLError`
  с `extensions.code` [ФАКТ: `server/src/utils/admin.ts:155-166`]; коды не согласованы.
- Логирование — более 50 `console.log`, включая magic link в открытом виде
  [ФАКТ: `docs/vision/00-reality-check.md` §3.7]; «аудит» админских операций — тот же
  `console.log` [ФАКТ: `utils/admin.ts:224-230`].
- Health-эндпоинта, метрик и трассировки нет.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Оставить как есть | — | Клиент не отличает «не найдено» от сбоя; логи бесполезны и опасны |
| **Единый словарь кодов ошибок + структурированный логгер + health** | Клиент и тесты опираются на коды; логи читаемы машиной | Правка всех резолверов (делается вместе с этапом 0) |
| Внешний APM с первого дня | Готовые дашборды | Данные за рубежом или счёт; при нулевой нагрузке — не нужно |

## Решение

1. Все ошибки — `GraphQLError` с `extensions.code` из словаря: `UNAUTHENTICATED`, `FORBIDDEN`,
   `NOT_FOUND`, `VALIDATION_ERROR`, `CONFLICT` (устаревшая ревизия), `RATE_LIMITED`,
   `CONTENT_INVALID`, `DUPLICATE`, `INTERNAL_ERROR`. Сообщения — английские, без персональных
   данных; человеческие тексты — на фронте по коду.
2. Маскирование Yoga остаётся включённым; всё, что не из словаря, превращается в
   `INTERNAL_ERROR` с идентификатором запроса в ответе и полным стеком в логе.
3. Логгер — структурированный JSON (`pino` `[ДОПУЩЕНИЕ]`) с уровнями; в логах нет e-mail, IP в
   открытом виде и токенов; `console.log` в `server/src` запрещён линтером.
4. Аудит действий — не логи, а таблица `audit_log` с этапа 2 (`docs/vision/04-roles-and-access.md`);
   до этого — поля `*ById` на сущностях.
5. `GET /health` на API (проверка базы, при включённом Redis — и его) и на Nuxt; метрики
   процесса — по потребности; ошибки — self-hosted Sentry-совместимый сборщик или провайдер
   РФ `[ДОПУЩЕНИЕ: выбирается на этапе 1]`.
6. Идентификатор запроса прокидывается из Nuxt в API и в ответ клиенту.

## Следствия

- Тесты резолверов проверяют коды, а не тексты.
- Фронт показывает состояния по кодам (`06`: состояния ошибок).
- CI проверяет старт сервера по `/health` (ADR-0031).

## Цена отката

Ноль: словарь кодов и логгер — соглашения.
