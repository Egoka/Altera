# ADR-0021: Компоненты чтения — свои, компоненты приложения — FishtVue

- **Статус**: принято 2026-09-05
- **Этап**: 1

## Контекст

- FishtVue 0.2.11 — библиотека виджетов, автор — владелец проекта [ФАКТ: `web/node_modules/fishtvue/package.json`];
  23 компонента (формы, таблица, меню, диалог, календарь, split, текстовый редактор на Quill),
  три темы, режимы `filled/outlined/underlined`; типографических и «редакционных»
  компонентов нет.
- В `web/app` FishtVue используется только в админке [ФАКТ: `docs/vision/00-reality-check.md` §5.5];
  публичный сайт свёрстан на голом Tailwind с собственными карточками материалов и
  четырьмя гарнитурами [ФАКТ: `web/app/components/article/*.vue`, `main.css:4-284`].
- `nuxt.config.ts:44` задаёт FishtVue `darkModeSelector: "html.dark"`, тогда как `main.css`
  переопределяет палитру для `body.dark` [ФАКТ: `main.css:364`] — два механизма темы.

## Рассмотренные варианты

| Вариант | За | Против | Цена замены |
|---|---|---|---|
| FishtVue везде, включая публичные страницы | Одна библиотека, своя | В ней нет типографики, сеток материала, карточек; журналу нужна типографика, а не виджеты | — |
| Заменить FishtVue на стороннюю библиотеку (PrimeVue, Nuxt UI) | Больше компонентов | Отказ от собственной библиотеки владельца без продуктовой причины; переписывание админки | 5–8 чд на админку |
| **Разделить по назначению**: поверхности чтения — собственные компоненты дизайн-системы; поверхности приложения (админка, кабинет, обвязка редактора) — FishtVue поверх общих токенов | Каждая библиотека делает то, для чего сделана; владелец развивает свою | Два набора компонентов, общий слой токенов обязателен | FishtVue заменима в приложении за 5–8 чд, публичные компоненты не затрагиваются |

## Решение

1. **Чтение** (страница материала, главная, ленты, рубрика, автор, тег, подборка, поиск,
   письма) — собственные компоненты дизайн-системы (`06`), без FishtVue: типографика,
   карточки, сетки, рендер блоков.
2. **Приложение** (админка, кабинет автора, формы, диалоги, таблицы, меню, обвязка
   редактора вокруг области текста) — FishtVue. Область редактирования — TipTap, а не
   `TextEditor` FishtVue; `TextEditor` (Quill) допустим для коротких rich-полей админки
   (описание рубрики, о себе) `[ДОПУЩЕНИЕ: по решению на этапе 1]`.
3. Общий слой токенов: цвета, шрифты, отступы и тема задаются в `main.css` и передаются
   FishtVue через его тему; один механизм тёмной темы — `@nuxtjs/color-mode` с классом на
   `html`; собственный `useTheme` и переопределения `body.dark` удаляются.
4. Границу пересекать нельзя: виджет FishtVue не появляется на странице материала, а
   карточка материала — в админке (там таблица).

## Следствия

- Дизайн-система описывает публичные компоненты и роли гарнитур; FishtVue конфигурируется
  под те же токены (тема, `componentsStyle`).
- Рендерер блоков (ADR-0029) выпускает только компоненты чтения.
- Развитие FishtVue — дело владельца; проект не зависит от её новых версий на публичной
  стороне.

## Цена отката

Замена FishtVue в приложении — 5–8 чд (админка, кабинет). Перенос публичных компонентов в
библиотеку владельца — возможное будущее, не откат.
