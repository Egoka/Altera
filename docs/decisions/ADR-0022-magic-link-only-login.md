# ADR-0022: Magic link — единственный способ входа до конца этапа 3

- **Статус**: принято 2026-09-05
- **Этап**: 0

## Контекст

Вход по одноразовой ссылке уже реализован: токен, срок 15 минут, одноразовость, создание
пользователя при первом запросе [ФАКТ: `server/src/graphql/auth/resolver.ts:19-99`]; письма не
отправляются, ссылка печатается в консоль [ФАКТ: `:56`]; паролей в модели нет
[ФАКТ: `server/prisma/schema.prisma:12-27`]. Промт разрешает оспорить magic link как
единственный способ входа.

## Рассмотренные варианты

| Вариант | За | Против | Цена |
|---|---|---|---|
| **Только magic link** | Нет паролей и их утечек; уже есть; один сценарий для регистрации и входа | Зависимость от доставки писем; вход с телефона требует почтового клиента | 0 |
| Пароли | Привычно | Хранение, сброс, политика сложности, утечки; вторая ветка кода | 3–5 чд + постоянная поддержка |
| OAuth (Яндекс ID, VK ID) | Быстрый вход для части аудитории | Ещё провайдеры, привязка аккаунтов, зависимость от их политик; при нулевой аудитории не измерить пользу | 2–4 чд на провайдера |
| Passkeys | Современно | Пока плохо поддержано в РФ-контексте `[ДОПУЩЕНИЕ]`; сложность восстановления | 4+ чд |

## Решение

1. До конца этапа 3 единственный способ входа — magic link; регистрация и вход — один
   сценарий.
2. Условие для добавления OAuth: измеренная потеря на входе (доля запросивших ссылку, но не
   вошедших, выше 30 % за месяц `[ДОПУЩЕНИЕ: порог — гипотеза]`) или явный запрос первых
   авторов. Первый кандидат — Яндекс ID `[ДОПУЩЕНИЕ]`.
3. Пароли не вводятся никогда.
4. Обязательные спутники: доставка писем и лимиты (ADR-0024), сессии (ADR-0009), хранение
   на клиенте (ADR-0023), страницы `/login` и `/auth/verify` на этапе 1.
5. Восстановление доступа при потере почты — ручная процедура через владельца с проверкой
   личности (`docs/vision/04-roles-and-access.md`).

## Следствия

- Меньше поверхности атаки и кода на этапе 0.
- Качество доставки писем становится критичным: SPF/DKIM/DMARC и провайдер РФ — гейт этапа 0.

## Цена отката

Добавить OAuth — 2–4 чд на провайдера, модель `Account` аддитивна. Добавить пароли — не
планируется.
