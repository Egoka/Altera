# ADR-0029: Пакет `content` — схема документа, валидация, рендер

- **Статус**: принято 2026-09-05
- **Этап**: 1

## Контекст

JSON-документ ProseMirror (ADR-0001) должен одинаково пониматься редактором в браузере,
сервером при сохранении и рендером при SSR. Сейчас workspace состоит из `web` и `server`
[ФАКТ: `pnpm-workspace.yaml`]; общего кода между ними нет.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Схема только в вебе, сервер хранит любой JSON | Меньше кода | Сервер не может отклонить неизвестные узлы; SSR-рендер дублирует схему |
| Схема в сервере, веб получает её по API | Один источник | Схема — это код (узлы, атрибуты, рендер), а не данные |
| **Третий пакет workspace `packages/content`**: схема, валидация, экстракторы, рендерер, экспорт | Один источник, используется тремя сторонами; тестируется отдельно | Третий пакет в монорепозитории и его сборка |

## Решение

1. `packages/content` (пакет `@altera/content`): определения узлов и марок TipTap/ProseMirror
   по каталогу ADR-0017; функция `validateDocument(json)` (схема + ограничения глубины и
   размеров); экстракторы `toPlainText`, `readingTime`, `firstParagraph`; сериализаторы
   `toMarkdown`, `toHTML` (через `@tiptap/static-renderer`); стабильные `attrs.id` блоков.
2. Сервер вызывает `validateDocument` при каждом сохранении и отклоняет недопустимый документ
   с кодом `CONTENT_INVALID`; экстракторы дают `bodyText`, время чтения и excerpt по умолчанию.
3. Веб использует те же расширения в редакторе и **рендерер JSON → Vue-компоненты
   дизайн-системы** для SSR страницы материала; HTML-сериализация — для RSS и писем.
4. Версия схемы хранится в документе (`attrs.schemaVersion` на корне `[ДОПУЩЕНИЕ]`); миграции
   документов при изменении схемы — функции в том же пакете, применяются лениво при чтении
   и навсегда при сохранении.
5. Пакет покрыт тестами: фикстуры документов для каждого блока, снимки HTML-рендера,
   round-trip экспорта.

## Следствия

- `pnpm-workspace.yaml` получает `packages/*`; CI собирает и тестирует пакет.
- Любой новый блок — изменение в одном пакете плюс компонент дизайн-системы.
- Экспорт материалов автору (Markdown/HTML) — бесплатная функция на базе сериализаторов.

## Цена отката

Слить пакет обратно в `web` или `server` — перенос файлов; логика не меняется.
