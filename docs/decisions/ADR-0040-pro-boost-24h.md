# ADR-0040: Pro-буст на сутки

- **Статус**: принято 2026-09-06
- **Этап**: 2

## Контекст

Владелец: pro-подписка поднимает статьи автора в рейтинге на сутки; каждая новая публикация,
во всех лентах, без пометки для читателя (ответы захода 0). Рейтинг материализован
(ADR-0034); подписка определяет план (ADR-0035).

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Буст как множитель к итоговому баллу | Сильный эффект | Непропорционально усиливает уже высокие баллы |
| **Буст как аддитивный вход с константой из `RankingConfig`, действующий 24 часа с момента публикации** | Предсказуем; одинаков для всех pro-авторов; легко объяснить в админке | Слабее для статей с низким базовым баллом — это ожидаемо |
| Автор сам выбирает, какую публикацию бустить | Контроль | Владелец выбрал «каждую новую публикацию» |

## Решение

1. При публикации версии автором с активным `pro` создаётся `ArticleBoost(articleId,
   translationId, subscriptionId, startsAt = publishedAt, endsAt = publishedAt + 24h)`.
2. Буст — аддитивный вход рейтинга статьи с величиной `boostWeight` из `RankingConfig`;
   действует во всех лентах (главная, рубрика, тег, автор); истекает сам; пересчёт рейтинга
   срабатывает на `startsAt` и `endsAt`.
3. **Повторная публикация ревизии буст не возобновляет**: буст выдаётся один раз на
   языковую версию — на её первую публикацию. Вторая языковая версия (AI-перевод, ADR-0046)
   получает свой буст `[ДОПУЩЕНИЕ]`.
4. Лимит: не более N публикаций с бустом на автора в сутки (`boostDailyLimit`, по умолчанию 3
   `[ДОПУЩЕНИЕ]`) — защита от массовых публикаций ради позиции; сверх лимита публикация
   проходит без буста, автор видит предупреждение до публикации.
5. Читателю факт буста не показывается; бейдж pro-автора показывается (ADR-0037). В кабинете
   автор видит активные бусты и их срок.
6. Буст истекает досрочно при снятии материала с публикации, блокировке автора, истечении
   подписки (ADR-0044).

## Следствия

- Инвариант «`ArticleBoost` только при активном `pro` в момент публикации» — тест.
- Событие `boost.start` / `boost.end` в реестре; `analyst` видит долю бустнутых публикаций.
- Спецификация формулы: `docs/spec/60-ranking/pro-boost.md`.

## Цена отката

Низкая: таблица аддитивна, вход отключается весом 0.
