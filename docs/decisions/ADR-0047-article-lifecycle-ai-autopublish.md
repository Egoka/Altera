# ADR-0047: Жизненный цикл статьи — автопубликация после AI, ручная ветка ревьюера

- **Статус**: принято 2026-09-14
- **Этап**: 1
- **Заменяет**: ADR-0045 (в части «финального человеческого шага перед первой публикацией»)

## Контекст

ADR-0045 описывал двухступенчатую проверку — AI, затем обязательное человеческое решение для
каждой публикуемой ревизии. По результатам гейта Г1 (журнал #8, #14, §6, 2026-09-08) это
правило пересмотрено: финальное человеческое решение перед первой публикацией отменено.
Нужен актуальный ADR, фиксирующий полный жизненный цикл статьи с учётом журнала.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Обязательная ручная проверка перед каждой публикацией | Полный контроль | Задержка каждой публикации; не масштабируется |
| **AI как первый фильтр; автоматическая публикация при одобрении; ручная ветка при отказе** | Быстрая публикация; ревьюер подключается только при проблемах | AI может ошибаться — предусмотрен ручной override |
| Пост-публичная проверка без предварительной | Максимальная скорость | Нежелательный контент попадает в публичный доступ до проверки |

## Решение

Жизненный цикл статьи (журнал §6, #8, #9, #14, 2026-09-08):

1. Автор с активным планом создаёт и редактирует черновик.
2. Каждая первая попытка опубликовать статью обязательно проходит AI-проверку (журнал #8).
   AI проверяет соответствие теме, правилам журнала, возрастным ограничениям и недопустимому
   контенту (журнал #9).
3. При одобрении AI статья публикуется автоматически, без дополнительного человеческого решения.
4. После автоматической публикации у автора есть одноразовое окно в 1 час только для того,
   чтобы нажать «перередактировать» и снять статью на доработку (журнал #9). Этот переход
   доступен ровно один раз.
5. После доработки повторная самостоятельная подача снова проходит AI-проверку: одобрение
   публикует статью автоматически, отказ отправляет её ревьюеру (журнал #9).
6. При отказе AI статья возвращается автору с причинами, а материал переходит в ручную ветку
   ревьюера (журнал #14). Новый автоматический запуск AI в этой ветке не происходит.
7. Ревьюер в любое время и неограниченное число раз может снять опубликованную статью на
   доработку с указанием причин (журнал #12). После такого возврата все дальнейшие решения
   принимает ревьюер вручную, без нового запуска AI.
8. В ручной ветке ревьюер может запрашивать доработки неограниченное число раз, вручную
   опубликовать материал (в том числе отменив отказ AI), либо вынести окончательный отказ —
   статья получает признак редакционного отказа и становится недоступной для дальнейшего
   редактирования, но доступной автору для чтения и копирования (журнал #12, #14).
9. Все версии текста сохраняются снимками; решения ревьюера, комментарии, причины, автор
   решения и время хранятся в истории (журнал #15, #16).

Границы: этот ADR описывает только жизненный цикл публикации. Права ролей на публикацию
фиксируют ADR-0003 и ADR-0045. Сама AI-проверка описана в ADR-0039 (бинарный результат)
и ADR-0050 (AI не входит в рейтинг).

## Следствия

- Статья может быть опубликована без единого ручного шага, если AI её одобряет.
- Ревьюер не обязан одобрять первую публикацию, но может в любой момент вмешаться в ручной
  ветке.
- Вся история переходов и решений хранится и доступна ревьюеру при работе.
- Нотификации автора о решениях направляются по email (журнал #43).

## Цена отката

Средняя: потребуется явное решение о возврате к обязательной ручной проверке и миграция
статусов публикаций, накопленных в автоматической ветке.
