# ADR-0041: Закладки

- **Статус**: принято 2026-09-06
- **Этап**: 1 (кабинет), 3 (страница закладок со списком, если разнесено по этапам)
- **Заменяет**: ADR-0026 в части «закладки не планируются»

## Контекст

Владелец включил «сохранённые статьи» в кабинет читателя (ADR-0043). Ревизия 1 отказывалась
от закладок «до запроса» (ADR-0026, таблица вариантов). В коде сущности нет [ФАКТ:
`server/prisma/schema.prisma` — таблиц кроме `users`, `magic_link_tokens`, `content_types`,
`section_tags`, `articles` нет].

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Закладки в localStorage | Без сервера | Теряются между устройствами; владелец просил кабинет |
| **`Bookmark(userId, articleId, createdAt)`, приватные, на материал (не на языковую версию)** | Просто; переживает переводы и ревизии | Ничего существенного |
| Закладки как публичные «коллекции» читателя | Социальность | Не просили; модерация чужих списков |

## Решение

1. `Bookmark(userId, articleId, createdAt)` с уникальностью пары; доступна любому аккаунту
   (`free` и выше); гость — приглашение войти.
2. Приватные: никто, кроме владельца закладки, их не видит; `analyst` — только агрегат «число
   закладок» без привязки к пользователям.
3. **Не входят в рейтинг** (ADR-0034): закладка — дешёвый сигнал для накрутки; решение
   пересматривается отдельным ADR, если появится антинакрутка на закладках.
4. Страница «Сохранённые» в кабинете: список по дате добавления, снятие закладки, пометка
   «снято с публикации» для недоступных материалов; закладки удаляются вместе с аккаунтом
   (ADR-0014 п. 5).
5. Кнопка на странице материала и на карточке `[ДОПУЩЕНИЕ: на карточке — да]`.

## Следствия

- Матрица прав: строка «закладка: добавить / убрать / список» — `свои` для всех аккаунтов.
- Событие `bookmark.add` / `bookmark.remove` — метрика, не аудит.

## Цена отката

Нулевая: одна таблица.
