# ADR-0046: Вторая языковая версия — AI-перевод для pro

- **Статус**: принято 2026-09-06
- **Этап**: 3 (вторая языковая версия), возможно раньше как возможность pro
- **Расширяет**: ADR-0002 (не заменяет)

## Контекст

Двуязычность — полные переводы материалов с общими метаданными и hreflang (ADR-0002,
ADR-0043). Ответ владельца (заход 0): вторую языковую версию делает платформа (AI) для
pro-авторов; standard публикует на одном языке. Ревизия 1 предполагала перевод автором или
редактором-переводчиком (`04-roles-and-access.md` §2.2).

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Автор переводит сам (любой план) | Без провайдера | Двуязычного контента почти не будет |
| Редакция переводит | Качество | Не масштабируется на одного человека |
| **AI-перевод по запросу pro-автора с правкой автором и обычной проверкой** | Двуязычность как продающая возможность pro; нагрузка на редакцию — только проверка | Стоимость на статью; качество перевода требует правки |

## Решение

1. Pro-автор нажимает «Создать перевод» на опубликованной версии: платформа создаёт
   языковую версию в `draft` с переводом текста, заголовка, дека, подписей к изображениям;
   слаг — транслитерация переведённого заголовка; метаданные общие (ADR-0002).
2. Автор правит перевод в редакторе и отправляет к публикации; версия проходит обе ступени
   проверки (ADR-0045) как любая другая.
3. Сущность `TranslationJob(translationId, sourceTranslationId, provider, model, status,
   costMinor, createdAt, completedAt)`; лимит переводов в сутки на автора — параметр
   `[ДОПУЩЕНИЕ: 3]`; повторный перевод той же версии после существенной ревизии — по запросу
   автора, с тем же лимитом.
4. Провайдеру отправляется текст ревизии без персональных данных (как в ADR-0039); провайдер
   и договор — гейт этапа `[ДОПУЩЕНИЕ: тот же провайдер, что для AI-проверки]`.
5. `standard` видит кнопку с объяснением «доступно в pro»; ручное создание второй версии
   `standard` не доступно `[ДОПУЩЕНИЕ: по ответу владельца]`; редакция (`editor` и выше) может
   создавать и переводить версии любых материалов вручную.
6. Переведённая версия получает свой буст при первой публикации (ADR-0040 п. 3).

## Следствия

- `05-editor.md` §9 «Перевод» переписывается; роль «переводчик» из матрицы уходит.
- Раздел «AI-оценки» админки расширяется статистикой переводов или отдельный раздел
  «AI-операции» `[ДОПУЩЕНИЕ]`.
- Стоимость AI на автора (проверка + оценка + перевод) — вход юнит-экономики
  (`docs/spec/90-business-model/unit-economics.md`).

## Цена отката

Низкая: сущность аддитивна; отказ возвращает ручной перевод.
