# ADR-0020: GraphQL Yoga остаётся транспортом

- **Статус**: принято 2026-09-05
- **Этап**: 0

## Контекст

Промт разрешает оспорить GraphQL Yoga при развёрнутом обосновании и цене перехода. Что есть:
Yoga поверх `node:http`, эндпоинт `/`, CORS на `FRONTEND_URL`, CSRF-плагин, схема из SDL и
резолверов [ФАКТ: `server/src/server.ts:11-21`, `server/src/graphql/schema.ts`]; пять доменов
резолверов общим объёмом около 2 300 строк [ФАКТ: `docs/vision/00-reality-check.md` §3]; на
фронте клиента нет — контракт живёт только на сервере.

## Рассмотренные варианты

| Вариант | За | Против | Цена перехода |
|---|---|---|---|
| **Оставить GraphQL Yoga** и добавить codegen (ADR-0012) | Резолверы, права и кеш уже написаны; SDL — готовый контракт; выборка полей под страницы | Нужна генерация типов; N+1 требует внимания (dataloader при необходимости) | 0 |
| tRPC | Сквозные типы без генерации; проще для одного разработчика с нуля | Переписать все резолверы и права; Nuxt-интеграция сторонняя; публичный API для партнёров (этап 6) хуже документируется | 8–12 чд переписывания, без продуктовой пользы |
| REST (Nitro-роуты в Nuxt) | Один процесс, кеш HTTP | Переписать всё; контракт описывать отдельно (OpenAPI); выборка полей под страницы теряется | 8–12 чд |
| Nuxt server-роуты как единственный бэкенд (убрать отдельный API) | Один деплой | Смешение SSR и API в одном процессе; переписывание; сервер уже отделён | 10+ чд |

## Решение

1. GraphQL Yoga остаётся транспортом API; схема — из SDL (schema-first), как сейчас.
2. Контракт становится единым через генерацию типов (ADR-0012); клиент минимальный, через
   BFF-прокси Nuxt (ADR-0023).
3. На этапе 0 в API добавляются: health-эндпоинт, структурированные ошибки и логгер
   (ADR-0032), лимиты (ADR-0024), защита от глубоких и дорогих запросов (ограничение глубины и
   сложности — `[ДОПУЩЕНИЕ: плагины graphql-armor]`), отключение GraphiQL в проде.
4. Решение пересматривается только при появлении внешних потребителей API (этап 6) или
   измеримой проблемы производительности.

## Следствия

- Экономия 8–12 чд на этапе 0 по сравнению с любой заменой.
- Существующие резолверы дорабатываются, а не переписываются: аргумент `locale`, видимость
  по правам, инвалидация по тегам.

## Цена отката

Смена транспорта позже стоит те же 8–12 чд плюс миграция клиентов; решение сознательно
отложено до появления причины.
