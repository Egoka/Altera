# ADR-0014: Права редактора на чужой текст; блокировка и удаление автора

- **Статус**: принято 2026-09-05
- **Этап**: 1 (правила), 2 (редакционные правки), 3 (самостоятельное удаление)

## Контекст

- Сейчас чужой материал не может править никто, включая администратора
  [ФАКТ: `server/src/graphql/article/resolver.ts:538-540`]; блокировки и удаления пользователя
  в модели нет [ФАКТ: `server/prisma/schema.prisma:12-27`].
- Права на материалы остаются у авторов (рамка «MIT относится к коду»); редакция работает с
  заказными материалами и отбором; открытый контур — территория автора.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Редактор правит любой текст | Просто | Нарушает право голоса в открытом контуре; конфликт с авторами |
| Редактор не правит ничего, только замечания | Чистота авторства | Редакционный контур не может работать: заказные материалы требуют правки |
| **Граница по контуру и статусу**: редактор правит `editorial` и версии в `review`, всегда с ревизией; в открытом опубликованном — только снятие с публикации с причиной | Совмещает право голоса и редакционную работу | Нужна проверка в одном месте и ревизии |

Для удаления аккаунта:

| Вариант | За | Против |
|---|---|---|
| Материалы остаются как есть | Ссылки живут | Противоречит правам автора на свой текст |
| Материалы удаляются физически | Чисто | Ломает ссылки, ревизии редакции, заказные материалы по договору |
| **Анонимизация аккаунта; материалы открытого контура — в архив по умолчанию с возможностью оставить; заказные — по договору** | Уважает права автора и договор; ссылки отвечают «снято», не 404 | Требует выбора при удалении |

## Решение

1. Редактор (`editor`, `admin`, `owner`) может изменять текст чужой языковой версии, только
   если `Article.contour = editorial` **или** `status = review`. Каждое такое сохранение
   создаёт ревизию `editorial` с указанием, кто правил (ADR-0007); автор видит историю.
2. Опубликованный материал открытого контура редактор не правит. Он может: снять с публикации
   с причиной (`archived` + `unpublishedById`, `unpublishReason`), вернуть на доработку,
   сбросить доверие автора (ADR-0013), передать жалобу. Причину видит автор.
3. Проверка — в одном хелпере на сервере (`assertCanEditTranslation`), интерфейс лишь скрывает
   кнопки.
4. **Блокировка** (`blockedAt`, `blockedById`, `blockReason`): вход запрещён, сессии отозваны,
   материалы остаются опубликованными; если блокировка за нарушения в материалах — они
   снимаются отдельным действием с причиной.
5. **Удаление аккаунта**: персональные данные анонимизируются («надгробие»: `deletedAt`,
   e-mail заменяется на технический, имя на «удалённый автор», хэндл на случайный, профиль
   очищается), сессии и ссылки для входа удаляются; запись остаётся, чтобы не рвать ссылки
   из материалов, медиа и платежей.
6. Материалы при удалении: открытого контура — по умолчанию все версии в `archived`; автор
   может выбрать «оставить опубликованными с подписью „автор удалил аккаунт“»; заказные
   (`Commission`) — по условиям договора, по умолчанию остаются. Медиа автора: владелец не
   меняется, неиспользуемые файлы помечаются к удалению.
7. Самостоятельное удаление из кабинета — этап 3; до этого — ручная процедура по запросу
   через владельца, зафиксированная в политике персональных данных.
8. Переход владения (`owner`) — только двусторонним подтверждением; восстановление доступа
   при потере почты — ручная процедура через владельца с проверкой личности; описано в
   `docs/vision/04-roles-and-access.md`.

## Следствия

- Матрица прав и список аудируемых действий (снятие с публикации, блокировка, сброс
  доверия, смена роли, передача владения) — в `04-roles-and-access.md`; запись аудита — с
  этапа 2, до этого след дают поля `*ById` и ревизии.
- Оферта и правила публикации описывают эти права явно (ADR-0028).
- Страница снятого материала отвечает «материал снят» (410), а не 404.

## Цена отката

Правила — код; расширить права редактора можно в любой момент, сузить после того, как
редакция привыкла, — продуктово болезненно. Анонимизация необратима по определению.
