# ADR-0024: Почта как зависимость и лимиты на вход

- **Статус**: принято 2026-09-05
- **Этап**: 0

## Контекст

- Magic link печатается в консоль [ФАКТ: `server/src/graphql/auth/resolver.ts:56`]; зависимости
  для отправки писем нет [ФАКТ: `server/package.json:23-36`].
- Ограничений частоты нет ни на запрос ссылки, ни на проверку токена, ни на API
  [ФАКТ: `docs/vision/00-reality-check.md` §3.5]: перебор адресов, спам письмами и перебор
  токенов возможны без препятствий.
- Персональные данные подписчиков и адреса — РФ-контур (ADR-0011).

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| SMTP напрямую с сервера | Без провайдера | Доставляемость и репутация домена — ручная работа |
| Зарубежный API-провайдер (Resend, Postmark) | Удобно | Адреса подписчиков уходят за рубеж; противоречит ADR-0011 |
| **Транспортная абстракция + провайдер с РФ-контуром** (кандидаты: Unisender, SendPulse, SMTP Яндекс 360 `[ДОПУЩЕНИЕ: выбор — гейт этапа 0]`) | Провайдер сменяем; локальная разработка через Mailpit или консоль | Ещё одна зависимость |

## Решение

1. Модуль `mail` с интерфейсом `send(template, to, params)` и реализациями: `smtp`
   (провайдер РФ), `console` (dev), `fake` (тесты). Шаблоны писем — те же компоненты
   дизайн-системы (рендер в HTML + текстовая версия).
2. Письма этапа 0–1: ссылка для входа, решение по проверке материала, смена хэндла/почты
   (позже), уведомления подписчикам автора (этап 3), выпуски рассылки (этап 5).
3. Домен: SPF, DKIM, DMARC настроены до открытой регистрации; адрес отправителя — `no-reply@`
   и `editor@` `[ДОПУЩЕНИЕ]`.
4. Лимиты (все значения — гипотеза, уточняются по логам): запрос ссылки — 3 на e-mail за
   15 минут и 10 с одного IP за час; проверка токена — 10 попыток с IP за 15 минут; общий
   лимит API — 300 запросов в минуту с IP; превышение — ошибка `RATE_LIMITED` без раскрытия,
   существует ли адрес.
5. Ответ на запрос ссылки одинаков для существующего и нового адреса (нет перечисления
   аккаунтов).
6. Хранение счётчиков — Redis, если есть, иначе память процесса (ADR-0019).

## Следствия

- Провайдер и домен — гейт владельца на этапе 0.
- Тесты: фейковый транспорт, проверка лимитов, `grep console.log` в auth = 0.
- Письма — персональные данные получателей; логи провайдера — вне репозитория, сроки хранения
  в политике ПД.

## Цена отката

Смена провайдера — новая реализация транспорта (часы). Отказ от лимитов — недопустим.
