# ADR-0051: Постоянный Pro-балл фиксируется снимком плана при публикации

- **Статус**: принято 2026-09-14
- **Этап**: 2
- **Заменяет**: ADR-0040 (Pro-буст на сутки отменён)

## Контекст

ADR-0040 описывал временный Pro-буст на 24 часа при публикации с активным `pro`. По результатам
гейта Г4 (журнал §21.15–16, 2026-09-09) буст на сутки отменён. Вместо него введён постоянный
Pro-балл, фиксируемый снимком плана в момент публикации. Нужен отдельный ADR для нового правила.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Временный буст на 24 часа | Быстрое первоначальное продвижение | Сложно поддерживать; несправедлив для ночных публикаций; поощряет тактику «публикации в лучшее время» |
| **Постоянный Pro-балл, зафиксированный при первой публикации с активным `pro`** | Предсказуем; честно: создал при `pro` — получил бонус навсегда | Не даёт кратковременного ускорения, но это скорее плюс |
| Pro-балл, пересчитываемый при каждом продлении плана | Актуальность | Непредсказуем для автора; сложная логика пересчёта |

## Решение

1. Если статья впервые опубликована при активном плане `pro`, она получает дополнительный
   фиксированный балл рейтинга. Право на него определяется снимком плана в момент
   публикации (журнал §21.15).
2. Pro-балл остаётся с опубликованной статьёй навсегда: он не прекращается через 24 часа и
   не уменьшается, если план автора позднее истёк или не был продлён (журнал §21.16).
3. После публикации общий рейтинг статьи меняется только от её собственных сигналов
   вовлечённости и иных утверждённых компонентов (журнал §21.16).
4. Ручная выдача `pro` сотрудником полностью равна оплаченной подписке по правам и
   последствиям для материалов: статья, опубликованная в срок такой выдачи, получает те же
   Pro-компоненты рейтинга. Основание выдачи аудируется (журнал §8.16).
5. Редакционные статьи журнала всегда используют стандартный базовый режим рейтинга. Ни
   редактор, ни иная служебная роль не могут получить Pro для добавления Pro-компонентов к
   публикациям журнала (журнал §8.17).

Граница: конкретная числовая величина Pro-балла и его спецификация определяются в Г4
(`docs/spec/60-ranking/pro-score.md`).

## Следствия

- При первой публикации система проверяет снимок активного плана автора и фиксирует
  Pro-компонент рейтинга.
- Повторная публикация после доработки не пересчитывает Pro-компонент: он фиксируется
  однажды и хранится отдельным полем.
- Интерфейс: карточка тарифа `pro` сообщает об усилении видимости; до Г4 не содержит
  чисел и описания конкретной формулы (журнал §20.13).

## Цена отката

Низкая: Pro-компонент хранится отдельным полем, которое можно обнулить без перестройки схемы.
