# ADR-0012: Контракт API — схема сервера как единственный источник

- **Статус**: принято 2026-09-05
- **Этап**: 0

## Контекст

- Операции фронта — 35 строк-шаблонов в `web/app/query/**`, никуда не отправляемых; против
  серверной схемы валидны 10 [ФАКТ: `docs/reports/2026-09-05-platform-reality-check-and-proposal-report.md`,
  раздел «Валидация»]. GraphQL-клиента и адреса API в вебе нет [ФАКТ: `web/package.json`,
  `web/nuxt.config.ts`].
- Типы ответов на фронте написаны вручную и расходятся между собой
  [ФАКТ: `web/app/types/user.ts:1` против `web/app/query/types.ts:56`].
- Схема сервера собирается из `*.graphql` автоматически [ФАКТ: `server/src/graphql/schema.ts:7-12`]
  и является единственным полным описанием контракта.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Продолжать писать строки и типы руками | Ничего не ставить | Уже привело к 25 невалидным операциям из 35 |
| Schema-first с генерацией типов операций (`graphql-codegen`) и минимальным клиентом | Компилятор ловит расхождения; один источник | Шаг генерации в сборке |
| Code-first (Pothos/Nexus) с генерацией SDL | Типы сервера из кода | Переписывание всех резолверов; SDL-файлы уже есть и понятны |
| tRPC вместо GraphQL | Сквозные типы без генерации | Смена транспорта (ADR-0020) |

## Решение

1. Единственный источник контракта — `server/src/graphql/**/*.graphql`. Изменение контракта
   начинается с правки SDL.
2. Типы и документы операций фронта генерируются `graphql-codegen` (`TypedDocumentNode`) из
   SDL сервера и файлов операций `web/app/graphql/**/*.graphql`. Ручные строки запросов и
   ручные типы ответов запрещены; текущие `web/app/query/**` и `web/app/types/*` удаляются
   после переноса.
3. Клиент — минимальный: `graphql-request` (или `$fetch`) через BFF-прокси Nuxt (ADR-0023) с
   `useAsyncData` для SSR; без Apollo-кеша на старте.
4. В CI — шаг `codegen --check`: сгенерированное совпадает с закоммиченным; плюс валидация всех
   операций против схемы (тест на базе скрипта из отчёта первого плана).
5. Enum ролей, статусов, локалей и контуров существуют только в SDL и Prisma; фронт получает
   их из генерации (ADR-0003).
6. Контракт версионируется вместе с кодом; ломающие изменения — только с одновременной
   правкой операций.

## Следствия

- Этап 0 переписывает операции под существующую схему и добавляет недостающие поля только те,
  без которых страницы не рендерятся (`sections`, `myArticles`, сессии).
- Появляется справочник API, генерируемый из SDL (`docs/vision/08-operations.md`, карта
  документации).
- Любое расхождение фронта и сервера ловится компилятором, а не на проде.

## Цена отката

Низкая: генерация — инструмент; удалить её значит вернуться к ручным строкам.
