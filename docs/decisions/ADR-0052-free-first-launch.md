# ADR-0052: Бесплатный первый запуск; базовое авторство без оплаты

- **Статус**: принято 2026-09-14
- **Этап**: 1
- **Заменяет**: ADR-0043 (в части п. о платежах с первого этапа) и ADR-0035 (в части п. о первом запуске)

## Контекст

ADR-0035 фиксировал, что платежи начинаются с этапа 1. ADR-0043 (продуктовые рамки ревизии 2)
устанавливал подписку и платежи как часть первого этапа. По результатам гейтов Г5 и Г5b
(журнал §24.1, §8.13, 2026-09-09) это решение пересмотрено. По результатам гейта Г6
(журнал §25.1) уточнён механизм базового авторства.

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Платный запуск с первого дня | Монетизация с первых пользователей | Барьер входа мешает проверке ценности продукта |
| **Бесплатный первый запуск; базовое авторство без оплаты; платность — отдельный этап** | Проверка ценности продукта без барьера оплаты | Откладывает монетизацию |
| Freemium с ограниченным функционалом с первого дня | Баланс | Требует отдельного проектирования тарифной матрицы до запуска |

## Решение

1. Первый запуск продукта — бесплатный. Базовое авторство и публикация доступны
   зарегистрированным пользователям без оплаты (журнал §24.1).
2. При регистрации пользователь остаётся читателем. При первом нажатии «Создать статью»
   ему автоматически и бессрочно открываются базовые авторские возможности, без оплаты и
   ручного одобрения (журнал §25.1).
3. Платные подписки (`standard`, `pro`), цены и реальная обработка платежей переносятся
   в отдельный этап после проверки ценности продукта (журнал §24.1).
4. Все документы должны оставаться корректными для сценария бесплатного первого запуска:
   ссылки на платежи в этапе 1 устарели (журнал §24.1).

Границы: этот ADR фиксирует только стратегию первого запуска. Архитектура подписок и
платёжной интеграции не меняется (ADR-0010, ADR-0035); они реализуются на отдельном этапе.
Базовое авторское право не является отдельным планом — это автоматическая разблокировка,
а не новый тарифный уровень.

## Следствия

- На этапе 1 не реализуются checkout, платёжный провайдер и управление подписками.
- Механизм «первого нажатия» на «Создать статью» автоматически открывает базовые авторские
  права без административного одобрения.
- Карточки тарифов и экраны подписки готовятся, но не показываются до старта платного этапа.

## Цена отката

Низкая: открытие платного этапа — отдельное решение и ADR; базовая бесплатная выдача
не конфликтует с последующей платностью.

## Связи

- ADR-0035 (подписка определяет роль; план «инвариант» сохраняется), ADR-0043 (рамки ревизии 2).
- Журнал §24.1, §25.1, §8.13.
